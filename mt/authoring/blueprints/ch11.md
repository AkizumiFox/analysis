## Named moves (in `index.md`, "Named moves")

- **Normalize, then apply Young.** Reduce an inequality homogeneous in f and g to the case ‖f‖ = ‖g‖ = 1, then integrate a pointwise inequality. First use: `thm-holder`.
- **Split the power.** Write |f + g|ᵖ ≤ |f||f + g|^{p−1} + |g||f + g|^{p−1} and apply Hölder with exponents (p, p′) to each term. First use: `thm-minkowski`.
- **Telescope a fast subsequence** (named in FA.1a; recalled, not re-introduced). From a Cauchy sequence pick n_k with ‖f_{n_{k+1}} − f_{n_k}‖ < 2^{−k}; the telescoping series is absolutely summable. Used here in `thm-lp-subsequence-ae`.
- **Scaling test.** Replace f by f(λ·) and compare powers of λ on both sides; an inequality that survives for all λ > 0 must balance its exponents. First use: `exm-scaling-forces-conjugate`.
- **Dense class plus a uniform bound** (spiral from AN2: Arzelà–Ascoli and Stone–Weierstrass arguments; in MT.2 for L¹). Prove the statement on C_c, then extend with a bound uniform over the operators. First use here: `thm-translation-continuous-lp`. This is the chapter's faded move (STYLE §11.4): worked in §3, last step blank in §5, last half blank in a §5 C exercise.
- **Norm of an average ≤ average of norms.** Minkowski's integral inequality, used to move a norm inside an integral. First use: `thm-minkowski-integral`.

## 01-lp-norms.md — Lᵖ norms and the inequalities of Young, Hölder and Minkowski

Budget ≤ 4,000 main-line words. Setting: a measure space (X, 𝒜, μ); real or complex scalars (𝔽).

- **Hook.** In MT.2, ‖f‖₁ = ∫|f| measured distance; L² distance appeared in HA.9. For 1 ≤ p < ∞, try ‖f‖_p = (∫|f|ᵖ dμ)^{1/p}. Two things can go wrong, and each produces a definition.
- **First failure: a nonzero function of norm zero.** `exm-ae-zero-seminorm`: 1_ℚ on ℝ has ‖1_ℚ‖_p = 0. `def-lp-seminorm` (ℒᵖ(μ): measurable f with ∫|f|ᵖ < ∞; ‖·‖_p is a seminorm once Minkowski is proved). Then **`def-lp`**: Lᵖ(μ) = ℒᵖ(μ)/𝒩, 𝒩 = {f : f = 0 a.e.}; elements are classes, and the book writes f for [f] from here on. State in one sentence that MT.2 did exactly this for p = 1 (spiral).
- **Second failure: the sup ignores nothing.** For p = ∞ the obvious sup |f| changes when f is changed on a null set (1_ℚ again). **`def-essential-supremum`**: ‖f‖_∞ = inf{M ≥ 0 : |f| ≤ M a.e.}, with inf ∅ = ∞. `thm-linfty-norm`: the infimum is attained (|f| ≤ ‖f‖_∞ a.e.); ‖·‖_∞ is a norm on L^∞(μ) = {classes with ‖f‖_∞ < ∞}. *Proof:* {|f| > ‖f‖_∞} = ⋃ₙ {|f| > ‖f‖_∞ + 1/n}, a countable union of null sets.
- **Third question: why that exponent?** FA.1a paired ℓᵖ with ℓ^{p′}, 1/p + 1/p′ = 1 (recall `@def-dual-exponent`; this volume says "conjugate exponent" from here on, same symbol). On a measure space with dilations the pairing is forced, not chosen: **`exm-scaling-forces-conjugate`** (the *scaling test*): on ℝ with Lebesgue measure, if ∫|fg| ≤ C‖f‖_p‖g‖_q for all f, g, apply it to f(λ·), g(λ·): the left side scales as λ^{−1}, the right as λ^{−1/p−1/q}; letting λ → 0 and λ → ∞ forces 1/p + 1/q = 1 (use any f = g = 1_{[0,1]}). Uses only dilation invariance (cite MT.1).
- **Young's product inequality** is recalled from FA.1a (`@lem-young`): ab ≤ aᵖ/p + b^{p′}/p′ for a, b ≥ 0, 1 < p < ∞, equality iff aᵖ = b^{p′}. One sentence recalls why (convexity of exp, or the area picture).
- **`thm-holder`** (key proof 1). Let 1 ≤ p ≤ ∞ and f, g measurable. Then ‖fg‖₁ ≤ ‖f‖_p‖g‖_{p′} (with 0·∞ = 0). For 1 < p < ∞ and 0 < ‖f‖_p, ‖g‖_{p′} < ∞, equality holds iff |f|ᵖ and |g|^{p′} are proportional a.e. (α|f|ᵖ = β|g|^{p′} a.e. for some α, β ≥ 0 not both 0).
  - **Scratch Work** (first appearance in MT of *normalize, then apply Young* for integrals; FA.1a did it for sums): both sides are homogeneous of degree 1 in f and in g; so it suffices to treat ‖f‖_p = ‖g‖_{p′} = 1; then integrate Young pointwise: ∫|f||g| ≤ 1/p + 1/p′ = 1. Then handle the degenerate cases (a norm 0 forces fg = 0 a.e.; a norm ∞ makes the claim trivial).
  - Proof: cases p = 1, ∞ directly (|fg| ≤ |f|·‖g‖_∞ a.e., using `thm-linfty-norm`); then 1 < p < ∞ as in the scratch. Equality from the equality case of `@lem-young` applied a.e. The proof is FA.1a's `@thm-holder-lp` with Σ replaced by ∫; say so (spiral) and say what is new: the a.e. bookkeeping and the p = ∞ case via the essential supremum.
  - Idea ends with: "*Before reading on: where is the normalization used, and why is it legal?*"
- **`cor-cauchy-schwarz-l2`.** |∫f ḡ| ≤ ‖f‖₂‖g‖₂. One line from `thm-holder`; this is LA3.11's Cauchy–Schwarz for the inner product ⟨f, g⟩ = ∫f ḡ (`see`, no dependency).
- **`rem-l2-inner-product`** (hook → FA.6). L²(μ) is an inner-product space and ‖f‖₂² = ⟨f, f⟩; for p ≠ 2 the parallelogram law fails in Lᵖ (exercise `exr-lp-norms-c2`). FA.6 asks which Banach spaces carry such an inner product.
- **`thm-minkowski`.** For 1 ≤ p ≤ ∞, ‖f + g‖_p ≤ ‖f‖_p + ‖g‖_p. Hence Lᵖ(μ) is a normed space.
  - Proof (first appearance of *split the power*): p = 1, ∞ directly. For 1 < p < ∞: first ‖f + g‖_p < ∞, since |f + g|ᵖ ≤ 2^{p−1}(|f|ᵖ + |g|ᵖ) (convexity of t ↦ tᵖ); then split the power and apply `thm-holder` with (p, p′) to each term, using (p − 1)p′ = p; divide by ‖f + g‖_p^{p−1} (the case ‖f + g‖_p = 0 is trivial).
  - Proof Idea only, no Scratch Work (the scratch-work budget is spent on Hölder; the proof-ordering item below trains this proof).
- **Counting measure.** For μ = counting measure on ℕ, Lᵖ(μ) = ℓᵖ, and `thm-holder`, `thm-minkowski` specialize to FA.1a's `@thm-holder-lp`, `@thm-minkowski-lp`; likewise `thm-riesz-fischer` (§2) specializes to FA.1a's ℓᵖ completeness.
- **`exm-p-less-than-one-functions`** (non-example by minimal change; FA.1a's `@exm-p-less-than-one` on 𝕂², recalled, now for functions). On (0, 1), p = 1/2, f = 1_{(0,1/2)}, g = 1_{(1/2,1)}: ‖f‖_{1/2} = ‖g‖_{1/2} = 1/4 and ‖f + g‖_{1/2} = 1 > 1/2. Minkowski needs p ≥ 1.
- **`exm-power-functions-lp`** (the standard test functions). On (0, ∞) with Lebesgue measure and a > 0: (a) x^{−a}1_{(0,1)} ∈ Lᵖ iff ap < 1; (b) x^{−a}1_{(1,∞)} ∈ Lᵖ iff ap > 1; (c) x^{−1/p} is in no L^q, 1 ≤ q < ∞, and is in L^∞ of no neighbourhood of 0 — yet the measure of {x^{−1/p} > t} is t^{−p}, finite for every t; MT.8 names this weak Lᵖ (hook).
- **Warning.** "‖f‖_p ≤ ‖f‖_q when p < q" is false in general: on ℝ take 1_{[0,2]}, ‖·‖₁ = 2 > √2 = ‖·‖₂. True on probability spaces (§2), reversed on ℓᵖ (§2).
- **Quick check.** For which p is the function e^{−|x|}|x|^{−1/3} on ℝ in Lᵖ? *(Answer: 1 ≤ p < 3; at 0 need p/3 < 1, at ∞ the exponential wins.)*
- **Exercises.**
  - **A.**
    - `exr-lp-norms-a1` (proof comprehension for `thm-holder`): (i) where is the hypothesis 1 < p < ∞ used in the equality case? *(Young's equality clause, which needs 1 < p < ∞; for p = 1 equality holds whenever |g| = ‖g‖_∞ a.e. on {f ≠ 0}, which is not "proportional powers".)* (ii) Run the proof on X = {1, 2} with counting measure, p = 2, f = (1, 1), g = (1, 0). *(Normalized: f/√2, g; Young gives ∫ ≤ 1; actual ∫|f||g|/(√2·1) = 1/√2.)* (iii) The idea in two sentences.
    - `exr-lp-norms-a2`: compute ‖f‖_p for f = 1_E (answer μ(E)^{1/p}) and ‖f‖_∞ (1 if μ(E) > 0, else 0).
    - `exr-lp-norms-a3`: conjugates of 1, 4/3, 2, 3, ∞ *(∞, 4, 2, 3/2, 1)*.
  - **B.**
    - `exr-lp-norms-b1`: generalized Hölder: 1/p + 1/q + 1/r = 1 ⇒ ‖fgh‖₁ ≤ ‖f‖_p‖g‖_q‖h‖_r. *(Apply Hölder with p and p′, then Hölder to ‖gh‖_{p′} with exponents q/p′, r/p′.)*
    - `exr-lp-norms-b2`: if ‖f‖_∞ < ∞ and μ(X) < ∞ then f ∈ Lᵖ for all p. *(‖f‖_p ≤ ‖f‖_∞ μ(X)^{1/p}.)*

## 03-density-translation-duality.md — Density, translation, and the norming formula

## 04-convolution.md — Convolution

Budget ≤ 4,500 main-line words. Support from here is one-line Proof Ideas; Scratch Work only at `thm-minkowski-integral`.

- **Hook.** Averaging f over a small ball, x ↦ m(B_ε)^{−1}∫_{B_ε(x)} f, smooths it: the result is continuous even when f is not. Write the average as ∫f(x − y)k(y) dy with k = m(B_ε)^{−1}1_{B_ε}, and let k be any function: that is convolution.
- **Convolution recalled** from ch05: `@def-convolution` (f ∗ g)(x) = ∫_{ℝᵈ} f(x − y)g(y) dy at every x where ∫|f(x − y)||g(y)| dy < ∞, and `@thm-convolution-l1`: for f, g ∈ L¹ this holds a.e., f ∗ g ∈ L¹ and ‖f ∗ g‖₁ ≤ ‖f‖₁‖g‖₁. Basic algebra: f ∗ g = g ∗ f (change of variables y ↦ x − y, cite MT.1), associativity (Fubini), τ_h(f ∗ g) = (τ_h f) ∗ g, supp(f ∗ g) ⊆ closure of supp f + supp g (supp here is the essential support for L¹ functions; for continuous compactly supported functions the usual support).
- **`thm-minkowski-integral`** (*norm of an average ≤ average of norms*). Let (X, μ), (Y, ν) be σ-finite, F ≥ 0 measurable on X × Y, 1 ≤ p < ∞. Then ‖∫_Y F(·, y) dν(y)‖_{Lᵖ(μ)} ≤ ∫_Y ‖F(·, y)‖_{Lᵖ(μ)} dν(y). For general F with the right side finite, ∫F(x, y)dν(y) exists for a.e. x and the same bound holds.
  - **Scratch Work** (first appearance of *proving a norm bound by testing against the dual ball*): to bound ‖H‖_p, H(x) = ∫F(x, y)dν, test against h ≥ 0 with ‖h‖_{p′} ≤ 1: ∫H h dμ = ∫∫F(x, y)h(x) dμ dν (Tonelli) ≤ ∫‖F(·, y)‖_p dν (Hölder in x). Then take the sup over h — the norming formula, but H might not be known to lie in Lᵖ yet.
  - Proof: as in the scratch, with the gap closed. Since `thm-norming-formula` was proved for f ∈ Lᵖ, apply it to truncations H_N = min(H, N)·1_{X_N} with X_N ↑ X of finite measure (σ-finite), each in Lᵖ, and use MCT. p = 1 is Tonelli alone.
  - Idea ends with: "*Before reading on: which hypothesis makes Tonelli applicable, and where is σ-finiteness of X used a second time?*"
  - Remark: for p = ∞ the inequality is immediate; for p < 1 it fails (exercise `exr-convolution-c2`).
- **`thm-young-convolution`.** If f ∈ L¹(ℝᵈ), g ∈ Lᵖ(ℝᵈ), 1 ≤ p ≤ ∞, then (f ∗ g)(x) is defined for a.e. x, f ∗ g ∈ Lᵖ and ‖f ∗ g‖_p ≤ ‖f‖₁‖g‖_p. Proof: apply `thm-minkowski-integral` to F(x, y) = |f(y)||g(x − y)|, using ‖τ_y g‖_p = ‖g‖_p; p = ∞ directly.
  - **Scaling check** (the *scaling test* again, as a remark): the general Young inequality ‖f ∗ g‖_r ≤ ‖f‖_p‖g‖_q can only hold if 1 + 1/r = 1/p + 1/q; here p = 1, r = q. The general case is `exr-convolution-c1`.
- **`thm-convolution-lp-lpprime`.** If f ∈ Lᵖ, g ∈ L^{p′}, 1 ≤ p ≤ ∞, then f ∗ g is defined everywhere, bounded by ‖f‖_p‖g‖_{p′}, and uniformly continuous; if 1 < p < ∞ then f ∗ g ∈ C₀(ℝᵈ). Proof: Hölder for boundedness; |f ∗ g(x + h) − f ∗ g(x)| ≤ ‖τ_{−h}f − f‖_p‖g‖_{p′} (or with the roles exchanged, whichever exponent is finite) and `thm-translation-continuous-lp`; C₀ by approximating both factors by C_c functions (C_c ∗ C_c ⊆ C_c) and uniform limits.
- **`def-locally-integrable`.** Motivated by a failure: the constant 1, polynomials and log|x| are not in any Lᵖ(ℝᵈ), p < ∞, but averaging them over small balls is harmless. L¹_loc(ℝᵈ): measurable f with ∫_K |f| < ∞ for every compact K. Lᵖ ⊆ L¹_loc for every p (Hölder on K, `thm-lp-inclusion-finite-measure`).
- **`thm-convolution-smooth`.** If f ∈ L¹_loc(ℝᵈ) and φ ∈ C_c^k(ℝᵈ) (0 ≤ k ≤ ∞), then f ∗ φ ∈ C^k and ∂^α(f ∗ φ) = f ∗ ∂^αφ for |α| ≤ k. Proof Idea: difference quotients of φ converge uniformly with support in a fixed compact; DCT (cite MT.2) with dominating function sup|∂_jφ|·|f|·1_K; induct on |α|.
- **`thm-no-convolution-identity`** (failure that motivates §5). There is no e ∈ L¹(ℝᵈ) with e ∗ f = f for all f ∈ L¹(ℝᵈ). ## 05-approximate-identities-mollifiers.md — Approximate identities and mollifiers

Budget ≤ 4,500 main-line words. Last section: carries the R group, the List of Results and the weird-examples table are in `index.md`.

- **Hook.** `thm-no-convolution-identity` says there is no identity; the tent example shows convolution with a narrow bump nearly reproduces f. Make the bump narrower and ask for a limit.
- **`def-approximate-identity`.** Given K ∈ L¹(ℝᵈ) with ∫K = 1, set K_ε(x) = ε^{−d}K(x/ε), ε > 0. The family (K_ε) is the approximate identity generated by K. Facts: ∫K_ε = 1, ‖K_ε‖₁ = ‖K‖₁, and ∫_{|x|>δ}|K_ε| → 0 as ε → 0 for each δ > 0 (dilation, cite MT.1; DCT).
- **`thm-approximate-identity-lp`** (key proof 3). Let (K_ε) be as above. (a) If f ∈ Lᵖ(ℝᵈ), 1 ≤ p < ∞, then ‖f ∗ K_ε − f‖_p → 0 as ε → 0. (b) If f is bounded and uniformly continuous, then f ∗ K_ε → f uniformly. (c) The conclusion of (a) fails for p = ∞: for f = 1_{[0,1/2]} ∈ L^∞(ℝ), f ∗ K_ε is continuous (`thm-convolution-lp-lpprime`, f ∈ L^∞, K_ε ∈ L¹) and every continuous φ has ‖f − φ‖_∞ ≥ 1/2 (`exm-linfty-nonseparable`).
  - **Scratch Work** (first appearance in MT of an approximate-identity argument; AN2's Bernstein / Weierstrass kernels were the earlier instance — say so in one sentence, spiral): write f ∗ K_ε(x) − f(x) = ∫(f(x − εz) − f(x))K(z) dz, using ∫K = 1 and the substitution y = εz. Now the norm of an average ≤ the average of norms.
  - Proof of (a): `thm-minkowski-integral` gives ‖f ∗ K_ε − f‖_p ≤ ∫‖τ_{εz}f − f‖_p|K(z)| dz; the integrand → 0 for each z (`thm-translation-continuous-lp`) and is ≤ 2‖f‖_p|K(z)|; DCT. (b) the same with sup norms. 
  - Idea ends with: "*Before reading on: where is ∫K = 1 used, and what does the proof give if ∫K = c ≠ 1?*" *(f ∗ K_ε → c f.)*
  - Comprehension in `exr-approximate-identities-a1`.
- **`rem-pointwise-later`** (hook → MT.9). Does f ∗ K_ε(x) → f(x) for a.e. x? The norm statement gives it only along a subsequence (`thm-lp-subsequence-ae`). MT.9 proves the full a.e. statement at every Lebesgue point, for K with a radially decreasing integrable majorant, through the maximal function. The Fejér and Poisson kernels of HA.2 are approximate identities on 𝕋 (see HA.2; HA.10 carries this to L¹(𝕋) and L²(𝕋)).
- **`lem-smooth-cutoff-function`.** ψ(t) = e^{−1/t} for t > 0, ψ(t) = 0 for t ≤ 0, is C^∞ on ℝ. Proof: by induction ψ^{(n)}(t) = Pₙ(1/t)e^{−1/t} for t > 0 with Pₙ a polynomial, and t^{−m}e^{−1/t} → 0 as t ↓ 0. (If AN2 already proves this, cite AN2 instead and turn this into a recall; check at S2a.)
- **`def-standard-mollifier`.** η(x) = c·ψ(1 − |x|²), c chosen so ∫η = 1; η ∈ C_c^∞, η ≥ 0, supp η = closed unit ball, η radial. η_ε as in `def-approximate-identity`; f ∗ η_ε is the *mollification* of f.
- **`thm-cc-infinity-dense`.** C_c^∞(ℝᵈ) is dense in Lᵖ(ℝᵈ), 1 ≤ p < ∞. Proof: approximate f by g ∈ C_c (`thm-cc-dense-lp`); g ∗ η_ε ∈ C_c^∞ (`thm-convolution-smooth`, supports) and → g in Lᵖ (`thm-approximate-identity-lp`).
- **`thm-smooth-urysohn`.** If K ⊆ U ⊆ ℝᵈ, K compact, U open, there is ψ ∈ C_c^∞(ℝᵈ) with 0 ≤ ψ ≤ 1, ψ = 1 on K, supp ψ ⊆ U.
  - **Scratch Work** (first appearance of *mollify an indicator to get a smooth cutoff*): picture K, a δ-fattening K_δ = {x : d(x, K) ≤ δ}, and the 2δ-fattening; averaging 1_{K_δ} over balls of radius δ gives 1 at points of K and 0 outside K_{2δ}. Choose δ = d(K, Uᶜ)/3 (δ = 1 if U = ℝᵈ).
  - Proof: ψ = 1_{K_δ} ∗ η_δ, using supp η_δ ⊆ closed B_δ, ∫η_δ = 1, η ≥ 0.
- **Smooth partitions of unity**: stated only as exercise `exr-approximate-identities-c3` (PDE.1, FA.11 and AM use them; AM.3 proves the manifold version, so here the ℝᵈ version for a finite open cover of a compact set suffices).
- **Warning.** Mollification does not commute with pointwise operations: (f²) ∗ η_ε ≠ (f ∗ η_ε)²; and f ∗ η_ε need not stay in a closed convex set unless η ≥ 0 (it does when η ≥ 0: convex combination).
- **Quick check.** If K = 1_{[−1/2,1/2]} on ℝ, write f ∗ K_ε(x) as an average. *(ε^{−1}∫_{x−ε/2}^{x+ε/2} f.)*
