## Chapter hook and where it is paid

- **Hook (index.md and §01 opening).** MT.1 built a set of reals with no Lebesgue measure, so no *countably* additive, translation-invariant length extends Lebesgue measure to all subsets of [0, 1). Ask the weaker question: is there a *finitely* additive, translation-invariant (mod 1) "length" defined on **every** subset of [0, 1), agreeing with Lebesgue measure on measurable sets? Nothing in MT so far can build one: every construction in MT.1–MT.3 goes through σ-algebras.
- **Paid in §05**, `cor-finitely-additive-measure`: yes. It falls out of one application of `thm-hb-analytic` with a cleverly chosen sublinear functional. Exercise §05 C1 shows the object cannot be countably additive, closing the loop with MT.1.
- **Second hook, inherited from FA.1a** (its closing "what is still missing"): is (ℓ^∞)* = ℓ¹? **Paid in §05** (`cor-linfty-dual-not-l1`); the L^∞ analogue is opened for MT.7 / FA.1b (promises below).

## Named moves (index.md, "Named moves")

1. **Extend one dimension at a time.** Find the one free number c by squeezing it between a sup and an inf (§01).
2. **Dominate, then extend.** To build a functional with properties, encode the properties as "≤ p" for a sublinear p; HB delivers an extension that inherits them (§01, used again in §05 twice).
3. **The real part carries everything.** A complex functional is determined by its real part, with the same norm (§02).
4. **Test against functionals.** To show x = 0, or x ∈ closure(M), or ‖x‖ = something, apply every f ∈ X* (§02; this is the duality move registered as decisions.md 14).
5. **Gauge a convex set.** Turn an open convex set into a sublinear functional and separation into domination (§04).
6. **Average away the asymmetry.** Invariance under a shift or translation is forced by dominating with averages, whose defect is O(1/n) (§05).

## 01-dominated-extension.md — Extending a functional under a sublinear bound

**Budget:** ≤ 4,500 main-line words.

- **Opening frame.** The extension problem: M ⊆ X a subspace, f a linear functional on M with |f| ≤ C‖·‖ on M; want F on X, linear, same bound.
- **Failure-motivated definition.** First attempt: extend f linearly by declaring F = 0 on an algebraic complement of M. Show in ℝ² with ‖·‖_∞ that the choice of complement matters: M = span{(1, 1)}, f(t, t) = t (norm 1); complement span{(1, 0)} gives F(x, y) = y, norm 1; complement span{(1, −1)} gives F(x, y) = (x + y)/2, norm 1; complement span{(1, 2)} gives F(x, y) = 2x − y, norm 3. So "extend linearly" ignores the bound, and in infinite dimensions there is no good complement at all. Fix: carry the bound along as a constraint F ≤ p. Since the norm bound must sometimes be replaced by an asymmetric one (§04's gauge, §05's limsup), abstract to **`def-sublinear`**: p : X → ℝ with p(x + y) ≤ p(x) + p(y) and p(tx) = t p(x) for t ≥ 0 (real X). Examples: any seminorm; x ↦ max coordinate on ℝⁿ; limsup on real ℓ^∞. Non-examples: x², |x₁| − |x₂| (A1).
- **`lem-hb-one-step`.** X real vector space, p sublinear on X, M a subspace, f linear on M with f ≤ p on M, x₀ ∈ X \ M. Then f extends to a linear g on M ⊕ ℝx₀ with g ≤ p there; the admissible values c = g(x₀) are exactly the closed interval [α, β] with α = sup_{m ∈ M} (f(m) − p(m − x₀)), β = inf_{m ∈ M} (p(m + x₀) − f(m)).
  - **Scratch Work (first appearance of the technique; kept apart from the proof).** Write the requirement f(m) + tc ≤ p(m + tx₀) for all m, t. Split t > 0 (divide by t, rename m/t) and t < 0 (divide by −t). Get c ≤ p(m + x₀) − f(m) for all m and c ≥ f(m′) − p(m′ − x₀) for all m′. So a c exists iff every lower quantity is ≤ every upper one: f(m′) + f(m) = f(m′ + m) ≤ p(m′ − x₀) + p(m + x₀). That is the whole proof; the theorem only has to be written forwards.
  - **Proof** (written forwards from the scratch): α ≤ β by the displayed inequality; α > −∞ and β < ∞ because both sets are non-empty; take c ∈ [α, β]; verify the two cases t > 0, t < 0 (t = 0 is the hypothesis).
- **Worked example** `exm-one-step-norms`: M = x-axis in ℝ², f(x, 0) = x, x₀ = (0, 1). For p = ‖·‖_∞: α = β = 0, unique extension. For p = ‖·‖₁: [α, β] = [−1, 1]. For p Euclidean: α = β = 0 (neither attained). Verify α, β numerically in the sidecar.
- **`thm-hb-separable`** (no Zorn). X a real separable normed space, M a subspace, f ∈ M* (bounded linear on M). Then there is F ∈ X* extending f with ‖F‖ = ‖f‖.
  - *Proof Idea:* fix a dense sequence (x_n); extend one step at a time to M_n = M + span{x₁, …, x_n} with p = ‖f‖‖·‖, skipping x_n already in M_{n−1}, taking c = β each time so no choice is made; the union D is a dense subspace on which the extension has norm ≤ ‖f‖; extend to X by FA.1a's BLT extension. Remark in one sentence: the recursion is ordinary recursion on ℕ, not choice.
- **`thm-hb-analytic`** (registry). X real vector space, p sublinear on X, M subspace, f linear on M with f ≤ p on M. Then there is a linear F : X → ℝ extending f with F ≤ p on X.
  - **Scratch Work for the Zorn move** (first use of Zorn in MT; F2.4 gave the pattern). Name the poset (partial extensions (N, g) with M ⊆ N, g ≤ p, ordered by extension); check a chain has an upper bound (union of domains, the function defined piecewise, well defined because the chain is a chain); a maximal element must have domain X, since otherwise `lem-hb-one-step` extends it. Show the three questions F2.4 trains: what is the poset, why is every chain bounded, why does maximal mean done.
  - **Proof:** as scratch, written forwards, citing `thm-zorn` and `lem-hb-one-step`. Non-empty poset: (M, f).
- **Remark.** Where Zorn is used and where it is not: separable spaces need none (`thm-hb-separable`); the general theorem cannot be proved in ZF alone (one sentence, stated without proof, no history).
- **Warning.** HB gives existence and no formula, and no uniqueness (forward to `exm-nonunique-extension`).
- **Quick checks** (answers in sibling solutions):
  1. If F ≤ p and F is linear, show −p(−x) ≤ F(x) ≤ p(x). *Answer:* −F(x) = F(−x) ≤ p(−x).
  2. In `lem-hb-one-step`, why can α not be +∞? *Answer:* α ≤ β < ∞, since β is an inf over a non-empty set of reals bounded below by every term of the sup.
- **Exercises.**
  - **A1.** Which are sublinear on ℝ²: ‖·‖₁; max(x, y); x²; |x| − |y|? *Answer:* yes, yes, no (p(2x) ≠ 2p(x)), no (p((0, 1) + (0, −1)) = 0 > −2 = p(0, 1) + p(0, −1)).
  - **A2.** In `exm-one-step-norms`, replace x₀ by (1, 1) with p = ‖·‖₁. Find [α, β]. *Answer:* the requirement is g(1, 1) = 1 + g(0, 1) with g(0, 1) ∈ [−1, 1], so c ∈ [0, 2]; check directly: α = sup_x (x − |x − 1| − 1) = 0, β = inf_x (|x + 1| + 1 − x) = 2.
  - **B1.** Let p(x) = limsup x_n on real ℓ^∞. Prove p is sublinear, and every linear F ≤ p satisfies liminf x_n ≤ F(x) ≤ limsup x_n and F = lim on the convergent sequences c. *Answer:* subadditivity of limsup; Quick check 1 for the lower bound; on c the bounds coincide.
  - **B2.** Show the extension in `lem-hb-one-step` is unique iff α = β, and that α = β = 0 for the Euclidean norm in `exm-one-step-norms`. *Answer:* the extensions correspond bijectively to c ∈ [α, β]; α = sup_x (x − √(x² + 1)) = 0, β = inf_x (√(x² + 1) − x) = 0.
  - **C1.** X real, p sublinear, x₀ ∈ X. Show there is a linear F ≤ p with F(x₀) = p(x₀). *Answer:* on ℝx₀ put g(tx₀) = t p(x₀); g ≤ p for t ≥ 0 by homogeneity, for t < 0 because 0 = p(0) ≤ p(x₀) + p(−x₀) gives t p(x₀) ≤ |t| p(−x₀) = p(tx₀); extend by `thm-hb-analytic`. (Bridge to `cor-hb-norming`.)

## 02-norms-and-consequences.md — Complex scalars, norming functionals, and testing against functionals

**Budget:** ≤ 4,500 main-line words. Support: Proof Idea only (fading).

- **Opening frame.** Most uses are in normed spaces, often complex (FA.6–FA.9, MT.11's complex measures). Two upgrades and then the consequences.
- **`def-seminorm`** if FA.1a lacks it (p(x + y) ≤ p(x) + p(y), p(λx) = |λ| p(x)).
- **`lem-real-part-functional`.** X complex vector space. (a) If f is complex-linear, u = Re f is real-linear and f(x) = u(x) − i u(ix). (b) Conversely, for real-linear u that formula defines a complex-linear f with Re f = u. (c) If X is normed, ‖f‖ = ‖u‖. *Proof Idea for (c):* ≥ is clear; for ≤, rotate: for f(x) ≠ 0 pick |λ| = 1 with λf(x) = |f(x)|, so |f(x)| = f(λx) = u(λx) ≤ ‖u‖‖x‖.
- **`thm-hb-complex`.** X a vector space over 𝔽, p a seminorm, M a subspace, f linear on M with |f| ≤ p on M. Then f extends to a linear F on X with |F| ≤ p. *Proof Idea:* real case from `thm-hb-analytic` plus F(−x) ≤ p(−x) = p(x); complex case: extend u = Re f as a real functional (u ≤ |f| ≤ p), rebuild F by the lemma, and rotate as in (c) to get |F| ≤ p.
- **`thm-hb-normed`.** X normed over 𝔽, M subspace, f ∈ M*. There is F ∈ X* extending f with ‖F‖ = ‖f‖. (Take p = ‖f‖‖·‖.)
- **`exm-nonunique-extension`.** (ℝ², ‖·‖₁), M = x-axis, f(x, 0) = x: the norm-1 extensions are x + cy, |c| ≤ 1. Point back to `exm-one-step-norms`; forward pointer (prose): in a Hilbert space the norm-preserving extension is unique (FA.6).
- **`cor-hb-norming`** (registry). X normed, x₀ ≠ 0: there is f ∈ X* with ‖f‖ = 1 and f(x₀) = ‖x₀‖. Hence ‖x‖ = max{|f(x)| : ‖f‖ ≤ 1} (the max is attained).
- **`exm-nonunique-norming`.** x = (1, 1) in (ℝ², ‖·‖_∞): f(a, b) = a, b, or (a + b)/2 all norm it.
- **`cor-hb-separates`.** x ≠ y ⇒ some f ∈ X* has f(x) ≠ f(y). (Apply norming to x − y.)
- **`cor-hb-distance`.** X normed, M a subspace, x₀ ∈ X with d = dist(x₀, M) > 0. There is f ∈ X* with ‖f‖ = 1, f = 0 on M, f(x₀) = d. *Proof Idea:* on M ⊕ 𝔽x₀ put g(m + tx₀) = td; |td| ≤ |t|‖x₀ + m/t‖ = ‖m + tx₀‖ for t ≠ 0, and ‖g‖ = 1 by a minimizing sequence m_k with ‖x₀ − m_k‖ → d; extend by `thm-hb-normed`.
- **`thm-dense-criterion`.** A subspace M of a normed space X is dense iff the only f ∈ X* vanishing on M is f = 0. More precisely, x₀ ∈ closure(M) iff f(x₀) = 0 for every f ∈ X* vanishing on M. This is the first named **Test against functionals**.
- **Worked examples.**
  - `exm-distance-hyperplane`: for φ ∈ X* \ {0}, dist(x, ker φ) = |φ(x)|/‖φ‖. In C[0, 1] with φ(g) = ∫₀¹ g, dist(1, ker φ) = 1, attained at 0.
  - Density by testing: the polynomials vanishing at 0 are *not* dense in C[0, 1] (the functional g ↦ g(0) kills them and not 1), while FA.1a's c₀₀ is dense in ℓᵖ for p < ∞ and not in ℓ^∞ (the functional of B2 in §03 — prose pointer only).
- **Quick checks.**
  1. If M is dense, what does `cor-hb-distance` give? *Answer:* nothing: d = 0 for every x₀, and every f vanishing on M is 0 (`thm-dense-criterion`), so no f with ‖f‖ = 1 vanishes on M.
  2. For f(z) = (1 + i)z on ℂ, compute u = Re f and recover f from u. *Answer:* u(x + iy) = x − y; u(i z) = −x − y; u(z) − i u(iz) = (x − y) + i(x + y) = (1 + i)z.
- **Exercises.**
  - **A1.** Quick check 2 with f(z) = 3iz. *Answer:* u(x + iy) = −3y, u(iz) = −3x, f = −3y + 3ix ✓.
  - **A2.** For x = (2, −1) in (ℝ², ‖·‖₁), find all norming functionals. *Answer:* f(a, b) = ra + sb has ‖f‖ = max(|r|, |s|); ‖f‖ = 1 and 2r − s = 3 = ‖x‖₁ force r = 1, s = −1, so f(a, b) = a − b is the unique one. (Contrast `exm-nonunique-norming`.)
  - **B1.** Prove dist(x₀, M) = max{|f(x₀)| : f ∈ X*, ‖f‖ ≤ 1, f = 0 on M}. *Answer:* ≥: |f(x₀)| = |f(x₀ − m)| ≤ ‖x₀ − m‖; equality attained by `cor-hb-distance` (and by f = 0 if d = 0).
  - **B2 (find the error; the conclusion is true).** "Claim: X* separates points. Proof: given x ≠ y, define f on span{x, y} by f(x) = 1, f(y) = 0; it is bounded since the span is finite-dimensional; extend by `thm-hb-normed`." *Answer:* if x, y are linearly dependent (y = 2x, or x = 0) the prescription is not linear; the fix is `cor-hb-norming` applied to x − y.
  - **C1.** Let M be a closed subspace of X and x₀ ∉ M. Prove M + 𝔽x₀ is closed. *Answer:* with f from `cor-hb-distance`, m_k + t_k x₀ → z gives t_k d = f(m_k + t_k x₀) → f(z), so t_k → t, then m_k → z − tx₀ ∈ M.
  - **C2.** In C[0, 1] (real), let φ(g) = ∫₀^{1/2} g − ∫_{1/2}^1 g and x₀(t) = 1 − 2t. Show dist(x₀, ker φ) = 1/2 and that no h ∈ ker φ attains it. *Answer:* ‖φ‖ = 1 (bound by ‖g‖, approach with continuous g ≈ sign pattern), φ(x₀) = 1/4 + 1/4 = 1/2, so dist = 1/2 by the worked example; attainment would give k = x₀ − h with ‖k‖ = 1/2 = φ(k), forcing k = 1/2 on [0, 1/2) and −1/2 on (1/2, 1], impossible for continuous k. (Weird-examples table.)

## 03-bidual-and-adjoints.md — The bidual, annihilators, and adjoint operators

**Budget:** ≤ 4,000 main-line words. Proof Idea only.

- **Opening frame.** X* is a Banach space (FA.1a), so it has a dual X**. Each x ∈ X already gives a functional on X*: evaluate at x.
- **`def-bidual`**, J x (f) = f(x). **`thm-bidual-isometry`.** J : X → X** is a linear isometry. *Proof Idea:* ‖Jx‖ ≤ ‖x‖ trivially; = by `cor-hb-norming`. Consequence (one paragraph): closure of J(X) in X** is a completion of X (FA.1a may already have a completion; if so, remark only).
- **`def-reflexive`**: J onto. Examples: finite-dimensional spaces (dimension count, Quick check 1); ℓᵖ for 1 < p < ∞ (compose FA.1a's two dualities and check the composite is J; Proof Idea).
- **`exm-c0-not-reflexive`.** Under c₀* = ℓ¹ and (ℓ¹)* = ℓ^∞, J becomes the inclusion c₀ ⊂ ℓ^∞, which is not onto. State carefully which identification is used and that "not reflexive" means *J* is not onto (a space can be isometric to its bidual by some other map; one sentence, no example).
- **`def-annihilator`**: M^⊥ = {f ∈ X* : f = 0 on M}; ⊥N = {x ∈ X : f(x) = 0 for all f ∈ N}. Restate `thm-dense-criterion` as ⊥(M^⊥) = closure(M).
- **`prp-dual-subspace`.** For a subspace M, restriction X* → M* is onto with kernel M^⊥, and induces an isometric isomorphism X*/M^⊥ ≅ M*. *Proof Idea:* onto and norm-preserving lifting by `thm-hb-normed`; quotient norm = least norm of an extension, attained.
- **`prp-dual-quotient`.** For a closed subspace M, f ↦ f ∘ q is an isometric isomorphism (X/M)* ≅ M^⊥. (No HB needed; say so: q maps the open unit ball onto the open unit ball.)
- **`def-banach-adjoint`**: T ∈ B(X, Y), T' : Y* → X*, T'g = g ∘ T. **`thm-adjoint-norm`**: T' ∈ B(Y*, X*), ‖T'‖ = ‖T‖, (ST)' = T'S', and T ↦ T' is linear (over 𝔽, no conjugation; contrast FA.9's Hilbert adjoint in one sentence). *Proof Idea:* ≤ trivial; ≥: given ‖x‖ ≤ 1 pick g norming Tx.
- **`prp-adjoint-kernel-range`.** ker T' = (ran T)^⊥ and ⊥(ker T') = closure(ran T). In particular T has dense range iff T' is injective. (Test against functionals, second use.)
- **`cor-weakly-bounded`.** A subset S of a normed space X with sup_{s ∈ S} |f(s)| < ∞ for every f ∈ X* is bounded. *Proof Idea:* J(S) ⊆ B(X*, 𝔽) is pointwise bounded on the Banach space X*; `thm-ubp` (FA.4) bounds ‖Js‖ = ‖s‖. This is the first payoff of reading FA.4 before FA.3.
- **Worked examples.**
  - Right shift R on ℓ¹: R' is the left shift on ℓ^∞; ‖R‖ = ‖R'‖ = 1; ran R = {x₁ = 0} is closed, not dense, and ker R' = span{e₁}, matching `prp-adjoint-kernel-range`.
  - Integral operator V g(t) = ∫₀ᵗ g on C[0, 1]: ran V = {h ∈ C¹ : h(0) = 0}, closure = {h(0) = 0}; identify (ran V)^⊥ as the multiples of evaluation at 0 via `thm-dense-criterion` and Weierstrass (AN2, cited as the density of polynomials — if AN2's label is not on the prerequisite list, keep the answer to "contains evaluation at 0").
- **Quick checks.**
  1. Why is J onto when dim X < ∞? *Answer:* J is injective and dim X** = dim X* = dim X.
  2. If T is an isometry, is T' an isometry? *Answer:* not in general; T' is onto (by `prp-dual-subspace`) with ‖T'‖ = 1. Example: the inclusion c₀ ⊂ ℓ^∞ has adjoint the restriction (ℓ^∞)* → ℓ¹, which kills a Banach limit (§05).
- **Exercises.**
  - **A1.** Compute R' for the right shift on ℓᵖ, 1 ≤ p < ∞, under (ℓᵖ)* = ℓ^q. *Answer:* the left shift on ℓ^q.
  - **A2.** Show M^⊥ is a closed subspace of X* for any subset M. *Answer:* intersection of kernels of the bounded maps f ↦ f(m).
  - **B1.** Show c₀^⊥ ⊆ (ℓ^∞)* is non-zero. *Answer:* dist(1, c₀) = 1 (any x ∈ c₀ has |1 − x_n| → 1), then `cor-hb-distance`.
  - **B2.** Prove: if (x_n) is a sequence with f(x_n) convergent for every f ∈ X*, then sup ‖x_n‖ < ∞. *Answer:* `cor-weakly-bounded`.
  - **C1.** Prove: if X is reflexive, every f ∈ X* attains its norm on the closed unit ball. Deduce again that c₀ is not reflexive using f(x) = Σ 2^{−k} x_k. *Answer:* `cor-hb-norming` in X* gives Φ ∈ X**, ‖Φ‖ = 1, Φ(f) = ‖f‖; Φ = Jx, so f(x) = ‖f‖ with ‖x‖ = 1.   - **C2.** Prove `prp-dual-quotient` in full. *Answer:* as the Proof Idea, with the open-ball statement proved from the definition of the quotient norm.

## 04-separation.md — The geometric form: separating convex sets

**Budget:** ≤ 4,500 main-line words. Scratch Work for the gauge (first appearance); Proof Idea elsewhere. Real normed spaces; the complex case by taking real parts (one paragraph, `lem-real-part-functional`).

- **Opening frame (revisits MA.18).** In ℝⁿ two disjoint convex sets, one of them open, lie on opposite sides of a hyperplane. Ask whether the same holds in a normed space.
- **Failure first: `exm-dense-subspace-no-separation`.** In ℓ², M = c₀₀ (dense, convex) and x₀ = (1/k) ∉ M. If f ∈ X* satisfies f ≤ α on M, then f = 0 on M (a functional bounded above on a subspace vanishes there), so f = 0 by density. No nonzero continuous functional separates M from {x₀}, even non-strictly. This is why the theorem needs an open set (and why the finite-dimensional proof of MA.18, which uses relative interiors, does not transfer).
- **`def-minkowski-gauge`.** C convex, open, 0 ∈ C: p_C(x) = inf{t > 0 : x ∈ tC}.
  - **Scratch Work.** Draw C as a convex blob in ℝ²; p_C rescales C to be its own unit ball. List what separation needs from p_C: finite, sublinear, comparable to the norm, and C = {p_C < 1}. Each item is one line once written down; the only real step is subadditivity, where convexity enters through the convex combination (s/(s + t)) (x/s) + (t/(s + t)) (y/t).
- **`lem-gauge-properties`.** If B(0, r) ⊆ C then 0 ≤ p_C(x) ≤ ‖x‖/r; p_C is sublinear; C = {x : p_C(x) < 1}.
- **`lem-separate-point-open-convex`.** C ⊆ X non-empty, open, convex; x₀ ∉ C. There is f ∈ X* with f(x) < f(x₀) for all x ∈ C. *Proof (written forwards from the Scratch Work):* translate so 0 ∈ C; on ℝx₀ put g(tx₀) = t; g ≤ p_C since p_C(x₀) ≥ 1; extend by `thm-hb-analytic`; continuity from f ≤ ‖·‖/r; f < 1 = f(x₀) on C.
- **`thm-hb-geometric`** (registry; first form). A, B ⊆ X non-empty, convex, disjoint, A open. There are f ∈ X* \ {0} and α ∈ ℝ with f(a) < α ≤ f(b) for all a ∈ A, b ∈ B. *Proof Idea:* C = A − B is open, convex, misses 0; apply the lemma to 0; take α = inf f(B); strictness on A because a nonzero functional maps the open set A to an open subset of ℝ.
- **`thm-hb-geometric-strict`** (second form). A closed, B compact, both non-empty, convex, disjoint. There are f ∈ X* and α, ε > 0 with f(a) ≤ α − ε and f(b) ≥ α + ε. *Proof Idea:* dist(A, B) = δ > 0 by compactness; fatten both by δ/3 into open convex sets and apply the first form; the fattening yields the margin ε = (δ/3)‖f‖.
- **`exm-closed-convex-no-strict`.** A = {(x, y) : x > 0, xy ≥ 1}, B = {y ≤ 0}: closed, convex, disjoint, distance 0. The line y = 0 separates non-strictly; no line separates strictly. So compactness of one set cannot be dropped to "closed".
- **`cor-closed-convex-halfspaces`.** A closed convex set is the intersection of the closed half-spaces {f ≤ α} containing it. Promise for FA.5 (Mazur: closed convex sets are weakly closed).
- **Worked examples.** Supporting functional at a boundary point of the closed unit ball of C[0, 1]: for g with ‖g‖ = 1 attained at t₀ with g(t₀) = 1, evaluation at t₀ supports the ball at g. The unit ball of ℓ² as an intersection of half-spaces (exercise B2 answered as a model).
- **Quick checks.**
  1. Gauge of the open ball of radius 2 in any normed space. *Answer:* ‖x‖/2.
  2. Which hypothesis fails in `exm-dense-subspace-no-separation` for the first form? for the second? *Answer:* M is not open; M is not closed.
- **Exercises.**
  - **A1.** Compute the gauge of C = (−1, 2) ⊆ ℝ. *Answer:* p(x) = x/2 for x ≥ 0, −x for x < 0.
  - **A2.** Separate A = {x² + y² < 1} from B = {x ≥ 2} in ℝ²; can it be done strictly? *Answer:* f(x, y) = x, any α ∈ [1, 2]; strictly yes, e.g. f ≤ 1 < 1.5 < 2 ≤ f on the closures (B is not compact, but the closure of A is).
  - **B1.** Prove `lem-gauge-properties` in full (the worked model is the Scratch Work).
  - **B2.** In ℓ², show the closed unit ball is the intersection of the half-spaces {x : Σ x_k y_k ≤ 1}, ‖y‖₂ = 1. *Answer:* ⊆ by Cauchy–Schwarz (Hölder with p = 2, FA.1a); if ‖x‖₂ > 1, y = x/‖x‖₂ gives Σ x_k y_k = ‖x‖₂ > 1.
  - **B3 (find the error; the conclusion is false).** "Any two disjoint non-empty convex sets A, B in a normed space are separated by a nonzero f ∈ X*: A − B is convex and misses 0, so apply `lem-separate-point-open-convex`." *Answer:* the lemma needs A − B open; `exm-dense-subspace-no-separation` (A = M, B = {x₀}) is a counterexample to the conclusion.
  - **C1.** If A, B are disjoint convex sets and A has non-empty interior, show some nonzero f ∈ X* has sup f(A) ≤ inf f(B). *Answer:* first form for int A (convex, open, non-empty) and B; then A ⊆ closure(int A) because for a ∈ A and a₀ ∈ int A the points (1 − s)a + s a₀, 0 < s ≤ 1, are interior; f is continuous.
  - **C2.** Show a closed convex C with non-empty interior has a supporting functional at each boundary point x₀: f ≠ 0 with f(x) ≤ f(x₀) for x ∈ C. *Answer:* x₀ ∉ int C, so the first form applied to int C and {x₀} gives f ≠ 0 with f < f(x₀) on int C; then C ⊆ closure(int C) as in C1 and continuity give f ≤ f(x₀) on C.

## 05-banach-limits-and-measure.md — Banach limits, the dual of ℓ^∞, and a length for every set

**Budget:** ≤ 4,500 main-line words. Proof Idea only, except Scratch Work for averaging translates (first appearance).

- **Opening frame.** Two hooks are due: FA.1a's (ℓ^∞)* question and the chapter hook. Both are answered by **Dominate, then extend** with a p built from averages.
- **`def-banach-limit`.** A linear L : ℓ^∞ → ℝ (real sequences) that is positive (x ≥ 0 ⇒ L(x) ≥ 0), normalized (L(1) = 1), and shift-invariant (L(Sx) = L(x)).
- **`prp-banach-limit-bounds`.** Every Banach limit L has ‖L‖ = 1, vanishes on c₀, satisfies liminf x_n ≤ L(x) ≤ limsup x_n (so L = lim on c), and for every n ≥ 1, L(x) = L(y^{(n)}) where y^{(n)}_m = (x_m + ⋯ + x_{m+n−1})/n is the sequence of moving averages; hence |L(x)| ≤ sup_m |y^{(n)}_m| for every n. *Proof Idea:* positivity and L(1) = 1 give |L(x)| ≤ ‖x‖_∞; L(e_k) = L(e_{k+1}) by shift-invariance and n L(e₁) ≤ L(1) give L(e_k) = 0; a sequence ≤ ε + limsup x_n off finitely many indices gives the limsup bound; y^{(n)} = (1/n) Σ_{j<n} S^j x gives the moving-average identity.
  - **Warning.** A Banach limit need *not* agree with the Cesàro limit: the indicator of ⋃_k [k³, k³ + k) has Cesàro limit 0 (it has about N^{2/3}/2 ones below N) but, for every n, moving averages of window n equal to 1 arbitrarily far out, and some Banach limit gives it the value 1 (stated, not proved; the bounds above allow it). The particular L built in `thm-banach-limit` does satisfy liminf A_n(x) ≤ L(x) ≤ limsup A_n(x), A_n(x) = (x₁ + ⋯ + x_n)/n, because it is dominated by p.
- **`thm-banach-limit`.** Banach limits exist.
  - **Scratch Work (averaging translates).** Want L with L(x − Sx) = 0. The sublinear functional p(x) = limsup A_n(x) does it: A_n(x − Sx) = (x₁ − x_{n+1})/n → 0. Dominate lim on c by p, extend with `thm-hb-analytic`, and read off invariance from L(±(x − Sx)) ≤ p(±(x − Sx)) = 0 and positivity from L(−x) ≤ p(−x) ≤ 0 for x ≥ 0.
  - **Proof** forwards.
- **`exm-banach-limit-values`.** For every Banach limit: L(1, 0, 1, 0, …) = 1/2; L((−1)ⁿ) = 0; L(sin n) = 0 (by the moving-average bound of `prp-banach-limit-bounds`: block sums of sin k are bounded by 1/sin(1/2)). Not multiplicative: x = (1, 0, 1, 0, …) has x² = x but L(x)² ≠ L(x).
- **`cor-linfty-dual-not-l1`.** The isometric embedding ℓ¹ → (ℓ^∞)*, y ↦ (x ↦ Σ x_k y_k), is not onto; consequently ℓ¹ is not reflexive. *Proof Idea:* if a Banach limit came from y, then y_k = L(e_k) = 0 for all k, so L = 0, contradicting L(1) = 1. Reflexivity: under FA.1a's identifications J_{ℓ¹} becomes this embedding.
- **`thm-invariant-mean-circle`.** Let B be the real bounded 1-periodic functions on ℝ with the sup norm, V ⊆ B those that are Lebesgue measurable. There is a linear I : B → ℝ with (i) I(f) = ∫₀¹ f for f ∈ V; (ii) I(f) ≥ 0 for f ≥ 0; (iii) I(f_a) = I(f) for every a ∈ ℝ.
  - *Proof Idea* (fading: no scratch, since this is the averaging move again). p(f) = inf over finite lists a₁, …, a_n of sup_x (1/n) Σ_j f(x + a_j). Sublinear: homogeneity is clear; subadditivity by merging lists (a_i) and (b_j) into the list (a_i + b_j), using that translations commute. ∫₀¹ f ≤ p(f) on V because each average has integral ∫₀¹ f (translation invariance of the integral of a periodic function, MT.2) and an integral is at most a sup. p(f − f_a) ≤ 0 via the list 0, a, …, (n − 1)a, whose average telescopes to (f(x) − f(x + na))/n. Extend by `thm-hb-analytic`; read off (ii) and (iii) as in `thm-banach-limit`.
- **`cor-finitely-additive-measure`** (pays the chapter hook). For E ⊆ [0, 1) put μ(E) = I(χ̃_E), χ̃_E the 1-periodic extension. Then μ is defined on all subsets, finitely additive, μ([0, 1)) = 1, invariant under translation mod 1, and equals Lebesgue measure on measurable sets.
- **Remark (no proof).** The same statement on ℝ³ with rotations added is false (one sentence; the obstruction is the free subgroup of the rotation group). No history.
- **Closing subsection: the weird-examples table** (above).
- **Quick checks.**
  1. Compute L(1, 0, 0, 1, 0, 0, …). *Answer:* 1/3 (the three shifts sum to 1).
  2. Is L(x) determined by x alone? *Answer:* no in general: the value is forced on c and on sequences like (1, 0, 1, 0, …) or (sin n), but the Warning's sequence takes different values under different Banach limits (stated, not proved).
- **Exercises.**
  - **A1.** Compute L(x) for x = (2, 0, 2, 0, …) + (1/n). *Answer:* 1 (L kills c₀).
  - **A2.** Show a Banach limit is not given by any y ∈ ℓ¹ directly from L(e_k) = 0. *Answer:* the Proof Idea of `cor-linfty-dual-not-l1`.
  - **B1.** Prove L(sin n) = 0 for every Banach limit in full. *Answer:* |Σ_{k=m}^{m+n−1} sin k| ≤ 1/sin(1/2), so ‖y^{(n)}‖_∞ ≤ 1/(n sin(1/2)) and |L(x)| = |L(y^{(n)})| ≤ ‖y^{(n)}‖_∞ → 0.
  - **B2.** Prove `prp-banach-limit-bounds`' claim that L vanishes on c₀ and equals lim on c. *Answer:* as the Proof Idea, then x − (lim x)1 ∈ c₀.
  - **C1.** Let μ be as in `cor-finitely-additive-measure` and let N ⊆ [0, 1) contain exactly one point of each class of ℝ/ℚ (MT.1's non-measurable set). Show μ(N) = 0, and deduce μ is not countably additive. *Answer:* the translates N + q mod 1, q ∈ ℚ ∩ [0, 1), are disjoint and each has measure μ(N), so any n of them give n μ(N) ≤ 1, hence μ(N) = 0; but their countable union is [0, 1), of measure 1.
  - **C2.** Construct a shift-invariant positive normalized L on two-sided bounded sequences ℓ^∞(ℤ). *Answer:* the same proof with A_n(x) = (x_{−n} + ⋯ + x_n)/(2n + 1); the defect of x − Sx is (x_{−n} − x_{n+1})/(2n + 1).

## 06-riesz-on-cab.md — (Optional) Riesz's representation of C[a, b]* via Hahn–Banach

**Budget:** ≤ 3,000 main-line words. No support (end of fading). Optional: no main-line result cites it; FA.2 proves Riesz–Markov independently, MT.11 handles complex measures.

- **Opening frame.** FA.1a found the duals of sequence spaces; C[a, b] was left open. HB gives a route that needs only AN2's Stieltjes integral.
- **`thm-riesz-cab`.** For every Λ ∈ C[a, b]* (real) there is g of bounded variation on [a, b] with Λf = ∫_a^b f dg (Riemann–Stieltjes) for all f ∈ C[a, b], and V_a^b(g) = ‖Λ‖.
  - *Proof Idea:* extend Λ to Λ̃ on the bounded functions B[a, b] with the same norm (`thm-hb-normed`); put g(a) = 0, g(t) = Λ̃(χ_{[a, t]}); a partition sum Σ|g(t_k) − g(t_{k−1})| equals Λ̃ of a step function with values ±1, so V(g) ≤ ‖Λ‖; for continuous f the step functions f(t₁)χ_{[a, t₁]} + Σ_{k ≥ 2} f(t_k)χ_{(t_{k−1}, t_k]} converge to f uniformly as the mesh goes to 0, and Λ̃ of them is a Riemann–Stieltjes sum (AN2.10); so Λf = ∫ f dg and |Λf| ≤ ‖f‖ V(g).
- **Remark.** g is not unique; it depends on the extension Λ̃ (exercise C1). Normalizing g (right-continuous, g(a) = 0) restores uniqueness; that is FA.2 / MT.11's business (prose pointer).
- **Worked example.** Λf = ∫_a^b f h for continuous h: g(t) = ∫_a^t h, V(g) = ∫|h| = ‖Λ‖.
- **Exercises.**
  - **A1.** For Λf = ∫_a^b f, verify that g(t) = t − a represents Λ and V(g) = b − a = ‖Λ‖.
  - **B1.** For Λf = f(c), a < c < b, show that every g produced by the construction has g(t) = 0 for a ≤ t < c and g(t) = 1 for c < t ≤ b. *Answer:* a norm-1 extension Λ̃ with Λ̃(1) = 1 is positive (for 0 ≤ h ≤ 1, ‖1 − 2h‖ ≤ 1 gives |1 − 2Λ̃h| ≤ 1). For t < c pick continuous φ with χ_{[a, t]} ≤ φ ≤ 1 and φ(c) = 0: 0 ≤ g(t) ≤ Λ̃φ = 0. For t > c pick continuous 0 ≤ ψ ≤ χ_{[a, t]} with ψ(c) = 1: 1 = Λ̃ψ ≤ g(t) ≤ Λ̃1 = 1. (For t = a < c the convention g(a) = 0 agrees.)
  - **C1.** Show g(c) in B1 depends on the extension. *Answer:* Λ̃₁(h) = L((h(c − 1/n))_n) and Λ̃₂(h) = L((h(c + 1/n))_n), L a Banach limit (finitely many undefined terms set to 0; L ignores them by `prp-banach-limit-bounds`), are norm-1 extensions of evaluation at c; they give g(c) = Λ̃(χ_{[a, c]}) = 1 and 0 respectively.
