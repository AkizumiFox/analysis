# Blueprint: MT.10 — Bounded Variation, Absolute Continuity, and the Fundamental Theorem

**Directory:** `mt/src/ch14-bv-absolute-continuity/`. **Volume MT** (*Measure, Integration, and Real Analysis*), **chapter 14** in the spec/08 D4 order HA.9 → MT.1 → MT.2 → MT.3 → MT.4 → MT.5 → MT.6 → FA.1a → FA.4 → FA.3 → MT.7 → MT.8 → MT.9 → **MT.10** → FA.6 → MT.11 → FA.1b → FA.9 → FA.7. **Place in the skeleton.** MIRA 4 is "maximal function and derivatives"; spec/08 D4 maps it to MT.9 (maximal function, Lebesgue differentiation) and MT.10 (this chapter: BV and AC). MT.9 answered "is (d/dx)∫ₐˣ f = f a.e.?" (yes). This chapter answers the converse question HA.9 left open: **when is F(b) − F(a) = ∫ₐᵇ F′?**

**Purpose.**
- Show the two different ways the fundamental theorem fails for the Riemann integral and for the naive Lebesgue statement: Volterra's function (F′ exists everywhere and is bounded, but is not Riemann integrable) and the Cantor function (F′ = 0 a.e., yet F rises by 1).
- Lebesgue's integral repairs the first failure outright. The second needs a new hypothesis on F, and the chapter finds it by asking exactly what the Cantor function does wrong: **absolute continuity**.
- Prove Lebesgue's theorem (monotone, hence BV, functions are differentiable a.e.), the fundamental theorem for AC functions in both directions, the decomposition of an increasing function into absolutely continuous, jump and singular parts, and the calculus of AC functions (parts, substitution, arc length).

Support fades through each section's exercises. Definitions are motivated by failure (absolute continuity from the Cantor function; the jump function from the failure of continuity). The weird-examples table continues (MT's table, opened in HA.9). A List of Results closes the chapter. No footnote jokes, no historical footnotes, no first-person persona.

## 01-two-failures.md — Two ways the fundamental theorem fails

Budget 3,200. Fading: full.

- **Hook** as in index: V and c. Recall V from HA.9 by label; do not rebuild it.
- **The Cantor function** (`def-cantor-function`, `exm-cantor-function`). Define c on the Cantor set C by c(Σ 2εₖ3⁻ᵏ) = Σ εₖ2⁻ᵏ (εₖ ∈ {0,1}), and extend as the constant value on each removed interval. Prove: well defined (the two ternary expansions of an endpoint give the same value), increasing, continuous (no jumps: the image of C is all of [0,1], so an increasing function onto an interval has no jump), c′ = 0 on [0,1] \ C, m(C) = 0 (MT.1). Conclude ∫₀¹ c′ dm = 0.
- **Recall BV** (revisit AN2.9, prose pointer): `def-total-variation` T_a^b(F) = sup over partitions of Σ\|F(xᵢ) − F(xᵢ₋₁)\|; `def-bounded-variation`; additivity T_a^c = T_a^b + T_b^c. `thm-jordan-decomposition-recalled`: F ∈ BV[a,b] ⇔ F = G − H with G, H increasing; take G(x) = T_a^x(F), H = G − F. One-paragraph proof (H increasing because F(y) − F(x) ≤ T_x^y(F)).
- **Monotone functions have few discontinuities.** An increasing F has one-sided limits everywhere and at most countably many jumps (disjoint open intervals (F(x−), F(x+)) each contain a rational). Short proof here; it is used in §3.
- **Dini derivatives** (`def-dini-derivatives`): D⁺F(x) = limsup_{h↓0} (F(x+h) − F(x))/h, D₊F (liminf, h ↓ 0), D⁻F, D₋F (h ↑ 0). F is differentiable at x iff all four are equal and finite. Worked example: F(x) = x sin(1/x), F(0) = 0, at x = 0: the difference quotient is sin(1/h), so D⁺F(0) = D⁻F(0) = 1 and D₊F(0) = D₋F(0) = −1.
- **The programme** (a displayed list):
  1. Every BV function is differentiable a.e. (§2–3).
  2. ∫ₐᵇ F′ ≤ F(b) − F(a) for increasing F; c shows "<" happens (§3).
  3. Which extra property forces equality (§4)?
- **Warning.** "Differentiable a.e. with F′ ∈ L¹" is not enough for the FTC: c. And "continuous and increasing" is not enough either: c again.
- **Quick check.** Is F(x) = x sin(1/x) of bounded variation on [0,1]? (No: at the points x = 2/((2k+1)π) the values alternate in sign with size ≈ 2/((2k+1)π), and Σ 1/k diverges.)
- **Weird-examples table:** add the rows c and x sin(1/x).
- **Exercises.**
  - **A1** (a) State the definition of D₋F(x). (b) True/false: an increasing function has D₊F ≥ 0 everywhere (true). (c) Give the value c(1/4) (1/4 = 0.0202…₃, so c(1/4) = 0.0101…₂ = 1/3). (d) Name the property of c that rules out every integral as a repair.
  - **B1** Compute the four Dini derivatives at 0 of F(x) = x for x ∈ ℚ, F(x) = 0 otherwise. (Answer: D⁺ = D⁻ = 1, D₊ = D₋ = 0.)
  - **B2** Show c(x/3) = c(x)/2 and c(x/3 + 2/3) = 1/2 + c(x)/2 for x ∈ [0,1], and use them to compute ∫₀¹ c dm = 1/2 by self-similarity (I = I/6 + (1/2·1/3 + I/6) + 1/2·(1/3); answer I = 1/2).
  - **B3** Let F be increasing on [a,b]. Show Σ over jumps of (F(x+) − F(x−)) ≤ F(b) − F(a) (finite subfamilies, then sup).
  - **C1** Show \|c(x) − c(y)\| ≤ 4\|x − y\|^α with α = log 2/log 3. (Answer: c varies by at most 2⁻ᵏ on each of the 2ᵏ level-k pieces and is constant on the gaps, which at levels ≤ k have length ≥ 3⁻ᵏ; if 3⁻ᵏ⁻¹ < \|x − y\| ≤ 3⁻ᵏ then [x, y] meets at most two level-k pieces, so \|c(x) − c(y)\| ≤ 2·2⁻ᵏ = 2(3⁻ᵏ)^α < 2(3\|x − y\|)^α = 4\|x − y\|^α.)

## 02-rising-sun.md — The rising sun lemma and continuous monotone functions

Budget 3,600. Fading: full (first appearance of the rising-sun technique: Scratch Work kept apart from the proof).

- **Lead-in.** To show D⁺F < ∞ a.e. one needs to control the set where difference quotients are large. "Large difference quotient at x" means "some later point is much higher than the line through F(x) with slope λ". Subtracting λx turns this into "some later point is higher".
- **`lem-rising-sun`.** Let G : [a,b] → ℝ be continuous. Let U = {x ∈ (a,b) : G(y) > G(x) for some y ∈ (x, b]}. Then U is open, so U is a countable disjoint union of open intervals (aₖ, bₖ); for each k, G(aₖ) ≤ G(bₖ), with equality when aₖ ≠ a.
  - **Scratch Work** (separate block): the picture with the sun on the right; U is the shadow; why an endpoint not in U sees nothing higher to its right; why the right endpoint bₖ must reach the height of aₖ (otherwise the max of G on [aₖ, bₖ] is attained at an interior point which is then not in U).
  - **Proof** (typeset register): U open by continuity. For bₖ ∉ U (or bₖ = b): G(y) ≤ G(bₖ) for y ∈ [bₖ, b]. If G(bₖ) < G(x) for some x ∈ (aₖ, bₖ), take x₀ ∈ [x, bₖ] maximizing G on [x, bₖ]; then x₀ ∈ U, so G(y) > G(x₀) for some y > x₀, and y > bₖ is impossible, while y ∈ (x₀, bₖ] contradicts maximality. So G(x) ≤ G(bₖ) on (aₖ, bₖ), and G(aₖ) ≤ G(bₖ) by continuity. If aₖ ≠ a, then aₖ ∉ U gives G(bₖ) ≤ G(aₖ).
  - *Hypothesis check (remark):* continuity is needed. Witness: G = 0 on [0, 1/2], G = 1 on (1/2, 1]; then U = (0, 1/2], which is not open.
- **`lem-dini-maximal-continuous`.** F continuous and increasing on [a,b], λ > 0 ⇒ m*({x ∈ (a,b) : D⁺F(x) > λ}) ≤ (F(b) − F(a))/λ.
  - Proof: apply `lem-rising-sun` to G(x) = F(x) − λx; the set lies in U; Σ(bₖ − aₖ) ≤ Σ(F(bₖ) − F(aₖ))/λ ≤ (F(b) − F(a))/λ (disjoint intervals, F increasing).
  - Consequence: D⁺F < ∞ a.e.
- **`thm-continuous-monotone-diff-ae`.** F continuous and increasing on [a,b] ⇒ F is differentiable a.e., with 0 ≤ F′ < ∞ a.e.
  - *Proof Idea / route:* (i) D⁺F < ∞ a.e. (above). (ii) For rationals 0 < r < R, the set E = {D⁺F > R, D₋F < r} has outer measure 0: on any (α, β), apply the rising sun lemma to x ↦ rx + F(−x) on [−β, −α] (shadow intervals where D₋F < r, with F(bₖ) − F(aₖ) ≤ r(bₖ − aₖ)), then inside each shadow interval apply it to F(x) − Rx; get m*(E ∩ (α, β)) ≤ (r/R)(β − α); iterate n times: ≤ (r/R)ⁿ(β − α) → 0. (iii) So D⁺F ≤ D₋F a.e.; applying this to −F(−x) gives D⁻F ≤ D₊F a.e. (iv) Chain D⁺ ≤ D₋ ≤ D⁻ ≤ D₊ ≤ D⁺ a.e.
  - Name the reflection trick ("look at the function from the other side").
  - The S3 drafter writes the iteration with the nested family of intervals indexed explicitly and verifies the inequality chain in step (ii) with a sidecar.
- **Warning.** The theorem says nothing at a given point: c′(x) does not exist (D⁺c = ∞) at many points of C.
- **Quick check.** Why does the rising-sun bound use only the endpoints of the shadow intervals and never the values of F inside them? (Because increasing F gives Σ(F(bₖ) − F(aₖ)) ≤ F(b) − F(a) for disjoint intervals.)
- **Exercises.**
  - **A1** (a) For G(x) = sin x on [0, 4π], find U exactly. (Answer: U = (0, π/2) ∪ (π/2, 5π/2) ∪ (3π, 4π); check the endpoint condition on each component: 0 ≤ 1, 1 = 1, 0 = 0.) (b) **Proof comprehension:** in `lem-rising-sun`, where is it used that bₖ ∉ U? (c) What breaks in `lem-dini-maximal-continuous` if the intervals were not disjoint?
  - **B1** Apply `lem-dini-maximal-continuous` to F(x) = x² on [0,1] and λ = 1; compare the bound with the actual set {2x > 1}. (Bound 1, actual measure 1/2.)
  - **B2** (faded, last step blank) Show that if F is continuous and increasing and D⁺F ≤ M everywhere on (a,b), then F(y) − F(x) ≤ M(y − x). *Name the move, then complete it.* (Rising sun applied to F(x) − (M + ε)x: U is empty; then ε → 0.)
  - **C1** Prove the rising sun lemma's "left-to-right" version: for continuous G, the set {x : G(y) > G(x) for some y ∈ [a, x)} is a disjoint union of intervals with G(aₖ) ≥ G(bₖ) (equality when bₖ ≠ b). Then derive the bound on {D₋F < … } needed in step (ii).
  - **C2** (find the error, conclusion true) A "proof" that D⁺F < ∞ a.e. for continuous increasing F which picks, for each x with D⁺F(x) > λ, one h(x) with F(x + h) − F(x) > λh, and then sums over all such x as if the intervals were disjoint. ## 03-jumps-and-lebesgue.md — Jump functions and Lebesgue's theorem

Budget 4,200. Fading: Scratch Work only for `lem-maximal-measure-1d` (first appearance of a maximal inequality for a measure that is not f dm); the rest Proof Idea.

- **Failure-motivated definition.** The rising-sun proof used continuity twice (U open; endpoint values). An increasing function with a jump at every rational (`exm-rational-jumps`: J(x) = Σ_{qₙ ≤ x} 2⁻ⁿ with qₙ an enumeration of ℚ ∩ [0,1]) is discontinuous on a dense set, so §2 does not apply. Remove the jumps.
- **`def-jump-function`.** Given countably many points xₙ ∈ [a,b] and nonnegative pairs (βₙ, γₙ) with Σ(βₙ + γₙ) < ∞, J(x) = Σ_{xₙ < x} (βₙ + γₙ) + βₙ·[x = xₙ]. (Jump βₙ from the left, γₙ to the right at xₙ.)
- **`lem-saltus-split`.** Every increasing F on [a,b] is F = F_c + J with F_c continuous increasing and J the jump function of F's jumps (βₙ = F(xₙ) − F(xₙ−), γₙ = F(xₙ+) − F(xₙ)). Proof: F − J has no jumps and is increasing (check y > x: J(y) − J(x) ≤ F(y) − F(x) using B3 of §1 on [x, y]).
- **The atomic measure** ν = Σ(βₙ + γₙ)δ_{xₙ}, ν(A) = Σ_{xₙ ∈ A}(βₙ + γₙ): a finite measure on all subsets (countable additivity is a rearrangement of a nonnegative series). For x < y: 0 ≤ J(y) − J(x) ≤ ν([x, y]).
- **`lem-maximal-measure-1d`.** For a finite measure ν on the Borel sets of ℝ, define Mν(x) = sup{ν(I)/\|I\| : I a bounded open interval containing x}. Then {Mν > λ} is open and m({Mν > λ}) ≤ 3ν(ℝ)/λ.
  - **Scratch Work:** put MT.9's proof of the weak (1,1) inequality beside this one; the only change is that ∫_I \|f\| becomes ν(I). Spell out why the sets are open (that is why open intervals are used).
  - **Proof:** openness; for compact K ⊆ {Mν > λ}, finitely many I with ν(I) > λ\|I\| cover K; `lem-vitali-finite` (MT.9) gives disjoint I₁,…,I_m with K ⊆ ∪ 3Iⱼ; m(K) ≤ 3Σ\|Iⱼ\| < 3Σν(Iⱼ)/λ ≤ 3ν(ℝ)/λ; inner regularity (MT.1).
- **`thm-jump-derivative-zero`.** Every jump function J is differentiable a.e. with J′ = 0 a.e.
  - Route (named move: dense class plus maximal inequality): split J = J_{≤N} + J_{>N}. J_{≤N} is a step function, J′_{≤N} = 0 off N points. For J_{>N} with measure ν_N, and x not an atom: \|J_{>N}(y) − J_{>N}(x)\|/\|y − x\| ≤ ν_N([x∧y, x∨y])/\|y − x\| ≤ Mν_N(x) (enlarge the closed interval to an open one by δ and let δ → 0). So {x : limsup_{y→x} \|J(y) − J(x)\|/\|y − x\| > ε} ⊆ {atoms} ∪ {Mν_N > ε} has outer measure ≤ 3ν_N(ℝ)/ε → 0 (N → ∞). Union over ε = 1/k.
- **`thm-lebesgue-monotone`.** Every increasing F on [a,b] is differentiable a.e. (`lem-saltus-split` + `thm-continuous-monotone-diff-ae` + `thm-jump-derivative-zero`).
- **Alternatively** (one paragraph, no proof): Lebesgue's theorem in one stroke from MT.9's `thm-vitali-covering-fine` (the Royden route): for rationals r < R the set {D⁺F > R > r > D₋F} is covered finely by intervals on which F rises by less than r·length, and by intervals inside those on which it rises by more than R·length; comparing gives R·m* ≤ r·m*. The text's route is preferred because each piece (rising sun, peel off the jumps, maximal inequality) is reused; §3 C3 asks for the Vitali route.
- **`cor-bv-diff-ae`.** Every F ∈ BV[a,b] is differentiable a.e. (Jordan).
- **`thm-integral-derivative-le`.** F increasing on [a,b] ⇒ F′ is measurable, F′ ∈ L¹[a,b] and ∫ₐᵇ F′ ≤ F(b) − F(a).
  - Proof: extend F by F(b) on (b, b+1]; gₙ(x) = n(F(x + 1/n) − F(x)) ≥ 0 is measurable (F monotone, so Borel) and gₙ → F′ a.e.; Fatou (MT.2): ∫F′ ≤ liminf ∫ₐᵇ gₙ = liminf (n∫_b^{b+1/n} F − n∫_a^{a+1/n} F) ≤ F(b) − F(a).
  - For BV: F′ ∈ L¹ and ∫\|F′\| ≤ T_a^b(F).
  - Strictness: c gives 0 < 1. A jump function gives 0 < J(b) − J(a).

## 04-absolute-continuity.md — Absolute continuity and the fundamental theorem

Budget 4,800. Fading: Scratch Work for `lem-image-measure-k` (first appearance of "measure the image"); Proof Idea elsewhere.

- **Failure-motivated definition.** What exactly does c do wrong? Cover C by 2ᵏ intervals of total length (2/3)ᵏ; c increases by the full amount 1 across them. So: tiny total length, total increase 1. Forbid that.
- **`def-absolutely-continuous`.** F : [a,b] → ℝ is AC if ∀ε > 0 ∃δ > 0 such that for every finite family of pairwise disjoint subintervals (aᵢ, bᵢ) with Σ(bᵢ − aᵢ) < δ, Σ\|F(bᵢ) − F(aᵢ)\| < ε. In symbols too (STYLE §10). Quick check on swapping "for every family" and "∃δ".
- **First facts** (one block, short proofs): AC ⇒ uniformly continuous; AC ⇒ BV (cut [a,b] into pieces of length < δ for ε = 1); Lipschitz ⇒ AC; sums and products of AC functions are AC; the indefinite integral of an L¹ function is AC (absolute continuity of the integral, MT.2).
- **Non-examples:** c (the hook); x sin(1/x) (not BV); and `exm-sqrt-ac-not-lipschitz`: √x on [0,1] is AC (indefinite integral of 1/(2√t) ∈ L¹, after the FTC; or directly by concavity: Σ(√bᵢ − √aᵢ) ≤ √(Σ(bᵢ − aᵢ))) and not Lipschitz.
- **`def-luzin-n`** and **`lem-ac-luzin-n`.** F has the Luzin N property if m(F(Z)) = 0 whenever m(Z) = 0. AC ⇒ Luzin N (cover Z by open intervals of total length < δ; F maps each into an interval of length at most the oscillation, which is attained as \|F(sᵢ) − F(tᵢ)\| by continuity). c fails it: c(C) = [0,1].
- **`lem-image-measure-k`.** F : [a,b] → ℝ, E ⊆ [a,b] arbitrary, F differentiable at every point of E with \|F′\| ≤ k on E ⇒ m*(F(E)) ≤ k·m*(E).
  - **Scratch Work:** for a single point, F is k-Lipschitz "near x"; the problem is that "near" depends on x. Sort the points by how near: Eₙ. Then the covering is uniform on Eₙ.
  - **Proof:** fix ε; Eₙ = {x ∈ E : \|F(y) − F(x)\| ≤ (k + ε)\|y − x\| whenever \|y − x\| < 1/n}; Eₙ ↑ E. Cover Eₙ by intervals Iⱼ of length < 1/n with Σ\|Iⱼ\| ≤ m*(Eₙ) + ε; diam F(Eₙ ∩ Iⱼ) ≤ (k + ε)\|Iⱼ\|; so m*(F(Eₙ)) ≤ (k + ε)(m*(E) + ε). Then m*(F(E)) = limₙ m*(F(Eₙ)) (MT.1: m* is continuous along increasing unions). Let ε → 0.
- **`lem-image-measure-integral`.** F continuous on [a,b], A ⊆ [a,b] measurable, F differentiable at every point of A ⇒ m*(F(A)) ≤ ∫_A \|F′\|.
  - Route: F′ is measurable on A (limit of difference quotients of a continuous function); slice A into A_j = {(j − 1)ε ≤ \|F′\| < jε}, j ≥ 1; apply `lem-image-measure-k`: m*(F(A_j)) ≤ jε·m(A_j) ≤ ∫_{A_j}\|F′\| + ε m(A_j); sum: ≤ ∫_A\|F′\| + ε(b − a).
- **`thm-ac-zero-derivative-constant`.** F AC on [a,b] and F′ = 0 a.e. ⇒ F constant.
  - Proof (named move: measure the image): [a, x] = Z ∪ N with Z = {F′ = 0} (measurable, after choosing a Borel version) and m(N) = 0; m*(F(Z)) ≤ 0 by `lem-image-measure-integral`; m(F(N)) = 0 by `lem-ac-luzin-n`; F([a, x]) is an interval (continuity) of measure 0, so F(x) = F(a).
  - Remark (hypothesis check): AC is needed (c); "F′ = 0 a.e." cannot be weakened to "F′ ≥ 0 a.e. ⇒ increasing" without AC either (−c has (−c)′ = 0 a.e. and decreases). Mention the alternative route through the Vitali covering theorem for fine covers (S&S, Royden) in one "Alternatively," paragraph.
- **`thm-ftc-lebesgue`** (both directions).
  1. f ∈ L¹[a,b], F(x) = ∫ₐˣ f ⇒ F is AC and F′ = f a.e. (AC: MT.2; F′ = f a.e.: `cor-indefinite-integral-derivative`, MT.9.)
  2. F AC on [a,b] ⇒ F is differentiable a.e., F′ ∈ L¹, and F(x) = F(a) + ∫ₐˣ F′ for all x.
  - Proof of 2: AC ⇒ BV ⇒ F′ ∈ L¹ (`cor-bv-diff-ae`, `thm-integral-derivative-le`); G(x) = ∫ₐˣ F′ is AC with G′ = F′ a.e. (part 1); F − G is AC with derivative 0 a.e.; `thm-ac-zero-derivative-constant`.
  - Corollary in prose: AC = "indefinite integrals of L¹ functions".
- **`thm-banach-zarecki`.** F : [a,b] → ℝ is AC ⇔ F is continuous, BV, and has the Luzin N property.
  - ⇐ route: A = set of differentiability points, N its complement (null by `cor-bv-diff-ae`; pass to a G_δ superset to keep A measurable). For [c, d]: \|F(d) − F(c)\| ≤ m(F([c, d])) ≤ m*(F([c,d] ∩ A)) + m*(F(N)) ≤ ∫_c^d \|F′\| + 0; absolute continuity of the integral finishes.
  - Witnesses for each hypothesis: drop continuity (a single jump: BV, Luzin N, not AC); drop BV (x sin(1/x): continuous, differentiable on (0,1] so Luzin N by `lem-image-measure-k` applied to the slices {\|F′\| ≤ k}, and not BV); drop Luzin N (c).
- **`thm-ftc-everywhere-differentiable`** (pays the HA.9 hook in full). F continuous on [a,b], differentiable at every point of [a,b] outside a countable set, and F′ ∈ L¹[a,b] ⇒ F is AC and F(b) − F(a) = ∫ₐᵇ F′.
  - Proof: as in Banach–Zarecki, with N countable, so m(F(N)) = 0 because F(N) is countable: \|F(d) − F(c)\| ≤ ∫_c^d \|F′\|.
  - Hypothesis witnesses: F′ ∈ L¹ is needed (`exm-x2sin-inv-x2`: F(x) = x² sin(1/x²), F(0) = 0, is differentiable everywhere on [0,1], not BV, and F′ ∉ L¹); "countable" cannot become "null" (c).

- **`exm-composition-not-ac`.** g(x) = x² sin²(1/x) (g(0) = 0) is Lipschitz on [0,1] (\|g′\| ≤ 3), √· is AC on [0,1], but √g = x\|sin(1/x)\| is not BV. So AC ∘ AC need not be AC. Table row.

## 05-decomposition.md — Decomposing an increasing function

Budget 3,800. Fading: Proof Idea only.

- **`def-singular-function`.** F is singular if F is increasing (or BV) and F′ = 0 a.e. Examples: c; jump functions; `exm-strictly-increasing-singular`.
- **`thm-decomposition-increasing`.** Every increasing F on [a,b] is uniquely, up to additive constants, F = F_ac + F_j + F_s with F_ac AC increasing, F_j a jump function, F_s continuous increasing singular.
  - Route: F_j from `lem-saltus-split`; F_ac(x) = ∫ₐˣ F′ (F′ ≥ 0, in L¹); F_s = F − F_j − F_ac. F_s is continuous; F_s′ = F′ − 0 − F′ = 0 a.e. (`thm-jump-derivative-zero`, `thm-ftc-lebesgue` 1). F_s increasing: for x < y, F_c(y) − F_c(x) ≥ ∫_x^y F_c′ = ∫_x^y F′ (`thm-integral-derivative-le` applied to the continuous part F_c = F − F_j on [x, y]). Uniqueness: a continuous function that is both AC and singular is constant (`thm-ac-zero-derivative-constant`); a jump function that is continuous is constant.
  - For BV: apply to the Jordan parts; uniqueness up to constants still holds.
- **The function–measure dictionary.** For F increasing and right-continuous on ℝ (normalize at a jump: replace F(x) by F(x+)), μ_F((x, y]) = F(y) − F(x) is the Lebesgue–Stieltjes measure (MT.3).
  - **`thm-ac-iff-measure-ac`.** μ_F(A) = ∫_A F′ dm for all Borel A ⇔ F is locally AC. Route: ⇐ both sides agree on intervals (FTC) and are finite on bounded sets, so agree on Borel sets by MT.3's uniqueness clause. ⇒ F(y) − F(x) = ∫_x^y F′ gives AC by absolute continuity of the integral.
  - **`thm-singular-iff-concentrated`.** F continuous, increasing; F′ = 0 a.e. ⇔ μ_F is concentrated on a Lebesgue null set.
    - ⇒ Let Z be the set of points where F′ exists and equals 0 (full measure). `lem-image-measure-integral` gives m*(F(Z)) = 0. Cover F(Z) by open intervals Jᵢ with Σ\|Jᵢ\| < ε; each F⁻¹(Jᵢ) is an interval (F continuous, increasing) and μ_F(F⁻¹(Jᵢ)) ≤ \|Jᵢ\| (μ_F of an interval I is the length of F(I), since F has no jumps); so μ_F(Z) ≤ ε. Hence μ_F lives on the null set ℝ \ Z.
    - ⇐ By `thm-integral-derivative-le` on each [x, y], ∫_x^y F′ ≤ μ_F((x, y]); the difference is a nonnegative premeasure on half-open intervals, so ∫_A F′ ≤ μ_F(A) for Borel A (MT.3). With μ_F(ℝ \ N) = 0, ∫_{ℝ\N} F′ = 0, so F′ = 0 a.e.
  - **The Cantor measure** μ_c: continuous (no atoms), concentrated on C, so neither AC nor atomic.
- **Hook to MT.11 (stated in a remark, not proved):** for every locally finite Borel measure μ on ℝ, μ = (AC part) + (atomic part) + (singular continuous part), with the AC part having density F′. MT.11 proves the measure-theoretic version (Lebesgue decomposition, Radon–Nikodym) on any σ-finite space; this section is its one-dimensional, by-hand instance.
- **Warning.** "Singular" depends on the convention: some books require continuity, some don't. State the book's convention (`def-singular-function` includes jump functions; "singular continuous" excludes them) and keep to it.
- **Quick check.** Decompose F(x) = x + 1_{[1/2,1]}(x) + c(x) on [0,1]. (F_ac = x, F_j = 1_{[1/2,1]}, F_s = c.)

## 06-calculus-with-ac.md — Calculus with absolutely continuous functions
