**Named moves** (in `index.md`):

- **Fatou on the non-negative remainder.** To prove a limit of integrals, find a non-negative quantity (2g − |fₙ − f|, or g ± fₙ) and apply Fatou to it, then cancel a finite integral. (DCT and its relatives.)

## 01-simple-functions.md — Partitioning the range: simple functions

Budget: ≤ 3,500 main-line words.

- **Hook (failure-motivated).** A Riemann sum for 1_ℚ on [0, 1] can be made 0 or 1 by choosing tags; no partition fixes this. A "Lebesgue sum" Σ cᵢ m({f = cᵢ}) for a function with finitely many values has no such ambiguity: for 1_ℚ it is 1 · m(ℚ ∩ [0, 1]) + 0 · m([0, 1] ∖ ℚ) = 0.
- **`def-simple-function`**: a measurable φ: ℝᵈ → [0, ∞) (this section: non-negative) with finitely many values; canonical form φ = Σᵢ aᵢ 1_{Aᵢ}, aᵢ the distinct values, Aᵢ = φ⁻¹(aᵢ). Examples: 1_ℚ; ⌊x⌋ 1_{[0, 5)}; a step function on boxes; degenerate: 0. Non-example by minimal change: ⌊x⌋ on [0, ∞) (infinitely many values). Warning: a simple function need not be a step function (1_ℚ, 1 of the Cantor set).
- **`def-simple-integral`**: ∫ φ ≔ Σ aᵢ m(Aᵢ) ∈ [0, ∞], with 0 · ∞ = 0. Why the convention: 0 · 1_ℝ must have integral 0.
- **`lem-simple-integral-representation`**: if φ = Σⱼ bⱼ 1_{Bⱼ} with bⱼ ≥ 0 and Bⱼ measurable (any representation, sets overlapping allowed), then ∫ φ = Σ bⱼ m(Bⱼ).
  - Scratch Work (first appearance of **common refinement**): draw two overlapping sets; the atoms are the 2ⁿ intersections B₁^{±} ∩ ⋯ ∩ Bₙ^{±}; on each atom φ is constant; both sums regroup into one sum over atoms by finite additivity of m.
  - Proof: write both sides as sums over atoms, cite finite additivity (MT.1).
- **`thm-simple-integral-properties`**: for non-negative simple φ, ψ and c ≥ 0: ∫(cφ) = c∫φ; ∫(φ + ψ) = ∫φ + ∫ψ; φ ≤ ψ ⇒ ∫φ ≤ ∫ψ. Proof: concatenate representations and apply the lemma; monotonicity: ψ = φ + (ψ − φ) with ψ − φ simple and non-negative.
- **`lem-simple-set-function`**: for non-negative simple φ, ν(E) ≔ ∫_E φ = Σ aᵢ m(Aᵢ ∩ E) is countably additive on measurable sets; in particular, Eₙ ↑ E ⇒ ∫_{Eₙ} φ ↑ ∫_E φ. Proof: each term is countably additive by MT.1; a finite sum of countably additive set functions is countably additive (non-negative terms, so sums may be rearranged). This lemma is the only place §2's MCT touches m; say so (it feeds the §3 box).
- **Worked example.** ∫ of φ = 3 · 1_{[0,2]} + 1_{[1,4]} on ℝ two ways: by the given representation 3 · 2 + 1 · 3 = 9; in canonical form (3 on [0,1), 4 on [1,2], 1 on (2,4]) 3 + 4 + 2 = 9.
- **Quick check.** ∫ 1_ℚ = ? and ∫ 1_{ℝ∖ℚ} over [0, 1] = ? Answer: 0 and 1, by m(ℚ) = 0.
- **Exercises.**
  - **A1.** Compute ∫ ⌊x⌋ 1_{[0,5)} (answer 10) and ∫ (1_{[0,3]} − 1_{[1,2]}) (answer 2; note the function is simple and non-negative even though written with a minus).
  - **A2.** True or false: (a) 1_ℚ is simple (true); (b) every step function on [a, b] is simple (true); (c) every simple function on [a, b] is a.e. equal to a step function (false: 1 of a fat Cantor set, cited from HA.9 in the solution).
  - **B1.** Prove ∫(φ + ψ) = ∫φ + ∫ψ directly from canonical forms (atoms Aᵢ ∩ Bⱼ).
  - **B2.** For a non-negative simple φ, show ∫φ = 0 iff m({φ > 0}) = 0, and ∫φ < ∞ iff m({φ > 0}) < ∞.
  - **C1** (preview of the shrink-then-exhaust move, hint ladder of two rungs). If φₙ, φ are non-negative simple, φₙ ≤ φₙ₊₁ and limₙ φₙ = φ pointwise, then ∫φₙ → ∫φ. Intended route: for t ∈ (0, 1), Eₙ = {φₙ ≥ tφ} ↑ ℝᵈ, then `lem-simple-set-function`. Solution notes that §2 does exactly this with φ replaced by an arbitrary measurable limit.

## 02-nonnegative-functions.md — The integral of a non-negative function, and the monotone convergence theorem

Budget: ≤ 4,500 main-line words.

- **Hook (failure-motivated definition).** Try "∫ f ≔ lim ∫ φₖ for the simple approximations φₖ ↑ f of MT.1". It is not yet clear that the limit does not depend on the chosen sequence. A supremum has no such problem; the price is that limits must now be proved, which is what MCT does.
- **`def-integral-nonnegative`** (major notion: full explain template): for measurable f: ℝᵈ → [0, ∞], ∫ f ≔ sup{∫ φ : φ simple, 0 ≤ φ ≤ f} ∈ [0, ∞]. Slogan: *the integral is the best lower estimate by functions with finitely many values.* Consistency: for simple f it agrees with `def-simple-integral` (monotonicity from §1). Examples: f = x^{-1/2} on (0, 1) (∫ = 2, computed only after §4; here only "finite, see §4"); 1_ℚ · ∞ (∫ = 0); e^{-|x|} on ℝ. Degenerate: f ≡ ∞ on a null set. Non-example: f(x) = x on ℝ is not non-negative; f = 1_V for a non-measurable V (MT.1) is not measurable, and the definition does not apply. Why this definition: lower estimates only, because upper estimates by simple functions fail for unbounded f. "Alternatively," one sentence: Pugh defines ∫ f as the measure of the region under the graph in ℝᵈ⁺¹; MT.4 shows the two agree.
- **`thm-integral-nonneg-basic`**: (a) 0 ≤ f ≤ g ⇒ ∫f ≤ ∫g; (b) ∫(cf) = c∫f for c ∈ [0, ∞); (c) ∫_E f ≤ ∫_F f for E ⊆ F. Proof from the sup.
- **`thm-markov-inequality`** (Markov): for c ∈ (0, ∞), m({f ≥ c}) ≤ (1/c) ∫ f. Proof: c 1_{f ≥ c} ≤ f is simple.
- **`cor-integral-zero-ae`**: ∫ f = 0 ⇔ f = 0 a.e.; ∫ f < ∞ ⇒ f < ∞ a.e.; f = g a.e. ⇒ ∫f = ∫g. Proofs: {f > 0} = ⋃ₙ {f ≥ 1/n}; m({f = ∞}) ≤ m({f ≥ n}) ≤ ∫f / n; for the third, compare simple minorants off the null set N (φ 1_{N^c} is simple and ≤ g).
- **Try it first, then `thm-monotone-convergence-integral`** [Monotone convergence theorem]: if fₙ: ℝᵈ → [0, ∞] are measurable and fₙ ≤ fₙ₊₁ for every n, and f = limₙ fₙ, then ∫ f = limₙ ∫ fₙ. (Remark after: holds if the hypotheses hold a.e., by `cor-integral-zero-ae`.)
  - **Scratch Work** (full; first appearance of **shrink, then exhaust**). The easy half: fₙ ≤ f gives lim ∫fₙ ≤ ∫f. The other half: it suffices to beat ∫φ for each simple φ ≤ f. First attempt with Eₙ = {fₙ ≥ φ}: show it fails on fₙ = (1 − 1/n) 1_{[0,1]}, φ = 1_{[0,1]} (every Eₙ ∩ [0,1] is empty). Repair: aim at tφ, t < 1; then x with φ(x) > 0 has f(x) ≥ φ(x) > tφ(x), so x ∈ Eₙ eventually; x with φ(x) = 0 is in every Eₙ. So Eₙ ↑ ℝᵈ, and `lem-simple-set-function` gives ∫_{Eₙ} tφ → t∫φ.
  - **Proof** (separate block, typeset register): as above; finally let t ↑ 1 and take the sup over φ. Self-explanation prompt: "*Self-explain why φ must take finite values for the step f(x) > tφ(x).*"
  - **Hypotheses.** Monotonicity cannot be dropped (escaping-mass examples below); non-negativity cannot be dropped: fₙ = −1_{[n, ∞)} increases to 0, ∫fₙ = −∞ for every n (stated after §3 defines signed integrals; here only the decreasing form: 1_{[n,∞)} ↓ 0 with ∫ = ∞).
- **`cor-integral-nonneg-additive`**: ∫(f + g) = ∫f + ∫g for measurable f, g ≥ 0. Proof: simple φₖ ↑ f, ψₖ ↑ g (MT.1), φₖ + ψₖ ↑ f + g, `thm-simple-integral-properties` and MCT three times.
- **`cor-series-nonneg-termwise`**: ∫ Σₙ gₙ = Σₙ ∫ gₙ for measurable gₙ ≥ 0. Worked example here: Σ 2⁻ⁿ 1_{[n, n+1)} (∫ = 1). The Riemann-flavoured example ∫₀^∞ x/(eˣ − 1) dx = Σ 1/k² is placed at the end of §4, where improper Riemann integrals are known to agree with Lebesgue integrals.
- **`cor-integral-countably-additive-set`**: for f ≥ 0 measurable, E ↦ ∫_E f is countably additive (a measure, in MT.3's word). Proof: `cor-series-nonneg-termwise` with gₙ = f 1_{Eₙ}.
- **`thm-fatou-lemma`** [Fatou's lemma]: for measurable fₙ ≥ 0, ∫ liminf fₙ ≤ liminf ∫ fₙ. Idea only (no Scratch Work: MCT again): gₙ = inf_{k ≥ n} f_k increases to liminf fₙ and gₙ ≤ f_k for k ≥ n.
- **Weird examples, first instalment** (`exm-escaping-mass`): three sequences of non-negative functions on ℝ, each → 0 pointwise with ∫ = 1 for every n: the spike n 1_{(0, 1/n)} (mass escapes vertically), the travelling block 1_{[n, n+1]} (horizontally), the flattening block (1/n) 1_{[0, n]} (it spreads out; the convergence is even uniform). Each makes Fatou strict. The table at the end of §6 collects them.
- **Warning.** "MCT also works for decreasing sequences": 1_{[n, ∞)}. The fix (∫ f₁ < ∞) is B2.
- **Quick check.** For fₙ = 1_{[n, n+1]}, compute both sides of Fatou. Answer: 0 ≤ 1.
- **Exercises.**
  - **A1** (comprehension, key proof MCT). (a) Which line uses t < 1, and what goes wrong with t = 1 on fₙ = (1 − 1/n) 1_{[0,1]}? (b) Where is `lem-simple-set-function` used? (c) The proof's idea in two sentences. Answers: (a) Eₙ ↑ ℝᵈ fails, every Eₙ misses [0, 1]; (b) for ∫_{Eₙ} φ → ∫ φ; (c) shrink, then exhaust.
  - **A2.** Compute limₙ ∫ 1_{[−n, n]}(x) e^{−|x|} dx by MCT, given ∫_{[−n,n]} e^{−|x|} = 2(1 − e^{−n}) (answer 2).
  - **B1.** For measurable f ≥ 0 with ∫ f < ∞, show c · m({f ≥ c}) → 0 as c → ∞. Route: c 1_{f ≥ c} ≤ f 1_{f ≥ c}, and ∫ f 1_{f ≥ c} = ∫ f − ∫ f 1_{f < c} → 0 by MCT (f 1_{f < c} ↑ f as c ↑ ∞, along any increasing sequence cₖ → ∞) and `cor-integral-nonneg-additive` with finiteness. Markov alone gives only c · m({f ≥ c}) ≤ ∫ f; the exercise improves it to o(1).
  - **B2.** If fₙ ↓ f ≥ 0 and ∫ f₁ < ∞, then ∫ fₙ → ∫ f. Route: MCT on f₁ − fₙ ↑ f₁ − f, `cor-integral-nonneg-additive` and finiteness to cancel. Counterexample without ∫ f₁ < ∞: 1_{[n, ∞)}.
  - **C1** (find the error, **true** conclusion). A "proof" of `cor-integral-nonneg-additive` directly from the sup: "given simple φ ≤ f + g, write φ = φ₁ + φ₂ with φ₁ ≤ f, φ₂ ≤ g simple; then ∫φ ≤ ∫f + ∫g". Solution: the conclusion is true; the decomposition step is illegal. Counterexample to the step: on [0, 1], f(x) = x, g(x) = 1 − x, φ = 1_{[0,1]}; φ₂ ≤ g forces φ₁ ≥ x, and φ₁ ≤ f forces φ₁ = x on [0, 1], which is not simple.

Route: ⌊f⌋ = Σ_k 1_{f ≥ k} ≤ f ≤ ⌊f⌋ + 1_{f > 0}, `cor-series-nonneg-termwise`. (Hint ladder: first rung "write ⌊f⌋ as a sum of indicators".)

## 03-integrable-functions.md — Integrable functions and the dominated convergence theorem

Budget: ≤ 4,500 main-line words.

- **Hook (failure-motivated definition).** For f taking both signs, "sup over simple minorants" makes no sense (no non-negative minorant). Splitting f = f⁺ − f⁻ and subtracting works unless both integrals are ∞; the example (sin x)/x on (0, ∞) (§4) has both infinite, so some restriction is forced.
- **`def-lebesgue-integrable`** (major notion): measurable f: ℝᵈ → ℝ (or [−∞, ∞]) is **integrable** if ∫|f| < ∞; then ∫ f ≔ ∫ f⁺ − ∫ f⁻. Complex f = u + iv: integrable if ∫|f| < ∞, ∫ f ≔ ∫u + i∫v. Paraphrase; examples (e^{−|x|} sin x; 1_{[0,1]} − 1_{[1,3]}, ∫ = −1; degenerate: functions = 0 a.e.); non-example by minimal change: x^{−1/2} on (0, 1) is integrable, x^{−1} is not (∫ = ∞, from §4). Why ∫|f| < ∞ and not "∫f⁺ or ∫f⁻ finite": linearity would fail (∞ − ∞). Warning: an integrable function may take the value ±∞, but only on a null set (`cor-integral-zero-ae`), so f + g is defined a.e.; "f + g" means its class off that set.
- **`thm-integral-linear`**: the integrable functions form a vector space and ∫ is linear on it; f ≤ g a.e. ⇒ ∫f ≤ ∫g. Proof: h = f + g gives h⁺ + f⁻ + g⁻ = h⁻ + f⁺ + g⁺; `cor-integral-nonneg-additive`; all terms finite, so rearrange. Complex scalars: reduce to real and imaginary parts; multiplication by i swaps them.
- **`thm-integral-abs-bound`**: |∫ f| ≤ ∫ |f| for complex integrable f. Idea: choose α with |α| = 1 and α∫f = |∫f|; then |∫f| = ∫ Re(αf) ≤ ∫ |f|.
- **`thm-absolute-continuity-integral`**: for integrable f and ε > 0 there is δ > 0 (depending on ε and f) with ∫_E |f| < ε whenever m(E) < δ. Proof: MCT on min(|f|, N) ↑ |f| gives N with ∫(|f| − min(|f|, N)) < ε/2; δ ≔ ε/(2N). Hook to MT.8 (uniform integrability: δ uniform over a family).
- **`thm-dominated-convergence`** [Dominated convergence theorem]: if fₙ, f: ℝᵈ → ℂ are measurable, fₙ → f a.e., and there is an integrable g with |fₙ| ≤ g a.e. for every n, then f is integrable, ∫ |fₙ − f| → 0, and in particular ∫ fₙ → ∫ f.
  - **Scratch Work** (full; first appearance of **Fatou on the non-negative remainder**). Fatou gives only an inequality, and only for non-negative functions. What is non-negative here? |fₙ − f| ≤ 2g, so hₙ = 2g − |fₙ − f| ≥ 0 and hₙ → 2g. Fatou: ∫2g ≤ liminf ∫hₙ = ∫2g − limsup ∫|fₙ − f|. Now cancel ∫2g, which is legal **because it is finite**. Point at the two uses of g: non-negativity of hₙ and finiteness for the cancellation.
  - **Proof** (separate block). First |f| ≤ g a.e., so f is integrable; then as above.

## 04-riemann-and-lebesgue.md — Riemann versus Lebesgue

Budget: ≤ 4,500 main-line words. First paragraph: this section uses boxes and lengths, so it is specific to ℝᵈ (and mostly to ℝ).

- **Opening frame (spiral).** Recall AN1.8's Darboux sums and AN2.10's Lebesgue criterion in prose; say what changes: "measure zero" is now m(N) = 0, and the criterion can be proved by integrating two functions.
- **`thm-riemann-is-lebesgue`**: if f: [a, b] → ℝ is Riemann integrable, then f is Lebesgue measurable and integrable on [a, b], and ∫_{[a,b]} f dm equals the Riemann integral.
  - Idea (Scratch Work not needed: monotone limits again, but this is the first **two-sided squeeze** of a function between monotone step sequences; give a short Scratch Work anyway, as the template for the criterion): choose nested partitions Pₖ with mesh → 0, U(f, Pₖ) → upper integral, L(f, Pₖ) → lower integral (possible: refine near-optimal partitions by a dyadic one; refinement lowers U and raises L, AN1.8). Step functions ℓₖ ≤ f ≤ uₖ (values at partition points: use f itself; finitely many points per k, a countable null set overall). ℓₖ ↑ ℓ, uₖ ↓ u, all bounded by sup|f|.
  - Proof: ∫ uₖ dm = U(f, Pₖ) (m of an interval is its length, MT.1), `cor-bounded-convergence` gives ∫u = Ū, ∫ℓ = L̲. If f is Riemann integrable, ∫(u − ℓ) = 0, u − ℓ ≥ 0, so u = ℓ a.e. (`cor-integral-zero-ae`), hence f = ℓ a.e.; f is measurable by completeness of m (MT.1), and ∫f = ∫ℓ = Riemann integral.
  - Remark: the same proof works on a box in ℝᵈ with AN3.4's Darboux sums (prose pointer).
- **`lem-envelope-continuity`**: with Pₖ as above and x not a partition point of any Pₖ, f is continuous at x iff u(x) = ℓ(x). Proof: the Pₖ-interval containing x shrinks to x and is a neighbourhood of x; uₖ(x) − ℓₖ(x) is the oscillation of f on it.
- **`thm-lebesgue-criterion-measure`** [Lebesgue's criterion, measure form]: a bounded f: [a, b] → ℝ is Riemann integrable iff m({x : f is discontinuous at x}) = 0. Proof: Ū − L̲ = ∫(u − ℓ) (from the previous proof), = 0 iff u = ℓ a.e. iff (by the lemma, off a countable set) f is continuous a.e. Aftermath: AN2.10 proved this with covers; here it is two integrals and one lemma.
- **`thm-arzela-bounded-convergence`** [Arzelà's bounded convergence theorem, as stated in HA.9]: if fₙ: [a, b] → ℝ are Riemann integrable, |fₙ| ≤ M, fₙ → f pointwise and f is Riemann integrable, then the Riemann integrals converge to that of f. Proof: `thm-riemann-is-lebesgue` and `cor-bounded-convergence`. Remark: without Riemann integrability of f the Riemann integrals still converge, to ∫ f dm (1_ℚ example: 0 → 0). **Pays HA.9's promise.**
- **`thm-improper-absolute-lebesgue`**: if f: [a, ∞) → ℝ is Riemann integrable on every [a, b] and the improper integral of |f| converges, then f ∈ L¹([a, ∞)) and ∫ f dm equals the improper Riemann integral. Proof: MCT on |f| 1_{[a,b]} ↑ |f|, then DCT on f 1_{[a,b]}. Same for (0, 1] with an endpoint singularity (x^{−1/2}: ∫ = 2).
- **`exm-sinc-not-lebesgue`**: (sin x)/x on (0, ∞) has a convergent improper Riemann integral but is not Lebesgue integrable: ∫_{kπ}^{(k+1)π} |sin x|/x dx ≥ 2/((k + 1)π), harmonic series. ∫ f⁺ = ∫ f⁻ = ∞. Remark: the improper integral is to the Lebesgue integral as a conditionally convergent series is to an absolutely convergent one (AN rearrangement theorem, prose).
- **Worked examples moved here from §2–§3:** ∫₀^∞ x/(eˣ − 1) dx = Σ 1/k² (`cor-series-nonneg-termwise` plus `thm-improper-absolute-lebesgue`); `exm-frullani-type`: F(t) = ∫₀^∞ (1 − cos tx) e^{−x}/x dx. F(t) is finite since 0 ≤ (1 − cos tx)/x ≤ min(t²x/2, 2/x); |∂_t| = |sin tx| e^{−x} ≤ e^{−x} for all t; so F′(t) = ∫₀^∞ sin(tx) e^{−x} dx = t/(1 + t²) (integration by parts in the improper Riemann integral, then `thm-improper-absolute-lebesgue`), F(0) = 0, F(t) = ½ ln(1 + t²). Sidecar `verify/ch03/exm-frullani-type.py` checks it numerically.
- **Weird examples, second instalment.** 1_{ℚ∩[0,1]} (Lebesgue, not Riemann; monotone limit of Riemann-integrable functions); Thomae's function (Riemann, discontinuous on a dense null set); 1 of a fat Cantor set C (HA.9: Lebesgue integrable, and **not a.e. equal to any Riemann-integrable function**, C2).

- **Quick check.** Is 1 of the middle-thirds Cantor set Riemann integrable? (Yes: discontinuous exactly on the Cantor set, which is null.)

## 05-the-space-l1.md — The space L¹ and its completeness

Budget: ≤ 4,000 main-line words. First paragraph: like §1–§3, this section uses only the facts in §3's box, and MT.3 cites it.

- **Hook.** HA.9 showed the Riemann-integrable functions are not complete in the mean-square distance; the same is true in the mean distance ∫|f − g| (C2 below). Before asking whether integrable functions do better, a defect: ∫|f − g| = 0 does not force f = g (1_ℚ and 0).
- **`def-l1-space`** (major notion): ℒ¹(E) the integrable functions on measurable E ⊆ ℝᵈ (real or complex), ‖f‖₁ = ∫_E |f|, a seminorm; 𝒩 = {f : f = 0 a.e.}; L¹(E) ≔ ℒ¹(E)/𝒩 with ‖[f]‖₁. Well-definedness: `cor-integral-zero-ae`. Slogan: *L¹ forgets what happens on null sets, and that is exactly what makes ‖·‖₁ a norm.* Examples: [1_{[0,1]}] = [1_{(0,1)}]; ℓ¹ as a cousin (prose; counting measure is MT.3). Warning: "f(0)" is not defined for f ∈ L¹; "f is continuous" means "the class has a continuous member".
- **`thm-l1-normed`**: ‖·‖₁ is a norm on L¹(E); ∫ is a bounded linear functional with |∫ f| ≤ ‖f‖₁ (`thm-integral-abs-bound`).
