## §1. Lebesgue measure under linear maps (`linear-maps`)

**Section question.** If T is a linear map of ℝᵈ, how is m(T(E)) related to m(E)? MT.1 answered this for translations and dilations by hand; the general answer needs an idea, not a computation.

### Definitions

- **Recall box (no new label): pushforward.** MT.3 `def-pushforward` (T_*μ(N) = μ(T^{−1}N)) and `thm-pushforward-integral`. The box says why the chapter works with images through preimages: E ↦ m(T(E)) is (T^{−1})_*m, a measure because preimages commute with all set operations; for a non-injective T, E ↦ m(T(E)) is not additive (x ↦ x² sends (−1, 0) and (0, 1) to the same set), the first sign of W6.

### Statements and proof sketches

- **Recall box: MT.3 `thm-translation-invariant-unique`.** A translation-invariant Borel measure on ℝᵈ, finite on bounded Borel sets, is c·m with c = μ((0, 1]ᵈ). (MT.3 proves it by half-open dyadic cubes and `thm-uniqueness-pi`; MT.3's blueprint names MT.5 as its consumer.) The box adds one sentence: finiteness on (0, 1]ᵈ already gives finiteness on bounded sets, by invariance.
- **exm-counting-invariant** (W1). Counting measure is translation invariant and not a multiple of m; it violates exactly c < ∞. Also μ(E) = ∞ for E ≠ ∅, μ(∅) = 0.
- **Scratch Work (first appearance of "pin it down by invariance"), placed before thm-linear-image-measure, visibly separate from the proof.** Write E ↦ m(T(E)); check it is a measure (T bijective, T^{−1} continuous, so Borel goes to Borel); check translation invariance (T(E + x) = T(E) + Tx: this is where linearity is used, not just continuity); check finiteness on the unit cube (T(cube) is bounded). So m(T(E)) = c(T) m(E) and the whole problem is the single number c(T). Next: c(ST) = c(S)c(T), so it suffices to compute c on generators of GL_d(ℝ), and LA2.7 supplies generators. Then: which generator is not obvious? The shear. *Try it first (ten minutes): show that the shear (x₁, x₂) ↦ (x₁ + a x₂, x₂) preserves the area of [0, 1)². Which tool from MT.4 sees the area of a slanted parallelogram?* The Idea that follows starts from the obstacle: the image is not a box, so a box computation fails; slicing parallel to the x₁-axis turns every slice into a translate of the original slice.
- **thm-linear-image-measure** (key proof 1). Let T: ℝᵈ → ℝᵈ be linear and E ⊆ ℝᵈ Lebesgue measurable. Then T(E) is Lebesgue measurable and m(T(E)) = |det T| m(E).
  *Proof sketch.*
  1. *T not invertible.* T(ℝᵈ) ⊆ H, a subspace of dimension < d. Pick a ≠ 0 with a·x = 0 on H and j with a_j ≠ 0; H lies in the graph x_j = −a_j^{−1} Σ_{i≠j} a_i x_i, a graph of a continuous function over ℝ^{d−1}, which is null by `cor-cavalieri` (MT.4: every section in the x_j-direction is one point). So T(E) is a subset of a null set: measurable (completeness, MT.1) and of measure 0 = |det T| m(E).
  2. *T invertible, Borel E.* μ_T(E) := m(T(E)) is a Borel measure (T is a homeomorphism), translation invariant (linearity), finite on (0, 1]ᵈ (bounded image). By MT.3 `thm-translation-invariant-unique`, m(T(E)) = c(T) m(E), and c(ST) = c(S) c(T).
  3. *Generators.* Scaling one coordinate by λ ≠ 0: a box goes to a box, c = |λ|. Swapping two coordinates: a box goes to a box with the same side lengths, c = 1. Shear x_i ↦ x_i + a x_j (i ≠ j): by `cor-cavalieri` / `thm-tonelli`, m(S(Q)) = ∫ m₁(S(Q)ˣ) dx over the other coordinates, and each section of S(Q) in the x_i-direction is a translate of the corresponding section of Q, so c = 1 = |det S|. By LA2.7 every invertible T is a product of these, and both c and |det| are multiplicative.
  4. *Lebesgue measurable E.* E = B ∪ N with B Borel and N ⊆ N′, N′ Borel null (MT.1). T(N) ⊆ T(N′), which is Borel with measure |det T|·0. So T(E) is measurable and m(T(E)) = m(T(B)) = |det T| m(E).
- **cor-linear-change-integral.** For invertible T and measurable f ≥ 0 (or f ∈ L¹): f∘T is measurable and ∫ f(Tx) dx = |det T|^{−1} ∫ f(y) dy. Special cases: ∫ f(λx) dx = |λ|^{−d} ∫ f; ∫ f(x + a) dx = ∫ f. *Sketch:* indicators by the theorem applied to T^{−1}, then simple functions and MCT (or MT.3 `thm-pushforward-integral` with Φ = T).
- **cor-orthogonal-invariance.** If U is orthogonal (UᵀU = I), then m(U(E)) = m(E); hence m(B(x, r)) = rᵈ v_d where v_d := m(B(0, 1)), and rigid motions preserve m. *Sketch:* det(Uᵀ) det(U) = 1 and det Uᵀ = det U (LA2.7) give |det U| = 1. Remark: a second proof avoids determinants: U(B₁) = B₁ and 0 < m(B₁) < ∞ force c(U) = 1. Both are given; the second shows the invariance move again.

### Worked examples

- **exm-parallelepiped.** The parallelepiped spanned by v₁, …, v_d has measure |det[v₁ ⋯ v_d]|. In ℝ³ with v₁ = (1, 1, 0), v₂ = (0, 1, 1), v₃ = (1, 0, 1): det = 2, volume 2.
- **exm-simplex-volume.** The standard simplex Δ_d = {x_i ≥ 0, Σ x_i ≤ 1} has m(Δ_d) = 1/d!, by Tonelli and induction (the section at height t is (1 − t)Δ_{d−1}, of measure (1 − t)^{d−1}/(d − 1)! by dilation). Hence the simplex with vertices p₀, …, p_d has measure |det[p₁ − p₀ ⋯ p_d − p₀]|/d!.
- **exm-ellipse-area.** {x²/a² + y²/b² < 1} = T(B₁) with T = diag(a, b): area πab, granted v₂ = π (which §4 or §5 proves; here quoted as a forward pointer and used only in an example, not a proof).

### Quick checks

1. In ℝ³, m(2E) = 8 m(E). Why 8 and not 2?
2. T(x, y) = (y, x): what is det T, and what is m(T(E))? (det = −1; m(E). The absolute value matters.)
3. Is m(T(E)) = m(E) for every T with det T = 1? (Yes, though T need not preserve distances: the shear.)

### Exercises

(d) In step 2 of the proof, where is finiteness of m(T((0, 1]ᵈ)) used, and which example shows it cannot be dropped from MT.3 `thm-translation-invariant-unique`? **C1** (find the error; true conclusion). "Claim: an orthogonal U preserves m. Proof: by step 2 of thm-linear-image-measure, m(U(E)) = c m(E). U maps the unit cube (0, 1]ᵈ onto a unit cube, so c = m(U((0, 1]ᵈ)) = 1." Is the claim true? Does the argument prove it? *Answer:* the claim is true (cor-orthogonal-invariance). ## §2. Lipschitz maps, null sets, and where the Jacobian vanishes (`lipschitz-and-null-sets`)

**Section question.** The change-of-variables formula will need G(E) to be measurable whenever E is. Which maps send measurable sets to measurable sets? The first answer people try, "continuous bijections", is wrong, and the reason is the Cantor set.

### Opening failure (W2, W3, motivating the hypothesis)

- **exm-cantor-homeomorphism** (W2). ψ(x) = x + c(x) on [0, 1], c the Cantor function (AN2.15; MT.1 if it already uses it, then only this reading). ψ is a strictly increasing homeomorphism onto [0, 2]; it maps each removed middle interval onto an interval of the same length, so ψ([0, 1] \ C) has measure 1 and ψ(C) has measure 1. A non-measurable W ⊆ ψ(C) (MT.1: every set of positive measure contains one) has ψ^{−1}(W) ⊆ C null, hence measurable: ψ^{−1}, a homeomorphism, maps a measurable set onto a non-measurable one. Lesson: what is needed is control of how much G stretches, i.e. Lipschitz.
- **exm-projection-nonmeasurable** (W3). V ⊆ [0, 1] a Vitali set; V × {0} is null in ℝ², hence measurable; π(x, y) = x is linear and 1-Lipschitz and π(V × {0}) = V is not measurable. Lesson: equal dimensions are needed in thm-lipschitz-null.

### Statements and proof sketches

- **def-locally-lipschitz.** G: Ω → ℝᵈ (Ω ⊆ ℝᵏ open) is locally Lipschitz if every point has a neighbourhood on which ‖G(x) − G(y)‖ ≤ L‖x − y‖. Every C¹ map is locally Lipschitz (AN3.1, the one-variable MVT applied to each component along segments in a convex neighbourhood).
- **lem-lipschitz-cube.** If ‖G(x) − G(y)‖_∞ ≤ L‖x − y‖_∞ for x, y ∈ A, then for every cube R (sup-norm ball) G(A ∩ R) lies in a cube of side L·side(R). One line.
- **thm-lipschitz-null.** Let Ω ⊆ ℝᵈ be open and G: Ω → ℝᵈ locally Lipschitz. (a) If N ⊆ Ω is null, G(N) is null. (b) If E ⊆ Ω is measurable, G(E) is measurable.
  *Proof sketch.* (a) Ω is a countable union of compact cubes Q_k on each of which G is L_k-Lipschitz in the sup norm (cover by Lipschitz neighbourhoods, Lindelöf via dyadic cubes). Cover N ∩ Q_k by cubes R_j with Σ m(R_j) < ε; by lem-lipschitz-cube, G(N ∩ Q_k ∩ R_j) lies in a cube of measure L_kᵈ m(R_j); so m*(G(N ∩ Q_k)) ≤ L_kᵈ ε. (b) E = F ∪ N with F a countable union of compact sets and N null (MT.1 `thm-regularity`, F_σ form; compacts by intersecting with closed cubes). G(F) is a countable union of compact sets (continuity), so Borel; G(N) is null by (a).
- **prp-lower-dim-image-null.** If U ⊆ ℝᵏ is open, k < d, and G: U → ℝᵈ is locally Lipschitz, then G(U) is null. *Sketch:* G̃(x, y) = G(x) on U × ℝ^{d−k} is locally Lipschitz and G(U) = G̃(U × {0}), the image of a null set. (So C¹ curves in ℝ², C¹ surfaces in ℝ³ and, for MT.6, C¹ hypersurfaces are null.)
- **rem-peano** (W4). The Peano curve (AN2.15) is continuous, not Lipschitz (it is Hölder with exponent 1/2), and its image is the whole square. Prose only.
- **Scratch Work (first appearance of "linearize on small cubes"), before thm-mini-sard.** Fix a cube of side s at a point x where det DG(x) = 0. To first order G(P) ≈ G(x) + DG(x)(P − x), and DG(x)(P − x) lies in a proper subspace W: a flat piece of diameter about Ms. The error is at most εs. So G(P) sits in a slab of thickness about εs around a (d − 1)-dimensional disc of radius about Ms; volume about M^{d−1} ε sᵈ. There are (ℓ/s)ᵈ subcubes, so the total is about M^{d−1} ε ℓᵈ, and ε was arbitrary. The proof below fixes the constants; the Scratch Work shows only where each factor comes from.
- **thm-mini-sard.** Let Ω ⊆ ℝᵈ be open, G: Ω → ℝᵈ C¹, and Z = {x ∈ Ω : det DG(x) = 0}. Then m(G(Z)) = 0.
  *Proof sketch (worked in full in the text: faded triple, item 1).* It suffices to treat Z ∩ Q for a compact cube Q ⊆ Ω of side ℓ. Let M = sup_Q ‖DG‖. Given ε ∈ (0, 1), uniform continuity of DG on Q gives δ with ‖G(y) − G(x) − DG(x)(y − x)‖ ≤ ε‖y − x‖ for x, y ∈ Q, ‖y − x‖ < δ (one-variable MVT along the segment). Cut Q into Nᵈ subcubes of side s = ℓ/N with √d s < δ. If a subcube P meets Z at x, then DG(x)(P − x) ⊆ W ∩ B(0, M√d s) with W = range DG(x) ≠ ℝᵈ, so G(P) ⊆ G(x) + {w + e : w ∈ W, |w| ≤ M√d s, |e| ≤ ε√d s}. Choose a unit vector a ⊥ W and j with |a_j| ≥ 1/√d. The set lies in {y : |a·(y − G(x))| ≤ ε√d s, ‖y − G(x)‖_∞ ≤ (M + 1)√d s}; for fixed other coordinates its y_j-section is an interval of length ≤ 2ε√d s/|a_j| ≤ 2dεs, so by Tonelli m(G(P)) ≤ (2(M + 1)√d s)^{d−1}·2dεs = C_{d,M} ε sᵈ. Summing over at most Nᵈ subcubes: m*(G(Z ∩ Q)) ≤ C_{d,M} ε ℓᵈ. (No rotation is used, so §1's orthogonal invariance is not needed; S2a item 7 checks the constants.)

### Worked examples

## §3. The change-of-variables theorem (`change-of-variables`)

**Section question.** AN3.4 §6 stated ∫ f = ∫ (f∘G)|det DG| for Riemann integrals over nice sets, and AM.1 proved it with Riemann tools. Here the statement is wanted for every measurable set and every nonnegative measurable function, with unbounded sets and unbounded integrands allowed, and the proof uses the measure theory of MT.1–MT.4 rather than partitions of unity.

### Definitions

- J_G := |det DG| (Jacobian). Recall from AN3.2: a C¹ diffeomorphism G: Ω → Ω′ between open sets is a C¹ bijection with C¹ inverse; equivalently (inverse function theorem) a C¹ bijection with det DG ≠ 0 on Ω.
- **def-admissible-change** (failure-motivated, after the theorem). Motivation: polar coordinates G(r, θ) = (r cos θ, r sin θ) are *not* a diffeomorphism from any open set onto ℝ²: at r = 0 injectivity and invertibility of DG both fail, and θ ↦ e^{iθ} cannot be injective on an open set covering the circle. The theorem as stated therefore does not apply, although the formula ought to ignore null sets. Definition: a C¹ map G: Ω → ℝᵈ is an admissible change of variables from Ω onto Ω′ (both open) if there are open Ω₀ ⊆ Ω and Ω₀′ ⊆ Ω′ with Ω \ Ω₀ and Ω′ \ Ω₀′ null and G|Ω₀: Ω₀ → Ω₀′ a C¹ diffeomorphism.

### Statements and proof sketches

- **lem-cube-estimate.** Let G: Ω → ℝᵈ be C¹ with det DG ≠ 0 on Ω and Q ⊆ Ω a compact cube. Then m(G(Q)) ≤ ∫_Q J_G dm.
  *Proof sketch (linearize on small cubes, second use).* (i) For a cube Q′ ⊆ Q with centre a and T ∈ GL_d: componentwise MVT gives ‖T^{−1}G(x) − T^{−1}G(a)‖_∞ ≤ (sup_{y∈Q′} ‖T^{−1}DG(y)‖_{∞→∞}) ‖x − a‖_∞, so by lem-lipschitz-cube and thm-linear-image-measure, m(G(Q′)) ≤ |det T| (sup_{Q′} ‖T^{−1}DG‖)ᵈ m(Q′). (ii) (x, y) ↦ DG(x)^{−1}DG(y) is uniformly continuous on Q × Q and equals I on the diagonal; given ε, cut Q into subcubes Q_i with centres x_i, small enough that sup_{Q_i} ‖DG(x_i)^{−1}DG‖ ≤ 1 + ε. Take T = DG(x_i): m(G(Q)) ≤ Σ m(G(Q_i)) ≤ (1 + ε)ᵈ Σ J_G(x_i) m(Q_i). (iii) J_G is uniformly continuous on Q, so for fine enough subdivisions Σ J_G(x_i) m(Q_i) ≤ ∫_Q J_G + ε m(Q). Let ε → 0.
- **Scratch Work (first appearance of "one inequality, then the inverse"), before the theorem.** The cube estimate gives only ≤ and only for cubes. Two questions: how to pass from cubes to all measurable sets (cubes → open sets → G_δ sets → measurable sets, which is MT.1's regularity used one more time), and how to get ≥. For ≥, notice the cube estimate holds for *every* diffeomorphism, in particular G^{−1}; the chain rule makes J_{G^{−1}}(G(x)) J_G(x) = 1, so the inequality for G^{−1} applied to the right function is the reverse inequality for G. *Try it first (ten minutes): assume ∫_{G(Ω)} f ≤ ∫_Ω (f∘G)J_G for all diffeomorphisms G and all f ≥ 0; prove equality.* The Idea in the text starts from the obstacle: applying the inequality to G^{−1} with f itself gives an inequality in the wrong variables; the right input is (f∘G)J_G.
- **thm-change-of-variables** (key proof 2; registry label, statements.yaml A1/R2). Let Ω, Ω′ ⊆ ℝᵈ be open and G: Ω → Ω′ a C¹ diffeomorphism. Then:
  (a) for every Lebesgue measurable E ⊆ Ω, G(E) is measurable and m(G(E)) = ∫_E J_G dm;
  (b) for every Lebesgue measurable f: Ω′ → [0, ∞], f∘G is measurable and ∫_{Ω′} f dm = ∫_Ω (f∘G) J_G dm;
  (c) a measurable f: Ω′ → ℂ is in L¹(Ω′) iff (f∘G)J_G ∈ L¹(Ω), and then (b) holds.
  *Proof sketch.*
  1. *Cubes:* lem-cube-estimate.
  2. *Open sets:* an open U ⊆ Ω is a countable union of almost disjoint closed cubes (MT.1 `thm-open-set-cubes`); their boundaries are null and so are their images (thm-lipschitz-null). So m(G(U)) ≤ Σ_k m(G(Q_k)) ≤ Σ_k ∫_{Q_k} J_G = ∫_U J_G.
  3. *Measurable sets:* first E ⊆ V with V open, V̄ compact ⊆ Ω (so J_G is bounded on V). By MT.1 `thm-outer-regularity` choose open U_n with E ⊆ U_n ⊆ V, U_n decreasing, m(U_n \ E) → 0. G(E) is measurable (thm-lipschitz-null). m(G(E)) ≤ m(G(∩U_n)) = lim m(G(U_n)) ≤ lim ∫_{U_n} J_G = ∫_E J_G (continuity from above: m(G(U₁)) ≤ ∫_{U₁} J_G < ∞; DCT or continuity of the finite measure J_G dm). General E: Ω is a countable disjoint union of Borel pieces each inside such a V; add.
  4. *Functions, one inequality:* (a)'s inequality for E = G^{−1}(F) reads ∫_{Ω′} χ_F ≤ ∫_Ω (χ_F∘G) J_G. f∘G is measurable because {f∘G > t} = G^{−1}({f > t}) and G^{−1} sends measurable sets to measurable sets (thm-lipschitz-null applied to G^{−1}). Linearity and MCT give (★) ∫_{Ω′} f ≤ ∫_Ω (f∘G) J_G for all measurable f ≥ 0.
  5. *The inverse:* apply (★) to H = G^{−1}: Ω′ → Ω and g = (f∘G) J_G on Ω: ∫_Ω (f∘G)J_G ≤ ∫_{Ω′} (f∘G∘H)(J_G∘H) J_H = ∫_{Ω′} f, since J_G(H(y)) J_H(y) = |det(DG(H(y)) DH(y))| = |det I| = 1 by the chain rule and LA2.7. So (b) holds with equality; (a) is (b) for f = χ_{G(E)}.
  6. *L¹:* apply (b) to |f|, then to the positive and negative parts of Re f and Im f.
- **cor-change-of-variables-admissible.** If G is an admissible change of variables from Ω onto Ω′, then ∫_{Ω′} f = ∫_Ω (f∘G)J_G for f ≥ 0 measurable on Ω′ (and in the L¹ sense). *Sketch:* apply the theorem on Ω₀ → Ω₀′; the discarded sets are null on both sides (on the Ω side the integrand (f∘G)J_G vanishes a.e. off Ω₀ in the sense that Ω \ Ω₀ is null).
- **cor-change-of-variables-injective.** Let G: Ω → ℝᵈ be C¹ and injective (no hypothesis on det DG). Then G(Ω) is measurable and ∫_{G(Ω)} f = ∫_Ω (f∘G)J_G for f ≥ 0 measurable. *Sketch:* Z = {J_G = 0} is closed; on the open set Ω \ Z, G is an injective local diffeomorphism, so G(Ω \ Z) is open and G: Ω \ Z → G(Ω \ Z) is a C¹ diffeomorphism (AN3.2: the global inverse agrees locally with the C¹ local inverses). G(Z) is null (thm-mini-sard) and J_G = 0 on Z. Apply the theorem. Example W7: x ↦ x³.
- **cor-riemann-change-of-variables** (pays AN3.4 §6 a second time; AM.1 paid it first). The statement of AN3.4 §6 (G a C¹ diffeomorphism Ω → Ω′, f Riemann integrable on a Jordan-measurable compact set K′ ⊆ Ω′, K = G^{−1}(K′)) follows: both sides are Lebesgue integrals equal to the Riemann ones (MT.2 `thm-riemann-is-lebesgue`, in its ℝⁿ form; S2a item 18), since (f∘G)J_G is bounded on K and continuous off G^{−1}(discontinuities of f) ∪ G^{−1}(∂K′), which is null by thm-lipschitz-null for G^{−1}, and K is Jordan measurable because ∂K = G^{−1}(∂K′). Remark comparing routes: AM.1 used partitions of unity and induction on dimension; here the work moved into MT.1's regularity and the cube estimate.

## §4. Polar coordinates (`polar-coordinates`)

**Section question.** Radial integrals ∫ g(|x|) dx and the ball volume should reduce to one-variable integrals. In ℝ² and ℝ³ the classical substitutions do it (cor-change-of-variables-admissible). In ℝᵈ, angle coordinates become unwieldy; what is wanted is a measure σ on the sphere with dm = r^{d−1} dr dσ, and the problem is to define σ.

### Failure-motivated definition of σ

Three attempts, in the text in this order:
1. *Restrict m to S^{d−1}.* S^{d−1} ⊆ B(0, 1 + ε) \ B(0, 1 − ε), of measure v_d((1 + ε)ᵈ − (1 − ε)ᵈ) → 0: the sphere is null, so this gives 0.
2. *Parametrize by angles and take the Jacobian.* Works for d = 2, 3 (the text does both at the end of the section) but the formulas grow with d and depend on the chart; proving chart-independence needs MT.6.
3. *Thicken.* Measure the shell piece {rω : 1 < r < 1 + ε, ω ∈ A} and divide by ε. By dilation (§1) the shell piece over A between radii a < b has measure (bᵈ − aᵈ) m(C(A)) with C(A) the cone piece below; the limit is d·m(C(A)). This suggests the definition, which is exact rather than a limit.

- **def-sphere-measure.** For Borel A ⊆ S^{d−1}, let C(A) = {rω : 0 < r ≤ 1, ω ∈ A} and σ(A) := d·m(C(A)). Set σ_{d−1} := σ(S^{d−1}) and let ρ be the Borel measure on (0, ∞) with dρ = r^{d−1} dr.
- **prp-sphere-measure-basic.** σ is a finite Borel measure on S^{d−1}; σ(U(A)) = σ(A) for orthogonal U; σ_{d−1} = d v_d; and σ(A) = lim_{ε→0} ε^{−1} m({rω : 1 < r < 1 + ε, ω ∈ A}). *Sketch:* A ↦ C(A) is the preimage of A under x ↦ x/|x| intersected with B̄₁ \ {0}, so it preserves countable disjoint unions and sends Borel to Borel; orthogonal invariance from cor-orthogonal-invariance with U(C(A)) = C(U(A)); the last from (1 + ε)ᵈ − 1 ∼ dε.
- **def-polar-map.** Φ: ℝᵈ \ {0} → (0, ∞) × S^{d−1}, Φ(x) = (|x|, x/|x|), a homeomorphism with inverse (r, ω) ↦ rω.
- **lem-borel-product-polar.** The Borel σ-algebra of (0, ∞) × S^{d−1} equals ℬ(0, ∞) ⊗ ℬ(S^{d−1}), and it is generated by the π-system of sets (a, b] × A, A ⊆ S^{d−1} Borel. *Sketch:* ⊇ by continuity of the projections; ⊆ because every open set of the product is a countable union of products of open sets (both factors have countable bases: rational intervals, and S^{d−1} ∩ rational balls); open intervals are countable unions of half-open ones. (MT.4 `prp-borel-product` covers ℝᵐ × ℝⁿ only.)

### Statements and proof sketches

## §5. The Gaussian, the volume of the ball, and integrability of powers (`gaussian-and-balls`)

**Section question.** Pay the chapter hook: compute v_d and see where the ball's volume lives; and settle once and for all which powers of |x| are integrable where.

### Statements and proof sketches

- **thm-gaussian-integral.** ∫_{ℝᵈ} e^{−π|x|²} dx = 1 for every d ≥ 1.
  *Proof sketch ("square it").* d = 2 by cor-radial-integral with σ₁ = 2π (prp-sigma-low-dimensions, or σ₁ = 2v₂ with v₂ from the same computation — the text uses prp-sigma-low-dimensions (a) to avoid circularity): 2π ∫₀^∞ e^{−πr²} r dr = 1. ## §6 (optional). The Brunn–Minkowski inequality (`brunn-minkowski`)

**Optional section.** No s-edge may depend on it (STYLE §4 "Optional results"); MT.6 may point to it.

**Section question.** How does m interact with Minkowski addition A + B = {a + b}? The answer gives the isoperimetric property of balls in its Minkowski-content form.

### Statements and proof sketches

- **thm-brunn-minkowski.** For nonempty compact A, B ⊆ ℝᵈ: m(A + B)^{1/d} ≥ m(A)^{1/d} + m(B)^{1/d}.
  *Proof sketch (boxes, then unions of boxes, then compact sets).* (i) Boxes with side lengths a_i, b_i: divide by Π(a_i + b_i)^{1/d} and apply the AM–GM inequality to the two terms Π(a_i/(a_i + b_i))^{1/d} and Π(b_i/(a_i + b_i))^{1/d}. (ii) Finite unions of boxes with disjoint interiors, induction on the total number of boxes: a coordinate hyperplane separates two boxes of A; translate B so that the same hyperplane splits B in the same measure ratio (intermediate value theorem; translation invariance); A± + B± ⊆ A + B on the two sides, disjoint interiors, induction hypothesis on each, add (one line of algebra). (iii) Compact sets: approximate A, B from outside by finite unions of grid cubes A_k ↓, B_k ↓ with ∩A_k = A; A_k + B_k ⊆ A + B + [−2^{1−k}, 2^{1−k}]ᵈ and m(A + B + small cube) → m(A + B) by continuity from above (A + B compact).
- **rem-bm-measurability.** For Borel A, B the sum need not be Borel (prose; not proved; Tao and S–S discuss). The compact case is all that is used.
- **cor-isoperimetric-minkowski.** For compact A with m(A) > 0: m(A + εB̄₁) ≥ (m(A)^{1/d} + ε v_d^{1/d})ᵈ, hence liminf_{ε→0} (m(A + εB̄₁) − m(A))/ε ≥ d v_d^{1/d} m(A)^{(d−1)/d}, with equality when A is a ball. (Opens hk-isoperimetry; for a ball the left side is σ_{d−1} rᵈ⁻¹, linking to §4.)

### Worked examples

- **exm-bm-boxes-equality.** A = [0, 1]ᵈ, B = [0, 2]ᵈ: equality; A a segment, B a segment in ℝ² (not parallel): m(A) = m(B) = 0, A + B a parallelogram of positive area: the inequality is far from equality.

### Quick checks

1. Is A + A = 2A for every set A? (No: A = {0, 1}; yes for convex A.)
2. What does the theorem say when B is a single point? (m(A + b)^{1/d} ≥ m(A)^{1/d}: translation invariance.)

### Exercises
