# Blueprint: CA.4 — Winding Numbers, the Global Cauchy Theorem, and Counting Zeros

**Directory:** `ca/src/ch05-winding-numbers-global-cauchy/` (CA chapter 5 in the spec/08 §D1 order: CA.1, CA.10, CA.2, CA.3, **CA.4**, CA.6, CA.5). Was `src/ch58-global-cauchy-theory/` (old blueprint `ca/authoring/blueprints/ch04.md`, git history at `5a60e6a`). State: S1 written, waiting for S2a.

**Purpose.**
- CA.2 proved Cauchy's theorem on discs and CA.3 proved the residue theorem for toy contours (circles, keyholes). Both stop at the same question: *for which closed curves γ in a region Ω is ∮_γ f = 0 for every f holomorphic on Ω?* This chapter answers it exactly: **iff γ winds zero times around every point outside Ω**.
- The answer needs one new number, the **winding number** n(γ, a), and the chapter turns it into a counting machine: the argument principle, Rouché, the local mapping theorem, open mapping, Hurwitz.
- Homotopy enters as the geometric sufficient condition (Apostol 16.6–16.8), simply connected regions are defined, and the chapter proves what CA.5 and CA.6 need from them: primitives, logarithms and square roots.
- The last section is the maximum principle on **unbounded** regions (Phragmén–Lindelöf, three lines, three circles). It stays here because PDE.3 (Riesz–Thorin) has an s-edge to CA.4 for the three-lines lemma.

**Named moves** (`index.md`, "Named moves"):
1. **Integer and continuous, hence constant.** A continuous integer-valued function on a connected set is constant (winding number on components, Rouché, Hurwitz, the local mapping count).
2. **Lift through exp.** To show a quantity is in 2πiℤ, or to build log f, integrate f′/f and show e^{(integral)} behaves (winding number integer, logs on simply connected regions).
3. **Liouville sweep.** Define a function by two formulas on two overlapping open sets covering ℂ, check they agree, show it tends to 0 at ∞, conclude it is 0 (Dixon's proof).
4. **Grid the homotopy.** Cut the parameter square into small squares by the Lebesgue number, so each image lies in a disc with a primitive; telescope.
5. **Deform the function, not the curve.** Interpolate f_t = f + t g; if no f_t vanishes on γ*, the zero count is an integer continuous in t (Rouché, Hurwitz).
6. **Penalty factor.** Multiply by e^{−ε h(z)} to force decay at ∞, apply the bounded maximum principle, let ε → 0 (Phragmén–Lindelöf, three lines).

## index.md

- **Chapter hook (opened here, paid in §5).** How many roots of p(z) = z⁵ − 7z² + 2 lie in the unit disc? The quintic has no formula, and nobody needs to find the roots: the answer is (1/2πi)∮_{|z|=1} p′(z)/p(z) dz, an integral that can only take integer values, and a one-line comparison (|7z²| = 7 > 3 ≥ |z⁵ + 2| on |z| = 1) evaluates it as 2. The same comparison on |z| = 2 (32 > 30) puts all five roots in |z| < 2. The chapter builds the machine that makes this argument legal. (Verified numerically: root moduli ≈ 0.529, 0.541, 1.859, 1.940, 1.940.)

## 01-winding-number.md — The winding number

- **Section hook.** ∮_{|z|=1} dz/z = 2πi; around the circle traversed twice it is 4πi; around |z − 3| = 1 it is 0. The integral of 1/(z − a) seems to count turns about a. Make that precise.
- **Failure-motivated definition.** Two naive definitions and why they fail:
  1. "Number of times γ crosses a ray from a": a curve can run along the ray, or touch it tangentially, and the count depends on the ray. Fix with signed transversal crossings (`prp-winding-crossings`, later).
  2. "Total change of arg(γ(t) − a) divided by 2π": arg is not a function on ℂ ∖ {a}; it needs a continuous choice along γ, whose existence is itself the issue.
  The integral avoids both: `def-winding-number` n(γ, a) = (1/2πi)∮_γ dz/(z − a) for a closed piecewise C¹ path γ and a ∉ γ*. Symbols given.
- **`thm-winding-integer`.** n(γ, a) ∈ ℤ.
  - **Scratch Work (first appearance of "lift through exp", set apart).** Want: ∫₀¹ γ′/(γ − a) ∈ 2πiℤ. Guess that h(t) = ∫₀ᵗ γ′(s)/(γ(s) − a) ds is a continuous logarithm of (γ(t) − a)/(γ(0) − a). Test by differentiating φ(t) = e^{−h(t)}(γ(t) − a): φ′ = 0 off finitely many points, φ continuous, so φ constant. Then e^{h(1)} = (γ(1) − a)/(γ(0) − a) = 1.
  - **Proof** (typeset): as above, written forward; piecewise C¹ handled by continuity of φ at the break points [CA.1 piecewise C¹ paths; AN1 MVT ⇒ constant on intervals].
- **`prp-winding-argument-lift`.** With h as above, θ(t) = Im h(t) + arg(γ(0) − a) is a continuous argument of γ(t) − a, and n(γ, a) = (θ(1) − θ(0))/2π. This recovers naive definition 2 as a theorem.
- **`thm-winding-locally-constant`.** a ↦ n(γ, a) is constant on each component of ℂ ∖ γ*.
  - Proof: continuity in a (uniform estimate of 1/(z − a) − 1/(z − b) on γ*, ML) + integer-valued + components connected [AN2.3 locally constant ⇒ constant]. First use of **Named move 1**, named here.
- **`thm-winding-zero-unbounded`.** ℂ ∖ γ* has exactly one unbounded component and n(γ, a) = 0 there.
  - Proof: γ* compact so contained in a disc D(0, R); ℂ ∖ D(0, R) is connected and lies in one component; |n(γ, a)| ≤ L(γ)/(2π dist(a, γ*)) → 0 as |a| → ∞.
  - Remark (CA.10, see): on the Riemann sphere this component is the one containing ∞.
- **`prp-winding-crossings`** (the computational rule, Needham 7.1.3 idea, our own statement). If a ray from a meets γ only at finitely many parameters, each a transversal crossing, then n(γ, a) = (#counterclockwise crossings) − (#clockwise crossings). Proof sketch via the continuous argument of `prp-winding-argument-lift`: θ changes by 2π exactly across crossings modulo the ray's direction. Proof kept short; full detail as exercise C1.
- **Remark: "inside".** For a simple closed curve the Jordan curve theorem says ℂ ∖ γ* has two components and n = ±1 on the bounded one. It is **cited only**, never used in a proof: everything in this chapter is phrased with n(γ, a), which is why the winding number replaces "inside".
- **Worked example.** A figure-eight γ through 0 with lobes around ±1, traversed so the right lobe is counterclockwise and the left clockwise: n(γ, 1) = 1, n(γ, −1) = −1, n(γ, 5i) = 0. Computed twice: by crossings and by splitting γ into two circles.
- **Warning.** n(γ, a) is undefined for a ∈ γ*; the integral diverges or is only a principal value.
- **Quick check.** γ(t) = e^{3it}, t ∈ [0, 2π]. What is n(γ, 0), and n(γ, 2)? Answer: 3 and 0.
- **Exercises.**
  - **A1.** n(γ, a) for γ(t) = a + r e^{−2it}, t ∈ [0, 2π]. *Answer:* −2.
  - **A2.** Show n(γ⁻, a) = −n(γ, a) and n(γ₁ + γ₂, a) = n(γ₁, a) + n(γ₂, a) for closed paths based at the same point. *Answer:* linearity of the integral; reversal flips sign [CA.1].
  - **B1.** Let γ(t) = 2cos t + i sin 2t, t ∈ [0, 2π] (a figure-eight through 0; it meets the imaginary axis only at 0). Find n(γ, 1), n(γ, −1), n(γ, i/2). *Answer:* 1, −1, 0 (right lobe counterclockwise, left lobe clockwise, i/2 in the unbounded component; checked numerically).
  - **B2.** If γ lies in a half-plane not containing a, then n(γ, a) = 0. *Answer:* a branch of log(z − a) exists on that half-plane, so 1/(z − a) has a primitive [CA.1].
  - **B3.** If |γ(t) − σ(t)| < |γ(t) − a| for all t (closed paths on the same parameter interval), then n(γ, a) = n(σ, a). *Answer:* the quotient (σ − a)/(γ − a) lies in D(1, 1), apply B2 to it; this is the "dog-walking lemma", named in a remark and reused in §5.
  - **C1.** Prove `prp-winding-crossings` in full.
  - **C2.** Show that for every integer k and every point a there is a closed path γ with n(γ, a) = k and n(γ, b) = 0 for all |b − a| > 1. *Answer:* a small circle traversed k times (orientation by sign of k).

## 02-global-cauchy.md — The global Cauchy theorem

- **Lead-in.** CA.2 proved ∮_γ f = 0 on a disc; CA.3 used keyhole contours, each needing its own argument. Ask the question once and for all.
- **Failure-motivated definition.** "γ does not surround a hole of Ω" fails on two counts: holes may be points, and "surround" needs Jordan. Test: in Ω = ℂ ∖ {0}, the obstruction to ∮_γ f = 0 is exactly f = 1/z, i.e. n(γ, 0). So:
  - `def-cycle`: a formal integer combination of closed piecewise C¹ paths; ∮ over a cycle is the sum. Why cycles: the boundary of an annulus is two circles, not one curve.
  - `def-homologous-zero`: γ ∼ 0 in Ω if γ* ⊂ Ω and n(γ, a) = 0 for every a ∉ Ω. Symbols given.
- **`thm-cauchy-global`** and **`thm-cauchy-formula-global`** (proved together). Ω open, f holomorphic on Ω, γ a cycle in Ω with γ ∼ 0. Then ∮_γ f = 0, and for z ∈ Ω ∖ γ*, n(γ, z) f(z) = (1/2πi)∮_γ f(w)/(w − z) dw.
  - **Scratch Work (first appearance of the Liouville sweep, set apart).** Want F(z) = ∮_γ g(z, w) dw ≡ 0 where g(z, w) = (f(w) − f(z))/(w − z), g(z, z) = f′(z). Inside: F is holomorphic on Ω. Outside: on U = {z ∉ γ* : n(γ, z) = 0}, the same F equals ∮ f(w)/(w − z) dw, which is holomorphic on U. Ω ∪ U = ℂ because γ ∼ 0. So F extends to an entire function; U contains a neighbourhood of ∞ (`thm-winding-zero-unbounded`), where F → 0. Liouville [CA.2]. Now check the pieces: continuity of g on Ω × Ω, holomorphy of F (Morera or differentiation under the integral [CA.2]).
  - **Proof** (typeset, Dixon's route, as in Conway IV.5; our own write-up): (i) g continuous on Ω × Ω and holomorphic in z for fixed w [CA.2 removable singularity / power series]; (ii) F holomorphic on Ω [CA.2 integrals with a parameter, via Morera]; (iii) agreement on Ω ∩ U; (iv) entire, bounded, → 0; (v) F ≡ 0 gives the formula; (vi) apply the formula to (z − z₀) f(z) at z₀ ∉ γ* to get ∮ f = 0.
- **`lem-winding-support-compact`.** If γ ∼ 0 in Ω, then K = γ* ∪ {z ∉ γ* : n(γ, z) ≠ 0} is a compact subset of Ω. Proof: bounded by `thm-winding-zero-unbounded`; its complement is the union of the components of ℂ ∖ γ* on which n = 0, which are open; K ⊂ Ω since n = 0 off Ω. Used in §4 and by CA.12.
- **`cor-cauchy-global-derivatives`.** n(γ, z) f⁽ᵏ⁾(z) = (k!/2πi)∮ f(w)/(w − z)^{k+1} dw. One line: differentiate under the integral.
- **`thm-cauchy-global-converse`.** If ∮_γ f = 0 for all f ∈ H(Ω), then γ ∼ 0. Proof: test f = 1/(z − a), a ∉ Ω. So the hypothesis of `thm-cauchy-global` is exactly right: the section question is answered.
- **Worked example.** Ω = annulus 1 < |z| < 3, γ = C(0, 2) − C(0, 1.5) (outer counterclockwise minus inner counterclockwise). Check n(γ, 0) = 0 and n(γ, a) = 0 for |a| ≥ 3, so γ ∼ 0, and ∮_γ f = 0 for every f holomorphic on the annulus. Then recover CA.3's Laurent coefficient formula's independence of radius as a corollary (cite CA.3 Laurent).
- **Warning.** γ ∼ 0 in Ω depends on Ω: C(0, 1) ∼ 0 in ℂ but not in ℂ ∖ {0}.
- **Quick check.** Ω = ℂ ∖ {1, −1}, γ = C(1, 1/2) + C(−1, 1/2)⁻. Is γ ∼ 0? Answer: no; n(γ, 1) = 1.
- **Exercises.**
  - **A1.** Decide γ ∼ 0 in Ω for three (γ, Ω) pairs: C(0, 2) in ℂ ∖ [3, 4]; C(0, 2) in ℂ ∖ [1, 4]; C(0, 2) + C(0, 2)⁻ in anything. *Answers:* yes; no (n = 1 at 1.5); yes.
  - **B1.** Compute ∮_{C(0,2)} e^z/(z² − 1) dz with `thm-cauchy-formula-global` by partial fractions. *Answer:* 2πi sinh 1 = πi(e − e⁻¹).
  - **B2.** Give an example of Ω and γ ∼ 0 in Ω for which K of `lem-winding-support-compact` is not contained in any disc inside Ω. *Answer:* Ω = ℂ ∖ {0}, γ = C(0, 2) − C(0, 1): K is the closed annulus 1 ≤ |z| ≤ 2, which surrounds 0.
  - **C1 (exit check).** Prove `thm-cauchy-global` from `thm-cauchy-formula-global` and vice versa, with all hypotheses.
  - **C2.** Ω = ℂ ∖ {0}. Show every f ∈ H(Ω) can be written as f = c/z + g′ with g ∈ H(Ω) and c = (1/2πi)∮_{C(0,1)} f. *Answer:* f − c/z has zero integral over every cycle in Ω (each cycle is ∼ n(γ,0)·C(0,1) in homology), so it has a primitive: define g by integrating along paths from 1.

## 03-homotopy-simply-connected.md — Homotopy and simply connected regions

- **Lead-in.** Checking n(γ, a) = 0 for all a ∉ Ω can be awkward; a picture argument "slide the curve" is often easier. Apostol 16 builds Cauchy on exactly that.
- **`def-homotopic-closed`** (closed curves, continuous, through closed curves; endpoints not fixed) and **`def-null-homotopic`**. Intermediate curves need only be continuous; they are never integrated over.
- **`thm-cauchy-homotopy`.** If γ₀ ≃ γ₁ in Ω (closed piecewise C¹ paths) and f ∈ H(Ω), then ∮_{γ₀} f = ∮_{γ₁} f.
  - **Scratch Work (first appearance of "grid the homotopy", set apart).** H: [0,1]² → Ω compact image; Lebesgue number δ for the cover by discs in Ω [AN2.3]; uniform continuity gives a grid of side 1/N with each small square mapped into one disc D_{jk} ⊂ Ω, where f has a primitive F_{jk} [CA.2 primitive on a disc]. Replace each intermediate curve H(·, s_k) by the closed polygon P_k through H(t_j, s_k). Show ∮_{P_k} f = ∮_{P_{k+1}} f by telescoping primitives over the quadrilaterals; and ∮_{γ₀} f = ∮_{P₀} f (each arc and chord lie in one disc).
  - **Proof** typeset (Apostol 16.7 route, our own write-up).
- **`cor-homotopic-homologous`.** If γ is null-homotopic in Ω, then γ ∼ 0 in Ω. Proof: apply `thm-cauchy-homotopy` to 1/(z − a), a ∉ Ω.
- **Hook 2, opened:** `exm-pochhammer-curve`. In Ω = ℂ ∖ {0, 1} let α loop once around 0, β once around 1 (based at 1/2), γ = αβα⁻¹β⁻¹. Then n(γ, 0) = n(γ, 1) = 0, so γ ∼ 0 and ∮_γ f = 0 for every f ∈ H(Ω) by `thm-cauchy-global`. But γ is **not** null-homotopic in Ω. This is stated, with the proof promised: it needs a function that "remembers the order of the loops", which a single-valued holomorphic f cannot; CA.8a (monodromy, CA2) proves it by continuing a multivalued function (√z + √(z − 1) style) along γ. Prose pointer only, no `@ref` (later volume). **Paid in part here:** the converse of `cor-homotopic-homologous` is false, and for integration purposes homology is the right notion.
- **Failure-motivated definition.** "Ω has no holes" — what is a hole? Test cases: ℂ ∖ {0} (a point), ℂ ∖ [0, ∞) (no hole, though not convex), an annulus, ℂ minus a spiral. `def-simply-connected`: Ω connected and every closed curve in Ω is null-homotopic. Convex and star-shaped regions are simply connected (straight-line homotopy).
- **`thm-simply-connected-primitive`.** Ω simply connected, f ∈ H(Ω) ⇒ f has a primitive on Ω. Proof: integrals over closed paths vanish (`thm-cauchy-homotopy` or `cor-homotopic-homologous` + `thm-cauchy-global`); define F(z) = ∫ from z₀ to z along any path [CA.1 path-independence ⇒ primitive; AN2.3 open connected ⇒ path-connected].
- **`thm-simply-connected-log`.** Ω simply connected, f ∈ H(Ω) with no zeros ⇒ there is g ∈ H(Ω) with e^g = f. Proof: **lift through exp** (Named move 2): g = primitive of f′/f, adjusted by a constant; (f e^{−g})′ = 0.
- **`cor-simply-connected-roots`.** Under the same hypotheses f has holomorphic n-th roots (e^{g/n}). Stated with an eye to CA.5 (the square-root trick in the Riemann mapping proof) and CA.6 (harmonic conjugates: u = Re of a primitive).
- **Weird example `exm-sqrt-z2-minus-1`.** Ω = ℂ ∖ [−1, 1] is **not** simply connected and z² − 1 has no holomorphic logarithm there, but it does have a holomorphic square root. Reason: for every closed γ in Ω, n(γ, 1) = n(γ, −1), so (1/2πi)∮ (2z)/(z² − 1) dz = 2n(γ, 1) is even; build √ by integrating f′/(2f). Moral: the hypotheses of `cor-simply-connected-roots` are sufficient, not necessary.
- **Remark (forward promise, prose only).** For a region in ℂ, "simply connected" is equivalent to: every cycle is ∼ 0; every holomorphic function has a primitive; every non-vanishing one has a logarithm; every non-vanishing one has a square root; ℂ̂ ∖ Ω is connected; Ω is ℂ or conformally a disc. The chain closes only after the Riemann mapping theorem (CA.5). This chapter proves the first links in the direction "simply connected ⇒ …". Pochhammer shows the analogous statement is false for "∼ 0" vs "null-homotopic" curve by curve.
- **Warning.** Homotopy here is of **closed curves through closed curves**; fixed-endpoint homotopy of paths is a different notion (both give the same Cauchy theorem; mention in one sentence, exercise B2).
- **Quick check.** Is ℂ ∖ (−∞, 0] simply connected? Is the punctured disc? Answer: yes (star-shaped about 1); no (C(0, 1/2) is not ∼ 0).
- **Exercises.**
  - **A1.** Write down the straight-line homotopy that shows a star-shaped region is simply connected; say where star-shaped is used. *Answer:* H(t, s) = (1 − s)γ(t) + s z₀; the segment from γ(t) to z₀ lies in Ω.
  - **B1.** Show every non-vanishing holomorphic f on Ω = ℂ ∖ (−∞, 0] has a square root, and find an explicit one for f(z) = z. *Answer:* `cor-simply-connected-roots`; e^{(Log z)/2} with the principal branch.
  - **B2.** Show that if two paths with common endpoints are homotopic with endpoints fixed, then their integrals of any f ∈ H(Ω) agree. *Answer:* γ₀ − γ₁ is a closed curve null-homotopic in Ω; or rerun the grid proof.

  - **C1.** Prove the claim in `exm-sqrt-z2-minus-1` in full, including n(γ, 1) = n(γ, −1) for closed γ in ℂ ∖ [−1, 1]. *Answer:* [−1, 1] is connected and misses γ*, so it lies in one component of ℂ ∖ γ*.
  - **C2.** Show there is no holomorphic g on ℂ ∖ {0, 1} with e^g = z(z − 1), but there is one on ℂ ∖ ((−∞, 0] ∪ [1, ∞)). *Answer:* first: if e^g = f then g′ = f′/f, so ∮_{C(0,1/2)} f′/f = 0, but it equals 2πi by the argument principle (or directly by partial fractions); second: the region is star-shaped about 1/2 (a segment from 1/2 to a non-real point meets ℝ only at 1/2), so `thm-simply-connected-log` applies.

## 04-argument-principle.md — The general residue theorem and the argument principle

- **Lead-in.** With `thm-cauchy-global` the residue theorem of CA.3 loses its toy contours.
- **`thm-residue-general`.** f holomorphic on Ω except for isolated singularities in a set S with no limit point in Ω; γ ∼ 0 in Ω, γ* ∩ S = ∅. Then {a ∈ S : n(γ, a) ≠ 0} is finite and ∮_γ f = 2πi Σ n(γ, a) Res(f, a).
  - Proof: finiteness from `lem-winding-support-compact` (S has no limit point in Ω, K is compact in Ω); subtract principal parts [CA.3]; apply `thm-cauchy-global` on Ω ∖ (S ∖ finite set) — check γ ∼ 0 there (S2a item 3).
- **`def-order-meromorphic`.** ord_a f: order of zero (>0) or minus order of pole [CA.3].
- **`thm-argument-principle`.** f meromorphic on Ω, not identically zero on any component, zeros and poles off γ*, γ ∼ 0. Then (1/2πi)∮_γ f′/f = Σ_a n(γ, a) ord_a f (finite sum).
  - Proof: Res(f′/f, a) = ord_a f (write f = (z − a)^m h, h(a) ≠ 0). One display.
  - Name the reading: for a simple closed curve with n = 1 inside, "zeros minus poles inside".
  - Geometric reading: (1/2πi)∮_γ f′/f = n(f∘γ, 0) — the image curve's winding about 0. Proof: change of variables w = f(z). This is Needham's view; a picture plan (curve and image curve side by side) is a figure request.
- **`thm-argument-principle-weighted`.** Same hypotheses, g holomorphic on Ω: (1/2πi)∮ g f′/f = Σ n(γ, a) ord_a f · g(a). Used in §6 for the inverse function formula.
- **Worked examples.**
  1. f(z) = (z² + 1)/(z − 2)³ around C(0, 3) and around C(0, 1.5): answers 2 − 3 = −1, and 2. Then read off n(f∘γ, 0).
  2. The number of zeros of sin z in |z| < 10 by the integral, compared with direct counting: 7 (0, ±π, ±2π, ±3π).
- **Warning.** Zeros on γ* make the integral meaningless; the hypothesis is not decorative. Also: f must not vanish identically on a component (else f′/f undefined).
- **Quick check.** f(z) = z³(z − 4)⁻², γ = C(0, 5). Value of (1/2πi)∮ f′/f? Answer: 3 − 2 = 1.
- **Exercises.**
  - **A1.** Evaluate (1/2πi)∮_{C(0,2)} f′/f for f = z⁴ − 1, f = tan z, f = e^z. *Answers:* 4; −1 (one zero, 0, since π > 2; two poles ±π/2); 0.
  - **A2.** State the argument principle for γ a circle in the language "zeros minus poles", listing every hypothesis used.
  - **B1.** Compute ∮_{C(0,4)} z f′(z)/f(z) dz for f(z) = (z − 1)²(z + 2)/(z − 3i). *Answer:* 2πi(2·1 + (−2) − 3i) = 2πi(−3i) = 6π.
  - **B2.** f entire and |f(z)| = 1 on |z| = 1 with no zeros in the closed disc: show f is constant. *Answer:* argument principle gives n(f∘γ, 0) = 0; with the maximum and minimum modulus [CA.2] f is a constant of modulus 1. (Alternatively directly from max modulus for f and 1/f.)
  - **C1.** Let p be a polynomial of degree n. Show (1/2πi)∮_{C(0,R)} p′/p = n for R large, and deduce the fundamental theorem of algebra a second time. *Answer:* p′/p = n/z + O(1/z²).
  - **C2.** Prove `thm-argument-principle-weighted` and use it with g(z) = z to show: if f is holomorphic and injective near the closed disc D̄(a, r), then the unique zero of f − w (w near f(a)) is (1/2πi)∮ z f′(z)/(f(z) − w) dz. (Bridge to §6.)

## 05-rouche.md — Rouché's theorem and counting zeros

- **Hook paid here.** The chapter hook: zeros of z⁵ − 7z² + 2.
- **Failure that motivates the comparison.** Computing ∮ p′/p by hand is hopeless. But the integral is n(p∘γ, 0), and §1 B3 (dog-walking) says winding numbers are stable under small perturbations. Write p = f + g with f dominant on γ*.
- **`thm-rouche`.** f, g holomorphic on Ω, γ ∼ 0 in Ω with n(γ, z) ∈ {0, 1} for all z ∉ γ*, and |g| < |f| on γ*. Then f and f + g have the same number of zeros (with multiplicity) in {z : n(γ, z) = 1}.
  - **Scratch Work (first appearance of "deform the function", set apart).** Consider f_t = f + t g, t ∈ [0, 1]; on γ*, |f_t| ≥ |f| − |g| > 0. N(t) = (1/2πi)∮ f_t′/f_t is an integer and continuous in t (integrand jointly continuous, γ* compact). Named move 1 ⇒ constant.
  - **Proof** typeset; also the one-line alternative via §1 B3 (n((f+g)∘γ, 0) = n(f∘γ, 0)).
- **`thm-rouche-symmetric`.** If |f + g| < |f| + |g| on γ* (same γ), then f and g have the same zero count. Remark: this version only needs f, g to have no common "opposite direction" points; proof via f/g avoiding (−∞, 0] and a branch of log.
- **Worked examples (all original; verified numerically).**
  1. **Hook payment:** z⁵ − 7z² + 2: 2 zeros in |z| < 1, 5 in |z| < 2, hence 3 in 1 < |z| < 2.
  2. **Transcendental:** 5z³ = e^z has exactly 3 solutions in |z| < 1 (|5z³| = 5 > e ≥ |e^z|). Verified by numerical integration: 3.000.
  3. **FTA again** with f = zⁿ, g = lower terms on a large circle.
- **Warning.** Strict inequality is essential: f = z, g = −z on C(0, 1) has |g| = |f| and f + g ≡ 0. A second warning: the count is in the region n(γ, ·) = 1, not "inside γ" informally.
- **Quick check.** How many zeros has z⁸ + 3z + 1 in |z| < 2? Answer: 8 (256 > 7). Is 2 the smallest radius this argument works for? Answer: no claim; it only gives an upper bound region.
- **Exercises.**
  - **A1.** Number of zeros of z⁶ − 5z² + 1 in |z| < 1 and in |z| < 2. *Answers:* 2 (5 > 2 on |z| = 1); 6 (64 > 21). (Root moduli ≈ 0.449, 0.449, 1.459, 1.459, 1.527, 1.527.)
  - **A2.** Number of zeros of z⁶ + 6z³ + 1 in |z| < 1 and in 1 < |z| < 2. *Answers:* 3; 3 (moduli ≈ 0.556 (×3), 1.800 (×3)).
  - **B1.** Show the two zeros of z⁶ − 5z² + 1 in the unit disc already lie in |z| < 1/2. *Answer:* on |z| = 1/2: |5z²| = 5/4 > 1/64 + 1.
  - **B2.** For λ > 1 show z e^{λ − z} = 1 has exactly one solution in |z| < 1, and it is real. *Answer:* Rouché with f = z e^{λ−z}, g = −1: |f| = e^{λ − Re z} ≥ e^{λ−1} > 1; real by IVT on [0, 1] and uniqueness. (Original variant; S2a check.)
  - **C1.** Count zeros of z⁶ + 9z⁴ − z + 3 in |z| < 1, |z| < 2 and |z| < 4; how many lie in 2 < |z| < 4? *Answers:* 4 (9 > 5); 4 (144 > 69); 6 (4096 > 2311); 2. (Moduli ≈ 0.725 (×2), 0.795 (×2), 3.006 (×2).)
  - **C2 (exit check).** Prove `thm-rouche` with all hypotheses, by the deformation argument, and say where n(γ, ·) ∈ {0, 1} is used. *Marking:* integer-valued (2), continuity in t (2), constancy via connectedness of [0, 1] (1), translation to zero counts (1).

## 06-local-mapping.md — Local mapping, open mapping and Hurwitz

- **Lead-in.** Count preimages instead of zeros: replace f by f − w and vary w.
- **`thm-preimage-count-constant`.** f holomorphic on Ω, γ ∼ 0, n(γ, ·) ∈ {0, 1}. For w ∉ f(γ*), N(w) = #{z : n(γ, z) = 1, f(z) = w} (with multiplicity) equals n(f∘γ, w), hence is constant on components of ℂ ∖ f(γ*). Named move 1 again.
- **`thm-local-mapping`.** f holomorphic and non-constant near z₀, f(z₀) = w₀, f − w₀ with a zero of order m at z₀. Then there are ε, δ > 0 such that every w with 0 < |w − w₀| < δ has exactly m preimages in D(z₀, ε), all simple.
  - Proof: isolated zeros of f − w₀ and of f′ [CA.2]; choose ε; δ = dist(w₀, f(C(z₀, ε))); `thm-preimage-count-constant`.
  - Picture: z ↦ z^m locally; Remark: f = (local coordinate)^m after a holomorphic change of variables, as exercise C1 using `cor-simply-connected-roots` on a disc.
- **`thm-open-mapping`.** Non-constant holomorphic f on a region Ω is an open map. (Apostol 16.18.) One paragraph from `thm-local-mapping`.
- **`thm-max-modulus-open-mapping`.** Maximum modulus as a corollary (|f| cannot have a local max at a point of an open image). Brief: re-derives CA.2's theorem by a second route; cite CA.2.
- **`thm-inverse-holomorphic`.** If f′(z₀) ≠ 0, f is injective near z₀ with holomorphic inverse given by f⁻¹(w) = (1/2πi)∮_{C(z₀,ε)} z f′(z)/(f(z) − w) dz. Via `thm-argument-principle-weighted`; holomorphy in w by differentiation under the integral [CA.2]. Corollary: injective holomorphic ⇒ f′ never 0 (from `thm-local-mapping` with m ≥ 2).
- **`thm-hurwitz`.** Ω region, f_n → f locally uniformly on Ω, f_n, f holomorphic, f ≢ 0, D̄(a, r) ⊂ Ω with f ≠ 0 on C(a, r). Then for large n, f_n and f have the same number of zeros in D(a, r).
  - Proof: f_n′ → f′ locally uniformly [CA.2], so f_n′/f_n → f′/f uniformly on C(a, r); integers converging ⇒ eventually equal. (Or Rouché with g = f_n − f.)
- **`cor-hurwitz-nonvanishing`.** If each f_n has no zeros in Ω (connected), then f ≡ 0 or f has no zeros.
- **`cor-hurwitz-injective`.** If each f_n is injective on Ω (connected), then f is injective or constant. Proof: apply `cor-hurwitz-nonvanishing` to f_n − f_n(b) on Ω ∖ {b}. Stated in the form CA.5 needs.
- **Weird example `exm-hurwitz-collapse`.** f_n(z) = z/n on D: each injective, limit constant 0; f_n(z) = e^z/n: nowhere zero, limit ≡ 0. Both alternatives occur. Also: real analogue fails, x³ − x/n → x³ on ℝ (each non-injective, limit injective) and x² + 1/n → x² (no real zeros, limit has a zero) — the complex conclusion is not about limits in general.
- **Warning.** The open mapping theorem fails for Re f (image in ℝ), for the smooth map (x, y) ↦ (x², y) (image in a closed half-plane), and for x ↦ x² on ℝ. Holomorphy is the hypothesis doing the work.
- **Quick check.** f(z) = z³ − 3z near z₀ = 1: what is m in `thm-local-mapping`? Answer: f′(1) = 0, f″(1) = 6 ≠ 0, so m = 2.
- **Gallery of edge cases (weird-examples table, section end)** — each row: example, which hypothesis it breaks, which theorem it limits.

| Example | What it shows | Theorem bounded |
|---|---|---|
| Pochhammer curve in ℂ ∖ {0, 1} | ∼ 0 but not null-homotopic | `cor-homotopic-homologous` has no converse |
| √(z² − 1) on ℂ ∖ [−1, 1] | roots without simple connectivity | `cor-simply-connected-roots` sufficient only |
| f = z, g = −z on C(0, 1) | equality in the comparison | `thm-rouche` needs strict < |

- **Exercises.**
  - **A1.** For f(z) = z⁴ near 0 and f(z) = cos z near 0, give m and describe the preimages of small w. *Answers:* 4; 2 (cos z − 1 = −z²/2 + …).
  - **B1.** Show that a non-constant holomorphic f on a region cannot have |f| constant on an open set, by `thm-open-mapping`. *Answer:* the image of that open set would be open yet inside a circle.
  - **B2.** Show that for every R > 0 the partial sums s_n(z) = Σ_{k≤n} z^k/k! of e^z have no zeros in D(0, R) once n is large. *Answer:* `thm-hurwitz` with f = e^z, which has no zeros; uniform convergence on D̄(0, R) [CA.1].
  - **C1.** Prove: if f − w₀ has a zero of order m at z₀, there is a holomorphic φ near z₀ with φ(z₀) = 0, φ′(z₀) ≠ 0 and f = w₀ + φ^m. *Answer:* f − w₀ = (z − z₀)^m h, h(z₀) ≠ 0, take an m-th root of h on a small disc (`cor-simply-connected-roots`).
  - **C2 (exit check).** Prove `cor-hurwitz-injective` from `thm-hurwitz`, stating where connectedness of Ω is used. *Marking:* reduction to zeros (2), Hurwitz on a small circle avoiding zeros of f − f(b) (2), connectedness for f ≢ const ⇒ zeros isolated (1).
  - **C3.** Prove that an injective holomorphic f: Ω → ℂ has f′ ≠ 0 everywhere and its inverse is holomorphic on the open set f(Ω).

## 07-unbounded-max-principles.md — Maximum principles on unbounded regions

- **Lead-in and failure.** CA.2's maximum modulus says sup over a bounded region is attained on the boundary. On the strip S = {|Im z| < π/2} the function F(z) = exp(exp z) has |F| = 1 on ∂S (exp z is purely imaginary there) and is unbounded on ℝ (`exm-exp-exp-strip`). The bounded-region principle fails; some growth condition must replace "bounded".
- **`thm-phragmen-lindelof-strip`.** f continuous on S̄, holomorphic on S, |f| ≤ 1 on ∂S, and |f(z)| ≤ exp(A e^{α|Re z|}) on S for some A > 0 and 0 ≤ α < 1. Then |f| ≤ 1 on S.
  - **Scratch Work (first appearance of the penalty factor, set apart).** Want an auxiliary h_ε with |h_ε| ≤ 1 on S̄ that decays faster than the allowed growth: try h_ε(z) = exp(−ε(e^{βz} + e^{−βz})) with α < β < 1. On S, Re(e^{βz} + e^{−βz}) = 2cosh(βx)cos(βy) ≥ 2cos(βπ/2) cosh(βx) > 0 since β < 1. Then f h_ε → 0 as |x| → ∞; bounded maximum principle on rectangles [CA.2]; let ε → 0.
  - **Proof** typeset.
  - Remark: α = 1 is sharp, by `exm-exp-exp-strip`. A sector version follows by z ↦ z^{π/θ} style maps (CA.10 see; the maps are CA.1 branches) — exercise C1.
- **`thm-three-lines`.** f bounded and continuous on the closed strip 0 ≤ Re z ≤ 1, holomorphic inside, |f| ≤ M₀ on Re z = 0 and |f| ≤ M₁ on Re z = 1 (M₀, M₁ > 0). Then |f(x + iy)| ≤ M₀^{1−x} M₁^x.
  - Proof: g(z) = f(z) M₀^{z−1} M₁^{−z} is bounded with |g| ≤ 1 on the boundary; penalty e^{εz²} (|e^{ε z²}| = e^{ε(x² − y²)} → 0 as |y| → ∞ uniformly for x ∈ [0, 1]); bounded max principle on rectangles; ε → 0.
  - Remark (prose): log M(x) = log sup_y |f(x + iy)| is convex; PDE.3 uses this lemma for Riesz–Thorin. State it in exactly the form PDE.3 needs (bounded, continuous on the closed strip, holomorphic inside).
- **`thm-three-circles`.** f holomorphic on an annulus r₁ < |z| < r₂, continuous on the closure, M(r) = max_{|z|=r} |f|. Then log M(r) is a convex function of log r: for r₁ ≤ r ≤ r₂, log M(r) ≤ ((log r₂ − log r)/(log r₂ − log r₁)) log M(r₁) + ((log r − log r₁)/(log r₂ − log r₁)) log M(r₂). Proof: F = f∘exp on the closed strip log r₁ ≤ Re w ≤ log r₂ is bounded (continuous, 2πi-periodic) and holomorphic inside; rescale the strip affinely to 0 ≤ Re ≤ 1 and apply `thm-three-lines` (exp need not be injective; only F is used). If some M(rⱼ) = 0 then f ≡ 0 by the identity theorem.
- **Warning.** The three-lines lemma needs boundedness of f on the strip; exercise B2 transplants `exm-exp-exp-strip` to show it fails otherwise.
- **Quick check.** For f(z) = e^z on 0 ≤ Re z ≤ 1, what are M₀ and M₁, and what bound does three lines give on Re z = 1/2? Is it sharp? Answer: M₀ = 1, M₁ = e, bound e^{1/2}, attained (|e^{1/2 + iy}| = e^{1/2}).
- **Exercises.**
  - **A1.** Verify |exp(exp z)| = 1 on Im z = ±π/2 and that exp(exp x) → ∞. *Answer:* exp(x ± iπ/2) = ±i e^x.
  - **B1.** Use `thm-three-lines` to show: if f is bounded and holomorphic on the strip and |f| ≤ M on the left edge and ≤ M on the right edge, then |f| ≤ M throughout. *Answer:* M^{1−x}M^x = M.
  - **B2.** Transplant `exm-exp-exp-strip` to the strip 0 < Re z < 1 by z ↦ iπ(z − 1/2) and show three lines fails without the boundedness hypothesis. *Answer:* with w = iπ(z − 1/2) = −πy + iπ(x − 1/2), Im w ∈ (−π/2, π/2) and Re w = −πy, so F(w) has modulus 1 on both edges and is unbounded as Im z → −∞.
  - **C1.** State and prove Phragmén–Lindelöf in the sector |arg z| < π/(2a) for growth |f(z)| ≤ exp(A|z|^b), b < a, by mapping to a strip or directly with the penalty exp(−ε z^c), b < c < a.
  - **C2 (exit check).** Prove `thm-three-lines`. *Marking:* normalization by M₀^{z−1}M₁^{−z} (2), penalty factor and decay (2), maximum principle on large rectangles (1), ε → 0 (1).
  - **R (reader-alone, chapter end).** (i) Ordering exercise: put the six steps of Dixon's proof in order. (ii) Find-the-error: in Ω = ℂ ∖ {0} take f = 2, g = 1/z, γ = C(0, 1). Then |g| = 1 < 2 = |f| on γ*, f has no zeros, and a "Rouché" argument concludes 2 + 1/z has no zeros in D(0, 1); but −1/2 is one. The missing hypothesis is γ ∼ 0 in Ω (n(γ, 0) = 1 with 0 ∉ Ω). (iii) Faded proof: `thm-preimage-count-constant` with two steps blank.
