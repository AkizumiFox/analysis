## 01-theta-function.md — The theta function and its zeros

**Main-line budget ≤ 3,500 words.**

- **Opening frame.** Recall the HA.4 kernel H_t; one sentence: "complex time" gives Θ(x∣4πit) = H_t(x). Then the question that runs the section: Θ(·∣τ) is 1-periodic; how close is it to being doubly periodic, and where are its zeros?
- **`def-jacobi-theta`.** For z ∈ ℂ, τ ∈ ℍ: Θ(z∣τ) ≔ Σ_{n∈ℤ} e^{πin²τ + 2πinz}.
- **`thm-theta-holomorphic`.** The series converges absolutely and uniformly on every set {|Im z| ≤ A, Im τ ≥ δ} (A ≥ 0, δ > 0); Θ is holomorphic in z for fixed τ, holomorphic in τ for fixed z, and continuous jointly. *Proof:* |term| = e^{−πn² Im τ − 2πn Im z} ≤ e^{−πδn² + 2πA|n|}, summable; M-test and `thm-weierstrass-limits`.
- **Quick check.** (i) Θ(x∣4πit) = H_t(x) for real x, t > 0: verify the exponent. (ii) Θ(−z∣τ) = Θ(z∣τ). (iii) Θ(z∣τ) → 1 as Im τ → ∞ for fixed z: why does the n = 0 term dominate?
- **`thm-theta-quasiperiodic`.** For all z, τ: (a) Θ(z + 1∣τ) = Θ(z∣τ); (b) Θ(z + τ∣τ) = e^{−πiτ − 2πiz} Θ(z∣τ). *Proof of (b):* shift the summation index n → n − 1 after completing the square: πin²τ + 2πinτ = πi(n + 1)²τ − πiτ.
- **Weird example (in passing, enters the §6 table):** a nonconstant entire function cannot be doubly periodic (bounded on a parallelogram, Liouville), but it can be periodic in one direction and change by a nowhere-zero factor in the other. Θ is the simplest such.
- **`thm-theta-zeros`.** Fix τ ∈ ℍ. The zeros of z ↦ Θ(z∣τ) are exactly the points ½ + τ/2 + m + nτ (m, n ∈ ℤ), and each is simple.
  - *Try it first* (ten minutes), as listed above.
  - **[SW] Scratch Work (first appearance of "quasi-periodicity counts zeros").** Let P be the parallelogram with vertices a, a + 1, a + 1 + τ, a + τ, chosen with no zero on ∂P. Write L = Θ′/Θ (derivative in z). Pair the sides: L(z + 1) = L(z), so the two slanted sides cancel; L(z + τ) = L(z) − 2πi, so bottom minus top gives ∫_a^{a+1} 2πi dz = 2πi. So (1/2πi)∮_{∂P} L = 1. Then find one zero by symmetry: at z = ½ + τ/2 the summand for n and for −1 − n are negatives of each other.
  - *Proof:* argument principle (`thm-argument-principle`) gives exactly one zero, counted with multiplicity, in each translate of P with no zero on its boundary; such translates exist (zeros are isolated) and every point lies in one; Θ(½ + τ/2∣τ) = Σ (−1)ⁿ e^{πi(n²+n)τ} = 0 by the pairing n ↔ −1 − n; quasi-periodicity carries this zero to the whole lattice coset; the count 1 gives simplicity and no other zeros.
  - *Self-explain:* where is 1-periodicity used, and where the multiplier?
- **`def-thetanulls`.** θ₃(τ) ≔ Θ(0∣τ) = Σ q^{n²}; θ₄(τ) ≔ Θ(½∣τ) = Σ (−1)ⁿ q^{n²}; θ₂(τ) ≔ e^{πiτ/4} Θ(τ/2∣τ) = Σ q^{(n+½)²}. (q^α = e^{πiατ}.) One line checking the θ₂ series.
- **`cor-thetanulls-nonzero`.** θ₂, θ₃, θ₄ are holomorphic on ℍ and have no zeros there. *Proof:* 0, ½, τ/2 are not of the form ½ + τ/2 + m + nτ (compare real and τ-coefficients; τ ∉ ℝ).
- **Hook 2 (paid in §2).** Quick check with numbers (sidecar): at τ = i, θ₃(i) ≈ 1.0864, θ₄(i) ≈ θ₂(i) ≈ 0.9135; compute θ₃(i)⁴ and θ₂(i)⁴ + θ₄(i)⁴. "These agree to every digit you can compute. §2 shows why, for every τ." (S2a: recompute the decimals; θ₃(i) = π^{1/4}/Γ(3/4) ≈ 1.086434, θ₂(i) = θ₄(i) = 2^{−1/4}θ₃(i) ≈ 0.913579.)

### Exercises

- **A1** (`exr-theta-function-a1`). (a) State both quasi-periodicity laws. (b) True or false: Θ(·∣τ) is doubly periodic. (c) Give the unique zero of Θ(·∣τ) in the parallelogram with vertices 0, 1, 1 + τ, τ. (d) For which τ is H_t(x) = Θ(x∣τ)? (e) Proof comprehension (`thm-theta-zeros`): why do the two slanted sides of ∂P contribute nothing? (f) Why is it necessary that no zero lies on ∂P, and why can a be chosen so?
  - *Answers:* (a) as `thm-theta-quasiperiodic`. (b) False: Θ(z + τ) = e^{−πiτ−2πiz}Θ(z) and the factor is not identically 1 (a doubly periodic entire function is constant by Liouville, and Θ is not constant: its Fourier coefficients in e^{2πiz} are e^{πin²τ} ≠ 0). (c) ½ + τ/2. (d) τ = 4πit. (e) Θ′/Θ is 1-periodic, and the two sides are traversed in opposite directions. (f) The argument principle needs f ≠ 0 on the contour. a = 0 works: a point s + tτ (s, t real) lies on ∂P only if s ∈ {0, 1} or t ∈ {0, 1}, while the zeros have s, t ∈ ½ + ℤ.
- **B1** (`exr-theta-function-b1`). Let A(z) = Θ(z + ½∣τ) and B(z) = e^{πiz + πiτ/4} Θ(z + τ/2∣τ). Compute A(z + 1), A(z + τ), B(z + 1), B(z + τ) in terms of A(z), B(z), and find all zeros of A and of B. Hence show A and B are not constant multiples of Θ(·∣τ).
  - *Answer:* A(z + 1) = A(z); A(z + τ) = −e^{−πiτ−2πiz}A(z). B(z + 1) = −B(z); B(z + τ) = e^{−πiτ−2πiz}B(z). Zeros: A at τ/2 + ℤ + ℤτ; B at ½ + ℤ + ℤτ. Different zero sets from Θ's.
- **B2** (`exr-theta-function-b2`). Show |θ₃(τ) − 1| ≤ 2|q|/(1 − |q|) for τ ∈ ℍ, |q| = e^{−π Im τ}. Hence θ₃(τ) → 1 as Im τ → ∞ uniformly in Re τ, and give an explicit c with θ₃(τ) ≠ 0 whenever Im τ > c without using `cor-thetanulls-nonzero`.
  - *Answer:* Σ_{n≠0}|q|^{n²} ≤ 2Σ_{n≥1}|q|ⁿ. Need 2|q|/(1 − |q|) < 1 ⇔ |q| < ⅓ ⇔ Im τ > (log 3)/π; c = (log 3)/π ≈ 0.35.
- **B3** (`exr-theta-function-b3`, example generation). Give an example of a nonconstant entire function f with f(z + 1) = f(z) and f(z + τ) = c f(z) for a constant c (fixed τ ∈ ℍ). Then show that if c is replaced by e^{−πiτ−2πiz}, every such f is a constant multiple of Θ(·∣τ). *Hint:* expand f in powers of e^{2πiz}.
  - *Answer:* f = e^{2πikz}, c = e^{2πikτ} (k ≠ 0). For the second part: f = Σ aₙe^{2πinz} (1-periodic entire); comparing coefficients in f(z + τ) = e^{−πiτ−2πiz}f(z) gives a_{n+1} = q^{2n+1}aₙ, so aₙ = q^{n²}a₀ and f = a₀Θ. Properties an answer to the first part must have: entire, 1-periodic, constant multiplier; any finite combination Σ c_k e^{2πikz} with all k equal works, mixed k does not.
- **C1** (`exr-theta-function-c1`). (a) Prove Θ(z∣τ + 1) = Θ(z + ½∣τ) and Θ(z∣τ + 2) = Θ(z∣τ). (b) Deduce θ₃(τ + 1) = θ₄(τ), θ₄(τ + 1) = θ₃(τ) and θ₂(τ + 1) = e^{πi/4}θ₂(τ).
  - *Answer:* e^{πin²} = (−1)ⁿ = e^{πin}; e^{2πin²} = 1. For θ₂: (n + ½)² = n² + n + ¼ and n² + n is even.
- **C2** (`exr-theta-function-c2`). Let f be entire, 1-periodic, with f(z + τ) = e^{−2πik z} c f(z) for an integer k ≥ 1 and a constant c ≠ 0. Show f has exactly k zeros (with multiplicity) in every period parallelogram whose boundary avoids them. What happens for k = 0 and for k < 0?
  - *Answer:* same contour computation: bottom minus top gives ∫ 2πik dz = 2πik. k = 0: no zeros (f = Σ aₙe^{2πinz} with aₙ(e^{2πinτ} − c) = 0, so f is a single exponential or 0); k < 0: the count would be negative, impossible, so f ≡ 0.

## 02-transformation-laws.md — Transformation laws and Jacobi's identity

**Main-line budget ≤ 4,500 words.**

- **Opening frame.** §1 C1 showed how the thetanulls change under τ ↦ τ + 1. The other basic map of ℍ is τ ↦ −1/τ; for τ = it it exchanges t and 1/t, i.e. short time and long time for the heat kernel. Poisson summation (HA.5, "see") is the general tool; here only the Gaussian is needed.
- **`thm-thetanull-translation`.** θ₃(τ + 1) = θ₄(τ), θ₄(τ + 1) = θ₃(τ), θ₂(τ + 1) = e^{πi/4}θ₂(τ). *Proof:* §1 C1 is an exercise, so the text proves it again in three lines (STYLE §9: proofs never cite exercises).
- **`thm-gaussian-poisson`.** For t > 0 and x ∈ ℝ: Σ_{n∈ℤ} e^{−πt(x+n)²} = t^{−1/2} Σ_{k∈ℤ} e^{−πk²/t} e^{2πikx}.
  - **[SW] Scratch Work (first appearance of the contour shift for a Fourier coefficient).** The left side G(x) is 1-periodic and C¹ (termwise differentiation, M-test on [0, 1]). Its k-th Fourier coefficient unfolds to ∫_ℝ e^{−πtx²}e^{−2πikx}dx. Complete the square: −πt(x + ik/t)² − πk²/t. Shift the line of integration from Im x = k/t to Im x = 0 (Cauchy's theorem on a long rectangle; the vertical sides are O(e^{−πtR²+πk²/t})). Result: e^{−πk²/t}·C t^{−1/2}, where C = ∫_ℝ e^{−πx²}dx.
  - *Proof:* the Scratch Work, then HA.3's pointwise convergence theorem for C¹ periodic functions gives G(x) = C t^{−1/2}Σ e^{−πk²/t}e^{2πikx}. At t = 1, x = 0 both sides contain θ₃(i) = Σ e^{−πn²} > 0, so C = 1. (Remark: the chapter thereby re-derives ∫e^{−πx²} = 1 without polar coordinates; one sentence.)
- **`thm-thetanull-inversion`.** For τ ∈ ℍ, with √(τ/i) the principal branch: θ₃(−1/τ) = √(τ/i) θ₃(τ), θ₄(−1/τ) = √(τ/i) θ₂(τ), θ₂(−1/τ) = √(τ/i) θ₄(τ).
  - **[SW] (first appearance of "prove it on a line, extend").** For τ = it, `thm-gaussian-poisson` at x = 0 gives θ₃(it) = t^{−1/2}θ₃(i/t), and at x = ½ gives θ₂(it) = t^{−1/2}θ₄(i/t). Both sides of each claimed identity are holomorphic on ℍ (√(τ/i) is holomorphic because τ/i has positive real part) and agree on iℝ₊, which has accumulation points: `thm-identity`.
  - *Proof:* as above; the third identity follows from the second applied to −1/τ, using √((−1/τ)/i)·√(τ/i) = 1 (both factors in the right half-plane, so the principal roots multiply).
- **Quick check.** At τ = i: θ₄(i) = θ₂(i). Combine with Hook 2: the claim becomes θ₃(i)⁴ = 2θ₄(i)⁴.
- **Failure that motivates `def-theta-space`.** Try to prove θ₃⁴ = θ₂⁴ + θ₄⁴ from the q-expansions: expanding the fourth powers turns the claim into one identity between lattice-point counts for each power of q, infinitely many identities with no finite end (B2 checks the first few). The way out is to find a *finite-dimensional* space containing the relevant functions.
- **`def-theta-space`.** For fixed τ, V(τ) ≔ {f entire : f(z + 1) = f(z), f(z + τ) = e^{−2πiτ − 4πiz} f(z)} (the multiplier of Θ², "theta functions of order 2").
- **`lem-theta-space-dimension`.** dim V(τ) = 2; the functions A₁(z) = Θ(z∣τ)² and A₂(z) = Θ(z + ½∣τ)² form a basis. *Proof:* if f ∈ V, f = Σ aₙe^{2πinz} and a_{n+2} = q^{2n+2}aₙ, so f is determined by a₀, a₁: dim ≤ 2. A₁, A₂ ∈ V by `thm-theta-quasiperiodic` (the sign in A₂'s multiplier squares away); they are independent because their zero sets differ (`thm-theta-zeros`: ½ + τ/2 versus τ/2).
- **`thm-jacobi-identity`.** For τ ∈ ℍ: θ₃(τ)⁴ = θ₂(τ)⁴ + θ₄(τ)⁴.
  - *Try it first* (ten minutes), as listed above.
  - *Idea:* the obvious attempt (q-series) fails as above. Instead put a third function A₃(z) = e^{2πiz + πiτ/2}Θ(z + ½ + τ/2∣τ)² into V(τ), write A₃ = αA₁ + βA₂, and evaluate at three points.
  - *Proof:* A₃ ∈ V (check both laws; the factor e^{2πiz} is 1-periodic and contributes e^{2πiτ} under z ↦ z + τ). Values (all from the definitions and `thm-theta-quasiperiodic`):
    - z = 0: A₁ = θ₃², A₂ = θ₄², A₃ = 0.
    - z = ½: A₁ = θ₄², A₂ = θ₃², A₃ = −θ₂².
    - z = τ/2: A₁ = e^{−πiτ/2}θ₂², A₂ = 0, A₃ = e^{−πiτ/2}θ₄².
    - From z = τ/2: α = θ₄²/θ₂². From z = 0: β = −θ₃²/θ₂². Then z = ½ gives −θ₂² = (θ₄⁴ − θ₃⁴)/θ₂². Divisions are legal by `cor-thetanulls-nonzero`.
  - Hook 2 paid in one sentence.
- **Remark** (`rem-triple-product`, prose, no proof): the same "same zeros, same multiplier ⇒ proportional" argument proves Jacobi's triple product Θ(z∣τ) = Π_{n≥1}(1 − q^{2n})(1 + q^{2n−1}e^{2πiz})(1 + q^{2n−1}e^{−2πiz}); fixing the constant is the hard part. R2 (§6) computes the zeros of the product side.

## 03-modular-lambda.md — The modular function λ and its symmetries

**Main-line budget ≤ 4,000 words.**

- **Opening frame.** Goal stated: a holomorphic function on ℍ that omits exactly 0 and 1 and "sees all of ℂ ∖ {0, 1}". Jacobi's identity makes the candidate obvious.
- **`def-theta-lambda`.** λ(τ) ≔ θ₂(τ)⁴ / θ₃(τ)⁴ on ℍ.
- **`thm-theta-lambda-omits`.** λ is holomorphic on ℍ and λ(τ) ∉ {0, 1}; moreover 1 − λ = θ₄⁴/θ₃⁴. *Proof:* `cor-thetanulls-nonzero` and `thm-jacobi-identity`.
- **`thm-theta-lambda-functional`.** For τ ∈ ℍ: (a) λ(τ + 1) = λ(τ)/(λ(τ) − 1); (b) λ(−1/τ) = 1 − λ(τ); (c) λ(τ + 2) = λ(τ); (d) λ(τ/(2τ + 1)) = λ(τ); (e) λ(−τ̄) = conj λ(τ). *Proof:* (a) `thm-thetanull-translation`: λ(τ + 1) = −θ₂⁴/θ₄⁴, and λ/(λ − 1) = −θ₂⁴/θ₄⁴ by `thm-theta-lambda-omits`. (b) `thm-thetanull-inversion`: the factors (τ/i)² cancel. (c) apply (a) twice. (d) τ/(2τ + 1) = −1/((−1/τ) − 2); apply (b), (c), (b). (e) the q-series have real coefficients and q(−τ̄) = conj q(τ).
- **`lem-theta-lambda-expansion`.** λ(τ) = 16q − 128q² + O(q³) as Im τ → ∞, uniformly in Re τ; in particular |λ(τ) − 16q| ≤ 200|q|² for Im τ ≥ 1 (sidecar 2026-10-25: sup of |λ − 16q|/|q|² over a grid with Im τ ∈ [1, 2] is ≈ 165; S2a to supply the analytic bound). *Proof:* θ₂⁴ = 16q(1 + O(q²)), θ₃⁴ = 1 + 8q + O(q²).
- **Quick check.** (i) λ(i) = ½ (from (b) at τ = i). (ii) λ is real on iℝ₊ (from (e)). (iii) Is λ invariant under τ ↦ τ + 1? (No: λ = λ/(λ − 1) forces λ = 2.)
- **`def-level-two-group`.** G₂ ≔ the group of Möbius maps generated by T²: τ ↦ τ + 2 and σ: τ ↦ τ/(2τ + 1).
- **`lem-level-two-matrices`.** Every g ∈ G₂ is τ ↦ (aτ + b)/(cτ + d) with integers a, b, c, d, ad − bc = 1, a ≡ d ≡ 1 and b ≡ c ≡ 0 (mod 2); g maps ℍ onto ℍ, Im g(τ) = Im τ / |cτ + d|², and λ ∘ g = λ. *Proof:* the generators' matrices (1 2; 0 1), (1 0; 2 1) have these properties, which are closed under products and inverses; the Im formula is a one-line computation (CA.10); invariance from (c), (d).
- **Remark.** G₂ is in fact all of Γ(2)/{±1} (the congruence subgroup mod 2); not needed and not proved; one sentence, "see CA.15 §07" in prose.
- **Failure that motivates `def-fundamental-set`.** λ has period 2, so one might hope the strip −1 ≤ Re τ < 1 carries each value once. It does not: `exm-strip-not-fundamental`: τ = ½ + i/10 and σ⁻¹(τ) = τ/(1 − 2τ) = −½ + 5i/2 both lie in the strip and have the same λ-value. The strip must be cut down by the circles where σ acts.
- **`def-fundamental-set`.** F ≔ {τ ∈ ℍ : −1 ≤ Re τ < 1, |τ + ½| ≥ ½, |τ − ½| > ½}. Picture: the strip with two half-disks removed; the left edge and the left circle belong to F, the right edge and the right circle do not. T² carries the left edge to the right edge; σ carries the left circle |τ + ½| = ½ to the right circle |τ − ½| = ½ (σ fixes 0 and sends −1 to 1, and maps circles orthogonal to ℝ to circles orthogonal to ℝ). The closure F̄ (in ℍ ∪ ℝ ∪ {∞}) meets ℝ ∪ {∞} only in the four cusps −1, 0, 1, ∞.
- **`lem-reduction-to-fundamental-set`.** Every τ ∈ ℍ has g ∈ G₂ with g(τ) ∈ F.
  - **[SW] Scratch Work (first appearance of "reduce to the fundamental set").** Run it on τ = 3/5 + i/5: it lies in the right half-disk (|τ − ½|² = 1/20 < ¼); σ⁻¹(τ) = (3 + i)/(−1 − 2i) = −1 + i, which lies in F. Im went from 1/5 to 1: each step through a circle raises Im because |2τ ± 1| < 1 inside the circles.
  - *Proof:* by `lem-level-two-matrices`, Im g(τ) = Im τ/|cτ + d|²; the set {|cτ + d| : (c, d) ∈ ℤ² ∖ {0}} has no accumulation at 0 (only finitely many pairs with |cτ + d| < 1), so Im attains a maximum on the orbit at some τ*. Translate τ* by a power of T² into −1 ≤ Re < 1 (Im unchanged). If |τ* + ½| < ½ then Im σ(τ*) > Im τ*; if |τ* − ½| < ½ then Im σ⁻¹(τ*) > Im τ*: both impossible. If |τ* − ½| = ½ (right circle, excluded from F), replace τ* by σ⁻¹(τ*): σ⁻¹ maps the right circle onto the left circle, and |1 − 2τ*| = 1 there, so Im is unchanged; the new point is in F (translate by T² again if needed).
- **Weird example** (`exm-lambda-omits-on-halfplane`, enters the table): λ itself is a nonconstant holomorphic function on the simply connected region ℍ omitting two values. So "simply connected" is not enough for Picard; ℂ is needed.

## 04-lambda-mapping.md — λ maps the fundamental set onto ℂ ∖ {0, 1}

**Main-line budget ≤ 5,000 words.** The longest section; the key proof is given in full.

- **Opening frame.** Two facts are needed for Picard: every value in ℂ ∖ {0, 1} is taken, and λ′ never vanishes. Both come from one count with the argument principle on the half of F with 0 < Re τ < 1.
- **`lem-theta-lambda-real-boundary`.** λ is real on ∂F ∩ ℍ and on iℝ₊ (proof as §3 C2 (a), written out; the text cannot cite the exercise).
- **`lem-theta-lambda-cusps`.** Let Ω₀ = {τ : 0 < Re τ < 1, |τ − ½| > ½}. As τ → ∞ in Ω₀, λ(τ) → 0; as τ → 0 in Ω₀, λ(τ) → 1; as τ → 1 in Ω₀, λ(τ) → ∞. All three limits are uniform in the corresponding cusp neighbourhoods: {Im τ > M}, {Im(−1/τ) > M}, {Im(−1/(τ − 1)) > M}. *Proof:* ∞ from `lem-theta-lambda-expansion`. The map τ ↦ −1/τ sends Ω₀ onto Ω₀′ = {−1 < Re < 0, |τ + ½| > ½} (sides to sides: Re = 0 to Re = 0, Re = 1 to the left circle, right circle to Re = −1), and τ → 0 in Ω₀ means −1/τ → ∞ in Ω₀′, where Im → ∞; then λ(τ) = 1 − λ(−1/τ) → 1. For τ → 1 write τ = w + 1 with w → 0 in Ω₀′, λ(w) = 1 − λ(−1/w) → 1, and λ(τ) = λ(w)/(λ(w) − 1) → ∞.
- **`thm-theta-lambda-half-plane`.** λ maps Ω₀ bijectively onto the upper half-plane {Im w > 0}.
  - **[SW] Scratch Work (first appearance of "follow the boundary").** Truncate Ω₀ at height t₀ (top segment Im τ = t₀, 0 ≤ Re ≤ 1) and at the images of that segment under τ ↦ −1/τ and τ ↦ 1 − 1/τ (two small circular arcs tangent to ℝ at 0 and at 1). Walk the boundary counterclockwise and track λ:
    - up the line Re τ = 1 from near 1 to 1 + it₀: λ real, from large negative to a small negative value (on Re τ = 1, q < 0, so λ ≈ 16q < 0 near the top);
    - along the top from 1 + it₀ to it₀: λ ≈ 16e^{−πt₀}e^{πix}, x from 1 to 0, a small arc through the upper half-plane from a small negative to a small positive number;
    - down iℝ₊ to near 0: λ real, from small positive to near 1;
    - around the small arc at 0: λ stays near 1;
    - along the right circle from near 0 to near 1: λ real, from near 1 to large positive;
    - around the small arc at 1: λ large, returning to large negative.
    The image is (up to small arcs near 0, 1 and a large arc) the boundary of a large upper half-disk with small half-disks at 0 and 1 removed. So the winding number about w₀ is 1 if Im w₀ > 0 and 0 if Im w₀ < 0, once t₀ is large.
  - *Proof:* make the Scratch Work exact. (i) On the real-image pieces, λ is real (`lem-theta-lambda-real-boundary`). (ii) On the top segment, `lem-theta-lambda-expansion` gives λ = 16q(1 + ε) with |ε| < ⅒ for t₀ large, and Im λ > 0 except at the endpoints, where λ is real. (iii) On the arc at 0, λ(τ) = 1 − λ(−1/τ) with −1/τ on a horizontal segment at height t₀ (shifted into the strip), so |λ − 1| is small; on the arc at 1 similarly |λ| is large, and by the same transport the image arc lies in the closed upper half-plane. (iv) Fix w₀ with Im w₀ ≠ 0; choose t₀ so large that the image of the top segment lies in |w| < |w₀|/2, the image of the arc at 0 in |w − 1| < |w₀ − 1|/2, and the image of the arc at 1 in |w| > 2|w₀|. The image curve does not pass through w₀, and its winding number about w₀ is 1 if Im w₀ > 0, 0 if Im w₀ < 0 (the curve is homotopic in ℂ ∖ {w₀} to the boundary of a half-annulus-like region in the closed upper half-plane). (v) `thm-argument-principle`: λ − w₀ has exactly one zero in the truncated region if Im w₀ > 0, none if Im w₀ < 0; letting t₀ → ∞ covers Ω₀. Real values are not taken in Ω₀: if λ(τ₀) = w₀ ∈ ℝ with τ₀ ∈ Ω₀, the open mapping theorem would give values with Im < 0 near τ₀.
  - *Self-explain:* why the image of the top segment lies in the upper half-plane.
- **`cor-theta-lambda-derivative`.** λ′(τ) ≠ 0 for every τ ∈ ℍ. *Proof:* λ is injective on Ω₀ (`thm-theta-lambda-half-plane`) and on Ω₀′ (its mirror image, by `thm-theta-lambda-functional` (e)), with images in opposite open half-planes, so λ′ ≠ 0 (`thm-local-mapping`). At τ₀ ∈ iℝ₊: if λ′(τ₀) = 0, by `thm-local-mapping` some nonreal value near λ(τ₀) with positive imaginary part is taken at least twice near τ₀; such preimages lie in Ω₀ (Ω₀′ gives Im < 0, iℝ₊ gives real values), contradicting injectivity on Ω₀. For the rest: λ ∘ M is a Möbius function of λ for M = τ ± 1, −1/τ (`thm-theta-lambda-functional` (a), (b)) and λ ∘ g = λ for g ∈ G₂, so λ′ ≠ 0 at τ iff at M(τ). By `lem-reduction-to-fundamental-set` every point is G₂-equivalent to a point of F = Ω₀ ∪ Ω₀′ ∪ iℝ₊ ∪ (left edge) ∪ (left circle). The left edge goes to iℝ₊ by τ ↦ τ + 1. The left circle |τ + ½| = ½ goes to the line Re τ = 1 by τ ↦ −1/τ (it passes through 0 and −1), and then to iℝ₊ by τ ↦ τ − 1.
- **`thm-theta-lambda-bijective`.** λ maps F bijectively onto ℂ ∖ {0, 1}. The pieces: Ω₀ → {Im w > 0}; Ω₀′ = {−1 < Re < 0, |τ + ½| > ½} → {Im w < 0}; iℝ₊ → (0, 1); the left edge {Re τ = −1} ∩ F → (−∞, 0); the left circle {|τ + ½| = ½} ∩ ℍ → (1, ∞). *Proof:* Ω₀′ is the reflection of Ω₀ in iℝ, and `thm-theta-lambda-functional` (e) carries the result. On each boundary arc λ is real, continuous, with the end limits from `lem-theta-lambda-cusps` (transported by (a), (b)); it is strictly monotone because λ′ ≠ 0 there (`cor-theta-lambda-derivative`, proved just before from Ω₀, Ω₀′ and the local mapping theorem only, so there is no circularity). Injectivity across pieces: the five image sets are disjoint.
- **`cor-theta-lambda-same-value`.** If λ(τ) = λ(τ′) then τ′ = g(τ) for some g ∈ G₂. *Proof:* reduce both into F (`lem-reduction-to-fundamental-set`), then use injectivity on F.
- **`exm-lambda-special-values`.** λ(i) = ½; λ(1 + i) = −1; λ((−1 + i)/2) = 2 (a point of the left circle); λ(e^{2πi/3}) = e^{−πi/3}. Derivation of the last: e^{2πi/3} = ρ is fixed by τ ↦ −1/(τ + 1) (since ρ + 1 = −ρ²), and λ(−1/(τ + 1)) = 1/(1 − λ(τ)); so λ(ρ)² − λ(ρ) + 1 = 0, and ρ ∈ Ω₀′ forces Im λ(ρ) < 0.
- **Remark** (`rem-universal-covering`, prose only): λ: ℍ → ℂ ∖ {0, 1} is a covering map, and since ℍ is simply connected it is the universal covering; the chapter never uses the words beyond this remark, because §5 needs only path lifting.

## 05-lifting-little-picard.md — Lifting through λ and the little Picard theorem

**Main-line budget ≤ 3,500 words.** Hook paid here.

- **Opening frame.** CA.8a `thm-lift-local-homeomorphism` lifts maps through any φ with φ′ ≠ 0 and the path-lifting property. λ has φ′ ≠ 0 (`cor-theta-lambda-derivative`); path lifting is what remains.
- **Failure that motivates `def-lift-through-lambda`.** If f is entire and omits 0, then f = e^g (CA.8a `cor-roots-and-logs-by-monodromy`), and g can be any entire function: the logarithm unrolls ℂ ∖ {0} by ℂ, which carries no restriction. If f also omits 1, then g omits 2πiℤ: infinitely many omitted values, still no bound. The fix is to unroll ℂ ∖ {0, 1} by a region with a Liouville property: ℍ.
- **`def-lift-through-lambda`.** For a region W and holomorphic f: W → ℂ ∖ {0, 1}, a lift of f through λ is a holomorphic h: W → ℍ with λ ∘ h = f.
- **`thm-theta-lambda-path-lifting`.** λ: ℍ → ℂ ∖ {0, 1} has the path-lifting property (CA.8a `def-path-lifting-property`): for every path γ: [0, 1] → ℂ ∖ {0, 1} and τ₀ with λ(τ₀) = γ(0) there is a path γ̃ in ℍ with γ̃(0) = τ₀ and λ ∘ γ̃ = γ.
  - **[SW] Scratch Work (first appearance of "lift through λ").** Lift locally with an inverse of λ (exists since λ′ ≠ 0). Let s be the supremum of the t up to which a lift exists. At γ(s) pick any τ₁ with λ(τ₁) = γ(s) (surjectivity, `thm-theta-lambda-bijective`) and a local inverse ψ₁ near γ(s). The lift we already have at a time t₂ slightly before s, and ψ₁(γ(t₂)), have the same λ-value, so they differ by some g ∈ G₂ (`cor-theta-lambda-same-value`). Then g ∘ ψ₁ ∘ γ continues the lift past s. The danger "the lift runs off to ∂ℍ" never arises, because g ∘ ψ₁ takes values in ℍ.
  - *Proof:* as above, with: local inverses from `thm-inverse-holomorphic`; the agreement g ∘ ψ₁ ∘ γ = γ̃ on [t₂, s) by local injectivity of λ and connectedness of [t₂, s) (the set where they agree is open and closed); the supremum is attained and equals 1 by the same step at s = 1.
  - *Self-explain:* where would the argument break if λ′ vanished somewhere?
- **`thm-lifting-through-lambda`.** Let W be a simply connected region, f: W → ℂ ∖ {0, 1} holomorphic, z₀ ∈ W, τ₀ ∈ ℍ with λ(τ₀) = f(z₀). There is a unique lift h of f through λ with h(z₀) = τ₀. *Proof:* CA.8a `thm-lift-local-homeomorphism` with φ = λ, U = ℍ, V = ℂ ∖ {0, 1}, using `cor-theta-lambda-derivative` and `thm-theta-lambda-path-lifting`.
- **`thm-little-picard-theta`.** An entire function that omits two distinct complex values is constant.
  - *Proof (worked in full; first of the faded triple):* normalize the omitted values to 0, 1 by f ↦ (f − a)/(b − a). Lift: h: ℂ → ℍ entire with λ ∘ h = f (`thm-lifting-through-lambda`; ℂ is simply connected). The Cayley map C(τ) = (τ − i)/(τ + i) sends ℍ into 𝔻, so C ∘ h is bounded entire, constant (`thm-liouville`); so h is constant and f = λ ∘ h is constant.
  - Hook paid: one sentence returning to the heat kernel.
- **`cor-meromorphic-three-values`.** A meromorphic function on ℂ that omits three distinct values of ℂ ∪ {∞} is constant. *Proof:* a Möbius map M sending the three values to 0, 1, ∞ (CA.10) makes M ∘ f entire and omitting 0, 1.
- **Weird examples** (enter the §6 table): e^z omits exactly one value (sharpness); tan z is meromorphic on ℂ and omits exactly ±i (two values; the meromorphic count is three).
- **Prose:** compare CA.14 in two sentences: Bloch's route needs no special function but needs Bloch's constant; this route needs λ but nothing quantitative. Neither proof is shorter once its inputs are counted.

## 06-normality-great-picard.md — The fundamental normality test and the great Picard theorem

**Main-line budget ≤ 4,500 words.** Last section: R group here.

- **Opening frame.** Recall CA.5: a family of holomorphic functions is normal if every sequence has a locally uniformly convergent subsequence; Montel: locally bounded families are normal. The goal is a normality criterion with no bound at all, only two omitted values.
- **Failure that motivates `def-normal-extended`.** The constant functions fₙ = n (n ≥ 2) omit 0 and 1, and no subsequence converges to a holomorphic function; yet they plainly "converge to ∞". A criterion based on omitted values must allow ∞ as a limit.
- **`def-normal-extended`.** A family ℱ of holomorphic functions on a region D is normal in the extended sense if every sequence in ℱ has a subsequence that converges locally uniformly on D either to a holomorphic function or to ∞ (|fₙ| → ∞ uniformly on compact subsets). Normality is local: it suffices that each point has a disk on which ℱ is normal (diagonal argument, as in CA.5).
- **Quick check.** {nz : n ≥ 1} on 𝔻 ∖ {0}: normal in the extended sense? (Yes, → ∞.) On 𝔻? (No: at 0 the values stay 0.) {zⁿ} on 𝔻? (Yes: → 0.)
- **`lem-pseudo-hyperbolic-height`.** For τ, τ′ ∈ ℍ, write ρ(τ, τ′) = |τ − τ′|/|τ − τ̄′| < 1. (a) If h: 𝔻(0, R) → ℍ is holomorphic then ρ(h(z), h(w)) ≤ |z − w|R/|R² − w̄z| (Schwarz–Pick, transported by Cayley maps; CA.5). (b) If ρ(τ, τ′) ≤ r < 1 then Im τ′ · (1 − r)/(1 + r) ≤ Im τ ≤ Im τ′ · (1 + r)/(1 − r). *Proof of (b):* fix τ′ = i by an affine map τ ↦ (τ − Re τ′)/Im τ′ (preserves ρ and ratios of Im); the set ρ(τ, i) ≤ r is a disk symmetric about iℝ meeting iℝ in [i(1 − r)/(1 + r), i(1 + r)/(1 − r)], and Im is extreme at those points.
- **`lem-theta-lambda-near-cusps`.** For every ε > 0 there is M such that: |λ(τ)| < ε if Im τ > M; |λ(τ) − 1| < ε if Im(−1/τ) > M; |λ(τ)| > 1/ε if Im(−1/(τ ∓ 1)) > M. Moreover, if τₙ ∈ F̄ ∩ ℍ and τₙ → c ∈ {∞, 0, 1, −1}, then respectively Im τₙ, Im(−1/τₙ), Im(−1/(τₙ ∓ 1)) → ∞. *Proof:* first part from `lem-theta-lambda-expansion` and `thm-theta-lambda-functional` (a), (b) (for c = −1 use λ(τ) = λ(τ + 2)). Second part: near 0, F̄ lies outside both circles |τ ± ½| < ½, and τ ↦ −1/τ maps that exterior into the strip |Re| ≤ 1; a point of the strip tending to ∞ has Im → ∞. Near ±1, translate by ∓1 first (F̄ − 1 near 0 lies in Re ≤ 0 outside |w + ½| < ½, which −1/w maps into 0 ≤ Re ≤ 1).
- **`thm-fundamental-normality`** (Montel's fundamental normality test). On a region D, the family of all holomorphic functions D → ℂ ∖ {0, 1} is normal in the extended sense.
  - *Proof Idea:* lift each fₙ through λ on a disk, normalizing the lift at the centre to lie in F̄; the lifts map into ℍ ≅ 𝔻, so Montel applies to them. Either the lifts converge inside ℍ (then fₙ converge to a holomorphic function), or they escape to ∂ℍ, and the normalization forces escape to a cusp (then fₙ → 0, 1 or ∞ by the cusp lemma).
  - *Self-explain:* why must the lift be normalized at z₀ and not elsewhere?
  - *Proof:* by locality, take D = 𝔻(z₀, R) (simply connected). Given fₙ, choose τₙ ∈ F with λ(τₙ) = fₙ(z₀) (`thm-theta-lambda-bijective`) and the lift hₙ with hₙ(z₀) = τₙ (`thm-lifting-through-lambda`). gₙ = C ∘ hₙ: D → 𝔻 is bounded; Montel (CA.5) gives a subsequence gₙ → g locally uniformly, with |g| ≤ 1. By the maximum modulus theorem either |g| < 1 on D or g ≡ c with |c| = 1.
    - Case |g| < 1: hₙ = C⁻¹ ∘ gₙ → h = C⁻¹ ∘ g locally uniformly in ℍ (C⁻¹ is uniformly continuous on compact subsets of 𝔻, and g(K) is a compact subset of 𝔻), so fₙ = λ ∘ hₙ → λ ∘ h locally uniformly.
    - Case g ≡ c, |c| = 1: τₙ = hₙ(z₀) → C⁻¹(c) ∈ ℝ ∪ {∞}; since τₙ ∈ F̄, the limit is a cusp c* ∈ {∞, 0, 1, −1}, and (passing to a subsequence along which one cusp is approached) by `lem-theta-lambda-near-cusps` the corresponding height of τₙ → ∞. For K ⊂ D compact, `lem-pseudo-hyperbolic-height` (a) bounds ρ(hₙ(z), τₙ) ≤ r_K < 1 for z ∈ K; applying (b) to hₙ, or to −1/hₙ, −1/(hₙ ∓ 1) (also holomorphic into ℍ, and ρ is invariant under these maps), the height of hₙ(z) → ∞ uniformly on K. By the cusp lemma fₙ → 0, 1 or ∞ uniformly on K. The constant limits 0 and 1 are holomorphic functions; ∞ is the extended case.
- **`cor-schottky-from-normality`.** For 0 < r < 1 and a > 0 there is M(a, r) such that every holomorphic f: 𝔻 → ℂ ∖ {0, 1} with |f(0)| ≤ a satisfies |f(z)| ≤ M(a, r) for |z| ≤ r. *Proof:* otherwise a sequence fₙ with max_{|z|≤r}|fₙ| → ∞; a subsequence converges uniformly on |z| ≤ r to a holomorphic function (bounded there, contradiction) or to ∞ (contradicting |fₙ(0)| ≤ a). Prose: CA.14 proves Schottky with an explicit bound via Bloch; here M is not explicit.
- **`thm-great-picard-theta`.** If f is holomorphic on 0 < |z| < r and omits two distinct complex values, then 0 is a removable singularity or a pole of f. Equivalently: near an essential singularity, f takes every complex value, with at most one exception, infinitely often.
  - *Proof:* normalize to omitted values 0, 1. Let A = {r/4 < |z| < r} and fₙ(z) = f(z/2ⁿ) on A; all omit 0, 1, so by `thm-fundamental-normality` a subsequence f_{n_k} converges uniformly on the circle |z| = r/2 either to a holomorphic φ, so |f| ≤ M on the circles |z| = r/2^{n_k+1}, hence on the annuli between consecutive ones (maximum modulus), hence near 0, and 0 is removable (CA.3 Riemann); or to ∞, so |f| ≥ 1 on those circles, and the same argument for 1/f (holomorphic on a small punctured disk since f ≠ 0) makes 0 removable for 1/f, so f has a pole or a removable singularity. The "infinitely often" form: if two values were taken only finitely often, a smaller punctured disk omits both.
- **`cor-values-infinitely-often`.** A nonpolynomial entire function takes every complex value, with at most one exception, infinitely often. *Proof:* f(1/z) has an essential singularity at 0 (a pole or removable singularity at 0 would make f a polynomial, CA.3).

The density claim is stated without proof (it needs more of the group than this chapter develops).
