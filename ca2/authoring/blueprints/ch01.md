**Purpose.**
- CA.6 solved the Dirichlet problem on a disc with a formula. On a general region there is no formula. This chapter solves it anyway, by a method that builds the solution as the *largest* function lying below the data: Perron's method. The engine is a class of functions closed under max, the subharmonic functions, and one compactness fact for harmonic functions, Harnack's principle.
- The method succeeds or fails one boundary point at a time. Whether it succeeds at a point is a local geometric question (a barrier), and the chapter answers it: in the plane, the method fails only at boundary points that are isolated pieces of the complement, like the centre of a punctured disc.
- The payoff: Green's function exists on every such region, and on a simply connected one it produces the Riemann map. That is a second proof of the Riemann mapping theorem, independent of the normal-families proof in CA.5.

**Named moves** (in `index.md`, "Named moves"):
- **Harnack chain.** To compare a positive harmonic function at two far-apart points, join them by a chain of overlapping discs and multiply the one-disc Harnack constants.
- **Harmonic replacement.** Inside a disc, replace a subharmonic function by the Poisson integral of its boundary values: the result is still subharmonic, still in every class v was in, and larger.
- **Replace and climb.** To show a supremum of subharmonic functions is harmonic near a point: pick a sequence approaching the sup at the point, take running maxima, replace on a disc, and let Harnack's principle produce a harmonic limit.
- **Barrier squeeze.** Trap the Perron function between f(ζ₀) ± (ε + M·ψ) where ψ is a barrier: the upper function bounds every member of 𝔓 from above, the lower function is itself a member.
- **Logarithmic comparison.** To ignore one boundary point a, compare with u ± t log|z − a| on a small annulus and let t → 0. A single point carries no weight for bounded harmonic functions.

## 01-harnack.md — Positive harmonic functions: Harnack's inequality and principle (≤ 3,500 words)

- **Hook.** A positive harmonic function on 𝔻 with u(0) = 1: how large can u(½) be? The mean value property says only that the average on each circle is 1. Yet the answer is a fixed number (3), and the reason is the Poisson kernel's two-sided bounds.
- **`thm-harnack-inequality`.** Let u be harmonic and u ≥ 0 on D(a, R). For |z − a| = r < R:
  (R − r)/(R + r) · u(a) ≤ u(z) ≤ (R + r)/(R − r) · u(a).
  - *Proof Idea:* the Poisson kernel on D(a, ρ) at |z − a| = r lies between (ρ − r)/(ρ + r) and (ρ + r)/(ρ − r) times 1/(2π)·(normalization); integrate against u ≥ 0 and use the mean value property for u(a). Prove it on D̄(a, ρ) for ρ < R (u continuous there, so CA.6's Poisson representation applies), then let ρ → R.
  - Hypothesis check (in the text): u ≥ 0 is needed (u = Re z on 𝔻, u(0) = 0, so both bounds force u ≡ 0 at |z| = r, false).
- **`exm-harnack-sharp`.** For ζ on the unit circle, P(z, ζ) = (1 − |z|²)/|ζ − z|² is positive harmonic on 𝔻 with value 1 at 0, and attains the upper bound at z = rζ and the lower bound at z = −rζ. So the constants cannot be improved.
- **`cor-harnack-compact`** (Harnack chain). Let Ω be a region and K ⊂ Ω compact. There is C = C(K, Ω) ≥ 1 such that every harmonic u > 0 on Ω satisfies u(z₁) ≤ C u(z₂) for all z₁, z₂ ∈ K.
  - *Proof Idea:* cover K by finitely many discs D(cⱼ, δ) with D(cⱼ, 2δ) ⊂ Ω (δ from a Lebesgue-number / distance-to-boundary argument); on each D(cⱼ, δ), sup/inf ≤ 9 by `thm-harnack-inequality` on D(cⱼ, 2δ) (each value is within the factor (2δ + δ)/(2δ − δ) = 3 of u(cⱼ)). The union of the K-cover together with a fixed connected compact set joining the centres (Ω is path connected; a polygonal path per pair) is covered by finitely many such discs N; chaining gives C ≤ 9^N.
  - **Named move: Harnack chain**, introduced here.
- **Failure first.** For a general sequence of harmonic functions, pointwise convergence at one point says nothing elsewhere (uₙ = n·Re z on 𝔻: uₙ(0) = 0 for all n, divergence everywhere else). Monotonicity changes this.
- **`thm-harnack-principle`.** Let (uₙ) be harmonic on a region Ω with u₁ ≤ u₂ ≤ ⋯. Then either uₙ → +∞ locally uniformly on Ω, or uₙ converges locally uniformly on Ω to a harmonic function.
  - *Proof Idea:* put vₙ = uₙ − u₁ ≥ 0. On a disc D(a, R) ⊂ Ω, Harnack on D(a, R) for v_m − v_n ≥ 0 (m ≥ n) compares the increment at a with the increment on D̄(a, R/2) both ways (factor 3). So the set A = {a : uₙ(a) → ∞} is open (lower bound) and its complement is open (upper bound, plus Cauchy-ness locally uniformly on D(a, R/2)). Connectedness gives A = Ω or A = ∅. Locally uniform Cauchy ⇒ locally uniform limit, harmonic by CA.6.
  - Write out the "both open" step fully; it is the model for later open–closed arguments in CA2.
  - Remark: the same holds for decreasing sequences (apply to −uₙ), with −∞.
- **`cor-harnack-series`.** If hₖ ≥ 0 are harmonic on Ω and Σ hₖ(z₀) < ∞ at one point z₀, then Σ hₖ converges locally uniformly on Ω to a harmonic function. (Partial sums increase; they do not tend to ∞ at z₀.) Used in §04*.
- **Prose: Montel's sibling.** CA.5's Montel theorem: locally bounded families of holomorphic functions are normal. Harnack is the harmonic analogue, and exercise C1 makes it literal. Open the second hook here.
- **Warning.** Harnack's inequality is about *non-negative* functions. A bounded harmonic function needs the shift u + M first, and the constants then involve M.
- **Quick check.** u > 0 harmonic on D(0, 3), u(0) = 4. Between which bounds must u(1) lie? *Answer:* r = 1, R = 3: (2/4)·4 = 2 ≤ u(1) ≤ (4/2)·4 = 8. (The bounds are best possible but not attained by functions harmonic on the open disc; the answer says only "between 2 and 8".)
- **Exercises.**
  - **A1.** u ≥ 0 harmonic on 𝔻, u(0) = 5. Bound u on |z| = 1/4. *Answer:* (3/4)/(5/4)·5 = 3 ≤ u ≤ (5/4)/(3/4)·5 = 25/3.
  - **A2.** Show the bound in A1 is sharp using `exm-harnack-sharp` (scale by 5). *Answer:* 5P(z, 1) at z = ±1/4 gives 25/3 and 3.
  - **B1.** Prove that a positive harmonic function on ℂ is constant. *Answer:* fix z, let R → ∞ in `thm-harnack-inequality`; both bounds tend to u(0). Contrast: u = Im z on the upper half-plane (weird table).
  - **B2.** Show that for every positive harmonic u on 𝔻, sup_{|z| ≤ 1/2} u ≤ 9 · inf_{|z| ≤ 1/2} u, and that 9 is best possible. *Answer:* each side is within factor 3 of u(0); P(z, 1) gives 3 at z = 1/2 and 1/3 at z = −1/2.
  - **B3.** State and prove Harnack's principle for decreasing sequences. *Answer:* apply the theorem to −uₙ.
  - **C1** (Harnack compactness). Let 𝓗 = {u harmonic on Ω : u > 0, u(z₀) = 1}. Prove every sequence in 𝓗 has a subsequence converging locally uniformly on Ω to a harmonic function u > 0 with u(z₀) = 1 (positivity: u ≥ 0 and u(z₀) = 1, then the minimum principle). *Answer outline:* `cor-harnack-compact` gives local boundedness; the gradient bound |∇u(a)| ≤ (2/R) u(a) on D(a, R) ⊂ Ω (differentiate the Poisson kernel at the centre: |∂ₓ P| ≤ 2/R there) gives local equicontinuity; Arzelà–Ascoli (AN2.5) on an exhaustion by compacts plus a diagonal argument; the limit is harmonic by CA.6 and u(z₀) = 1. *S2a: check the constant 2/R.*
  - **C2.** Let hₖ ≥ 0 be harmonic on 𝔻 with Σ hₖ(0) = 1. Show Σ hₖ is harmonic on 𝔻 and bounded by (1 + r)/(1 − r) on |z| = r. *Answer:* `cor-harnack-series`, then Harnack for the sum.

## 02-subharmonic.md — Subharmonic functions (≤ 4,000 words)

- **Hook: a failure.** Perron's plan (announced here in one paragraph): to solve the Dirichlet problem on Ω, take the supremum of all functions that lie below the data and "could be part of a solution". Harmonic functions are the wrong class: max(u₁, u₂) of harmonic functions is not harmonic (max(x, −x) = |x|, which fails the mean value property at 0). We need a class closed under max that is still controlled by harmonic functions. In one variable the analogue is convex functions: a convex function lies below the linear function (the 1-D harmonic function) with the same endpoint values, and the max of two convex functions is convex. Make this analogy a short framed paragraph with a picture (graph of a convex function under a chord).
- **`def-subharmonic`** (failure-motivated). Let Ω be open. A **continuous** function v : Ω → ℝ is subharmonic if for every closed disc D̄ ⊂ Ω and every function u continuous on D̄ and harmonic on D with v ≤ u on ∂D, we have v ≤ u on D. ("Below every harmonic majorant on every disc.") `def-superharmonic`: −v subharmonic.
  - Say plainly: the book keeps subharmonic functions continuous. The full theory allows upper semicontinuous functions with values in [−∞, ∞) (so that log|f| belongs); its circle averages need the Lebesgue integral, which is MT. Prose pointer only.
  - Slogan: *subharmonic = lies below its harmonic replacement on every disc.*
- **`thm-subharmonic-local`** (the usable test). For continuous v on Ω, the following are equivalent:
  (a) v is subharmonic;
  (b) v(a) ≤ A_v(a, r) for every D̄(a, r) ⊂ Ω;
  (c) every a ∈ Ω has r_a > 0 with v(a) ≤ A_v(a, r) for 0 < r < r_a.
  - *Proof Idea:* (a)⇒(b): the Poisson integral u of v|_{∂D(a,r)} is a harmonic majorant on the circle, so v(a) ≤ u(a) = A_v(a, r). (b)⇒(c) trivial. (c)⇒(a): w = v − u is continuous on D̄, satisfies (c) inside D (u has the mean value property), and w ≤ 0 on ∂D. A maximum principle for functions with property (c) (proved first, as Step 1: if w attains its max m at an interior point, the set {w = m} is open by (c) and continuity — w ≤ m on the small circle and average ≥ m force w = m on each small circle — and closed, so it is the whole component) gives w ≤ 0.
  - Consequence stated: subharmonicity is a local property.
- **`thm-subharmonic-max-principle`.** v subharmonic on a region Ω, attaining its supremum at a point of Ω ⇒ v constant. (Step 1 above, now for subharmonic v via (c).)
- **`cor-subharmonic-boundary-max`.** Ω bounded region, v subharmonic on Ω, and limsup_{z→ζ} v(z) ≤ m for every ζ ∈ ∂Ω. Then v ≤ m on Ω, and v < m unless v ≡ m. (Proof by compactness of Ω̄: extend v by the limsup to an upper semicontinuous function on Ω̄... avoid "usc": argue directly — if sup_Ω v > m, take zₙ with v(zₙ) → sup, a limit point lies in Ω̄; not on ∂Ω by the limsup hypothesis; so in Ω, where v attains its sup: constant, contradiction.)
- **`thm-subharmonic-laplacian`.** If v ∈ C²(Ω), then v is subharmonic iff Δv ≥ 0 on Ω.
  - *Proof Idea:* Taylor's theorem to second order at a, averaged over the circle: A_v(a, r) = v(a) + (r²/4)Δv(a) + o(r²) (first-order terms and the mixed term average to 0; the averages of cos²θ and sin²θ are ½). If Δv > 0 on Ω, (c) holds; for Δv ≥ 0 apply this to v + ε|z|² (Δ = 4ε) and let ε → 0 (sub-mean-value inequalities pass to uniform limits on circles). Conversely, if Δv(a) < 0 then A_v(a, r) < v(a) for small r, contradicting (b).
  - No Green's identity needed; say so (the old stub's Green-identity route is dropped).
- **`prp-subharmonic-operations`.** (i) v₁ + v₂ and cv (c ≥ 0) are subharmonic; (ii) max(v₁, v₂) is subharmonic; (iii) a uniform limit on compacts of subharmonic functions is subharmonic; (iv) if φ: ℝ → ℝ is convex and non-decreasing, φ ∘ v is subharmonic (exercise B1). All via (b)/(c).
- **`exm-min-not-subharmonic`.** min(x, −x) = −|x|: at 0, v(0) = 0 > A_v(0, r) = −2r/π. So the class is not closed under min. (Compute the average: (1/2π)∫|r cos θ| dθ = 2r/π.)
- **`prp-modulus-subharmonic`.** f holomorphic on Ω ⇒ |f| is subharmonic, and |f|^p is subharmonic for every p > 0.
  - |f|: Cauchy's formula on a circle gives |f(a)| ≤ A_{|f|}(a, r).
  - |f|^p: near a with f(a) ≠ 0, f has a holomorphic p-th power branch g on a small disc (CA.4: holomorphic log of a zero-free function on a disc), and |f|^p = |g|; at a zero, |f(a)|^p = 0 ≤ any average of a non-negative function. Then `thm-subharmonic-local` (c).
- **`cor-max-log-modulus`.** For f holomorphic on Ω (not identically 0) and c ∈ ℝ, max(log|f|, c) is subharmonic. Same two-case argument: near a non-zero, log|f| is harmonic (real part of a local log), so the max with c is subharmonic; near a zero, the value is c and every average of a function ≥ c is ≥ c. Also log(1 + |f|²) is subharmonic: Δ(w ∘ f) = |f′|²(Δw) ∘ f for C² w (state as a one-line computation with ∂, ∂̄), and Δ log(1 + |z|²) = 4/(1 + |z|²)².
- **`exm-subharmonic-catalogue`.** One table: |z|², e^{x}, |e^{z}|, max(x, 0), log(1 + |z|²), |sin z|, max(log|z|, 0) subharmonic; −|z|, x³, min(x, −x) not; x² − y² harmonic (both).
- **Weird examples** (to the table): log|f| (value −∞ at zeros; not in the continuous class; the repair `cor-max-log-modulus`); −|x|^{2−n} in ℝⁿ (n ≥ 3), subharmonic, bounded above, non-constant: contrast with exercise C1 (prose, see PDE).
- **Warning.** "Sub" points the wrong way for intuition: subharmonic functions lie *below* harmonic ones and satisfy the *maximum* principle (not the minimum principle). The witness: |z|² on 𝔻 attains its minimum at the interior point 0 and is not constant.

## 03-perron.md — Perron's method: the candidate solution is harmonic (≤ 3,500 words)

- **Setting.** Ω a bounded region, f : ∂Ω → ℝ continuous (∂Ω is compact, so |f| ≤ M). The Dirichlet problem: find u continuous on Ω̄, harmonic on Ω, u = f on ∂Ω. `def-dirichlet-region`: a bounded region where this is solvable for every continuous f. Uniqueness is free (CA.6 maximum principle); existence is the question.
- **`def-harmonic-replacement`.** v continuous subharmonic on Ω, D̄ ⊂ Ω a closed disc. v_D = v on Ω ∖ D, v_D = P_D[v|_{∂D}] on D.
- **`lem-harmonic-replacement`.** v_D is continuous on Ω, subharmonic on Ω, harmonic on D, and v ≤ v_D.
  - **Scratch Work** (first appearance of the move; kept apart from the proof): draw v, the disc, the Poisson "tent" over the disc; ask which inequality each claim needs. Continuity across ∂D is CA.6's boundary continuity of the Poisson integral. v ≤ v_D on D is the definition of subharmonic. Subharmonic at points of ∂D is the only real point: at a ∈ ∂D, v_D(a) = v(a) ≤ A_v(a, r) ≤ A_{v_D}(a, r) because v ≤ v_D everywhere. Inside D it is harmonic, outside D it is v.
  - Then the forward proof, citing `thm-subharmonic-local` (c).
  - **Named move: harmonic replacement.**
- **`def-perron-family`.** 𝔓(f) = {v continuous subharmonic on Ω : limsup_{z→ζ} v(z) ≤ f(ζ) for every ζ ∈ ∂Ω}. **`def-perron-function`.** u_f(z) = sup{v(z) : v ∈ 𝔓(f)}.
  - −M ∈ 𝔓(f), so 𝔓(f) ≠ ∅; every v ∈ 𝔓(f) satisfies v ≤ M (`cor-subharmonic-boundary-max`). So −M ≤ u_f ≤ M.
- **`lem-perron-family-closed`.** v₁, v₂ ∈ 𝔓(f) ⇒ max(v₁, v₂) ∈ 𝔓(f); v ∈ 𝔓(f), D̄ ⊂ Ω ⇒ v_D ∈ 𝔓(f). (Replacement changes nothing near ∂Ω.)
- **`thm-perron-harmonic`.** u_f is harmonic on Ω.
  - **Scratch Work** (first appearance of replace and climb): the sup of infinitely many functions need not even be continuous; the plan is to show that on each disc u_f *equals* a harmonic function. Fix D̄ ⊂ Ω and z₀ ∈ D. Choose vₙ ∈ 𝔓(f) with vₙ(z₀) → u_f(z₀). Climb: Vₙ = max(−M, v₁, …, vₙ) is increasing in n and in 𝔓(f). Replace: Wₙ = (Vₙ)_D is still increasing (check: replacement preserves order, since the Poisson integral is monotone), in 𝔓(f), harmonic on D, ≤ M. Harnack's principle on D: Wₙ → U harmonic on D, U ≤ u_f, U(z₀) = u_f(z₀). Is U = u_f on all of D? Take z₁ ∈ D and redo the climb with sequences good at z₁ *and* dominating the old Vₙ; get U₁ ≥ U harmonic on D with U₁(z₁) = u_f(z₁) and U₁(z₀) = u_f(z₀) = U(z₀). Then U − U₁ ≤ 0 is harmonic and attains 0 at z₀: U ≡ U₁ (CA.6 maximum principle), so U(z₁) = u_f(z₁).
  - Then the forward proof in four numbered steps.
  - **Named move: replace and climb.**
- **`prp-perron-classical`.** If the Dirichlet problem for f has a solution U, then U = u_f on Ω. (U ∈ 𝔓(f); and v − U ≤ 0 for every v ∈ 𝔓(f) by `cor-subharmonic-boundary-max`.) So Perron's method finds every classical solution; the remaining question is only whether u_f takes the values f at the boundary.
- **`exm-perron-annulus`.** Ω = {1 < |z| < 2}, f = 0 on |z| = 1, f = 1 on |z| = 2. The harmonic function log|z| / log 2 solves the problem, so it is u_f by `prp-perron-classical`.
- **Remark (prose).** The definition makes sense for bounded (not necessarily continuous) f and still gives a harmonic u_f by the same proof; this is how harmonic measure is defined later (CA.9 / PR pointer, no `@ref`).
- **Warning.** u_f is defined as a sup over an uncountable family: do not conclude continuity of u_f from continuity of each v. Harmonicity comes from the replacement argument, not from the definition.
- **Quick check.** Ω = 𝔻, f(ζ) = Re ζ. What is u_f? *Answer:* Re z (the classical solution, `prp-perron-classical`).
- **Exercises.**
  - **A1.** Show directly from the definitions that −M ∈ 𝔓(f) and that every v ∈ 𝔓(f) satisfies v ≤ M.
  - **A2.** Ω = D(0, 2), f(ζ) = (Re ζ)² − (Im ζ)². Find u_f. *Answer:* x² − y² (harmonic, continuous to the boundary).
  - **B1.** Show that harmonic replacement is monotone: v ≤ w on Ω ⇒ v_D ≤ w_D. *Answer:* the Poisson kernel is positive.
  - **B2.** Prove: f ≤ g ⇒ u_f ≤ u_g; u_{f+c} = u_f + c; |u_f − u_g| ≤ max_{∂Ω}|f − g|. *Answer:* 𝔓(f) ⊂ 𝔓(g); v ↦ v + c is a bijection 𝔓(f) → 𝔓(f + c); combine the first two with f ≤ g + δ.

## 04-barriers.md — Barriers: when the Perron function takes its boundary values (≤ 4,500 words, of which the starred subsection ≤ 1,300)

- **Hook paid, first half: the punctured disc.**
  - **`thm-punctured-disc-irregular`.** Let Ω = 𝔻 ∖ {0}, f = 0 on |ζ| = 1, f(0) = 1. Then u_f ≡ 0. In particular the Dirichlet problem for f has no solution, and Ω is not a Dirichlet region.
  - **Scratch Work** (first appearance of the logarithmic comparison): every v ∈ 𝔓(f) is ≤ 1. We want v ≤ 0. The function t·log(1/|z|) is harmonic, 0 on the outer circle, and huge near 0, so it beats the "1 at the centre" for every t > 0, however small. Compare v with it on an annulus ρ < |z| < 1 whose inner circle is so small that t log(1/ρ) ≥ 1, then let t → 0.
  - Proof: for v ∈ 𝔓(f), t > 0 and ρ = e^{−1/t}, the function v − t log(1/|z|) is subharmonic on ρ < |z| < 1 with limsup ≤ 0 at |z| = 1 and ≤ 1 − 1 = 0 at |z| = ρ; so v ≤ t log(1/|z|) on ρ < |z| < 1, hence on 0 < |z| < 1 (ρ → 0 as t → 0 is irrelevant: for fixed z take t small enough that ρ < |z|... careful: fix z, then for every t with e^{−1/t} < |z| get v(z) ≤ t log(1/|z|); let t → 0). So v ≤ 0 and u_f ≤ 0; and 0 ∈ 𝔓(f)? limsup at 0 of the zero function is 0 ≤ 1, at the circle 0 ≤ 0: yes. So u_f ≡ 0, and u_f(z) ↛ 1 as z → 0.
  - **Named move: logarithmic comparison.**
  - Physical reading: a single point cannot hold heat. The chapter now shows this is the only obstruction in the plane.
- **Failure-motivated definition.** What went wrong at 0 is that nothing in Ω "feels" the point 0 from far away. A barrier is a function that does feel it.
- **`def-barrier`.** Let Ω be a bounded region and ζ₀ ∈ ∂Ω. A barrier at ζ₀ is a family (ψ_r)_{0<r<r₀} such that, writing G_r = Ω ∩ D(ζ₀, r):
  (i) ψ_r is continuous and superharmonic on G_r, and ψ_r > 0 there;
  (ii) ψ_r(z) → 0 as z → ζ₀ in G_r;
  (iii) liminf_{z→w, z∈G_r} ψ_r(z) ≥ 1 for every w ∈ Ω with |w − ζ₀| = r.
  `def-regular-point`: ζ₀ is regular if lim_{z→ζ₀} u_f(z) = f(ζ₀) for every continuous f on ∂Ω.
  - Note: (iii) asks nothing at other boundary points of Ω. This local form is what makes slits and spirals manageable (contrast with a global barrier, `lem-global-barrier-local`).
  - Capping remark (proved in the text, used twice): ψ̂_r = min(ψ_r, 1) on G_r and ψ̂_r = 1 on Ω ∖ D(ζ₀, r) is continuous and superharmonic on Ω, with 0 < ψ̂_r ≤ 1. (Continuity at w ∈ Ω on the circle by (iii); super-mean value at such w because ψ̂_r ≤ 1 = ψ̂_r(w); elsewhere local.)
- **`thm-barrier-boundary-limit`.** Ω bounded region, f continuous on ∂Ω, barrier at ζ₀ ∈ ∂Ω. Then u_f(z) → f(ζ₀) as z → ζ₀.
  - **Scratch Work** (first appearance of the barrier squeeze): normalize f(ζ₀) = 0 (`B2` of §03: u_{f−c} = u_f − c). Given ε, choose δ < r₀ with |f| < ε on ∂Ω ∩ D̄(ζ₀, δ). Upper function W = ε + M ψ̂_δ: superharmonic; at boundary points near ζ₀, W ≥ ε > f; at boundary points away from ζ₀, W = ε + M > f. So every v ∈ 𝔓(f) has v ≤ W, hence u_f ≤ W and limsup u_f ≤ ε at ζ₀ by (ii). Lower function V = −ε − M ψ̂_δ: subharmonic and in 𝔓(f) by the same two cases, so u_f ≥ V and liminf ≥ −ε.
  - Then the forward proof.
  - **Named move: barrier squeeze.**
- **`cor-barrier-dirichlet`.** If every point of ∂Ω has a barrier, Ω is a Dirichlet region, and the solution is u_f extended by f.
- **`prp-dirichlet-region-barrier`** (converse). If Ω is a Dirichlet region, every ζ₀ ∈ ∂Ω has a barrier. Proof: solve with data |ζ − ζ₀|; the solution h is > 0 on Ω (minimum principle; h ≡ 0 is impossible because ∂Ω has points other than ζ₀ — a bounded region's boundary is infinite), continuous on Ω̄, zero only at ζ₀ in Ω̄; put ψ_r = h / m_r with m_r = min{h(z) : z ∈ Ω̄, |z − ζ₀| = r} > 0 (compact, h > 0 off ζ₀; if the set is empty, any constant works). So: Ω is a Dirichlet region iff every boundary point has a barrier iff every boundary point is regular.
- **`lem-global-barrier-local`.** If ω is continuous on Ω̄, superharmonic on Ω, ω(ζ₀) = 0 and ω > 0 on Ω̄ ∖ {ζ₀}, then ψ_r = ω / m_r (m_r as above) is a barrier at ζ₀. (Ahlfors's form of barrier, reduced to ours.)
- **`thm-segment-barrier`.** If ζ₀ ∈ ∂Ω is the endpoint of a segment [ζ₀, ζ₁] with [ζ₀, ζ₁] ∩ Ω̄ = {ζ₀}, then ζ₀ has a barrier.
  - Construction (original presentation): T(z) = (z − ζ₀)/(z − ζ₁) maps ℂ ∖ [ζ₀, ζ₁] onto ℂ ∖ (−∞, 0] (segment points z = ζ₀ + t(ζ₁ − ζ₀), 0 ≤ t < 1, go to t/(t − 1) ≤ 0; CA.10). Let s = √T with the principal branch: holomorphic on ℂ ∖ [ζ₀, ζ₁] with Re s > 0. ω = Re s is harmonic on a neighbourhood of Ω̄ ∖ {ζ₀}, positive there, continuous on Ω̄ with ω(ζ₀) = 0. Apply `lem-global-barrier-local`.
  - **Quick check inside the proof:** why Re √w > 0 for w ∉ (−∞, 0].
- **`cor-convex-dirichlet`.** Every bounded convex region is a Dirichlet region; so is every bounded region whose boundary consists of finitely many disjoint polygons, or more generally finitely many disjoint C¹ Jordan curves (state the polygon case with proof; the C¹ case as a remark with the segment along the outer normal, "check").
  - Convex case: at ζ₀ ∈ ∂Ω take a supporting line; Ω̄ lies in the closed half-plane on one side, and the outward normal segment lies strictly on the other side except ζ₀.
- **`exm-slit-disc`.** Ω = 𝔻 ∖ [0, ½]. At a slit point t ∈ (0, ½), every segment from t meets Ω̄ in more than t (Ω̄ = D̄), so `thm-segment-barrier` does not apply. - **Starred subsection: points on a non-degenerate component (≤ 1,300 words).**

    3. Fix r < r₀ and put Φ(z) = log r − ℓ(z), mapping G_r into the right half-plane H = {Re w > 0} (Re Φ = log(r/|z − ζ₀|)) and the arcs C_r = Ω ∩ {|z − ζ₀| = r} (non-empty since Ω is connected and meets both sides of the circle) injectively onto an open subset E of iℝ. ## 05-green.md — Green's function and the Riemann map (≤ 4,000 words)

- **Hook (failure-motivated).** On the disc, the Poisson kernel solves everything, but it is built from the disc's symmetry. On a general region there is no such kernel, but one function survives: the potential of a unit point charge at a, grounded on the boundary. Its singular part is −log|z − a| (the planar fundamental solution: harmonic off a, a log singularity at a); its regular part is fixed by the Dirichlet problem.
- **`def-green-function`.** Ω a bounded region, a ∈ Ω. A Green's function with pole a is g(z) = g_Ω(z, a) such that g(z) + log|z − a| extends harmonically to Ω, and g(z) → 0 as z → ∂Ω.
- **`thm-green-exists`.** If Ω is a Dirichlet region, g_Ω(·, a) exists for every a ∈ Ω and is unique. Proof: h = solution of the Dirichlet problem with data log|ζ − a| (continuous on ∂Ω since a ∉ ∂Ω); g = h − log|z − a|. Uniqueness: the difference of two is harmonic on Ω and → 0 at ∂Ω.
- **`prp-green-properties`.** (i) g > 0 on Ω ∖ {a} (minimum principle on Ω ∖ D̄(a, ρ) for small ρ: g → +∞ at a); (ii) monotone in the region: Ω₁ ⊂ Ω₂ Dirichlet regions, a ∈ Ω₁ ⇒ g₁(·, a) ≤ g₂(·, a) on Ω₁; (iii) **check:** g(z, a) = g(a, z) is stated as a remark with a pointer, not proved (it needs Green's identity on non-smooth regions; out of scope; exercise A1 checks it on the disc). *S2a: confirm no later chapter of CA2 needs symmetry; if one does, prove it for regions bounded by finitely many smooth curves.*
- **`prp-green-conformal`.** If φ : Ω → Ω′ is a conformal bijection between Dirichlet regions, then g_Ω(z, a) = g_{Ω′}(φ(z), φ(a)). Proof: φ is a homeomorphism, so z → ∂Ω iff φ(z) → ∂Ω′ (it leaves every compact set); and log|φ(z) − φ(a)| − log|z − a| is harmonic near a since φ′(a) ≠ 0. (Conformal-invariance viewpoint, S&S II ch. 8.)
- **`exm-green-disc`.** g_𝔻(z, a) = log|(1 − āz)/(z − a)|. In particular g_𝔻(z, 0) = log(1/|z|). Proof: the Möbius map z ↦ (z − a)/(1 − āz) and `prp-green-conformal`, or directly.
- **Second hook paid: `thm-green-riemann-map`.** Let Ω be a bounded region with ℂ̂ ∖ Ω connected, and a ∈ Ω. Then Ω is a Dirichlet region (`cor-simply-connected-dirichlet`); write g = g_Ω(·, a) = h − log|z − a|. Let h̃ be a harmonic conjugate of h on Ω (CA.6; Ω is simply connected) and
  F(z) = (z − a) e^{−(h(z) + i h̃(z))}.
  Then F is a conformal bijection of Ω onto 𝔻 with F(a) = 0, and |F| = e^{−g}.
  - Proof route:
    1. F is holomorphic, |F(z)| = |z − a| e^{−h(z)} = e^{−g(z)} < 1 on Ω ∖ {a} (by `prp-green-properties` (i)), F(a) = 0 with F′(a) = e^{−(h(a) + i h̃(a))} ≠ 0, and F ≠ 0 elsewhere.
    2. |F(z)| → 1 as z → ∂Ω (g → 0). So for 0 < ρ < 1 the set K_ρ = {z ∈ Ω : |F(z)| ≤ ρ} is closed in ℂ (it stays away from ∂Ω) and bounded: compact.
    3. CA.4: a cycle Γ in Ω ∖ K_ρ with n(Γ, z) = 1 on K_ρ and n(Γ, z) = 0 for z ∉ Ω. On Γ, |F| > ρ. For |w| < ρ, all zeros of F − w lie in K_ρ (where |F| < ρ... at a zero |F| = |w| < ρ), so the argument principle gives N(w) = (1/2πi)∫_Γ F′/(F − w) dz = number of zeros of F − w in Ω, with multiplicity.
    4. N is continuous in w on |w| < ρ (the integrand is jointly continuous, |F − w| ≥ ρ − |w| > 0 on Γ) and integer-valued, so constant; N(0) = 1 (only zero a, simple). Hence F takes each w with |w| < ρ exactly once. Let ρ → 1.
  - **Comparison with CA.5.** By the uniqueness in CA.5, e^{i h̃(a)} F is *the* Riemann map with f(a) = 0, f′(a) > 0. The extremal problem of CA.5 (maximize |f′(a)|) is solved by |F′(a)| = e^{−h(a)}; the quantity e^{h(a)} is the conformal radius of Ω at a (exercise C1).
  - Remark: this proof needs the Dirichlet problem on Ω, i.e. §04, including the starred subsection for general Ω; for Ω satisfying the segment condition (polygons, convex regions, C¹ Jordan regions) the unstarred §04 suffices. Say so in one sentence so the reader who skipped the starred subsection knows what they have.
- **`cor-green-from-riemann-map`.** Conversely, for any simply connected region Ω ⊊ ℂ (bounded or not) and a ∈ Ω, with φ the Riemann map of CA.5 normalized by φ(a) = 0, the function −log|φ| is positive, harmonic on Ω ∖ {a}, has the singularity −log|z − a| + harmonic, and tends to 0 at ∂Ω in the sense that −log|φ(z)| → 0 when z leaves every compact subset of Ω. For bounded Ω it equals g_Ω(·, a). (Unbounded simply connected regions have a Green's function in this sense though the bounded-region theory above does not apply.)
- **Warning.** g → 0 at the boundary does not mean F extends continuously to ∂Ω; boundary behaviour of conformal maps (Carathéodory) is not proved in this book. |F| → 1 is all that the proof uses.
- **Quick check.** g_𝔻(1/e, 0) = ? *Answer:* 1.
- **Exercises.**
  - **A1.** Compute g_𝔻(½, 0), g_𝔻(0, ½) and g_𝔻(i/2, ½). *Answer:* log 2, log 2, ½ log(17/8). (|i/2 − ½| = √2/2, |1 − i/4| = √17/4.)
  - **A2.** Find g_{D(0,R)}(z, 0) and the map F of `thm-green-riemann-map` for Ω = D(0, R), a = 0. *Answer:* log(R/|z|); h = log R, h̃ = 0, F(z) = z/R.
  - **B1.** Using the Cayley-type map z ↦ (z − a)/(z − ā), show that −log|(z − a)/(z − ā)| = log|(z − ā)/(z − a)| is, for the upper half-plane H and a ∈ H, a positive harmonic function on H ∖ {a} with the right singularity and limit 0 at every point of ℝ. Is it a Green's function in the sense of `def-green-function`? *Answer:* the properties hold; but H is unbounded, so `def-green-function` does not literally apply; it is the Green's function in the sense of `cor-green-from-riemann-map` (tends to 0 also as |z| → ∞).
  - **B2.** Prove `prp-green-properties` (ii). *Answer:* g₂ − g₁ is harmonic on Ω₁ (singularities cancel), and at ∂Ω₁ its liminf is ≥ 0 because g₂ ≥ 0 and g₁ → 0.
  - **B3.** Let Ω be a bounded region with ℂ̂ ∖ Ω connected and a ∈ Ω. Show that the level sets {g = c}, c > 0, are compact and that F maps {g > c} onto the disc |w| < e^{−c}.
  - **C1** (conformal radius). With the notation of `thm-green-riemann-map`, let R(a) = e^{h(a)} = 1/|F′(a)|. Show dist(a, ∂Ω) ≤ R(a) ≤ max_{z∈∂Ω}|z − a|. *Answer:* apply B2 with Ω₁ = D(a, dist) ⊂ Ω and with Ω ⊂ D(a, max) = Ω₂, and compare h(a) using `exm-green-disc` scaled: g_{D(a,r)}(z, a) = log(r/|z − a|), so h = log r for the disc.
  - **C2** (exam style). Let Ω be a bounded region with ℂ̂ ∖ Ω connected, a ∈ Ω, and f : Ω → 𝔻 holomorphic with f(a) = 0. Show |f(z)| ≤ e^{−g_Ω(z, a)} on Ω. *Answer:* f ∘ F⁻¹ : 𝔻 → 𝔻 fixes 0; Schwarz's lemma (CA.5) gives |f(F⁻¹(w))| ≤ |w|, i.e. |f(z)| ≤ |F(z)| = e^{−g}. (Alternatively, log|f| + g is subharmonic... via `cor-max-log-modulus` and the boundary maximum principle, which works without simple connectivity; mention as a remark.)
