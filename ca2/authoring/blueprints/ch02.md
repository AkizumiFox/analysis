**Purpose.**
- A polynomial is determined by its zeros up to a constant factor. This chapter asks how much of that survives for entire functions, and answers in three steps: any zero set with no finite accumulation point is the zero set of some entire function (Weierstrass); the zeros determine the function up to a zero-free factor e^{g}; and when the function grows at finite order, g is a polynomial of controlled degree (Hadamard).
- The bridge between growth and zeros is Jensen's formula: an entire function cannot have many zeros without growing fast.

**Named moves** (in `index.md`, "Named moves"):
- **Convergence factors.** When Π(1 − z/aₙ) diverges, multiply each factor by an exponential that cancels the first Taylor terms of its logarithm; choose how many terms so that the leftover series converges on every disk.
- **Log-derivative transfer.** To prove a product identity F = G, prove F′/F = G′/G off the zeros and match F and G at one point.
- **Liouville through periodicity.** An entire periodic function bounded on one period strip is bounded on ℂ, hence constant.
- **Count zeros by growth.** n(r) log 2 ≤ log M(2r) − log|f(0)| (from Jensen).
- **Good circles.** When a function is small only near its zeros, choose radiuses rₖ → ∞ whose circles avoid small disks around every zero, and estimate there.
- **The real part controls a polynomial.** If Re g ≤ C rₖ^s on |z| = rₖ along rₖ → ∞, then g is a polynomial of degree ≤ s.

## 01-infinite-products.md — Infinite products of holomorphic functions (≤ 3,000 words)

- **Hook.** We want to build functions from their zeros, Π(1 − z/aₙ). First: when does an infinite product mean anything? AN2.12 answered for numbers; we need locally uniform convergence so that the limit is holomorphic.
- **Failure-motivated definition.** Naive: "Π(1+aₙ) converges if the partial products converge." Then Π 1/2 "converges" to 0, and so does any product with one factor 0 followed by anything at all — the limit would forget the factors. Since we want "the product vanishes exactly where a factor vanishes", demand a non-zero limit after discarding finitely many zero factors: `def-product-converges` (finitely many factors 0; the partial products of the rest have a non-zero limit). `def-product-converges-abs`: Π(1+|aₙ|) converges. Short recall of AN2.12: convergence forces aₙ → 0.
- **`thm-product-abs-criterion`.** If Σ|aₙ| < ∞ then Π(1+aₙ) converges, and its value is 0 iff some factor is 0; the product does not depend on the order of the factors. *Route:* AN2.12 for the numerical statement; restate the proof's key inequality |Π_{n≤N}(1+aₙ) − 1| ≤ Π(1+|aₙ|) − 1 ≤ e^{Σ|aₙ|} − 1 with its own display, because §01's uniform version reuses it. (Re-proved in four lines, since AN2.12's proof may use real logarithms only.)
- **`lem-product-log-series`.** Let aₙ ≠ −1 for all n. Then Π(1+aₙ) converges (`def-product-converges`, non-zero limit) iff Σ Log(1+aₙ) converges (principal branch), and then Π(1+aₙ) = exp Σ Log(1+aₙ). *Route (four lines, branch argument):* ⇐ by continuity of exp. ⇒: let P_N → P ≠ 0; then aₙ → 0. Rotate so that P is not on the cut: pick c with |c| = 1 and cP ∉ (−∞, 0], and work with Log(cP_N), which tends to Log(cP). Write S_N = Σ_{n≤N} Log(1+aₙ); then S_N = Log(cP_N) − Log c + 2πi k_N with k_N ∈ ℤ. The differences k_{N+1} − k_N = (Log(1+a_{N+1}) − Log(cP_{N+1}) + Log(cP_N))/(2πi) are integers tending to 0, so k_N is eventually constant and S_N converges. (AN2.12 states only the real-factor version; this lemma is new here.)
- **`def-product-converges-locally-uniformly`** and **`thm-holomorphic-product`.** Let U ⊆ ℂ be open, fₙ: U → ℂ holomorphic, and suppose that for each compact K ⊆ U there are Mₙ(K) with |fₙ| ≤ Mₙ on K and ΣMₙ < ∞ (M-test form; this is all §02 and §03 use. A Remark may note that uniform convergence of Σ|fₙ| on compacts also suffices, by running the estimate pointwise: |P_N(z) − P_M(z)| ≤ exp(Σ|fₙ(z)|)(exp(Σ_{n>M}|fₙ(z)|) − 1); it is not equivalent to the M-test form). Then Π(1+fₙ) converges locally uniformly on U to a holomorphic F. *Proof sketch:* on K, the inequality above gives the uniform Cauchy property of the partial products (bound |P_N − P_M| ≤ |P_M| (e^{Σ_{M<n≤N} Mₙ} − 1) ≤ e^{ΣMₙ}(e^{Σ_{n>M}Mₙ} − 1)); CA.2's Weierstrass convergence theorem gives holomorphy.
- **`cor-product-zeros`.** Under the same hypotheses, F(z) = 0 iff 1+fₙ(z) = 0 for some n, and the multiplicity of a zero of F is the sum of the multiplicities over the factors. *Route:* near z₀ only finitely many factors can vanish (fₙ → 0 uniformly near z₀); split off those finitely many factors; the tail product is non-zero at z₀ by `thm-product-abs-criterion`.
- **`thm-product-log-derivative`.** Under the same hypotheses, F′/F = Σ fₙ′/(1+fₙ) locally uniformly on U minus the zeros of F (and the series converges locally uniformly on compact sets avoiding them). *Route:* (F_N)′/F_N is a finite sum; F_N → F and F_N′ → F′ locally uniformly (CA.2); divide on compacts where F ≠ 0. This is what makes **log-derivative transfer** work in §03.
- **Scratch Work (first appearance of the uniform product estimate).** Before the proof of `thm-holomorphic-product`, a short scratch block: "we know how to make a sum small; turn the product difference into a sum — P_N − P_M = P_M(Π_{M<n≤N}(1+fₙ) − 1) — then bound each bracket by the exponential." Proof follows separately, without the scratch reasoning.
- **Weird examples.**
  - `exm-product-modulus-only`: Π_{n≥2}(1 + i/(n log n)). Π|1 + i/(n log n)|² = Π(1 + 1/(n log n)²) converges, but the argument of the partial product is Σ arctan(1/(n log n)), which diverges (like log log N), so the partial products circle forever and the product diverges. *(Sidecar: numeric partial products; show how slowly the argument grows.)*
  - `exm-product-alternating-sqrt`: Π(1 + (−1)ⁿ/√n), n ≥ 2. Σaₙ converges, but log(1+aₙ) = aₙ − aₙ²/2 + O(n^{−3/2}) and Σ aₙ²/2 = Σ 1/(2n) diverges, so the partial products tend to 0: divergent by the definition.
  - `exm-product-converges-series-diverges`: a₂ₖ₋₁ = k^{−1/2}, a₂ₖ = −k^{−1/2} + k^{−1}. Pairs multiply to 1 + k^{−3/2}, so the product converges; Σaₙ has pair sums 1/k, so the series diverges. (For the even-index partial products; check the odd-index ones too: they differ by a factor 1 + k^{−1/2} → 1.)
- **Worked example.** Π_{n≥1}(1 − z²/n²) converges locally uniformly on ℂ (|z²/n²| ≤ R²/n² on |z| ≤ R) and vanishes exactly at the non-zero integers, each simply; F(0) = 1. Its log derivative is Σ −2z/(n² − z²). This is the product §03 identifies.
- **Find-the-error.** "Σaₙ converges, so log Π(1+aₙ) = Σ log(1+aₙ) ≈ Σ aₙ converges." Error: ≈ hides Σaₙ², and `exm-product-alternating-sqrt` is the counterexample. (The step "product converges ⇔ log series converges" itself is correct: `lem-product-log-series`.)
- **Quick checks.** (1) Does Π(1 + 1/n) converge? No: partial product n+1. (2) Does Π_{n≥2}(1 − 2/(n(n+1))) converge, and to what? Yes: the factor is (n−1)(n+2)/(n(n+1)), the partial product is (1/N)·(N+2)/3, the limit is 1/3. (3) Is Π_{n≥1} (1 + zⁿ) holomorphic on the unit disk? Yes, Σ|z|ⁿ ≤ Σ rⁿ on |z| ≤ r.
- **Exercises.**
  - **A1** (one exercise, lettered parts). (a)–(c) Which of Π_{n≥1}(1 + 1/n²), Π_{n≥2}(1 − 1/n), Π_{n≥2}(1 + (−1)ⁿ/n) converge? *Answer:* yes (absolutely); no (partial product 1/N → 0); yes, to 1 (the pair (1 + 1/(2k))(1 − 1/(2k+1)) equals 1, so the partial products are 1 after each odd index and 1 + 1/(2k) after index 2k). (d) Where does Π(1 + zⁿ/n!) define a holomorphic function? *Answer:* on all of ℂ. (e) State `def-product-converges` and say what goes wrong without "non-zero limit". *Answer:* Π 1/2 would converge, to 0, and the zeros of the limit would not be the zeros of the factors.
  - **B1.** Show Π_{n≥0}(1 + z^{3ⁿ} + z^{2·3ⁿ}) = 1/(1 − z) on the unit disk. *Answer:* (1 − w)(1 + w + w²) = 1 − w³ with w = z^{3ⁿ}, so (1 − z)P_N = 1 − z^{3^{N+1}} → 1; convergence is locally uniform by `thm-holomorphic-product`. (The reason it works: base-3 digits.)
  - **B2.** Prove: if Σ|aₙ|³ < ∞ and aₙ ≠ −1, then Π(1+aₙ) converges iff Σ(aₙ − aₙ²/2) converges. *Answer:* `lem-product-log-series` and |Log(1+a) − a + a²/2| ≤ Σ_{k≥3}|a|^k/k ≤ |a|³ for |a| ≤ 1/2 (aₙ → 0 under either condition, since Σ|aₙ|³ < ∞).
  - **C1.** Prove that Π_{n≥1}(1 + zⁿ) · Π_{n≥1}(1 − z^{2n−1}) = 1 on the unit disk. *Answer:* 1 + zⁿ = (1 − z^{2n})/(1 − zⁿ); all products converge absolutely on |z| ≤ r < 1 and can be rearranged (`thm-product-abs-criterion`), so Π(1 + zⁿ) = Π(1 − z^{2n}) / Π(1 − zⁿ) = 1 / Π(1 − z^{2n−1}). ## 02-weierstrass.md — Prescribing zeros: the Weierstrass factorization (≤ 4,000 words)

- **Hook (failure motivates convergence factors).** Try zeros at 1, 2, 3, …: Π(1 − z/n) diverges for every z ≠ 0 (Σ z/n diverges). The trouble is the first term −z/n of log(1 − z/n). Multiply by e^{z/n} to cancel it: (1 − z/n)e^{z/n} = exp(−z²/(2n²) − …), and now Σ 1/n² converges.
- **`def-elementary-factor`.** E₀(w) = 1 − w; E_p(w) = (1 − w) exp(w + w²/2 + ⋯ + w^p/p) for p ≥ 1. E_p has one simple zero at w = 1.
- **`lem-elementary-factor-bound`.** For |w| ≤ 1 and p ≥ 0: |1 − E_p(w)| ≤ |w|^{p+1}. *Proof sketch:* E_p′(w) = −w^p exp(w + ⋯ + w^p/p), so the Taylor series of 1 − E_p at 0 starts at w^{p+1} and has **non-negative** coefficients; hence (1 − E_p(w))/w^{p+1} has non-negative coefficients summing to its value at w = 1, which is 1. Sidecar: check coefficients and the bound numerically for p ≤ 5.
- **Scratch Work (first appearance of convergence factors).** "We need Σ |z/aₙ|^{pₙ+1} < ∞ for every z. Fix R; only finitely many |aₙ| ≤ 2R. For the others |z/aₙ| ≤ 1/2, so (1/2)^{pₙ+1} would do — pₙ = n − 1 always works, and if Σ|aₙ|^{−(p+1)} < ∞ for one fixed p, then pₙ = p works." Then the proof, separate.
- **`thm-weierstrass-existence`.** Let (aₙ) be a sequence of non-zero complex numbers with |aₙ| → ∞ (repetitions allowed), and let m ≥ 0. Let (pₙ) be non-negative integers with Σ (r/|aₙ|)^{pₙ+1} < ∞ for every r > 0 (e.g. pₙ = n − 1). Then f(z) = z^m Π E_{pₙ}(z/aₙ) converges locally uniformly on ℂ to an entire function whose zeros are exactly 0 (order m, if m ≥ 1) and the aₙ, each with multiplicity the number of times it occurs. *Route:* `lem-elementary-factor-bound` + `thm-holomorphic-product` + `cor-product-zeros`. Verify pₙ = n − 1: for n large, r/|aₙ| < 1/2, so the terms are ≤ 2^{−n}.
- **`thm-weierstrass-factorization`.** Let f be entire, not identically 0, with a zero of order m at 0 and other zeros (aₙ) (with multiplicity). Then f(z) = e^{g(z)} z^m Π E_{pₙ}(z/aₙ) for some entire g, with (pₙ) as in the previous theorem. *Route:* the quotient f / (z^m Π…) has only removable singularities (CA.3) and no zeros (`cor-product-zeros`), so it is entire and zero-free, hence has an entire logarithm (CA.4: ℂ is simply connected). Finite zero sets: the product is a polynomial, and the statement is the polynomial case with e^{g}.
- **`cor-meromorphic-quotient`.** Every function meromorphic on ℂ is a quotient of two entire functions. *Route:* take h entire with zeros at the poles of F, to the pole orders; Fh has removable singularities.
- **`thm-weierstrass-region` (stated, not proved).** For an open U ⊆ ℂ and a sequence in U with no accumulation point in U, there is f holomorphic on U with exactly those zeros. "Proved in CA.12" — prose pointer only, no `@ref` dependency; nothing in this chapter uses it. CA.12's blueprint (`ca2/authoring/blueprints/ch03.md`) takes the proof; the promise is recorded in coordinator notes.
- **Worked examples.**
  - `exm-zeros-at-integers`: simple zeros at the positive integers: z ↦ Π(1 − z/n)e^{z/n}. At all integers: z Π_{n≠0}(1 − z/n)e^{z/n}, and pairing n with −n gives z Π(1 − z²/n²), the §01 product, with no exponentials left. Mark that the pairing is a lucky cancellation, which §03 exploits.
  - The product z Π(1 + z/n)e^{−z/n} (zeros 0, −1, −2, …): one sentence, "this is 1/Γ up to e^{γz}; CA.13". No statement used.
  - **Faded example** `exm-zeros-at-sqrt-n` (first part): zeros at √n, n ≥ 1. Reader fills: Σ|aₙ|^{−2} = Σ 1/n diverges, Σ|aₙ|^{−3} converges, so pₙ = 2 works. The order is computed in §05.
  - `exm-zeros-at-sqrt-log-n` (first part): zeros at √(log n), n ≥ 2. Σ (log n)^{−s/2} diverges for every s, so no constant p works; pₙ = n − 1 does. §04 shows any such function has infinite order.
- **`exm-sine-not-unique`.** sin πz and e^{h(z)} sin πz have the same zeros for every entire h: the Weierstrass theorem cannot see g. Pointer: §05 controls g by growth.
- **Warning.** The pₙ are not unique and the e^{g} absorbs the choice; "the" Weierstrass product is not canonical until §05 fixes pₙ = p.
- **Quick checks.** (1) Why can't the zeros 1/n, n ≥ 1, be prescribed for a non-zero entire function? Identity theorem: they accumulate at 0. (2) Smallest constant p for zeros at n²? p = 0, since Σ 1/n² < ∞.

## 03-sine-product.md — The sine product, and Euler made honest (≤ 3,500 words)

- **Hook paid (first time).** Back to Euler. We now know z Π(1 − z²/n²) is entire with exactly the zeros of sin πz, so sin πz = e^{g(z)} πz Π(1 − z²/n²) for some entire g (`thm-weierstrass-factorization`). Show g = 0.
- **`thm-cot-partial-fractions`.** For z ∈ ℂ∖ℤ, π cot πz = 1/z + Σ_{n≥1} 2z/(z² − n²), the series converging absolutely and locally uniformly on ℂ∖ℤ.
  - *Proof route (Liouville through periodicity):* (i) convergence: |2z/(z² − n²)| ≤ 4R/n² for |z| ≤ R and n ≥ 2R. (ii) Call the right side S. S is odd. S(z+1) = S(z): write S as lim_{N} Σ_{|n|≤N} 1/(z − n); shifting z by 1 changes the symmetric sum by 1/(z + N + 1) − 1/(z − N) → 0. (iii) D = π cot πz − S has removable singularities at the integers: both sides have simple poles with residue 1 (CA.3). (iv) D is bounded on the strip 0 ≤ Re z ≤ 1: on |Im z| ≤ 1 by continuity; on |Im z| ≥ 1, |cot πz| is bounded, and for z = x + iy, n ≥ 2, |z² − n²| ≥ y² + n² − 1 ≥ (y² + n²)/2, so |Σ_{n≥2} 2z/(z² − n²)| ≤ 4(1 + |y|) Σ 1/(y² + n²) ≤ 4(1 + |y|)·π/(2|y|) ≤ 4π; the n = 1 term and 1/z are bounded there. (v) Periodic + bounded on a period strip ⇒ bounded entire ⇒ constant (CA.2, Liouville); odd ⇒ D = 0.
  - **Scratch Work (first appearance of Liouville through periodicity):** "the difference is entire once residues match; we cannot evaluate it, but we can bound it, and periodicity reduces 'bounded on ℂ' to 'bounded on a strip'; oddness then pins the constant." Then the proof.

- **`thm-sine-product`.** For all z ∈ ℂ, sin πz = πz Π_{n≥1}(1 − z²/n²), the product converging absolutely and locally uniformly. *Route (log-derivative transfer):* with P(z) = πz Π(1 − z²/n²), `thm-product-log-derivative` gives P′/P = 1/z + Σ 2z/(z² − n²) = π cot πz = (sin πz)′/sin πz on ℂ∖ℤ (`thm-cot-partial-fractions`); so (sin πz / P)′ = 0 on the connected set ℂ∖ℤ, the ratio is constant, and its limit at z → 0 is 1. ## 04-jensen-and-order.md — Jensen's formula and the order of growth (≤ 4,000 words)

- **Hook.** Polynomials of degree d have d zeros and grow like r^d. Is there a dictionary "fast growth ⇔ many zeros" for entire functions? First half: many zeros force growth. The tool is a mean-value identity for log|f|.
- **`thm-jensen`.** Let f be holomorphic on an open set containing the closed disk |z| ≤ R, with f(0) ≠ 0, and let a₁, …, a_N be its zeros in |z| < R, with multiplicity. Then log|f(0)| = Σ_{k=1}^{N} log(|aₖ|/R) + (1/2π)∫₀^{2π} log|f(Re^{iθ})| dθ (the integral exists, also when f has zeros on |z| = R).
  - *Proof route:* (1) zero-free case on a slightly larger disk: f = e^{h} with h holomorphic (CA.4), log|f| = Re h, and the mean value of h over the circle is h(0) (Cauchy's formula, CA.2). (2) Divide out each interior zero by the Blaschke factor B_a(z) = R(z − a)/(R² − āz): |B_a| = 1 on |z| = R and |B_a(0)| = |a|/R. (3) Boundary zeros: divide by (z − Re^{iφ}) and use ∫₀^{2π} log|1 − e^{iθ}| dθ = 0 (Scratch Work computes it: log|1 − w| = Re log(1 − w) is harmonic for |w| < 1, mean value 0 on |w| = r < 1, and the limit r ↑ 1 is justified by domination by an integrable log singularity; or by the real integral ∫₀^π log sin t dt = −π log 2 — choose one in S3, the first is preferred).
  - **Ordering item:** the three steps above, shuffled, for the reader to order and justify.
  - Remark (prose only): CA.11 reads this as "log|f| is subharmonic"; and the formula with the zeros as the Riesz-measure term is Poisson–Jensen (exercise C2).
- **`cor-zero-count-growth`** (count zeros by growth). For f entire with f(0) ≠ 0: ∫₀^R n(t)/t dt = (1/2π)∫ log|f(Re^{iθ})| dθ − log|f(0)|, and hence n(r) log 2 ≤ log M(2r) − log|f(0)|. *Route:* Σ log(R/|aₖ|) = ∫₀^R n(t)/t dt (Stieltjes-free: write log(R/|a|) = ∫_{|a|}^{R} dt/t and swap the finite sum and integral); bound ∫_r^{2r} n(t)/t dt ≥ n(r) log 2.
- **Failure-motivated definition of order.** "Grows like a polynomial" is too strong: |f(z)| ≤ C(1 + |z|)^d forces f to be a polynomial (Cauchy estimates, `prp-order-polynomial-growth`). "Grows like e^{|z|}" is the next natural scale, and e^{z²}, cos √z show the exponent varies. So measure the exponent: `def-order-entire` — f has order ρ_f = inf{ s ≥ 0 : |f(z)| ≤ A_s e^{B_s|z|^s} for all z }, possibly ∞; equivalently ρ_f = limsup_{r→∞} log log M(r)/log r for non-constant f (prove the equivalence as a short lemma inside the definition's explanation, or as exercise B1 with answer; *S1 choice: exercise B1, statement used only through the first form*).
- **`prp-order-polynomial-growth`.** If |f(z)| ≤ C(1 + |z|)^d for all z, f is a polynomial of degree ≤ d. Polynomials have order 0.
- **`exm-orders-table`.** e^{z}: 1. e^{z²}: 2. sin z, cos z: 1. cos √z (= Σ (−1)ⁿ zⁿ/(2n)!, entire): 1/2. e^{e^{z}}: ∞. Polynomials: 0. Each with the one-line estimate of M(r).
- **`thm-finite-order-zero-sum`.** If f is entire of finite order ρ, f(0) ≠ 0, then n(r) = O(r^{s}) for every s > ρ, and Σ |aₙ|^{−s} < ∞ for every s > ρ. *Route:* `cor-zero-count-growth` gives n(r) ≤ C r^{s'} for ρ < s' < s; then Σ_{|aₙ|≥1} |aₙ|^{−s} = ∫_1^∞ t^{−s} dn(t) — avoid Stieltjes: sum over dyadic shells, at most n(2^{k+1}) zeros with 2^k ≤ |aₙ| < 2^{k+1}, each contributing ≤ 2^{−ks}, and Σ_k C 2^{(k+1)s'} 2^{−ks} < ∞. (f(0) = 0: apply to f/z^m.)
- **`def-exponent-of-convergence`.** ρ₁ = inf{ s > 0 : Σ|aₙ|^{−s} < ∞ } (= 0 for finitely many zeros). Restate the theorem as ρ₁ ≤ ρ.
- **Worked examples.** For sin πz, ρ₁ = 1 = ρ. For e^{z}, ρ₁ = 0 < ρ = 1. For cos √z, zeros at ((2n−1)π/2)², ρ₁ = 1/2 = ρ.
- **`exm-zeros-at-log-n` (second part).** Any entire function with zeros at all log n has infinite order: n(r) ≥ e^{r} − 2, so log M(2r) grows at least like e^{r}.
- **Quick checks.** (1) Order of f·g, f + g? ≤ max (exercise A2). (2) Does f(z) = Σ zⁿ/(n!)² have order 1/2? Yes (compare with cos √z / cosh √z; exercise B2).
- **Exercises.**
  - **A1.** Order of z³e^{2z} + 1, cosh z, e^{z³} sin z. *Answer:* 1, 1, 3.
  - **A2.** Show ρ_{fg} ≤ max(ρ_f, ρ_g) and ρ_{f+g} ≤ max(ρ_f, ρ_g). Give an example with strict inequality for the sum. *Answer:* f = e^{z²} + e^{z}, g = −e^{z²}.
  - **B1.** Prove the limsup formula for ρ_f. *Answer outline:* both directions from M(r) ≤ A e^{B r^s} and its converse for large r.
  - **B2.** Order of Σ zⁿ/(n!)^α for α > 0. *Answer:* 1/α (use Stirling-free bound: M(r) ≥ max term, M(r) ≤ sum; or the coefficient formula ρ = limsup n log n / log(1/|cₙ|), proved as C1).
  - **C1.** Prove: for f = Σ cₙ zⁿ entire, ρ_f = limsup_{n→∞} (n log n)/log(1/|cₙ|). *Answer outline:* Cauchy estimates and max-term comparison.
  - **C2.** Poisson–Jensen: for f as in `thm-jensen` with no zeros on |z| = R and |z| < R, z ≠ aₖ, log|f(z)| = Σ log|R(z − aₖ)/(R² − āₖ z)| + (1/2π)∫ Re((Re^{iθ} + z)/(Re^{iθ} − z)) log|f(Re^{iθ})| dθ. *Answer outline:* compose f with a disk automorphism of |w| ≤ R sending 0 to z, apply `thm-jensen`, and change variables on the circle; the derivative of the boundary map is the Poisson kernel. CA.6 is not needed.

## 05-hadamard.md — Canonical products, genus, and Hadamard's theorem (≤ 5,000 words)

- **Hook.** §04: growth bounds zeros (ρ₁ ≤ ρ). §02: zeros determine f up to e^{g}. Now the converse half: if f has finite order, g is a polynomial — and then the hook's question about the sine is settled.
- **`def-canonical-product`.** If Σ|aₙ|^{−(p+1)} < ∞ for some integer p ≥ 0, let p be the least such; the canonical product is P(z) = Π E_p(z/aₙ) (entire by `thm-weierstrass-existence` with pₙ = p). p is the genus of the zero sequence.
- **`lem-log-elementary-factor`.** For p ≤ s ≤ p + 1, with s > 0 when p = 0, there is C = C(p) with log|E_p(w)| ≤ C|w|^s for all w ∈ ℂ, and log|E_p(w)| ≥ −C|w|^{p+1} for |w| ≤ 1/2. *Route:* for |w| ≤ 1/2, |log E_p(w)| ≤ 2|w|^{p+1} (principal branch of log(1 − w) series minus its first p terms); for |w| ≥ 1/2, log|E_p(w)| ≤ log(1 + |w|) + Σ_{k≤p}|w|^k/k ≤ C|w|^p ≤ C'|w|^s. Sidecar: numeric check of the constants for p ≤ 3.
- **`thm-canonical-product-order`.** The canonical product of genus p of a sequence with exponent of convergence ρ₁ has order exactly ρ₁. *Route:* ≤: for s with ρ₁ < s ≤ p + 1 and s ≥ p (possible since p ≤ ρ₁ ≤ p + 1), log|P(z)| ≤ C Σ |z/aₙ|^s = C' |z|^s. ≥: `thm-finite-order-zero-sum`.
- **`lem-canonical-product-lower`.** Let p ≥ 0 be an integer with Σ|aₙ|^{−(p+1)} < ∞ (p need not be minimal), P = Π E_p(z/aₙ), and let s satisfy ρ₁ < s < p + 1. Then there are C and radiuses rₖ → ∞ with |P(z)| ≥ e^{−C|z|^s} on |z| = rₖ. *Route (good circles):* (1) off the union of disks D(aₙ, |aₙ|^{−(p+1)}) (for |aₙ| ≥ 1), |P(z)| ≥ e^{−C|z|^s}: split zeros into |aₙ| ≤ 2|z| and |aₙ| > 2|z|; the far ones by `lem-log-elementary-factor` (lower bound), the near ones by |1 − z/aₙ| ≥ |aₙ|^{−p−2} off the disks and by counting them (n(2r) = O(r^{s})) and bounding the exponential factors; (2) Σ_{|aₙ|≥1} 2|aₙ|^{−(p+1)} < ∞, so the set of r for which the circle |z| = r meets some disk has finite total length; pick rₖ ∈ [k, k+1] outside it for large k.
  - **Scratch Work (first appearance of good circles):** "a product is small near its zeros and nowhere else; we cannot control |P| on every circle, but the bad disks are so small that their radial shadows have finite total length, so most circles are good." Then the proof.
- **`lem-real-part-polynomial`** (the real part controls a polynomial). Let g be entire, s ≥ 0, and suppose Re g(z) ≤ C rₖ^s on |z| = rₖ for a sequence rₖ → ∞. Then g is a polynomial of degree ≤ s. *Route:* with g = Σ bₙ zⁿ and u = Re g: for n ≥ 1, bₙ rⁿ = (1/π)∫₀^{2π} u(re^{iθ}) e^{−inθ} dθ, and ∫ u dθ = 2π Re b₀. So |bₙ| rⁿ ≤ (1/π)∫|u| = (1/π)∫(2u⁺ − u) ≤ 4C r^s − 2 Re b₀ on r = rₖ. Let k → ∞: bₙ = 0 for n > s. (Coefficient identity from Cauchy's formula, CA.2; no harmonic-function theory needed.)
  - **Scratch Work:** "Liouville from the real part alone: the mean of u is pinned by b₀, so an upper bound on u bounds |u| on average."
- **`thm-hadamard`.** Let f be entire of finite order ρ, with a zero of order m ≥ 0 at 0 and other zeros (aₙ) (with multiplicity). Let p = ⌊ρ⌋. Then Σ|aₙ|^{−(p+1)} < ∞, and f(z) = z^m e^{Q(z)} Π E_p(z/aₙ) with Q a polynomial of degree ≤ p. *Route:* Σ|aₙ|^{−(p+1)} < ∞ by `thm-finite-order-zero-sum` (p + 1 > ρ). The product E(z) = Π E_p(z/aₙ) is entire; write f = z^m e^{Q} E (`thm-weierstrass-factorization`). Choose s with ρ < s < p + 1 and ρ₁ ≤ ρ < s. On the good circles |z| = rₖ of `lem-canonical-product-lower` (applied with this s; note the lemma uses only Σ|aₙ|^{−(p+1)} < ∞ and ρ₁ < s < p + 1, not that p is minimal — state it that way), Re Q = log|f| − m log|z| − log|E| ≤ C rₖ^s. `lem-real-part-polynomial`: deg Q ≤ s < p + 1.
  - Write in full; this is a key proof. Mark explicitly where finite order enters (twice: the zero sum and the bound on log|f|).
- **`def-genus`** and **`cor-genus-order`.** The genus μ of f is max(deg Q, p₀) where p₀ is the genus of the zero sequence and f = z^m e^{Q} Π E_{p₀}(z/aₙ). For f of finite order: μ ≤ ρ ≤ μ + 1. *Route:* μ ≤ ρ from Hadamard (with the least p, deg Q ≤ ⌊ρ⌋ and p₀ ≤ ⌊ρ⌋ since Σ|aₙ|^{−(⌊ρ⌋+1)} < ∞); ρ ≤ μ + 1 from `thm-canonical-product-order` and ρ_{e^Q} = deg Q.
- **Hook paid (second time).** sin πz / (πz) is even, of order 1, with zeros ±n. Hadamard with p = 1: sin πz = πz e^{az+b} Π_{n≠0} (1 − z/n)e^{z/n} = πz e^{az+b} Π(1 − z²/n²). Evenness of the left side divided by z forces a = 0; z → 0 gives e^{b} = 1. So Euler's guess *had* to be right, and e^{z} sin πz is excluded because it is not even — the correct invariant is order + symmetry, not zeros alone.
- **Worked examples.**
  - `exm-zeros-at-sqrt-n` (second part, faded): the canonical product has genus 2 and order 2 (ρ₁ = 2 because n(r) ≈ r²). Reader completes "order = 2" from `thm-canonical-product-order`.
  - `exm-order-zero-transcendental`: Π(1 − z/2ⁿ), genus 0, order 0, not a polynomial. Contrast with `prp-order-polynomial-growth`: order 0 does not mean polynomial.
  - `exm-hadamard-fails-infinite-order`: e^{e^{z}} is zero-free and not e^{polynomial}; finite order is necessary.
  - cos √z = Π(1 − 4z/((2n − 1)²π²)) by Hadamard with p = 0 (order 1/2, so Q is constant; Q(0) = 0). Sidecar check.
- **Warning.** ⌊ρ⌋, not ⌈ρ⌉: for ρ = 1 (sin πz), p = 1 and convergence factors e^{z/n} are needed in the unpaired form; the pairing hides them.
- **Quick checks.** (1) f of order 1/2 with zeros exactly at the squares n²: what is f? c Π(1 − z/n²) = c sin(π√z)/(π√z). (2) Can an entire f of order 3/2 be zero-free? No (§06).
- **Exercises.**
  - **A1.** State Hadamard's theorem for f of order 0. *Answer:* f = c z^m Π(1 − z/aₙ).
  - **A2.** Genus of e^{z²}, sin z, cos √z, Π(1 − z/n²)·e^{z}. *Answer:* 2, 1, 0, 1.
  - **B1.** Prove `cor-genus-order` is sharp at both ends: examples with ρ = μ and with ρ = μ + 1. *Answer:* e^{z} (μ = ρ = 1); Π (1 − z/(n log² n)) for n ≥ 2 (genus 0 since Σ 1/(n log² n) < ∞, order 1 since ρ₁ = 1). *S2a: confirm ρ₁ = 1 for aₙ = n log² n.*
  - **B2 (faded good circles).** Show: if f is entire of order ρ < 1 and f(aₙ) = 0 exactly at a sequence with Σ|aₙ|^{−1} < ∞, then |f(z)| ≥ e^{−|z|^{s}} on a sequence of circles, for every s ∈ (ρ, 1). Steps given, reader fills the measure-of-bad-radiuses step.
  - **C1.** Let f be entire of order ρ < 2 with f(−z) = f(z) and real zeros ±aₙ. Show f(z) = c Π(1 − z²/aₙ²) if f(0) ≠ 0 and Σ aₙ^{−2} < ∞. *Answer outline:* Hadamard with p ≤ 1, pairing; evenness kills the linear term of Q.
  - **C2.** Show that an entire function of finite order whose zeros are all real and which is real on ℝ has a real Q in its Hadamard factorization (up to adding 2πi k). *Answer outline:* compare f with f*(z) = conj f(conj z).

## 06-consequences.md — Consequences: values taken, zero-free functions, and a look ahead (≤ 2,500 words)

- **Hook.** e^{z} has order 1 and no zeros; e^{z} − a has zeros for every a ≠ 0. Which entire functions can omit values?
- **`cor-order-less-one-zero-free`.** An entire function of order < 1 with no zeros is constant. More generally, a zero-free f of finite order is e^{Q} with Q a polynomial and ρ_f = deg Q, an integer. *Route:* Hadamard with no zeros; ρ_{e^Q} = deg Q (one-line M(r) estimate).
- **`cor-noninteger-order-zeros`.** An entire function of finite non-integer order has infinitely many zeros. *Route:* finitely many zeros ⇒ f = polynomial · e^{Q} ⇒ integer order.
- **`cor-noninteger-order-values`.** If f has finite non-integer order, then for every a ∈ ℂ the equation f(z) = a has infinitely many solutions. *Route:* f − a has the same order (exercise §04 A2 and its converse, f = (f − a) + a).
- **Example.** cos √z takes every value infinitely often. sin z (order 1) also does (direct computation), and e^{z} (order 1) omits 0: the corollary is sharp in requiring non-integer order.
- **Look ahead (prose; hooks opened).**
  - Little Picard: a non-constant entire function omits at most one value. For finite order, it follows from this chapter (exercise C2 below). The general case is **CA.14** (Bloch route).

  - Weierstrass in arbitrary regions, and prescribed principal parts (Mittag-Leffler): **CA.12**.
  - The Weierstrass σ-function of a lattice is a canonical product of genus 2 (B1 of §02): **CA.15** (optional).
- **Weird-examples table** closes here (rows listed above), with one line per row saying which hypothesis of which theorem it shows is needed.
- **Quick checks.** (1) Does `cor-noninteger-order-values` decide whether e^{z²} + z has infinitely many zeros? No: the order is 2, an integer (C1 settles it another way). (2) Can an entire function of order 1/3 be zero-free? No.
- **Exercises.**
  - **A1.** Which of these can be zero-free entire functions: order 0 non-constant, order 1, order 5/2, order ∞? *Answer:* no, yes (e^{z}), no, yes (e^{e^{z}}).
  - **A2.** If f is entire of order 1/2, is f(z) = 7 solvable? *Answer:* yes, infinitely often.
  - **B1.** Let f be entire of finite order with f(z) ≠ 0 and f(z) ≠ 1 for all z. Show f is constant. *Answer:* f = e^{Q} with Q a polynomial (`cor-order-less-one-zero-free`, general form). A non-constant polynomial is onto ℂ (fundamental theorem of algebra), so Q would take the value 2πi and f the value 1. Hence Q is constant.
  - **B2.** Let f be entire of finite order with f′ zero-free. Show f′ = e^{Q} and give an example where f itself has infinitely many zeros. *Answer:* f′ = e^{Q} by `cor-order-less-one-zero-free` (f′ has the order of f; S2a: this needs ρ_{f′} = ρ_f, add it as a §04 B exercise or avoid it by assuming f′ of finite order); f = e^{z} − 1 has f′ = e^{z} and zeros at 2πik.
  - **C1.** Show e^{z²} + z has infinitely many zeros. *Answer outline:* otherwise e^{z²} + z = P(z)e^{Q(z)} with P a polynomial and deg Q ≤ 2 (Hadamard, order 2). Then u = Re Q = a(x² − y²) + bxy + cx + dy + e is a harmonic polynomial with u = log|e^{z²} + z| − log|P|. On the real axis this is x² + O(log|x|), so a = 1; on the imaginary axis |e^{−y²} + iy| ~ |y|, so u(0, y) = O(log|y|), forcing a = 0. Contradiction.
  - **C2 (little Picard for finite order).** Exercise B1 in general form: a non-constant entire function of finite order omits at most one value. *Answer:* if f omits a and b, apply B1 to (f − a)/(b − a). Remark: CA.14 removes "finite order".
