### 0.2 Chapter hook and where it is paid

**Hook (index story and §6.1 opening, `exm-three-functions`).** Three functions on ℝ: the Dirichlet function D (1 on ℚ, 0 off ℚ), M(x) ≔ x·D(x), and Thomae's function T (T(p/q) = 1/q in lowest terms with q ≥ 1, T = 0 off ℚ). Ask: *where is each one continuous?* The answers, which the chapter proves, are: nowhere; only at 0; exactly at the irrationals. Then the question that drives the story: *which sets can be the set of points where some function ℝ → ℝ is continuous? Is there a function continuous exactly at the rationals?*

**Where it is paid.**
- §6.3 proves the first two answers (`exm-dirichlet-nowhere-continuous`, `exm-x-dirichlet-continuous-only-at-zero`).
- §6.6 proves the third (`thm-thomae`), and proves that the continuity set of **every** f : X → Y is a countable intersection of open sets (`thm-continuity-set-g-delta`). §6.6 C2 shows that every closed subset of ℝ is a continuity set. So the irrationals are a continuity set. "Exactly at the rationals" is left open, and §6.6 says what would settle it: ℚ would have to be a countable intersection of open sets.
- **Paid later:** *Integration, Series, and Function Spaces*, Chapter 12 (AN2.6) proves by Baire's theorem that ℚ is not such an intersection, so no function is continuous exactly on ℚ (the old AN2.6 blueprint's §6 already plans "ℚ is not a G_δ; no function is continuous exactly on ℚ"; STATUS promise row, §6). This is the chapter's one cross-volume story hook. Its Looking-ahead box in §6.6 is the only forward pointer of §6.6 besides the integration pointer for Thomae.

## 1. Devices as applied

- **Failure-motivated definitions** (C5), each a short paragraph (≤ 120 words) before the definition, with a concrete failing case on the page:
  1. `def-function-limit` (§6.1): "plug in p" fails (h of `exm-limit-ignores-value` has the wrong value at 3, and (x² − 9)/(x − 3) has none); "f(xₙ) → L along **some** sequence xₙ → p" fails (D along rationals gives 1, along irrationals 0). So the definition must control f at **every** point near p, and never look at p itself.
  2. `def-continuous-at` (§6.3): the "pen test" fails. s(x) ≔ z(1/x), s(0) ≔ 0, takes every value of [0, ½] on every interval around 0 (proved on the page from the explicit formula of z on [n, n + ½]), so no picture of "no gaps in the values" detects anything; yet s(1/n) = 0 and s(2/(2n + 1)) = ½ disagree in the limit. So continuity is defined by the limit, not by the shape of the image.
  3. (prepared here, defined in Chapter 8) homeomorphism: a continuous bijection need not carry open sets to open sets (`exm-continuous-bijection-tears`, §6.4), so "same open sets" will need the inverse continuous too. §6.4 says this in one sentence with a prose pointer to Chapter 8.
  4. `def-one-sided-limit` (§6.5): the floor function has no limit at 1, yet it is as tame as a function can be on each side; the two-sided definition throws that information away.
  5. `def-oscillation` (§6.6): the kinds of §6.5 say *how* a function breaks, not *how much*. D breaks by 1 everywhere; T breaks at 3/4 by 1/4 and at 1/1000 by 1/1000; we need a number.

- **Named moves** (7):

  2. **Reduce to sequences.** Prove a limit law by the sequential criterion and the matching law for sequences; disprove a limit with two sequences whose images have different limits.
  3. **Chain the δs.** For a composite, choose the outer δ first and use it as the inner ε.
  4. **Pull back an open set.** Prove a set open (closed) by writing it as the preimage of an open (closed) set under a continuous map.
  5. **One-sided limits of a monotone function are a sup and an inf.**
  6. **Count with rationals.** Put a rational in each of a family of disjoint open intervals, the first one in a fixed list, to show the family is countable without choice.
  7. **Keep δ below finitely many distances.** When only finitely many points are bad, let δ be the least distance from p to them (Thomae; the jump function).

### 4.1 Section 6.1: Limits of Functions (`01-limits-of-functions.md`)

**Budget:** ≤ 5,000 (expected ~4,700). Four Quick checks, two warnings. Major notion: limit of a function (STYLE §3, all eleven steps).

**May use:** AN1.1; Chapters 2–4 (accumulation points in metric spaces, sequences and their limits in metric spaces, the algebra of sequence limits); F4.7 (floor), F4.8, F4.11.

**Opening (~120).** Chapter 4 studied a sequence approaching a limit. Here the input moves continuously: x approaches a point p, and we ask what f(x) approaches. This section defines that limit for functions between metric spaces, shows it is unique when it exists, and proves that it can be tested with sequences, which lets every fact of Chapter 4 do work here.

**`## Three functions` (hook, ~350).** `exm-three-functions` `[Three functions on the line]`: defines D, M(x) ≔ x·D(x), and T (with T(0) = 1, since 0 = 0/1, and the lowest-terms convention p ∈ ℤ, q ≥ 1, gcd(p, q) = 1). A short table of values: T(3/4) = 1/4, T(−2/6) = T(−1/3) = 1/3, T(1/1000) = 1/1000, T(√2) = 0. The question of §0.2, posed and left open: "where is each continuous?", and the larger question about continuity sets. "Before reading on, sketch each function on [0, 1] as best you can." No answers here; one sentence says that the three answers come in Sections 6.3 and 6.6.

**`## What a limit should mean` (~650).**
1. **`exm-limit-ignores-value`** `[A limit ignores the value at the point]`: g(x) ≔ (x² − 9)/(x − 3) on ℝ ∖ {3}, and h(x) ≔ x + 3 for x ≠ 3, h(3) ≔ 0. For x ≠ 3, g(x) = h(x) = x + 3, so near 3 both are near 6; g(3) does not exist and h(3) = 0. Moral: the limit at p must not look at p.
2. **Failure paragraph** (≤ 120 words, §1 item 1): one sequence is not enough. Along xₙ ≔ 1/n, D(xₙ) = 1; along yₙ ≔ √2/n (irrational by `@fd1:thm-sqrt2-irrational` and closure of ℚ under ×, ÷), D(yₙ) = 0. Whatever "the limit of D at 0" means, it cannot be read off one sequence.
3. Slogan (italic): *f(x) is as close to L as we please for every x ≠ p that is close enough to p.*
4. **`def-function-limit`** `[Limit of a Function]`: Let (X, d), (Y, ρ) be metric spaces, A ⊆ X, f : A → Y, and p an accumulation point of A (Chapter 3's `@def-accumulation-point-metric`; p need not lie in A). Then L ∈ Y is a **limit of f at p**, written lim_{x→p} f(x) = L or f(x) → L as x → p, if **for every** ε > 0 **there exists** δ > 0 such that **for every** x ∈ A with 0 < d(x, p) < δ we have ρ(f(x), L) < ε. Symbols line (STYLE §10): ∀ε > 0 ∃δ > 0 ∀x ∈ A (0 < d(x, p) < δ ⇒ ρ(f(x), L) < ε). Paraphrase clause by clause; δ depends on ε (and on p, f, L).
5. The case X = Y = ℝ in one sentence: 0 < |x − p| < δ ⇒ |f(x) − L| < ε, the interval form of `@eq-abs-interval`.

**`## A first computation` (~700).**
1. **`exm-limit-polynomial-scratch`** `[Computing a δ]`: show lim_{x→3} (x² + x) = 12.
   - **`[Scratch work]`** (≤ 20 lines). Goal: |x² + x − 12| < ε. Factor: x² + x − 12 = (x − 3)(x + 4). The factor |x − 3| is what δ controls; the **cofactor** |x + 4| must be bounded. Restrict first: if |x − 3| < 1, then 2 < x < 4, so |x + 4| < 8. Then |x − 3|·|x + 4| < 8|x − 3| < ε as soon as |x − 3| < ε/8. Table:

     | Givens | Goal |
     |---|---|
     | ε > 0 | δ > 0 with 0 < \|x − 3\| < δ ⇒ \|x² + x − 12\| < ε |
     | \|x² + x − 12\| = \|x − 3\|·\|x + 4\| | bound \|x + 4\| |
     | δ ≤ 1 ⇒ \|x + 4\| < 8 | 8\|x − 3\| < ε: δ ≤ ε/8 |

     "Both restrictions at once: δ ≔ min{1, ε/8}."
   - *Solution* (forward, constant first, STYLE §4): "Let ε > 0 and δ ≔ min{1, ε/8} > 0. Let 0 < |x − 3| < δ. Since |x − 3| < 1, 2 < x < 4 and so 0 < x + 4 < 8. Hence |x² + x − 12| = |x − 3|·|x + 4| < (ε/8)·8 = ε." Sidecar `verify/ch06/exm-limit-polynomial-scratch.py`.
   - Aftermath: this is **bound the cofactor**, the chapter's main named move (index).
2. **Quick check:** "In @exm-limit-polynomial-scratch, why not δ ≔ ε/8 alone?" *Solution:* for ε = 80, δ = 10 admits x = 12, where |x + 4| = 16 > 8 and |x² + x − 12| = 144 > 80. The bound on the cofactor needs the restriction δ ≤ 1.
3. **Warning** `**δ may not depend on x.**` "δ is chosen after ε and before x. A 'δ' like |x − 3|/2 is not a number chosen in advance, and the definition is not met."

**`## Why p must be an accumulation point` (~450).**
1. **`exm-limit-isolated-point`** `[Every number is a limit at an isolated point]` (non-example by minimal change): A ≔ [0, 1] ∪ {2}, f ≔ 0 on A, p ≔ 2. If the definition were applied at p = 2, then with δ ≔ 1 no x ∈ A has 0 < |x − 2| < 1, so "ρ(f(x), L) < ε" holds vacuously for **every** L. The clause "p is an accumulation point of A" is exactly what makes the definition say something.
2. **`thm-function-limit-unique`** `[Limits Are Unique]`: under the hypotheses of `def-function-limit`, f has at most one limit at p. Idea (2 lines): two limits L ≠ L′, take ε ≔ ρ(L, L′)/2, and a point x close enough to p for both; it exists because p is an accumulation point. Proof ~6 lines with `@thm-triangle-inequality` in its metric form (F4.11's triangle axiom).
3. **Quick check:** "Where does the proof of @thm-function-limit-unique use that p is an accumulation point?" *Solution:* to produce x ∈ A with 0 < d(x, p) < min{δ, δ′}; without such x nothing is contradicted, and @exm-limit-isolated-point shows the failure.

**`## Testing limits with sequences` (~1,300).**
1. Lead: the definition quantifies over all x near p; a sequence visits countably many of them. Remarkably, sequences suffice.
2. **`thm-sequential-criterion-limits`** `[Sequential Criterion for Limits]`: under the hypotheses of `def-function-limit`, lim_{x→p} f(x) = L **if and only if** for **every** sequence (xₙ) in A ∖ {p} with xₙ → p we have f(xₙ) → L. **Key proof.**
3. Idea for (⇒) (3 lines): given ε, the definition's δ, then N from xₙ → p with d(xₙ, p) < δ; xₙ ≠ p gives the 0 <.
4. **`[Scratch work]`** for (⇐) (≤ 20 lines): prove the contrapositive. Negate the definition, quantifier by quantifier, as its own display: ∃ε₀ > 0 ∀δ > 0 ∃x ∈ A (0 < d(x, p) < δ and ρ(f(x), L) ≥ ε₀). "For every δ" is too many choices to build a sequence from; take only δ = 1/n (n ≥ 1). Each n hands us a point xₙ: a sequence in A ∖ {p} with d(xₙ, p) < 1/n, so xₙ → p, and ρ(f(xₙ), L) ≥ ε₀ for all n, so f(xₙ) ↛ L. One clause: choosing xₙ for each n is a countable family of choices (the axiom of countable choice, *Sets and Functions*, Chapter 3, where `@fd2:thm-countable-union` used it).
5. **Proof** both directions (~15 lines). (⇐) begins "Suppose lim_{x→p} f(x) = L fails."
6. Self-explanation prompt: "*Self-explain why the sequence (xₙ) of the (⇐) part lies in A ∖ {p} and converges to p.*"
7. **`cor-divergence-criterion`** `[Divergence Criterion]`: if there are sequences (xₙ), (yₙ) in A ∖ {p}, both → p, with f(xₙ) → L and f(yₙ) → L′ ≠ L, or one sequence with (f(xₙ)) divergent, then f has no limit at p. Proof: two lines from the theorem and uniqueness of sequence limits.
8. **`exm-dirichlet-no-limit`** `[The Dirichlet function has no limit anywhere]`: for p ∈ ℝ, rationals xₙ ∈ (p, p + 1/n) by `@thm-rationals-dense` and irrationals yₙ there by `@cor-irrationals-dense`; D(xₙ) = 1, D(yₙ) = 0. Choice is avoidable (one sentence: AN1.1's proofs produce explicit points), but is not discussed further.
9. **Quick check:** "Does the sequential criterion still hold if 'every sequence' is replaced by 'every sequence of rational numbers' when A = ℝ? Test it on D at p = 0." *Solution:* no: along rational sequences D → 1, yet D has no limit at 0 (@exm-dirichlet-no-limit).

**`## The zigzag` (~700).**
1. **`exm-zigzag`** `[The zigzag function]`: z(x) ≔ min{x − ⌊x⌋, ⌊x⌋ + 1 − x}, the distance from x to the nearest integer (⌊x⌋ from `@lem-integer-part`; F4.7 has floor). Facts proved in the example from the formula: z(x) = dist(x, ℤ) (the distance of `prp-distance-to-set-lipschitz`, §6.3, read on ℝ with S = ℤ; the nearest integers to x are ⌊x⌋ and ⌊x⌋ + 1, so the identity is a computation, written in the example and used only from §6.3 on); 0 ≤ z ≤ ½; z(k) = 0 and z(k + ½) = ½ for k ∈ ℤ; z(x + 1) = z(x); z(x) = x − k on [k, k + ½]. (Lipschitz continuity waits for §6.3, `prp-lipschitz-continuous`.) Sidecar for the values.
2. **`exm-zigzag-reciprocal`** `[A function that oscillates near 0]`: s(x) ≔ z(1/x) on ℝ ∖ {0}. (a) No limit at 0: xₙ ≔ 1/n gives s = 0; yₙ ≔ 2/(2n + 1) gives 1/yₙ = n + ½ and s = ½ (`@cor-divergence-criterion`). (b) x·s(x) → 0 as x → 0: |x·s(x)| ≤ |x|/2, so δ ≔ 2ε. A TikZ sketch of s on [−1, 1] (one idea: the teeth crowd toward 0).
3. **Remark** (≤ 50 words): readers who know the sine from school will recognize the same picture in sin(1/x); the book uses z because every property of z is proved here, and nothing below rests on the sine.
4. **Quick check:** "Find a sequence xₙ → 0 with s(xₙ) → ¼." *Solution:* xₙ ≔ 1/(n + ¼) = 4/(4n + 1), since z(n + ¼) = ¼.

**`## A limit in the plane` (~600).**
1. Lead: in ℝ² a point can be approached along infinitely many paths, and agreeing along all lines is not enough.
2. **`exm-limit-two-variables`** `[Lines are not enough]`: f(x, y) ≔ x³y/(x⁶ + y²) on ℝ² ∖ {(0, 0)}. Along the line y = mx (m ∈ ℝ), for x ≠ 0, f = m x²/(x⁴ + m²) → 0 (for m = 0 it is 0; for m ≠ 0, |f| ≤ x²/|m|). Along the x³-curve, xₙ ≔ (1/n, 1/n³), f = ½. So no limit at the origin (`@cor-divergence-criterion`). Sidecar.
3. **Warning** `**Checking lines is not checking the limit.**` One or two sentences pointing at the example.

### 4.2 Section 6.2: Limit Laws (`02-limit-laws.md`)

**Budget:** ≤ 5,000 (expected ~4,400). Four Quick checks, two warnings.

**May use:** §6.1; Chapter 4's algebra, order and squeeze for sequences, divergence to ±∞ and the extended reals; F4.8 (|x_j| ≤ |x| ≤ Σ|x_j|, Cauchy–Schwarz); F4.1 for the modulus of a complex number (remark only).

**Opening (~100).** Section 6.1 computed one limit with an explicit δ and promised that sequences would carry Chapter 4's work over. This section collects the rules, says where they fail, and extends the definition to x → ±∞ and to infinite limits on the real line.

**`## Near p, a limit controls the function` (~450).**
1. **`lem-limit-local-bound-sign`** `[Limits Are Locally Bounded and Keep Their Sign]`: let f : A → ℝ, p an accumulation point of A, lim_{x→p} f(x) = L. (a) There are δ > 0 and M with |f(x)| ≤ M for x ∈ A, 0 < |x − p| < δ. (b) If L > 0 there is δ > 0 with f(x) > L/2 for such x; similarly for L < 0. Proof: ε = 1 and ε = L/2 in the definition.
2. Quick check: "Give f with lim_{x→0} f(x) = 0 that is not bounded on A = ℝ ∖ {0}." *Solution:* f(x) = x. Local means local.

**`## The algebra of limits` (~900).**
1. **`thm-limit-algebra`** `[Algebra of Limits]`: let A ⊆ X, p an accumulation point of A, f, g : A → 𝕂 with 𝕂 = ℝ or ℂ, lim f = L, lim g = M at p. Then f + g → L + M, fg → LM, cf → cL; and if M ≠ 0, then g(x) ≠ 0 for x ∈ A near p (x ≠ p) and f/g → L/M on that set.
2. **`[Scratch work]`** (≤ 10 lines, the "reduce to sequences" move): "For a sequence xₙ → p in A ∖ {p}, f(xₙ) → L and g(xₙ) → M (@thm-sequential-criterion-limits). Chapter 4's algebra of limits gives f(xₙ)g(xₙ) → LM. Every sequence gives LM, so the criterion gives fg → LM. The work was done in Chapter 4." For the quotient: `lem-limit-local-bound-sign` (b) applied to |g| (|g| → |M| > 0 by the reverse triangle inequality) keeps g away from 0 near p, and p is still an accumulation point of that smaller set (one sentence: a punctured ball of A around p lies in it).
3. **Proof** (~12 lines). For ℂ, Chapter 4's algebra of limits is cited as holding for complex sequences (its proof uses only |zw| = |z||w| and the triangle inequality, F4.1); S2a item 1 confirms Chapter 4 states it for ℂ or for ℝ only. If only for ℝ, the theorem is stated for ℝ and a remark gives the ℂ case with the one-line reason.
4. **`exm-limit-rational-function`** `[Polynomials and quotients]`: (a) for a polynomial P, lim_{x→p} P(x) = P(p) (induction on the degree from x → p and constants); (b) lim_{x→1} (x³ − 1)/(x² − 1) = lim (x² + x + 1)/(x + 1) = 3/2, where the cancellation is legal because the limit ignores x = 1.
5. **Warning** `**A sum can have a limit when neither term does.**` D and 1 − D at any p: neither has a limit, the sum is 1. The algebra theorem runs in one direction only.
6. Quick check: "Is the hypothesis M ≠ 0 needed for f/g → L/M? Test f(x) = x, g(x) = x² at 0." *Solution:* yes: L = M = 0, and f/g = 1/x has no limit.

**`## Order and squeeze` (~400).**
1. **`thm-limit-order-squeeze`** `[Order and Squeeze for Limits]`: (a) if f ≤ g on A ∖ {p} near p and both limits exist, then lim f ≤ lim g; (b) if f ≤ h ≤ g near p and lim f = lim g = L, then lim h = L. Proof by sequences (Chapter 4's order and squeeze theorems, planned *thm-order-limit* and Chapter 4's squeeze theorem).
2. Remark: strict inequalities are not preserved: x² > 0 on ℝ ∖ {0}, limit 0.
3. Application line: x·s(x) → 0 from −|x|/2 ≤ x s(x) ≤ |x|/2, re-deriving @exm-zigzag-reciprocal (b).

**`## Vector-valued and complex-valued limits` (~600).**
1. **`thm-limit-componentwise`** `[Limits Are Taken Componentwise]`: f = (f₁, …, f_k) : A → ℝᵏ; then f → L = (L₁, …, L_k) iff f_j → L_j for each j. Proof: |f_j(x) − L_j| ≤ |f(x) − L| ≤ Σ_j |f_j(x) − L_j| (F4.8), and ε/k with a min of k δs (finiteness named, H13).
2. Corollary paragraph (no label): f · g → L · M (inner product) and |f| → |L|, from the theorem and `thm-limit-algebra`, or from Cauchy–Schwarz and the reverse triangle inequality.
3. **Remark:** ℂ is ℝ² with |z| the Euclidean length (F4.1), so f → L in ℂ iff Re f → Re L and Im f → Im L.
4. Quick check: "lim_{t→0} (t, (t² + t)/t)?" *Solution:* (0, 1), componentwise.

**`## Limits of composites` (~700).**
1. **`exm-composition-trap`** `[Composing two limits can fail]`: g ≔ 0 on ℝ, f(y) ≔ 1 for y ≠ 0 and f(0) ≔ 0. Then lim_{x→0} g(x) = 0 and lim_{y→0} f(y) = 1, but f(g(x)) = 0 for all x, so lim f∘g = 0 ≠ 1. The inner function sits **on** the point the outer limit ignores.
2. **`prp-limit-composition`** `[Limit of a Composite]`: A ⊆ X, B ⊆ Y, g : A → B, f : B → Z; p an accumulation point of A, q an accumulation point of B; lim_{x→p} g(x) = q, lim_{y→q} f(y) = L; and there is δ₀ > 0 with g(x) ≠ q for all x ∈ A with 0 < d(x, p) < δ₀. Then lim_{x→p} f(g(x)) = L. Proof by sequences (5 lines): yₙ ≔ g(xₙ) → q and yₙ ≠ q for large n. (The continuous-outer-function version is `thm-composition-continuous`, §6.3.)
3. Quick check: "Which hypothesis of @prp-limit-composition fails in @exm-composition-trap?" *Solution:* g(x) ≠ q near p: g(x) = 0 = q for every x.

**`## Limits at infinity and infinite limits` (~900).** Real line only (opening sentence says so).
1. **`def-limit-at-infinity`** `[Limit at Infinity]`: A ⊆ ℝ not bounded above, f : A → Y; lim_{x→∞} f(x) = L if ∀ε > 0 ∃M ∈ ℝ ∀x ∈ A (x > M ⇒ ρ(f(x), L) < ε). Similarly x → −∞.
2. **`def-infinite-limit`** `[Infinite Limits]`: f : A → ℝ, p an accumulation point of A; lim_{x→p} f(x) = ∞ if ∀K ∈ ℝ ∃δ > 0 ∀x ∈ A (0 < |x − p| < δ ⇒ f(x) > K); likewise −∞, and lim_{x→±∞} f(x) = ±∞. One sentence: these use Chapter 4's extended-real conventions (planned *def-diverges-to-infinity*); ∞ is not a point of ℝ, and "the limit exists" means a real limit unless ±∞ is said.
3. **`prp-sequential-criterion-infinity`** `[Sequential Criterion at Infinity]`: lim_{x→∞} f(x) = L iff f(xₙ) → L for every sequence in A with xₙ → ∞; and lim_{x→p} f(x) = ∞ iff f(xₙ) → ∞ for every xₙ → p in A ∖ {p}. Proof: "as in @thm-sequential-criterion-limits, with M = n in place of δ = 1/n" — written out in 8 lines (no proof may rest on "similarly" when the quantifiers change; STYLE §4).
4. **`exm-limit-at-infinity-quotient`** `[A limit at infinity]`: lim_{x→∞} (2x + 1)/(x + 3) = 2: for x > −3, |(2x + 1)/(x + 3) − 2| = 5/(x + 3); M ≔ 5/ε gives 5/(x + 3) < 5/M = ε. Sidecar.
5. **`exm-infinite-limit-reciprocal-square`** `[An infinite limit]`: lim_{x→0} 1/x² = ∞: for K > 0, δ ≔ 1/√K (`@thm-nth-root`); 0 < |x| < δ gives x² < 1/K. For K ≤ 0 any δ works. And 1/x has neither a limit nor an infinite limit at 0 (xₙ = 1/n, yₙ = −1/n), a fact §6.5 reads as two one-sided infinite limits.
6. Quick check: "Write lim_{x→−∞} f(x) = −∞ in symbols." *Solution:* ∀K ∃M ∀x ∈ A (x < M ⇒ f(x) < K).

**Exercises (6.2).**

### 4.3 Section 6.3: Continuity (`03-continuity.md`)

**Budget:** ≤ 5,000 (expected ~4,800). Five Quick checks, two warnings. Major notion: continuity (STYLE §3, all eleven steps).

**May use:** §6.1–6.2; AN1.1 density; Chapter 3 isolated points; Chapter 4 sequences in metric spaces; F4.8, F4.11; Chapter 3's distance to a set; Chapter 5's Lipschitz maps and contractions.

**Opening (~100).** A limit ignores the value at the point; continuity asks that the value be the limit. Section 6.1 asked where D, M and T are continuous; this section answers for D and M.

**`## A picture that does not decide` (failure, ~400).** **`exm-zigzag-pen-test`** `[The pen test fails]`: extend s by s(0) ≔ 0. On each [1/(n + ½), 1/n] (n ≥ 1), 1/x runs over [n, n + ½], where z(y) = y − n takes every value in [0, ½] (explicit inverse: y = n + c gives z = c). So on every interval around 0, s takes every value of [0, ½]: there is no gap in its values to see. Yet s(1/n) = 0 and s(2/(2n + 1)) = ½ while both inputs → 0. "Whatever continuity at 0 means, s should fail it. The definition compares f(x) with f(p), not the shape of the image." (Rule 3: no claim about intervals not containing 0.)

**`## Continuity at a point` (~900).**
1. Slogan: *f(x) is as close to f(p) as we please for every x close enough to p.*
2. **`def-continuous-at`** `[Continuity at a Point]`: (X, d), (Y, ρ), A ⊆ X, f : A → Y, p ∈ **A**. f is **continuous at p** if ∀ε > 0 ∃δ > 0 ∀x ∈ A (d(x, p) < δ ⇒ ρ(f(x), f(p)) < ε). Symbols line. Paraphrase; compare with `def-function-limit`: p must be in A, need not be an accumulation point, and x = p is allowed (harmless).
3. **`def-continuous-on`**: f is **continuous on** S ⊆ A if continuous at every p ∈ S; **continuous** means on A.
4. **`exm-continuous-isolated-points`** `[Every function is continuous at an isolated point]`: if p is isolated in A, a δ with A ∩ B(p, δ) = {p} works for every ε. So every f : ℤ → ℝ, and every function on a discrete metric space (F4.11), is continuous.
5. **`thm-continuity-characterizations`** `[Three Forms of Continuity]`: for p ∈ A the following are equivalent: (a) f continuous at p; (b) for every sequence xₙ → p in A, f(xₙ) → f(p); and, when p is an accumulation point of A, (c) lim_{x→p} f(x) = f(p). Proof: (a) ⇔ (c) is a comparison of definitions; (a) ⇔ (b) is @thm-sequential-criterion-limits's proof with xₙ = p allowed (written in 8 lines, citing the criterion where possible: for an accumulation point, (b) ⇒ (c) by the criterion; for an isolated point both hold).
6. Quick check: "Negate 'f is continuous at p' in symbols." *Solution:* ∃ε > 0 ∀δ > 0 ∃x ∈ A (d(x, p) < δ ∧ ρ(f(x), f(p)) ≥ ε).
7. **Warning** `**Continuity is a property of a function on its domain.**` "1/x is continuous on ℝ ∖ {0}; asking whether it is continuous at 0 has no meaning, since 0 is not in its domain. Section 6.5 has words for what happens near such a point."

**`## Building continuous functions` (~1,300).**
1. **`thm-continuity-algebra`** `[Algebra of Continuous Functions]`: for f, g : A → 𝕂 continuous at p, so are f + g, fg, cf, and f/g if g(p) ≠ 0 (on {g ≠ 0}); f = (f₁, …, f_k) : A → ℝᵏ is continuous at p iff each f_j is. Proof: `thm-continuity-characterizations` (b) with Chapter 4's sequence laws and componentwise convergence.
2. **`thm-composition-continuous`** `[Composition of Continuous Functions]`: g : A → B ⊆ Y continuous at p, f : B → Z continuous at g(p); then f∘g is continuous at p.
   - **`[Scratch work]`** (≤ 12 lines, chain the δs): the goal is about f(g(x)) near f(g(p)); f's continuity at g(p) turns ε into η, a distance in Y; g's continuity at p turns that η, used as its ε, into δ. Read from the outside in; write from the inside out. Contrast with `exm-composition-trap`: here no point is ignored, so no extra hypothesis.
   - Proof (6 lines).
3. Recall Chapter 5's Lipschitz maps (`@def-lipschitz`: ρ(f(x), f(y)) ≤ K d(x, y), K ≥ 0). **`prp-lipschitz-continuous`** `[Lipschitz Maps Are Continuous]`: every Lipschitz map is continuous; δ ≔ ε/(K + 1), the +1 covering K = 0, and δ does not depend on the point (one clause; Chapter 7 names this). So every contraction of Chapter 5 (`@def-contraction`) and every isometry is continuous.
4. **`prp-distance-to-set-lipschitz`** `[Distance to a Set Is 1-Lipschitz]`: for non-empty S ⊆ X, dist(x, S) ≔ inf{d(x, s) : s ∈ S} (defined in the statement, NOTATION `\dist`; it exists since the set is non-empty and bounded below by 0, `@thm-greatest-lower-bound`) satisfies |dist(x, S) − dist(y, S)| ≤ d(x, y). Proof: dist(x, S) ≤ d(x, s) ≤ d(x, y) + d(y, s) for each s ∈ S, so dist(x, S) − d(x, y) is a lower bound of {d(y, s)}, hence ≤ dist(y, S); swap x and y. With `prp-lipschitz-continuous`: x ↦ dist(x, S) is continuous; in particular x ↦ d(x, a) (S = {a}); and z = dist(·, ℤ) of @exm-zigzag (the identification z(x) = dist(x, ℤ) is checked in `exm-zigzag`), so z is continuous, and s is continuous on ℝ ∖ {0} by `thm-composition-continuous`. Also d : X × X → ℝ is continuous for the product metric of F4.11, since |d(x, y) − d(x′, y′)| ≤ d(x, x′) + d(y, y′) (one line; Chapter 3's blueprint lists this use of `@thm-product-open-sets`, which the drafter may cite instead).
5. **`exm-continuous-standard`** `[A stock of continuous functions]`: (a) constants, the identity, coordinate projections ℝⁿ → ℝ (1-Lipschitz, F4.8); (b) polynomials in n variables and rational functions where the denominator is non-zero (by (a) and the algebra theorem); (c) the norm x ↦ |x| on ℝⁿ (reverse triangle inequality, F4.8) and x ↦ |x| on ℝ; (d) √ on [0, ∞) at p > 0 via |√x − √p| = |x − p|/(√x + √p) ≤ |x − p|/√p, and at 0 with δ ≔ ε² (R3 revisits); (e) the restriction of a continuous function to a subset, and the inclusion of a subspace. One sentence: on ℝⁿ, continuity is the same for d₁, d₂ and d_∞ (`@cor-rn-metrics-equivalent`, same open sets), so "continuous on ℝⁿ" needs no metric named.
6. Quick check: "Is f(x, y) ≔ (x² + y²)/(1 + x²) continuous on ℝ²? Name the results used." *Solution:* yes: polynomials, denominator ≥ 1, `thm-continuity-algebra`.

**`## The first two answers` (~1,000).**
1. **`exm-dirichlet-nowhere-continuous`** `[D is continuous nowhere]`: by `thm-continuity-characterizations` (b) and the sequences of `exm-dirichlet-no-limit` (rational and irrational sequences → p; one of the two images does not tend to D(p)).

### 4.4 Section 6.4: Continuity and Open Sets (`04-continuity-and-open-sets.md`)

**Budget:** ≤ 5,000 (expected ~4,000). Three Quick checks, two warnings.

**May use:** §6.1–6.3; Chapters 2–3 (open, closed, relatively open sets; open balls are open; complements; the characterization U relatively open in A iff U = W ∩ A with W open in X).

**Opening (~100).** Continuity has been a statement about points. This section turns it into a statement about sets: a function is continuous exactly when it pulls open sets back to open sets. The open-set form is what proves sets open or closed at a stroke, and it is the form in which Chapter 8 and every later topology chapter use continuity.

**`## Pulling back open sets` (~1,100).**
1. Lead: "Which points satisfy x² + y² < 1 and y > x³? Proving such a set open with balls means one radius per point; the open-set form of continuity proves it at once."
2. **`thm-continuity-open-preimages`** `[Continuity and Open Sets]`: f : X → Y between metric spaces is continuous on X **if and only if** f⁻¹(V) is open in X for every open V ⊆ Y. **Key proof.**
3. **`[Scratch work]`** (≤ 12 lines): (⇒) take p ∈ f⁻¹(V); V open gives a ball B(f(p), ε) ⊆ V; continuity turns ε into δ with f(B(p, δ)) ⊆ B(f(p), ε); so B(p, δ) ⊆ f⁻¹(V). (⇐) the ball B(f(p), ε) is open (`@thm-ball-open`), so its preimage is open and contains p, so it contains some B(p, δ): that is the ε-δ statement.
4. Proof (~12 lines). Self-explanation prompt: "*Self-explain where the proof of (⇐) uses that open balls are open.*"
5. **`cor-continuity-closed-preimages`**: f continuous iff f⁻¹(F) closed for every closed F. Proof: f⁻¹(Y ∖ F) = X ∖ f⁻¹(F).
6. **`thm-continuity-relative-preimages`** `[Continuity on a Subset]`: for A ⊆ X and f : A → Y, f is continuous iff for every open V ⊆ Y there is W open in X with f⁻¹(V) = W ∩ A. Proof: A with the restricted metric is a metric space; apply the theorem and Chapter 3's characterization of relatively open sets (`@thm-relatively-open`).
7. Quick check: "Run the theorem on f(x) = x² and V = (1, 4)." *Solution:* f⁻¹(V) = (−2, −1) ∪ (1, 2), open.

**`## Sets cut out by inequalities` (~800).**
1. **`exm-sets-by-inequalities`** `[Open and closed by inspection]`: (a) U ≔ {(x, y) : x² + y² < 1, y > x³} = f⁻¹((−∞, 1)) ∩ g⁻¹((0, ∞)) with f(x, y) = x² + y², g(x, y) = y − x³, open (finite intersection). (b) For continuous φ, ψ : X → ℝ, {φ = ψ}, {φ ≤ ψ} are closed and {φ < ψ} is open. (c) The graph {(x, f(x))} of a continuous f : ℝ → ℝ is closed in ℝ² (the zero set of y − f(x)).
2. **Warning** `**Preimages, not images.**` x² maps the open (−1, 1) onto [0, 1), not open; see the next example.
3. **`exm-images-not-open-or-closed`** `[Images keep neither property]`: (a) as in the warning; (b) u(x) ≔ 1/(1 + x²) maps the closed set ℝ onto (0, 1], not closed. (Compact sets do better: Chapter 7, prose only.)
4. Quick check: "Why does `cor-continuity-closed-preimages` not show that ⌊x⌋ ≤ 0 defines a closed set?" *Solution:* the floor is not continuous; and indeed {x : ⌊x⌋ ≤ 0} = (−∞, 1) is not closed.

**`## Continuous bijections` (~800).**
1. **`exm-continuous-bijection-tears`** `[A continuous bijection that tears]`: A ≔ [0, 1) ∪ [2, 3] ⊆ ℝ, f(x) ≔ x on [0, 1), f(x) ≔ x − 1 on [2, 3]. f is a continuous bijection A → [0, 2] (continuity: on each piece, with δ ≤ 1 so pieces do not mix). Its inverse is discontinuous at 1: f⁻¹(1) = 2, while f⁻¹(1 − 1/n) = 1 − 1/n → 1. Open-set reading: [2, 3] is relatively open in A (= (1.5, 3.5) ∩ A) but its image [1, 2] is not relatively open in [0, 2].
2. One paragraph (no definition block): by `thm-continuity-relative-preimages`, a bijection f whose inverse is also continuous matches the relatively open sets of its domain with those of its image, both ways; f above is not such a map. "Chapter 8 calls such maps homeomorphisms and studies what they preserve." (Label ownership: Chapter 8's blueprint owns `def-homeomorphism`; §8 Seams.)
3. **`exm-line-and-interval`** `[ℝ and (−1, 1)]`: φ(x) ≔ x/(1 + |x|) is a bijection ℝ → (−1, 1) with inverse ψ(y) ≔ y/(1 − |y|); check φ∘ψ = id, ψ∘φ = id, and both are continuous by the algebra theorem (|x| continuous, denominators non-zero). So ℝ and (−1, 1) have "the same open sets" through φ, though one is bounded and the other is not, and Cauchy sequences are not matched (ψ(1 − 1/n) = n − 1). One clause recalls Chapter 5's point that completeness is not decided by the open sets alone; S2a item 5 checks what Chapter 5 says.
4. Quick check: "The identity map from ℝ with the discrete metric to ℝ with the usual metric: is it continuous? Is its inverse?" *Solution:* it is continuous (every function on a discrete space is, @exm-continuous-isolated-points); its inverse is not: the preimage of the open set {0} under the inverse is {0}, which is not open in the usual metric.
5. Aftermath sentence: compactness and connectedness are preserved by continuous maps (Chapters 7–8, prose only).

### 4.5 Section 6.5: Discontinuities and Monotone Functions (`05-discontinuities-and-monotone-functions.md`)

**Budget:** ≤ 5,000 (expected ~4,700). Four Quick checks, two warnings. Real line only.

**May use:** §6.1–6.4; AN1.1 sup and inf (`@def-supremum`, `@def-infimum`, `@thm-sup-epsilon`, `@cor-sup-approximation`), density; F4.7 (monotone, increasing, strictly increasing), F4.6 (finite geometric sums); Chapter 4 monotone convergence (*thm-monotone-convergence*); fd2 countability.

**Opening (~120).** On the real line a point can be approached from two sides, and a function may behave differently on each. This section names the two one-sided limits, sorts discontinuities into kinds by them, and proves that a monotone function, however wild, breaks only by jumps, and only at countably many points.

**`## One-sided limits` (~800).**
1. Failure first (≤ 100 words): ⌊x⌋ has no limit at 1 (xₙ = 1 − 1/n gives 0, yₙ = 1 + 1/n gives 1), yet on each side it is constant near 1. The two-sided definition loses that.
2. **`def-one-sided-limit`** `[One-Sided Limits]`: A ⊆ ℝ, f : A → Y, p an accumulation point of A ∩ (p, ∞). f(p+) ≔ lim_{x→p+} f(x) = L means the limit at p of f restricted to A ∩ (p, ∞); in ε-δ form: ∀ε ∃δ ∀x ∈ A (p < x < p + δ ⇒ ρ(f(x), L) < ε). Likewise f(p−). Infinite one-sided limits as in `def-infinite-limit`.
3. **`prp-limit-iff-one-sided`**: if p is an accumulation point of both A ∩ (p, ∞) and A ∩ (−∞, p), then lim_{x→p} f(x) = L iff f(p+) = f(p−) = L. Proof: δ = min of the two δs (⇐); restriction (⇒).
4. Examples paragraph: ⌊1−⌋ = 0, ⌊1+⌋ = 1; 1/x at 0: f(0+) = ∞, f(0−) = −∞; s = z(1/x) has neither one-sided limit at 0 (the sequences of `exm-zigzag-reciprocal` are positive; their negatives serve on the left).
5. Quick check: "Compute f(0+) and f(0−) for f(x) = x/|x|." *Solution:* 1 and −1.

**`## Kinds of discontinuity` (~1,000).**
1. **`def-discontinuity-kinds`** `[Removable, Jump and Essential Discontinuities]`: let f : A → ℝ (or Y), p ∈ A an accumulation point of A from both sides, f discontinuous at p. The discontinuity is **removable** if lim_{x→p} f(x) exists (and ≠ f(p)); a **jump** if f(p+) and f(p−) both exist and differ; these two are the **first kind**. Otherwise (some one-sided limit fails to exist, including the case of an infinite one) it is of the **second kind** (essential). One sentence: the names say what can be repaired: a removable discontinuity disappears when f(p) is redefined; a jump cannot be removed by changing one value.
2. **`exm-discontinuity-gallery`** `[A gallery]`: (a) h of `exm-limit-ignores-value`, removable at 3; (b) ⌊x⌋ + ⌊−x⌋ (= 0 on ℤ, −1 off ℤ), removable at every integer; (c) ⌊x⌋, jump at every integer, ⌊n−⌋ = n − 1, ⌊n+⌋ = n; (d) s with s(0) ≔ 0, second kind at 0, both one-sided limits fail; (e) f(x) ≔ 1/x, f(0) ≔ 0, second kind at 0 (infinite one-sided limits); (f) D, second kind at every point; M, second kind at every p ≠ 0. A small TikZ figure for (b) and (c) only.
3. Quick check: "Is the discontinuity of ⌊x⌋ + ⌊−x⌋ at 0 removable? Which value at 0 removes it?" *Solution:* yes: the limit at 0 is −1 (the function is −1 on (−1, 0) ∪ (0, 1)), and the value −1 at 0 removes it.
4. **Warning** `**A jump needs both one-sided limits.**` s at 0 "jumps" between 0 and ½ in a picture, but has no one-sided limit; it is of the second kind.

**`## Monotone functions` (~1,500).**
1. Lead: the gallery's second-kind discontinuities oscillate. A monotone function cannot oscillate, so its one-sided limits should always exist; the natural candidate for f(p−) is the supremum of the values to the left.
2. **`thm-monotone-one-sided-limits`** `[One-Sided Limits of Monotone Functions]`: let f : (a, b) → ℝ be increasing (−∞ ≤ a < b ≤ ∞), and p ∈ (a, b). Then f(p−) and f(p+) exist, and f(p−) = sup{f(x) : a < x < p} ≤ f(p) ≤ inf{f(x) : p < x < b} = f(p+). Decreasing: reverse the inequalities.
   - *Try it first (ten minutes): which number should f(p−) be, and why does it exist?*
   - **`[Scratch work]`** (≤ 15 lines): candidate s ≔ sup{f(x) : x < p}, which exists because the set is non-empty and bounded above by f(p) (monotone) (`@def-supremum`, the axiom). Goal: for ε > 0, a δ with s − ε < f(x) ≤ s for p − δ < x < p. Sup approximation (`@cor-sup-approximation`) hands us x₀ < p with f(x₀) > s − ε; monotonicity carries this to every x ∈ (x₀, p). So δ ≔ p − x₀. The Idea ends: this is the proof of monotone convergence (Chapter 4) with x in place of n.
   - Proof (~10 lines); the right side "by the symmetric argument with infima" is allowed (STYLE §4: a symmetric half), stated in one sentence naming the inf form.
3. **`cor-monotone-jump-discontinuities`** `[Monotone Functions Only Jump]`: an increasing f on (a, b) is continuous at p iff f(p−) = f(p+); otherwise the discontinuity is a jump of size f(p+) − f(p−) > 0. No removable discontinuity and no second kind. Proof: the theorem's chain of inequalities and `prp-limit-iff-one-sided`.
4. **`thm-monotone-discontinuities-countable`** `[Monotone Functions Have Countably Many Discontinuities]`: let I ⊆ ℝ be an interval and f : I → ℝ monotone. Then the set of points of I at which f is discontinuous is countable. **Key proof.**
   - **`[Scratch work]`** (≤ 15 lines): WLOG increasing (−f). Each interior discontinuity p gives a non-empty open interval J_p ≔ (f(p−), f(p+)). For p < p′ interior discontinuities, any x ∈ (p, p′) has f(p+) ≤ f(x) ≤ f(p′−), so J_p and J_{p′} are disjoint. Disjoint non-empty open intervals can be counted by rationals: each contains one (`@thm-rationals-dense`). To avoid choosing, fix a list q₀, q₁, … of ℚ (`@fd2:thm-integers-rationals-countable`) and take the rational with the **least index** in J_p. Distinct p give distinct rationals (disjointness), so p ↦ r(p) is an injection into ℚ. Endpoints of I belonging to I add at most two points.
   - Proof (~14 lines), citing `@fd2:thm-countable-characterizations` (an injection into a countable set) and `@fd2:prp-countable-subset` / finite unions. One clause: no choice is used, since the least index is determined by p.
   - Self-explanation prompt: "*Self-explain why the intervals J_p are pairwise disjoint.*"
5. Quick check: "Does `thm-monotone-discontinuities-countable` say the discontinuities are finitely many? Test it on ⌊x⌋ on ℝ." *Solution:* no: ⌊x⌋ is discontinuous at every integer, countably many and infinitely many.

**`## A function that jumps at every rational` (~900).**
1. **`exm-jumps-at-every-rational`** `[A monotone function jumping at every rational]`: fix a list (qₙ)_{n ∈ ℕ} of all rationals (repetitions allowed). For x ∈ ℝ and N ∈ ℕ let J_N(x) ≔ Σ_{n ≤ N, qₙ < x} 2^{−(n+1)}. Then J_N(x) ≤ Σ_{n=0}^{N} 2^{−(n+1)} = 1 − 2^{−(N+1)} < 1 (F4.6), and J_N(x) increases with N, so J(x) ≔ lim_N J_N(x) exists (Chapter 4's monotone convergence) and 0 ≤ J ≤ 1. Claims, each proved in the solution:
   - (a) J is increasing: x < y gives J_N(x) ≤ J_N(y) for each N; pass to the limit (order of limits, Chapter 4).
   - (b) J is discontinuous at every rational: if q = q_m, then for x > q_m and N ≥ m, J_N(x) − J_N(q_m) ≥ 2^{−(m+1)} (the term n = m is counted at x, not at q_m), so J(x) − J(q_m) ≥ 2^{−(m+1)} for every x > q_m, and J(q_m+) ≥ J(q_m) + 2^{−(m+1)}.
   - (c) J is continuous at every irrational t: given ε > 0, choose N with 2^{−(N+1)} < ε (`@cor-archimedean-epsilon` with 2^{N+1} ≥ N + 2, F4.6). The finitely many q₀, …, q_N differ from t; let δ be the least of their distances to t (move 7). For t − δ < x < y < t + δ and any M ≥ N, J_M(y) − J_M(x) = Σ over n ≤ M with x ≤ qₙ < y, and every such n has n > N, so the sum is ≤ Σ_{n=N+1}^{M} 2^{−(n+1)} < 2^{−(N+1)} < ε. Passing to M → ∞, |J(y) − J(x)| ≤ ε for x, y in the δ-interval, in particular |J(x) − J(t)| ≤ ε. (Strictness: use ε/2 in place of ε; the drafter writes "< ε".)
   So the discontinuities of J are exactly the rationals: countable, as the theorem says, and dense. Sidecar `verify/ch06/exm-jumps-at-every-rational.py` checks the geometric bounds and a numeric J with a fixed enumeration.
2. Quick check: "Why may the list (qₙ) have repetitions?" *Solution:* a repeated rational contributes two terms; (b) needs only one index m with q_m = q, and (c) only that finitely many indices are excluded.

**`## Thomae's function` (~1,200).**

(d) True or false: the set of points where a function ℝ → ℝ is continuous is always open.
  - *Solution:* (a) 1/4, 1/3, 1, 0. (b) ½, 1, 1. (c) for each q, at most 2q integers in an open interval of length 2q; if t ∈ S, the minimum includes |t − t| = 0, so δ = 0 is not allowed. (d) False: T's continuity set ℝ ∖ ℚ is not open.
- **B1** `[B1: Oscillations]` (a) f(x) ≔ x on ℚ, −x off ℚ: show ω_f(p) = 2|p|. (b) g ≔ ⌊x⌋ + ⌊−x⌋: ω_g(n) for n ∈ ℤ, and ω_g elsewhere. *Solution:* (a) for r > 0, f(B(p, r)) contains points arbitrarily near p and near −p and lies in (p − r, p + r) ∪ (−p − r, −p + r); diam → 2|p|; full ε-argument both inequalities. (b) 1 at integers (values 0 and −1 in every ball), 0 elsewhere.
- **B2** `[B2: T has a limit everywhere]` Prove lim_{x→p} T(x) = 0 for every p ∈ ℝ, and deduce the kind of each discontinuity of T. *Solution:* the proof of @thm-thomae with S ∖ {p} and the punctured condition 0 < |x − p| < δ; so every discontinuity is removable.
- **C1** `[C1: Exit check: Where is xT(x) continuous?]` Let G(x) ≔ x·T(x). Find the set of points where G is continuous, and prove your answer. *Solution:* {0} ∪ (ℝ ∖ ℚ). At irrational t: for |x − t| < 1, |G(x)| ≤ (|t| + 1)T(x), and T(x) → 0 = T(t) by @thm-thomae; so G(x) → 0 = G(t). At 0: |G(x)| ≤ |x| (T ≤ 1). At p/q ≠ 0 in lowest terms: G(p/q) = p/q² ≠ 0, while irrationals yₙ → p/q have G(yₙ) = 0. *Marking scheme* (10): correct set 2; irrational points via thm-thomae with the factor bounded near t 3; the point 0 separately 2; non-zero rationals with a sequence or ε 3. Fatal: treating 0 as an ordinary rational (G(0) = 0, so the rational argument fails there).
- **C2** `[C2: Every closed set is a continuity set]` Let F ⊆ ℝ be closed. Show that f(x) ≔ dist(x, F)·D(x) is continuous exactly at the points of F. (If F = ∅, read dist(x, ∅) as 1, so f = D.) *Solution:* at x ∈ F, |f(y)| ≤ dist(y, F) ≤ |y − x| (`prp-distance-to-set-lipschitz`, with dist(x, F) = 0); at x ∉ F, c ≔ dist(x, F) > 0 (6.3 C3 (a), which this exercise may cite), and dist(·, F) is continuous at x, and rational yₙ → x give f(yₙ) = dist(yₙ, F) → c ≠ 0, while irrational yₙ give 0. One closing sentence: so every closed set and, by T, the irrationals are continuity sets; the Looking-ahead box says what remains.

- **R1** (Chapter 5): "Let g(x) ≔ 1/(2 + x) on [0, 1]. Show that g maps [0, 1] into itself and that |g(x) − g(y)| ≤ ¼|x − y|. Deduce that x₀ ≔ 0, x_{n+1} ≔ g(xₙ) converges, and find its limit." *Solution:* g([0, 1]) ⊆ [1/3, 1/2]; |g(x) − g(y)| = |x − y|/((2 + x)(2 + y)) ≤ |x − y|/4; Chapter 5's Banach fixed point theorem (`@thm-banach-fixed-point`) on the complete [0, 1] (closed in ℝ); limit = the fixed point x² + 2x − 1 = 0, x = √2 − 1 (using continuity of g to pass to the limit, `thm-continuity-characterizations`). - **R2** (Chapters 2–3): "Let A ⊆ ℝ be non-empty and bounded above. Show sup A lies in the closure of A, and deduce that a non-empty closed set bounded above contains its supremum." *Solution:* sup approximation gives aₙ ∈ A with aₙ > sup A − 1/n (`@cor-sup-approximation`), so aₙ → sup A; closure by sequences (Chapter 3).

(The uniformity anticipates Chapter 7; the solution says so in one clause.)

For x < 0: multiplying ⌊1/x⌋ ≤ 1/x < ⌊1/x⌋ + 1 by x < 0 gives 1 ≤ x⌊1/x⌋ < 1 − x.
