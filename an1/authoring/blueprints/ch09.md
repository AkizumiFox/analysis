- **Chapter hook** (index and §9.1 opening). *A puzzle about slopes.* Three questions, posed without answers:
  - **(H1)** The function s(x) = 0 for x < 0 and s(x) = 1 for x ≥ 0 is a step. Is there a function F : ℝ → ℝ with F′ = s at **every** point? The guess F(x) = max(x, 0) fails only at 0. Can some cleverer F succeed?

- **Named moves** (index, linked in order of first appearance; each line names the label of its first use):
  1. **Factor out x − c.** Write f(x) − f(c) = (x − c)φ(x) with φ continuous at c; every derivative rule becomes a rule about continuous functions (`thm-caratheodory-derivative`).
  2. **Tilt by the secant.** Subtract the chord so the endpoint values agree, then use Rolle (`thm-cauchy-mean-value`, `thm-mean-value`).
  3. **Bound the change by the derivative.** |f(x) − f(y)| ≤ sup|f′|·|x − y| (`cor-lipschitz-from-derivative`).
  4. **Shear to an extremum.** To find where f′ = λ, subtract λx and find where the new function has an interior extremum (`thm-darboux`).
  5. **Squeeze the mean-value point.** The ξ of the MVT on [c, x] is trapped between c and x, so it tends to c with x (`thm-derivative-limit`, `thm-lhospital`).
  6. **The Rolle ladder.** Build g with g = g′ = … = g^{(n−1)} = 0 at one point and g = 0 at another; climb with Rolle n times (`thm-taylor-lagrange`).
  7. **Dot with the displacement.** To bound a vector change, dot it with its own direction and use the real MVT and Cauchy–Schwarz (`thm-vector-mean-value-inequality`).
  8. **Approach along two paths.** A limit in ℂ or ℝ² that exists has the same value along every path; two paths with two values refute it (`exm-conjugate-nowhere-differentiable`, `thm-cauchy-riemann`).
  9. **One variable at a time.** Move horizontally, then vertically, and use the one-variable MVT on each leg (`thm-cauchy-riemann-sufficient`, `thm-constant-on-disk`).

### 4.1 Section 9.1: The Derivative (`01-the-derivative.md`)

**Budget:** ≤ 5,000 (expected ~4,700). Five Quick checks, two warnings.

1. **`## A puzzle about slopes`** (hook, ~280). (H1), (H2), (H3) as in §1, each in two or three sentences, no answers. "Each is settled in this chapter; each answer turns on a theorem rather than a computation."
2. **`## Slopes of secants, and their limit`** (~520). Failure-motivated lead: the secant through (c, f(c)) and (x, f(x)) has slope (f(x) − f(c))/(x − c); at x = c the expression is 0/0, so "the slope at c" can only mean what the secant slopes approach. Then:
   - **`def-derivative`** `[Derivative]`. Let I ⊆ ℝ be an interval containing more than one point, f : I → ℝ, c ∈ I. f is **differentiable at c** if the limit f′(c) ≔ lim_{x→c} (f(x) − f(c))/(x − c), taken over x ∈ I ∖ {c} (Chapter 6's limit relative to a set, @def-fn-limit), exists in ℝ. f is differentiable on I if it is at every c ∈ I; f′ is then a function I → ℝ. In symbols: ∀ε > 0 ∃δ > 0 ∀x ∈ I (0 < |x − c| < δ ⇒ |(f(x) − f(c))/(x − c) − f′(c)| < ε). One sentence: at an endpoint of I this is automatically a one-sided limit; Apostol works on open intervals, the closed-interval version (Rudin's) is what Rolle's theorem needs.
   - **`exm-derivative-from-definition`** `[Two derivatives from the definition]`: (a) f(x) = x² + 3x at c: quotient = x + c + 3 for x ≠ c, limit 2c + 3; (b) f(x) = 1/x on (0, ∞) at c: quotient = −1/(xc), limit −1/c² (one line: limit of a quotient, Chapter 6, since xc → c² ≠ 0).
   - **`exm-abs-corner`** `[A corner]`: f(x) = |x| at 0: quotient |x|/x = ±1 on either side; no limit; f is continuous at 0. Non-example of differentiability.
   - **Quick check:** "Is f(x) = x|x| differentiable at 0? Compute the quotient." *Solution:* the quotient is |x|, which → 0; f′(0) = 0. (Sets up `exm-x-abs-x`.)
3. **`## One-sided and infinite derivatives`** (~450). Failure lead: |x| has two slopes; x^{1/3} has a vertical tangent; the definition above names neither.
   - **`def-one-sided-derivative`** `[One-sided and infinite derivatives]`: for c with points of I on the right, f′₊(c) ≔ lim_{x→c⁺} of the quotient when it exists in ℝ or is +∞ or −∞ (Chapter 6's infinite limits); f′₋(c) likewise. For c interior, f′(c) = +∞ means both one-sided derivatives are +∞. **"Differentiable" always means a finite derivative.** Fact (one line, from Chapter 6's one-sided limits): at an interior c, f is differentiable at c iff f′₊(c), f′₋(c) are finite and equal.
   - **`exm-cube-root-vertical`** `[A vertical tangent]`: f(x) = x^{1/3} (AN1.1's odd roots, extended to x < 0 by f(−x) = −f(x)); at 0 the quotient is x^{−2/3} = 1/(x^{1/3})² > 0, unbounded: f′(0) = +∞, f not differentiable at 0. Ledger: the root laws from AN1.1 and F4.6.
   - **Warning** `**An infinite derivative is not a derivative.**` "f′(0) = +∞ records a vertical tangent; it does not make f differentiable at 0, and none of the rules below applies to it."
4. **`## Factoring out x − c`** (~620).
   - **`thm-caratheodory-derivative`** `[Derivative as a Factorization]`: f is differentiable at c iff there is φ : I → ℝ, continuous at c, with f(x) − f(c) = (x − c)φ(x) for all x ∈ I (`eq-caratheodory`); then φ(c) = f′(c), and φ is unique.
   - **`[Scratch work]`**: the quotient is defined except at c; it wants to be continuous at c, and the only obstacle is that it has no value there. So *give it one*: φ(x) = quotient for x ≠ c, φ(c) = f′(c). The converse: divide by x − c for x ≠ c and let x → c. Uniqueness: two such φ agree off c, and continuity at c pins the value.
   - **Proof** (~8 lines), as the scratch work, forwards.
   - Aftermath (2 sentences): this turns "differentiable" into "a continuous function times x − c", so the rules about derivatives become rules about continuous functions (Chapter 6). Named move 1.
   - **`thm-differentiable-continuous`** `[Differentiable Implies Continuous]`: f(x) = f(c) + (x − c)φ(x) → f(c). Proof: one line from `thm-caratheodory-derivative` and continuity of products (Chapter 6). The converse fails: `exm-abs-corner`.
   - **Quick check:** "Find φ in @thm-caratheodory-derivative for f(x) = x³ at c = 2." *Solution:* φ(x) = x² + 2x + 4 (x³ − 8 = (x − 2)(x² + 2x + 4)); φ(2) = 12 = f′(2).
5. **`## The rules`** (~900).
   - **`thm-derivative-algebra`** `[Algebra of Derivatives]`: f, g differentiable at c ⇒ f + g, fg, and (if g(c) ≠ 0) f/g differentiable at c with the usual formulas. (f/g is defined on I ∩ {g ≠ 0}, which contains I ∩ (c − δ, c + δ) for some δ by continuity of g at c; the derivative is taken on that interval.) Proof: by factorization. f = f(c) + (x − c)φ, g = g(c) + (x − c)ψ; then fg − f(c)g(c) = (x − c)[φ g + f(c) ψ], and the bracket is continuous at c with value f′(c)g(c) + f(c)g′(c). Quotient: 1/g first: 1/g(x) − 1/g(c) = (x − c)·(−ψ(x)/(g(x)g(c))); then product. The quotient rule's computation in a fold.
   - **`exm-power-rule`** `[Integer powers]`: (xⁿ)′ = n x^{n−1} for n ≥ 1 by induction on n with the product rule; for n ≤ −1 and x ≠ 0 by 1/g. Polynomials and rational functions are differentiable on their domains.
   - **`thm-chain-rule`** `[Chain Rule]`: I, J intervals, f : I → ℝ, f(I) ⊆ J, g : J → ℝ; f differentiable at c and g differentiable at f(c) ⇒ g ∘ f differentiable at c with (g ∘ f)′(c) = g′(f(c)) f′(c).
   - **`[Scratch work]`** (≤ 18 lines). The tempting proof: (g(f(x)) − g(f(c)))/(x − c) = [(g(f(x)) − g(f(c)))/(f(x) − f(c))]·[(f(x) − f(c))/(x − c)], let x → c. It divides by f(x) − f(c), which can be 0 for x arbitrarily close to c. **`exm-chain-rule-trap`** `[Where the naive proof breaks]` sits here, as an example inside the scratch work's flow (placed between scratch and proof): f(x) = x² for x ∈ ℚ, 0 for x ∉ ℚ. Then f is differentiable at 0 with f′(0) = 0 (|f(x)/x| ≤ |x|), and f(x) = f(0) = 0 at every irrational x, so every interval around 0 has points where the first bracket is 0/0. The fix: the factorization never divides. Givens/Goal: f(x) − f(c) = (x − c)φ(x); g(y) − g(d) = (y − d)ψ(y) with d = f(c); want g(f(x)) − g(d) = (x − c)·(something continuous at c). Substitute y = f(x): g(f(x)) − g(d) = (f(x) − d)ψ(f(x)) = (x − c)φ(x)ψ(f(x)). Is ψ ∘ f continuous at c? ψ is continuous at d and f at c (`thm-differentiable-continuous`): composition (Chapter 6).
   - **Proof** (~7 lines), forwards.
   - **Quick check:** "In the proof, where was it used that f is continuous at c?" *Solution:* to get ψ ∘ f continuous at c; without it, ψ(f(x)) need not approach ψ(d).
6. **`## Inverse functions`** (~650).
   - Lead: x^{1/n} is the inverse of xⁿ on (0, ∞); to differentiate it, differentiate an inverse.
   - **`thm-inverse-derivative`** `[Derivative of an Inverse]`: f : I → ℝ continuous and strictly monotone on the interval I, J ≔ f(I) (an interval, ⟨IVT⟩), f⁻¹ : J → I continuous (⟨continuous inverse⟩). If f is differentiable at c with f′(c) ≠ 0, then f⁻¹ is differentiable at d ≔ f(c) with (f⁻¹)′(d) = 1/f′(c).
   - **`[Scratch work]`** (≤ 12 lines). From `eq-caratheodory`: y − d = (f⁻¹(y) − c)·φ(f⁻¹(y)) for y ∈ J (put x = f⁻¹(y)). Solve for f⁻¹(y) − c: need φ(f⁻¹(y)) ≠ 0. At y = d it is φ(c) = f′(c) ≠ 0. At y ≠ d, x ≠ c (injective), and φ(x) = (f(x) − f(c))/(x − c) ≠ 0 (injective again). So f⁻¹(y) − c = (y − d)·[1/φ(f⁻¹(y))], and the bracket is continuous at d because f⁻¹ is continuous at d and φ at c.
   - **Proof** forwards (~8 lines).
   - **`exm-root-derivative`** `[Roots]`: for q ≥ 1 and x > 0, (x^{1/q})′ = (1/q) x^{1/q − 1}: f(y) = y^q on (0, ∞), f′(y) = q y^{q−1} ≠ 0, so (f⁻¹)′(x) = 1/(q (x^{1/q})^{q−1}) = (1/q) x^{(1−q)/q} (F4.6's rational powers). At x = 0 with f′(0) = 0 the theorem is silent and the derivative is in fact infinite (`exm-cube-root-vertical`).
   - **Warning** `**f′(c) ≠ 0 is needed.**` "x³ is strictly increasing and differentiable on ℝ, but its inverse x^{1/3} is not differentiable at 0 = 0³, where (x³)′ = 0."
   - **Quick check:** "Let f(x) = x³ + 2x. Compute (f⁻¹)′(3)." *Solution:* f(1) = 3, f′(1) = 5, so 1/5. (f is strictly increasing: sum of two strictly increasing functions.)
   - **Quick check** (end of section): "True or false: if f is differentiable at c then |f| is differentiable at c." *Solution:* False: f(x) = x at c = 0. (True when f(c) ≠ 0: §9.1 B4 (c).)

### 4.2 Section 9.2: Local Extrema and the Mean Value Theorem (`02-mean-value-theorem.md`)

**Budget:** ≤ 5,000 (expected ~4,800). Five Quick checks, two warnings. The faded triple and the proof-ordering item are here.

1. **Opening** (~120): the derivative is a limit at one point; this section learns what it says about f on a whole interval. One theorem does the work, and its proof uses completeness once.
2. **`## The sign of the derivative at a point`** (~450).
   - **`prp-nonzero-derivative-local`** `[A Nonzero Derivative Moves the Function]`: f : I → ℝ, c ∈ I. If f′(c) > 0 (at an endpoint c of I, f′(c) is the one-sided derivative; the case f′(c) = +∞ of `def-one-sided-derivative` is included), there is δ > 0 with f(x) > f(c) for x ∈ I, c < x < c + δ, and f(x) < f(c) for x ∈ I, c − δ < x < c. Mirror statement for < 0. Proof: φ(c) > 0 and φ continuous at c give φ > 0 on I ∩ (c − δ, c + δ) (sign preservation); f(x) − f(c) = (x − c)φ(x) has the sign of x − c. Infinite case: the quotient exceeds 1 near c.
   - **Warning** `**Not "increasing near c".**` "The proposition compares f(x) with f(c) only, not f(x) with f(y). Section 9.3 gives a function with f′(0) > 0 that is increasing on no interval around 0." (In-chapter pointer, not forward across chapters.)
   - **`def-local-extremum`** `[Local Maximum and Minimum]`: S ⊆ ℝ (or a metric space; one sentence), f : S → ℝ, a ∈ S: local max if there is δ > 0 with f(x) ≤ f(a) for x ∈ S ∩ (a − δ, a + δ); local min likewise; strict with < for x ≠ a.
   - **`thm-fermat-interior-extremum`** `[Interior Extremum]`: f has a local extremum at an **interior** point c of I and f′(c) exists ⇒ f′(c) = 0. Proof: contrapositive of `prp-nonzero-derivative-local` (f′(c) > 0 puts larger values to the right and smaller to the left, inside I since c is interior).
   - **Quick check:** "Where does the proof use that c is interior? Give f on [0, 1] with a maximum at an endpoint where f′ ≠ 0." *Solution:* to have points of I on both sides; f(x) = x has its maximum at 1 with f′(1) = 1 (one-sided).
   - **Quick check:** "True or false: f′(c) = 0 implies a local extremum at c." *Solution:* False: x³ at 0.
3. **`## Rolle's theorem`** (~600).
   - **`thm-rolle`** `[Rolle]`: f continuous on [a, b], differentiable on (a, b), f(a) = f(b) ⇒ ∃ξ ∈ (a, b), f′(ξ) = 0.
   - **`[Scratch work]`** (≤ 15 lines). A horizontal tangent should sit at a highest or lowest point; `thm-fermat-interior-extremum` turns "highest point inside" into f′ = 0. Two things to secure: a highest point **exists** (the EVT, @thm-evt; this is the only place completeness enters) and it is **inside** (if both max and min are at the endpoints, they are equal and f is constant, so any ξ works).
   - **Proof** (~8 lines).
   - Aftermath (2 sentences): the theorem asks for continuity on the closed interval and differentiability only inside; |x| on [−1, 1] satisfies the first and fails the second, and its conclusion fails.
   - **`exm-mvt-fails-over-rationals`** `[Without completeness: derivative zero, not constant]` (pays (H2)). On Q ≔ ℚ ∩ [0, 2], let f(x) = 0 if x² < 2 and f(x) = 1 if x² > 2 (no rational has x² = 2, AN1.1). For c ∈ Q, c² ≠ 2, so there is δ > 0 with x² − 2 of the same sign as c² − 2 for all x ∈ Q with |x − c| < δ (sign preservation for the continuous x² − 2, restricted to Q; no √2 is named). So f is constant on that piece of Q, the quotient is 0 there, and f′(c) = 0 for every c ∈ Q. But f(0) = 0 ≠ 1 = f(2): "f′ = 0 ⇒ constant" fails, and so does the MVT below. The Rolle proof breaks at the EVT: on Q, the continuous x ↦ −(x² − 2)² has no maximum (its values are < 0 and come arbitrarily close to 0, so the supremum 0 is not attained). One paragraph: "Chapter 10 returns to this: over an ordered field, 'f′ = 0 on an interval forces f constant' is one more form of completeness." (In-volume pointer.)
   - **Quick check:** "Which line of the proof of @thm-rolle fails in @exm-mvt-fails-over-rationals's setting?" *Solution:* the existence of a maximum (EVT), which rests on the least upper bound axiom.
4. **`## The mean value theorems`** (~800).
   - **`thm-cauchy-mean-value`** `[Cauchy's Mean Value Theorem]`: f, g continuous on [a, b], differentiable on (a, b) ⇒ ∃ξ ∈ (a, b) with [f(b) − f(a)] g′(ξ) = [g(b) − g(a)] f′(ξ).
   - **`[Scratch work]`** (≤ 18 lines). Want to reduce to Rolle: build h from f and g with h(a) = h(b). Try h = f − λg and choose λ so that h(a) = h(b): λ = (f(b) − f(a))/(g(b) − g(a)), which needs g(b) ≠ g(a). Avoid the division by multiplying through: h(x) = [g(b) − g(a)] f(x) − [f(b) − f(a)] g(x). Check h(a) = g(b)f(a) − f(b)g(a) = h(b). Picture for g(x) = x: f minus its chord (Named move 2, tilt by the secant).
   - **Proof** (~6 lines).
   - **`thm-mean-value`** `[Mean Value Theorem]`: f continuous on [a, b], differentiable on (a, b) ⇒ ∃ξ ∈ (a, b), f(b) − f(a) = f′(ξ)(b − a). Proof: g(x) = x.
   - Geometric reading (2 sentences, figure: `::: {.figure}` a graph with chord and a parallel tangent; TikZ, the book's own curve).
   - **Quick check:** "Find all ξ in @thm-mean-value for f(x) = x³ on [−1, 2]." *Solution:* f(2) − f(−1) = 9 = 3ξ²·3 ⇒ ξ² = 1, ξ ∈ (−1, 2): ξ = 1 only (ξ = −1 is an endpoint).
5. **`## What the derivative says about the function`** (~1,100). The faded triple.
   - **`cor-zero-derivative-constant`** `[Zero Derivative]`: f differentiable on an interval I (one-sided at endpoints in I) with f′ = 0 ⇒ f constant. **Full support:** a two-line Scratch Work ("constant means f(x) = f(y) for all x, y; the MVT links f(y) − f(x) to f′"), then the proof: for x < y in I, MVT on [x, y] ⊆ I gives f(y) − f(x) = f′(ξ)(y − x) = 0. Consequence (one line): f′ = g′ on I ⇒ f − g constant.
   - **Warning** `**"Interval" matters.**` f = 0 on (0, 1) and 1 on (2, 3) has f′ = 0 and is not constant. (A1 (c) tests it.)
   - **`cor-monotone-from-derivative`** `[Monotonicity from the Derivative]`: f′ ≥ 0 on I ⇒ f increasing; f′ > 0 ⇒ strictly increasing; mirror for ≤, <. **Half support:** the proof is printed with two blanks, "For x < y in I, by ___ there is ξ ∈ (x, y) with f(y) − f(x) = ___ ≥ 0." followed by a **Quick check** asking for the blanks. *Solution:* the MVT; f′(ξ)(y − x). The converse direction (increasing ⇒ f′ ≥ 0) in one line: the quotients are ≥ 0, limits preserve ≥. Strictly increasing does **not** give f′ > 0 (x³).

### 4.3 Section 9.3: Derivatives and the Intermediate Value Property (`03-intermediate-values-of-derivatives.md`)

**Budget:** ≤ 5,000 (expected ~4,100). Four Quick checks, one warning, one Looking-ahead box.

1. **Opening** (~150): (H1) asks whether a derivative can jump. First, how badly can a derivative behave at all?
2. **The borrowed box** (unlabelled `::: {.remark}`, title `[What this chapter borrows about sine and cosine]`, ~130 words). 3. **`## A derivative that is not continuous`** (~650).
   - **`exm-derivative-discontinuous`** `[A discontinuous derivative]` (borrowed box): f(x) = x² sin(1/x) for x ≠ 0, f(0) = 0. (a) f′(0) = 0: |f(x)/x| ≤ |x|. (b) For x ≠ 0, f′(x) = 2x sin(1/x) − cos(1/x) (rules and (B1)). (c) f′ has no limit at 0: at x_k = 1/(2kπ), f′(x_k) = −1; at y_k = 1/((2k + 1)π), f′(y_k) = 1 (2x sin(1/x) → 0 in both). So f is differentiable on ℝ and f′ is discontinuous at 0, and the discontinuity is not a jump (Chapter 6's classification: neither one-sided limit exists).
   - **`exm-positive-derivative-not-monotone`** `[Positive at a point, increasing nowhere near it]` (borrowed box; pays the §9.2 warning): g(x) = x/2 + f(x), f as above. g′(0) = ½ > 0. g′(x) = ½ + 2x sin(1/x) − cos(1/x); at x_k = 1/(2kπ), g′(x_k) = ½ − 1 < 0, so by `cor-monotone-from-derivative` and continuity of g′ near x_k (x ≠ 0) g decreases on a small interval around each x_k; x_k → 0, so g is increasing on no interval around 0.
   - **Quick check:** "Does @exm-positive-derivative-not-monotone contradict @prp-nonzero-derivative-local?" *Solution:* No: the proposition gives g(x) > g(0) for small x > 0 and g(x) < g(0) for small x < 0, comparing with g(0) only.
4. **`## Darboux's theorem`** (~900).
   - **`thm-darboux`** `[Darboux: Derivatives Have the Intermediate Value Property]`: f differentiable on [a, b] (one-sided at a, b) and λ strictly between f′(a) and f′(b) ⇒ ∃ξ ∈ (a, b), f′(ξ) = λ.
   - **`[Scratch work]`** (≤ 18 lines). f′ need not be continuous, so the IVT cannot be applied to f′. Turn "f′ = λ" into "derivative = 0" by shearing: g(x) = f(x) − λx has g′ = f′ − λ, and g′(a) < 0 < g′(b) (case f′(a) < λ < f′(b)). Now find an interior extremum of g. g is continuous on [a, b] (`thm-differentiable-continuous`), so @thm-evt gives a minimum. Not at a: g′(a) < 0 means g(x) < g(a) just right of a (`prp-nonzero-derivative-local`, one-sided). Not at b: g′(b) > 0 means g(x) < g(b) just left of b. So the minimum is interior and `thm-fermat-interior-extremum` gives g′(ξ) = 0. Self-explanation prompt here (§1).
   - **Proof** (~10 lines). Other case by −f.
   - Aftermath (one sentence): Named move 4; the proof is Rolle's proof with the shear.
   - **`exm-step-no-antiderivative`** `[The step has no antiderivative]` (pays (H1)): if F′ = s on ℝ, then F′(−1) = 0, F′(1) = 1, and Darboux gives ξ with F′(ξ) = ½, but s takes only the values 0 and 1. The same argument: no derivative takes exactly two values on an interval.
   - **Quick check:** "f is differentiable on ℝ and f′(x) ∈ {−1, 1} for every x. What is f?" *Solution:* f′ is constant by Darboux, so f(x) = x + C or f(x) = −x + C (`cor-zero-derivative-constant` applied to f ∓ x).
5. **`## One-sided limits of a derivative`** (~800).
   - **`thm-derivative-limit`** `[Limits of the Derivative]`: f continuous on [c, c + δ), differentiable on (c, c + δ), and lim_{x→c⁺} f′(x) = L ∈ ℝ ⇒ f′₊(c) = L. Mirror on the left; at an interior point with both one-sided limits equal to L, f′(c) = L.
   - **`[Scratch work]`** (≤ 10 lines). The quotient (f(x) − f(c))/(x − c) is, by the MVT on [c, x], f′(ξ_x) with c < ξ_x < x. As x → c⁺, ξ_x is squeezed to c, so f′(ξ_x) → L. Formal: given ε, choose η with |f′(t) − L| < ε for c < t < c + η; then for c < x < c + η, ξ_x is also in (c, c + η). (Named move 5.)
   - **Proof** (~6 lines).
   - **`cor-derivative-discontinuities-essential`** `[A Derivative Has No Jumps]`: f differentiable on an interval I, c interior. If both one-sided limits of f′ at c exist (in ℝ), they equal f′(c), so f′ is continuous at c. Hence every discontinuity of a derivative is essential in Chapter 6's sense: at least one one-sided limit of f′ fails to exist. (Proof: `thm-derivative-limit` on each side; f is continuous by `thm-differentiable-continuous`.) One sentence: Darboux gives (H1) a second way; this corollary gives it a third (the step's one-sided limits exist and differ).
   - **Quick check:** "Can a derivative on (0, 2) equal ⌊x⌋?" *Solution:* No: ⌊x⌋ has one-sided limits 0 and 1 at 1 (a jump), forbidden by @cor-derivative-discontinuities-essential (or by Darboux).
6. **`## A nonvanishing derivative`** (~450).
   - **`cor-nonvanishing-derivative-monotone`** `[A Derivative That Never Vanishes]`: f differentiable on an interval I with f′(x) ≠ 0 for all x ⇒ f′ has one sign on I (Darboux: a sign change would force a zero), so f is strictly monotone (`cor-monotone-from-derivative`), and f⁻¹ : f(I) → I is differentiable with (f⁻¹)′(f(x)) = 1/f′(x) (`thm-inverse-derivative`).
   - One sentence: this is the one-variable inverse function theorem; its several-variable version is a chapter of *Analysis in Several Variables* (prose, not the section's Looking-ahead box).
7. **Looking ahead** (`::: {.remark}` `[Looking ahead]`, the section's one forward pointer): the nowhere-differentiable function, as in §1.

### 4.4 Section 9.4: Higher Derivatives, L'Hôpital's Rule and Taylor's Theorem (`04-taylor-and-lhospital.md`)

**Budget:** ≤ 5,000 (expected ~4,900). Five Quick checks, two warnings.

1. **`## How smooth is differentiable?`** (~500). Failure lead (`exm-x-abs-x` first, then the definition).

   - **`def-higher-derivative`** `[Higher Derivatives; the Classes Cⁿ]`: f″ ≔ (f′)′ where it exists, f^{(n+1)} ≔ (f^{(n)})′ (recursion, F2-volume), f^{(0)} ≔ f. f is n times differentiable on I if f^{(n)} exists on I; f ∈ Cⁿ(I) if moreover f^{(n)} is continuous; C^∞(I) ≔ ⋂ Cⁿ(I). 2. **`## L'Hôpital's rule`** (~1,300).
   - Lead: a limit of a quotient where both parts → 0 (Chapter 6's quotient law does not apply). Cauchy's MVT (§9.2) compares two functions' changes at one point ξ: exactly what a ratio needs.
   - **`thm-lhospital`** `[L'Hôpital's Rule]`: f, g differentiable on (a, b), g′(x) ≠ 0 on (a, b), and f′(x)/g′(x) → L ∈ ℝ as x → a⁺. If (i) f(x), g(x) → 0 as x → a⁺, or (ii) |g(x)| → ∞ as x → a⁺, then f(x)/g(x) → L as x → a⁺. Mirror at b⁻; two-sided at an interior point by combining. (L = ±∞: §9.4 C3; x → ∞: one sentence, substitute x = 1/t, left to C3 (b).)
   - **`[Scratch work]`** (≤ 22 lines). Case (i): extend f(a) = g(a) = 0; then f, g are continuous on [a, x], and Cauchy's MVT on [a, x] gives f(x)/g(x) = f′(ξ)/g′(ξ) with a < ξ < x (g(x) ≠ 0 by Rolle, since g(a) = 0 and g′ ≠ 0). Squeeze ξ (Named move 5). Case (ii): there is no value at a to anchor. Anchor instead at a point c close to a where f′/g′ is already within ε of L, and use Cauchy's MVT on [x, c]: (f(x) − f(c))/(g(x) − g(c)) = f′(ξ)/g′(ξ). Then unwrap: f(x)/g(x) = [(f(x) − f(c))/(g(x) − g(c))]·[1 − g(c)/g(x)] + f(c)/g(x), and as x → a⁺ with c **fixed**, g(c)/g(x) → 0 and f(c)/g(x) → 0. Self-explanation prompt ("why c is fixed before x moves").
   - **Proof** (~16 lines). Case (ii) with explicit ε-bookkeeping: choose c with |f′/g′ − L| < ε on (a, c); g(x) ≠ g(c) for x ∈ (a, c) by Rolle; then choose δ so that for a < x < a + δ, |g(c)/g(x)| < ε and |f(c)/g(x)| < ε; conclude |f(x)/g(x) − L| ≤ (|L| + ε)ε + ε + ε … give the clean bound (|L| + 3)ε for ε < 1.
   - **`exm-lhospital-roots`** `[A quotient of roots]`: lim_{x→1} (x^{1/3} − 1)/(x^{1/2} − 1) = 2/3: case (i) on each side of 1; f′/g′ = (⅓x^{−2/3})/(½x^{−1/2}) → 2/3 (`exm-root-derivative`); g′ ≠ 0 near 1. Check by algebra (one line, sidecar): with t = x^{1/6}, (t² − 1)/(t³ − 1) = (t + 1)/(t² + t + 1) → 2/3.
   - **`exm-lhospital-misuse`** `[When f′/g′ has no limit]` (borrowed box): f(x) = x² sin(1/x), g(x) = x as x → 0⁺: f/g = x sin(1/x) → 0, while f′/g′ = 2x sin(1/x) − cos(1/x) has no limit. The theorem is one-directional.

3. **`## Taylor's theorem`** (~1,500).
   - **`def-taylor-polynomial`** `[Taylor Polynomial]`: f n times differentiable at c (so f^{(n−1)} exists near c): T_{n,c}f(x) ≔ Σ_{k=0}^{n} f^{(k)}(c)(x − c)^k / k!. Fact (one line, computation): T_{n,c}f is the unique polynomial p of degree ≤ n with p^{(k)}(c) = f^{(k)}(c) for k ≤ n.
   - **Quick check:** "T_{3,1}f for f(x) = x⁴ − 2x." *Solution:* f(1) = −1, f′(1) = 2, f″(1) = 12, f‴(1) = 24: −1 + 2(x − 1) + 6(x − 1)² + 4(x − 1)³. (Check: expand (1 + h)⁴ − 2(1 + h) = −1 + 2h + 6h² + 4h³ + h⁴.)
   - **`thm-taylor-lagrange`** `[Taylor's Theorem with Lagrange Remainder]`: f : [a, b] → ℝ with f^{(n−1)} continuous on [a, b] and f^{(n)} existing on (a, b), n ≥ 1; α ≠ β in [a, b]. Then there is ξ strictly between α and β with f(β) = T_{n−1,α}f(β) + f^{(n)}(ξ)(β − α)ⁿ / n!. (n = 1 is the MVT.)
   - **`[Scratch work]`** (≤ 22 lines). The MVT is the case n = 1, proved by making two values agree and using Rolle once. Here: define M by f(β) = T_{n−1,α}f(β) + M(β − α)ⁿ (possible since β ≠ α), and g(t) ≔ f(t) − T_{n−1,α}f(t) − M(t − α)ⁿ. Then g(β) = 0, and g^{(k)}(α) = 0 for k = 0, …, n − 1 (the Taylor polynomial matches derivatives; (t − α)ⁿ has zero derivatives of order < n at α). Rolle on [α, β] gives ξ₁ with g′(ξ₁) = 0; g′(α) = 0, so Rolle on [α, ξ₁] gives ξ₂ with g″(ξ₂) = 0; … the Rolle ladder (Named move 6) reaches ξ_n with g^{(n)}(ξ_n) = 0. And g^{(n)} = f^{(n)} − n! M (the polynomial has degree n − 1). So M = f^{(n)}(ξ)/n!. Check the hypotheses at each rung: g^{(k)} continuous on the closed subinterval (k ≤ n − 1) and differentiable inside.
   - **Proof** (~12 lines), written for α < β; the case β < α is symmetric (one sentence).
   - **`exm-taylor-error-bound`** `[An error bound]`: f(x) = √(1 + x) on [0, 0.1]; T_{2,0}f(x) = 1 + x/2 − x²/8; f‴(x) = (3/8)(1 + x)^{−5/2} ≤ 3/8 for x ≥ 0 (B3 of §9.1 and the chain rule); so |f(x) − T_{2,0}f(x)| ≤ (3/8)(0.1)³/6 = 1/16000 for 0 ≤ x ≤ 0.1. At x = 0.1: 1.04875 approximates √1.1 = 1.0488088…, error ≈ 0.0000588 < 0.0000625. Sign: f‴ > 0, so T underestimates.
   - **`thm-taylor-peano`** `[Taylor's Theorem, Peano Form]` (Pugh's breadth): if f^{(n)}(c) exists (n ≥ 1), then (f(x) − T_{n,c}f(x))/(x − c)ⁿ → 0 as x → c. Idea + proof (~10 lines): R(x) ≔ f(x) − T_{n,c}f(x) has R^{(k)}(c) = 0 for k ≤ n, and R^{(n−1)} exists on an interval around c. Apply `thm-lhospital` case (i) n − 1 times to R(x)/(x − c)ⁿ (each time numerator and denominator → 0, and the denominator's derivative (x − c)^{n−k} times a constant ≠ 0 for x ≠ c), reaching R^{(n−1)}(x)/(n!(x − c)), which → R^{(n)}(c)/n! = 0 by the definition of R^{(n)}(c) (R^{(n−1)}(c) = 0). (The application runs backwards: L'Hôpital's hypothesis is that the **last** quotient has a limit; write it in the right order.) Aftermath: only f^{(n)}(c) is needed, not f^{(n)} near c; the price is that there is no bound, only o((x − c)ⁿ).
   - **`cor-second-derivative-test`** `[Second Derivative Test]`: f′ exists on an interval around c, f′(c) = 0 and f″(c) > 0 ⇒ f has a strict local minimum at c (mirror for < 0). Proof: `prp-nonzero-derivative-local` applied to f′ at c: f′(x) < 0 just left of c and > 0 just right; `cor-monotone-from-derivative` on each side. (No continuity of f″ needed.)

3. **`## The mean value inequality`** (~800).
   - **`thm-vector-mean-value-inequality`** `[Mean Value Inequality]`: f : [a, b] → ℝⁿ continuous, differentiable on (a, b) ⇒ there is ξ ∈ (a, b) with ‖f(b) − f(a)‖ ≤ (b − a)‖f′(ξ)‖. In particular ‖f′‖ ≤ M on (a, b) ⇒ ‖f(b) − f(a)‖ ≤ M(b − a).
   - **`[Scratch work]`** (≤ 14 lines). The MVT needs a real-valued function. Which real number measures f(b) − f(a)? Its length, which is its dot product with its own unit direction.    - **Proof** (~6 lines).
   - **Quick check:** "Why does the proof not give equality?" *Solution:* Cauchy–Schwarz is an equality only when f′(ξ) is parallel to z; @exm-mvt-fails-vector shows equality can fail (z = 0, f′(ξ) ≠ 0).

4. **`## Partial derivatives`** (~1,100).
   - Lead: for f of two variables, freeze one and differentiate in the other.
   - **`def-partial-derivative`** `[Partial Derivative]`: S ⊆ ℝⁿ open (Chapter 2), f : S → ℝ, c ∈ S, e_k the k-th unit vector (F4.8).    - **Quick check:** "D₁f(1, 2) and D₂f(1, 2) for the f of @exm-partials-computed." *Solution:* 4 and 13.
   - **`exm-partials-not-continuous`** `[Both partials, no continuity]` (the failure that motivates AN3.1's definition): f(x, y) = 1 if y = x² and x ≠ 0, and 0 otherwise. ### 4.6 Section 9.6: The Complex Derivative and the Cauchy–Riemann Equations (`06-complex-derivative.md`)

**Budget:** ≤ 5,000 (expected ~4,300 main line), plus the List of Results and the strange-functions table (reference matter). Four Quick checks, one warning, R items.

1. **Opening** (~180): ℂ = ℝ² with a multiplication (@fd4:def-complex-numbers) and modulus (@fd4:def-conjugate-modulus); limits and continuity in ℂ are those of the metric space ℝ² (Chapters 3 and 6). A function f : S → ℂ on S ⊆ ℂ is a map ℝ² → ℝ²; but because ℂ is a field, its difference quotient makes sense, which ℝ² alone does not provide. The one-sentence remark on ℝ³ (§1).
2. **`## The definition, and what carries over`** (~800).
   - **`def-complex-derivative`** `[Complex Derivative]`: S ⊆ ℂ open, f : S → ℂ, c ∈ S: f′(c) ≔ lim_{z→c} (f(z) − f(c))/(z − c) when it exists in ℂ (limit in the metric of ℂ, z ∈ S ∖ {c}).
   - **`prp-complex-derivative-rules`** `[What Carries Over]`: (a) the factorization `thm-caratheodory-derivative` (φ : S → ℂ continuous at c); (b) differentiable ⇒ continuous; (c) sum, product, quotient; (d) chain rule (f differentiable at c, g at f(c), g defined on an open set containing f(S)). Proof: "the proofs of §9.1, word for word, with |·| the modulus." Quick check below asks why. (e) (zⁿ)′ = nz^{n−1} for n ∈ ℤ (z ≠ 0 if n < 0); polynomials and rational functions are differentiable on their domains.
   - **Quick check:** "The proofs of §9.1's rules used three facts about |·| and the operations. Which?" *Solution:* field operations (including division by nonzero numbers), the triangle inequality (@fd4:thm-complex-triangle-inequality), and |zw| = |z||w|; all hold in ℂ. (Not used: the order of ℝ. That is why Rolle and the MVT do **not** carry over: next warning.)
   - **Warning** `**No mean value theorem in ℂ.**` "Rolle's theorem and the MVT used maxima, which need the order of ℝ. A complex-differentiable function can return to its starting value along a segment with a derivative that never vanishes; *Complex Analysis* gives examples once exp is available. What survives is an inequality, as in Section 9.5." (In-chapter back-pointer; the CA mention is prose, not the section's Looking-ahead box; there is none in §9.6.)
3. **`## Two functions that are not complex-differentiable`** (~700). Pays (H3).
   - **`exm-conjugate-nowhere-differentiable`** `[Conjugation]`: f(z) = z̄. At any c, the quotient is h̄/h with h = z − c. For h = t real, it is 1; for h = it, it is −1. Two paths, two limits (Named move 8): no derivative anywhere. Yet z̄ is an isometry (|z̄ − w̄| = |z − w|) and, as a map ℝ² → ℝ², it is linear.
   - **`exm-modulus-squared-one-point`** `[Differentiable at one point]`: f(z) = |z|² = z z̄. Quotient at c: (|c + h|² − |c|²)/h = c̄ + c·(h̄/h) + h̄. At c = 0 it is h̄ → 0: f′(0) = 0. At c ≠ 0, c·(h̄/h) takes the values c and −c along the two paths, so no limit.
   - **Quick check:** "Is f(z) = Re z differentiable anywhere?" *Solution:* No: the quotient Re h / h is 1 for real h and 0 for imaginary h.
4. **`## The Cauchy–Riemann equations`** (~1,400).
   - Notation: f = u + iv with u, v : S → ℝ, viewed as functions of (x, y) where z = x + iy; u_x ≔ D₁u, u_y ≔ D₂u (§9.5).
   - **`thm-cauchy-riemann`** `[Cauchy–Riemann Equations]`: if f′(c) exists, then the four partials of u, v at c exist and f′(c) = u_x(c) + i v_x(c) = v_y(c) − i u_y(c); in particular u_x = v_y and u_y = −v_x at c (`eq-cauchy-riemann`).
   - **`[Scratch work]`** (≤ 15 lines). A limit as h → 0 in ℂ that exists is also the limit along any path (restriction of a limit, Chapter 6). Take h = t real: (f(c + t) − f(c))/t → f′(c); its real and imaginary parts are the difference quotients of u and v in x, and |Re w| ≤ |w|, |Im w| ≤ |w| pass limits to parts. So u_x = Re f′(c), v_x = Im f′(c). Take h = it: (f(c + it) − f(c))/(it) → f′(c), so (f(c + it) − f(c))/t → i f′(c); real part u_y = Re(i f′(c)) = −Im f′(c), imaginary part v_y = Im(i f′(c)) = Re f′(c). Compare.
   - **Proof** (~8 lines).
   - **`exm-cauchy-riemann-check`** `[Checking the equations]`: z²: u = x² − y², v = 2xy: u_x = 2x = v_y, u_y = −2y = −v_x, and f′ = 2x + 2iy = 2z. |z|²: u = x² + y², v = 0: the equations hold only at 0, matching `exm-modulus-squared-one-point`. z̄: u = x, v = −y: u_x = 1 ≠ −1 = v_y anywhere, matching `exm-conjugate-nowhere-differentiable`.
   - **`thm-cauchy-riemann-sufficient`** `[A Sufficient Condition]`: u, v have first partial derivatives on an open disk around c, continuous at c, and satisfying `eq-cauchy-riemann` at c ⇒ f′(c) exists and equals u_x(c) + i v_x(c).
   - **`[Scratch work]`** (≤ 22 lines). Write h = s + it, c = a + ib. Move horizontally, then vertically (Named move 9): u(a + s, b + t) − u(a, b) = [u(a + s, b + t) − u(a, b + t)] + [u(a, b + t) − u(a, b)]. Each bracket is a one-variable change: the MVT (the partials exist along the segments, which lie in the disk) gives s·u_x(a + σ, b + t) + t·u_y(a, b + τ) with σ between 0 and s, τ between 0 and t. Continuity of u_x, u_y at c: = s u_x(c) + t u_y(c) + s ε₁ + t ε₂, ε₁, ε₂ → 0 as h → 0. Same for v with ε₃, ε₄. Then f(c + h) − f(c) = s(u_x + i v_x) + t(u_y + i v_y) + E, and Cauchy–Riemann give u_y + i v_y = −v_x + i u_x = i(u_x + i v_x). So f(c + h) − f(c) = (s + it)(u_x + i v_x) + E, and |E|/|h| ≤ |ε₁| + |ε₂| + |ε₃| + |ε₄| → 0 since |s|, |t| ≤ |h|. Self-explanation prompt.
   - **Proof** (~14 lines). One sentence after it: without continuity of the partials the converse of `thm-cauchy-riemann` fails (A1 (d)).
   - **Quick check:** "Where is f(z) = x² + iy² complex-differentiable?" *Solution:* u_x = 2x, v_y = 2y, u_y = 0 = −v_x: the equations hold exactly on the line y = x; the partials are continuous everywhere, so `thm-cauchy-riemann-sufficient` gives f′ = 2x there, and `thm-cauchy-riemann` rules out every other point.
5. **`## When the derivative vanishes`** (~650).
   - **`thm-constant-on-disk`** `[Constant on a Disk]`: f complex-differentiable on an open disk D. If f′ = 0 on D, or Re f is constant on D, or Im f is constant on D, then f is constant on D.
   - Idea (no Scratch Work: the technique is the previous one; back-reference): f′ = 0 gives u_x = u_y = v_x = v_y = 0 by `thm-cauchy-riemann`. From the centre (a, b) of D to (x, y) ∈ D, go horizontally to (x, b) and vertically to (x, y): both segments lie in D (each point on them is no farther from the centre than (x, y): |x′ − a| ≤ |x − a| and |(x, y′) − (a, b)| ≤ |(x, y) − (a, b)|), and the one-variable `cor-zero-derivative-constant` on each gives u(x, y) = u(a, b); likewise v. If u is constant, u_x = u_y = 0, so v_x = v_y = 0 by `eq-cauchy-riemann`, so f′ = u_x + i v_x = 0. Same for v.

**Exercises (9.6).**
- **A1.** (a) f′(i) for f(z) = z³ − 2iz. (b) u, v for z², and check `eq-cauchy-riemann`. (c) Is Re z differentiable anywhere? (d) True or false: if the partials of u, v exist at c and satisfy `eq-cauchy-riemann` there, then f′(c) exists.
  - *Solution:* (a) 3i² − 2i = −3 − 2i. (b) `exm-cauchy-riemann-check`. (c) No (Quick check). (d) False: f(x + iy) = √|xy| (u = √|xy|, v = 0). u(t, 0) = u(0, t) = 0, so all four partials at 0 are 0 and the equations hold. But along h = t(1 + i), t > 0, the quotient is |t|/(t(1 + i)) = 1/(1 + i), and along h = t real it is 0: no derivative.
- **B1** `[B1: A line of differentiability]`. Where is f(z) = x² + i y² differentiable, and what is f′ there? (The §9.6 Quick check written out in full, both directions.)
  - *Solution:* as in the Quick check; f′(x + ix) = 2x.
- **B2** `[B2: Constant modulus]`. f differentiable on an open disk D with |f| constant ⇒ f constant.
  - *Hints:* none (B item); the problem says: "If |f|² = k > 0, express f̄ through f."
  - *Solution:* If k = 0, f = 0. If k > 0, f ≠ 0 on D and f̄ = k/f is complex-differentiable on D (`prp-complex-derivative-rules` (c)). Then Re f = (f + f̄)/2 is complex-differentiable and real-valued, so its imaginary part 0 is constant and `thm-constant-on-disk` makes Re f constant; then again `thm-constant-on-disk` (Re f constant) makes f constant.
- **B3** `[B3: 1/z by the equations]`. Verify `eq-cauchy-riemann` for f(z) = 1/z on ℂ ∖ {0}, and check that u_x + i v_x = −1/z².
  - *Solution:* u = x/(x² + y²), v = −y/(x² + y²). u_x = (y² − x²)/(x² + y²)², v_y = (y² − x²)/(x² + y²)²; u_y = −2xy/(x² + y²)², v_x = 2xy/(x² + y²)². u_x + i v_x = (y² − x² + 2ixy)/|z|⁴ = −(x − iy)²/|z|⁴ = −z̄²/(z z̄)² = −1/z².
- **B4** `[B4: Prove or disprove]`. (a) f complex-differentiable at c ⇒ u, v have partials at c. (b) f complex-differentiable on ℂ and real-valued ⇒ f constant. (c) |z| is complex-differentiable at 0. (d) z ↦ z̄² is complex-differentiable exactly at 0. (e) If f is complex-differentiable on ℂ, then so is z ↦ conj(f(z̄)).
  - *Solution:* (a) True: `thm-cauchy-riemann`. (b) True: `thm-constant-on-disk` (Im f = 0) on every disk centred at 0, which exhaust ℂ. (c) False: |h|/h is 1 for h > 0 and −1 for h < 0. (d) True: at 0, |z̄²/z| = |z| → 0; elsewhere u = x² − y², v = −2xy give u_x = 2x, v_y = −2x, u_y = −2y, −v_x = 2y, so the equations need x = y = 0. (e) True: with g(z) = conj(f(z̄)), (g(z) − g(c))/(z − c) = conj[(f(z̄) − f(c̄))/(z̄ − c̄)] → conj f′(c̄) (conjugation is continuous, z̄ → c̄).
- **C1** `[C1: A rigid relation]`. f = u + iv complex-differentiable on an open disk D with u = v² on D. Show f is constant.
  - *Hints:* 1. "Differentiate u = v² in x and in y, and substitute `eq-cauchy-riemann`." 2. "You should reach v_x(1 + 4v²) = 0."
  - *Solution:* u_x = 2v v_x, u_y = 2v v_y. Cauchy–Riemann: v_y = u_x = 2v v_x and −v_x = u_y = 2v v_y = 4v² v_x. So v_x(1 + 4v²) = 0, v_x = 0, then v_y = 0, so v is constant (`thm-constant-on-disk`'s path argument, or the theorem with Im f constant), and f is constant.
  - *Marking scheme* (8): differentiating the relation 2; substitution 2; v_x = 0 and v_y = 0 2; conclusion citing the theorem 2.
- **C2** `[C2: The Jacobian is |f′|²]`. If f′(c) exists, prove u_x v_y − u_y v_x = |f′(c)|² at c. Interpret: a complex-differentiable map with f′(c) ≠ 0 does not collapse area to first order near c (prose; area is not defined in this volume).
  - *Solution:* by `eq-cauchy-riemann`, u_x v_y − u_y v_x = u_x² + v_x² = |u_x + i v_x|² = |f′(c)|².
- **R1** `[R1]`. f(x) = x³ − 3x + 1. (a) f has exactly three real roots. (b) Classify the critical points.
  - *Solution:* (a) f(−2) = −1, f(0) = 1, f(1) = −1, f(2) = 3: three sign changes, three roots by ⟨IVT⟩. Four roots would give three zeros of f′ = 3x² − 3 by Rolle; it has two. (b) f′ = 0 at ±1; f″ = 6x: strict local max at −1, strict local min at 1 (`cor-second-derivative-test`).
- **R2** `[R2: Three theorems over ℚ]`. For each, show it fails for functions ℚ ∩ [a, b] → ℚ (with derivatives defined by the same limit within ℚ): (a) Rolle, for f(x) = x³ − 7x on [1, 2]; (b) the MVT, for x³ on [0, 1]; (c) "f′ = 0 ⇒ f constant".
  - *Solution:* (a) f(1) = −6 = f(2) (x³ − 7x + 6 = (x − 1)(x − 2)(x + 3)); f′(x) = 3x² − 7 = 0 needs x² = 7/3, not a rational square (if (p/q)² = 7/3 in lowest terms, 3p² = 7q², so 3 | q and then 3 | p). (b) §9.2 C1 (d). (c) `exm-mvt-fails-over-rationals`.
- **R3** `[R3]`. Find all differentiable f : ℝ → ℝ with f′(x) = 2x for all x and f(1) = 5.
  - *Solution:* (f − x²)′ = 0, so f − x² = C (`cor-zero-derivative-constant`); C = 4; f(x) = x² + 4.
- **R4** `[R4]`. Find all f complex-differentiable on ℂ with Re f(x + iy) = x² − y² + 3x.
  - *Solution:* `eq-cauchy-riemann`: v_y = u_x = 2x + 3, v_x = −u_y = 2y. The function w ≔ v − (2xy + 3y) has w_x = w_y = 0, so it is constant (`thm-constant-on-disk`'s path argument on disks centred at 0, which exhaust ℂ). So v = 2xy + 3y + C, C ∈ ℝ, and f(z) = z² + 3z + iC. Check: each such f is differentiable, with the right real part.
