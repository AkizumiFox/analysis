# Blueprint: AN1.1 — Ordered Fields and the Least Upper Bound Axiom

**Directory:** `an1/src/ch01-least-upper-bound/`. **Part I, chapter 1**, main line. **Pilot chapter**: once the author approves it, it becomes the exemplar for all Part I–VI chapters (`authoring/STATUS.md`). It is written to the full standard of `authoring/STYLE.md`, including §10. The node specification is in `authoring/design/curriculum.md`, "The least upper bound axiom node", and it is binding.

**Purpose.**
- Every theorem of calculus that "obviously" holds (the IVT, the EVT, the MVT, the convergence of a bounded monotone sequence) is **false over ℚ**. The one property that separates ℝ from ℚ is that bounded sets have least upper bounds.
- This chapter states that property as an axiom and learns to use it. The main tool is the **ε-characterization of the supremum**. It derives the first consequences: Archimedes, density of ℚ, existence of roots, nested intervals, and the uncountability of ℝ.
- It does not construct ℝ. That is the optional F3.3 (Dedekind cuts), at the end of Part I, and the index and the axiom's aftermath point to it **in prose only**.
- It does not prove that the forms of completeness are equivalent. That is the last main-line chapter of Part I.

**Signature moves** (in `index.md`, "Named moves"; these are skill nodes reused in the IVT, Heine–Borel and the rest of Part I):
- **Sup approximation.** "sup A − ε is not an upper bound, so some a ∈ A exceeds it." With ε = 1/n this gives aₙ ∈ A with aₙ > sup A − 1/n.
- **Equality of sups by two inequalities.** Prove ≤, then prove ≥ with an ε.
- **Construct a point as a sup.** Define the set of points where "things are still fine", take its supremum, and rule out each way it could fail. √2 is the first instance.
- **Split sup into its two properties** (kwok-proof `ana.md` H24): it is an upper bound, and it is the least one.

## index.md

- **Story.** In ℚ, the numbers whose square is less than 2 have no least upper bound. There is a gap where √2 should be.
  - Calculus lives on that gap. The IVT fails for x² − 2 on [1, 2] over ℚ, and the bounded increasing sequence 1, 1.4, 1.41, … has no rational limit. Show both.
  - One axiom closes every gap at once. This chapter states it and learns to use it.
  - Two things are said in prose. First, the axiom can be *proved* by building ℝ; the optional F3.3 does so. Second, the chapter at the end of Part I shows that several other "no gaps" properties are equivalent to it.
- **What you need:** F1.1 (proof by cases) and F1.2 (in particular the irrationality of √2, negation, the contrapositive), and from F1.4–F2.3: quantifiers and their negation, sets and images, induction and well-ordering.
- **Roadmap.**
- **Named moves:** the four above.

## 01-ordered-fields.md — Ordered fields, and the gap in ℚ

- **Hook.** Over ℚ, x² − 2 changes sign on [1, 2] but has no zero. That is `thm-sqrt2-irrational`, cited from F1.2. Whatever ℝ is, it must be "ℚ with no gaps". First we say what ℚ and ℝ share.
- **Ordered field** (`def-ordered-field`), with the axioms in a labelled list:
  - field axioms (F1)–(F9), compactly;
  - order axioms: trichotomy, transitivity, a < b ⇒ a + c < b + c, and a, b > 0 ⇒ ab > 0.
  - Examples: ℚ and ℝ. Non-examples by minimal change: ℂ admits no order compatible with the field operations (i² = −1 < 0 is impossible); ℤ is not a field.
- **Consequences** (`thm-ordered-field-rules`), proved from the axioms, with 4–6 representative items proved and the rest as exercises:
  - 0 < 1;
  - x² ≥ 0;
  - a < b and c > 0 ⇒ ac < bc;
  - a < b and c < 0 ⇒ ac > bc;
  - 0 < a < b ⇒ 0 < 1/b < 1/a.
  F1.1 and F1.2 took these as school algebra. Say that they now follow from the axioms, so nothing earlier was circular.
- **Absolute value** (`def-absolute-value`) and `thm-triangle-inequality`, with the reverse triangle inequality.
  - F1.1 proved it by cases. Here it is re-proved from −|x| ≤ x ≤ |x|, which is shorter and no longer needs case analysis.
  - **|x − a| < r ⇔ a − r < x < a + r**: this is the move AN1.2 lives on, so give it its own display.
- **Warning.** The order axioms are about < with a strict inequality. A careless "a ≤ b and c ≤ d ⇒ ac ≤ bd" is false: take negative numbers.
- **Check.** Is the set {0, 1} with arithmetic mod 2 orderable? No: 1 + 1 = 0 would force 0 > 0.
- **Exercises.**
  - **A:** which axiom justifies each step.
  - **B:**
    - prove three of the remaining items of `thm-ordered-field-rules`;
    - prove ||x| − |y|| ≤ |x − y|;
    - solve |2x − 3| < 5.
  - **C:** show there is no order on the field of 3 elements. Then show that in any ordered field 1 + 1 + ⋯ + 1 (n times) > 0, so an ordered field contains a copy of ℕ. Mark that as a bridge to §05.

## 02-suprema.md — Upper bounds, maxima and suprema

- **Hook: a naive notion that fails.** Look for the "largest element" of {x ∈ ℚ : x² < 2}, or of (0, 1). There is none. Yet there is something the set "reaches toward".
- **Definitions**, each its own def node: `def-upper-bound`, `def-bounded-above` (and below, and bounded), `def-maximum`, `def-supremum` (a least upper bound), `def-infimum`.
  - Follow the full explain template for **supremum**, which is a major notion.
  - **Slogan:** *the supremum is the upper bound that cannot be lowered.*
  - Give the definition in symbols as well (`STYLE.md` §10): s is an upper bound, and for every upper bound M, s ≤ M.
- **Uniqueness** (`thm-sup-unique`): two suprema are each ≤ the other (H28). Only now may we write "*the* supremum".
- **Examples:**
  - finite sets, where sup = max;
  - (0, 1], where sup = max = 1;
  - (0, 1), where sup = 1 ∉ A;
  - {1 − 1/n : n ∈ ℕ}, where sup = 1 is *proved* by ε. The proof needs Archimedes. **Order problem:** Archimedes is §05. Either prove this example only after §05, as an exercise there, or state it here with "we will prove this in §05" and give the proof there. Prefer the latter: prove it in §05's examples.
  - A degenerate case: the empty set. Every real number is an upper bound, and there is no least one.
- **In ℚ:** `thm-no-rational-sup-sqrt2`. The set {x ∈ ℚ : x > 0, x² < 2} has no supremum in ℚ.
  - *Idea:* for any rational candidate s, either s² < 2 and a slightly larger rational is still in the set, or s² > 2 and a slightly smaller rational is still an upper bound.
  - Give an explicit rational h in each case, with the arithmetic in the ordered field. Verify it with sympy privately.
  - This is also the template for §06.
- **Warning: sup is not max.** The misconception that the supremum belongs to the set, with (0, 1) as the witness. A second warning: "every bounded set has a maximum" fails for the same witness.
- **Check.** Find sup and max, if they exist, of {(−1)ⁿ/n : n ∈ ℕ}.
- **Exercises.**
  - **A:** sup, inf, max and min of five sets, or "does not exist".
  - **B:** prove that if a set has a maximum, the maximum is its supremum; negate "s is an upper bound of A" in symbols.
  - **C:** a set A ⊆ ℚ with a supremum in ℝ that is rational but not in A, and another whose supremum is irrational. Here "supremum in ℝ" is informal; phrase the exercise so it does not need the axiom.

## 03-the-axiom.md — The least upper bound axiom

- **The axiom** (`ax-least-upper-bound`): every **non-empty** subset of ℝ that is **bounded above** has a supremum in ℝ.
  - State the standing assumption: ℝ is an ordered field satisfying this axiom. Explain why each hypothesis is there: ∅ has none, and ℕ has none (proved in §05).
  - **Remark (prose only):** this axiom is a theorem once ℝ is constructed (optional F3.3), and any two fields satisfying it are the same up to relabelling (optional F3.4). The rest of the book needs only the axiom.
- **Infima come free** (`thm-greatest-lower-bound`, `thm-inf-neg-sup`): inf A = −sup(−A).
  - Define −A as a set-builder set, and prove it as two properties.
  - Alternatively, take the supremum of the set of lower bounds. Mention this in one "Alternatively," paragraph.
- **Conventions, flagged.** sup A = +∞ for a set not bounded above, and sup ∅ = −∞. Use them only as notation when a sentence needs them, and say that Part IV relies on them. They are not numbers.
- **Warning: forgetting "non-empty"**, with ∅ as the witness. Also: the axiom asserts existence, and gives no formula.
- **Check.** Does ℤ ∩ (−∞, 3.5] have a supremum? Is it a maximum?
- **Exercises.**
  - **A:** which hypothesis of the axiom fails for each of four sets.
  - **B:** prove inf A = −sup(−A) in full; prove that sup and inf of a bounded non-empty A satisfy inf A ≤ sup A, with equality iff A is a singleton.
  - **C:** show that the axiom fails in ℚ. Is `thm-no-rational-sup-sqrt2` exactly the witness? Then show that the "greatest lower bound axiom" implies the least upper bound axiom in any ordered field, which is the converse of this section.

## 04-epsilon-characterization.md — Working with the supremum

- **Lead-in.** The definition of supremum quantifies over all upper bounds, which is unusable in practice. There is a version with ε that is.
- **`thm-sup-epsilon`.** Let s be an upper bound of A. Then s = sup A if and only if for every ε > 0 there is a ∈ A with a > s − ε.
  - Prove both directions in the typeset register.
  - The Idea explains the picture: the band (s − ε, s] always meets A.
  - Mark with one clause that the a found **depends on ε** (curriculum misconception).
- **`cor-sup-approximation`.** For each n ∈ ℕ there is aₙ ∈ A with sup A − 1/n < aₙ ≤ sup A. Say that this uses a choice for each n; the flag is one clause (`STYLE.md` §10).
- **Algebra of sup:**
  - `thm-sup-monotone`: A ⊆ B ⇒ sup A ≤ sup B;
  - `thm-sup-scaling`: sup(cA) = c sup A for c > 0, and the c < 0 case turns sup into inf;
  - `thm-sup-sum`: sup(A + B) = sup A + sup B.
  - For `thm-sup-sum`, name the move **equality by two inequalities**. The ≥ half uses ε/2 for each set: this is the first ε/2 argument in the book, so name it.
- **Warning: proving one inequality only.** Show a "proof" of sup(A + B) = sup A + sup B that shows only ≤ and stops. Name what is missing.
- **Quick check** (quantifier swap, `STYLE.md` §10): "for every ε > 0 there is a ∈ A with a > s − ε" versus "there is a ∈ A with a > s − ε for every ε > 0". What does the second say, and when is it true? Answer: exactly when s ∈ A, that is, when s is a maximum.
- **Exercises.**
  - **A:** use the ε-characterization to confirm three suprema.
  - **B:**
    - sup{x² : x ∈ (−1, 2)} = 4;
    - sup(A ∪ B) = max(sup A, sup B);
    - sup{a − b : a ∈ A, b ∈ B} = sup A − inf B.
  - **C:**
    - is sup(AB) = sup A · sup B for sets of positive numbers? Prove it, or refute it and repair it;
    - **exit check:** prove sup(A + B) = sup A + sup B in full;
    - **verification exercise:** a flawed proof that silently assumes sup A ∈ A (it picks "a = sup A ∈ A"). Find the line and give a set on which it fails.

## 05-archimedean-property.md — The natural numbers inside ℝ

- **ℕ inside ℝ.**
  - `def-inductive-set`: S ⊆ ℝ is inductive if 1 ∈ S and x ∈ S ⇒ x + 1 ∈ S.
  - ℕ is the intersection of all inductive subsets. State this as a remark connecting it to the ℕ of Part 0 by prose pointer (F2.2). Induction on ℕ is then exactly the statement that ℕ is the smallest inductive set.
  - Keep it to one short subsection. ℤ and ℚ inside ℝ are then the usual ones.
- **`thm-naturals-unbounded` (the Archimedean property)**, proved by contradiction via s = sup ℕ: s − 1 is not an upper bound, so n > s − 1 for some n, and then n + 1 > s.
  - Say that this is ¬I, not RAA, and point back to F1.2's `def-rule-raa`, which carries that distinction.
  - `cor-archimedean-epsilon`: for every ε > 0 there is n with 1/n < ε. Show the quantifier order in symbols, and say that n depends on ε.
- **Now pay the §02 debt:** sup{1 − 1/n} = 1, proved by ε.
- **`exm-nonarchimedean-field`: ℝ(x) with the order "p/q > 0 iff the leading coefficients have the same sign".**
  - The element x is larger than every natural number, so ℕ is bounded, and the Archimedean property fails.
  - Point out **the line of the Archimedes proof that fails**: sup ℕ does not exist in ℝ(x), because the LUB axiom fails there.
  - Keep the verification that this is an ordered field brief, with the details as an exercise.
- **Warning.** Archimedes is not "obvious". It is exactly the property ℝ(x) lacks, and ℝ has it only because of the axiom.
- **Check.** Find n with 1/n < 0.003; then say what n does for ε = 0.0003.
- **Exercises.**
  - **A:** negate the Archimedean property in symbols.
  - **B:**
    - inf{1/n : n ∈ ℕ} = 0;
    - for x > 0 and y ∈ ℝ, some n has nx > y;
    - if 0 ≤ x < 1/n for every n, then x = 0 (used constantly later).
  - **C:**
    - **exit check:** Archimedes from the axiom, and the line where the proof fails in ℝ(x);
    - prove that ℝ(x) is an ordered field, with at least the transitivity and product axioms checked.

## 06-density-and-roots.md — Density of ℚ and the existence of roots

- **`thm-rationals-dense`: between any two reals there is a rational.**
  - *Idea:* with the picture of a ruler of step 1/n, choose n with 1/n < y − x (Archimedes), then choose the least integer m with m/n > x.
  - Well-ordering is used here, with a prose pointer to F2.2. The subtle step is that such an m exists and is the least one; justify it with Archimedes and well-ordering.
  - `cor-irrationals-dense`: apply it to x − √2 and y − √2. This needs √2, so order the section √2-first, or prove the corollary after `thm-sqrt2-exists`. **Prefer √2 first:** put `thm-sqrt2-exists` as the section's first theorem, since it is the template.
- **`thm-sqrt2-exists`: construct a point as a sup.**
  - s = sup{x > 0 : x² < 2}. Rule out s² < 2 and s² > 2, reusing the explicit h of `thm-no-rational-sup-sqrt2`. The difference from §02 is that s now exists, by the axiom.
  - Name the move. Say that the IVT (AN1.6) and Heine–Borel (AN1.4) are proved the same way, as a prose forward pointer.
- **`thm-nth-root`:** every a > 0 has a unique positive n-th root.
  - Use the same template with the estimate (s + h)ⁿ ≤ sⁿ + h·C for 0 < h < 1. The Idea derives C backwards (`ana.md` H17, G2), and the proof places it first.
- **Warning.** Density does not mean "next to": there is no smallest rational greater than 0. Give the witness: if q > 0, then q/2 is smaller.
- **Check.** Name a rational between √2 and 1.415, and an irrational between 0 and 10⁻⁶.
- **Exercises.**
  - **A:** true or false with reasons: there is a least positive irrational; between two rationals lies an irrational.
  - **B:**
    - every real number is a supremum of rationals: x = sup{q ∈ ℚ : q < x};
    - √3 exists;
    - the cube root of 5 exists (from `thm-nth-root`).
  - **C:**
    - **exit check:** existence of √2 together with the non-existence of a rational supremum;
    - show that the set of dyadic rationals m/2ᵏ is dense.

## 07-nested-intervals.md — Nested intervals, and why ℝ is uncountable

- **`thm-nested-intervals`.** If [a₁, b₁] ⊇ [a₂, b₂] ⊇ ⋯, the intersection is non-empty. It is a single point if bₙ − aₙ can be made smaller than every ε > 0.
  - *Idea:* the left endpoints are bounded above by every right endpoint. Take their sup, which lies below every bₙ.
  - **Counterexamples for each hypothesis** (`STYLE.md` §10):
    - open intervals (0, 1/n) have empty intersection;
    - unbounded closed intervals [n, ∞) have empty intersection;
    - over ℚ, rational intervals shrinking to √2 have empty intersection in ℚ.
- **Payoff: `thm-reals-uncountable` by nested intervals** (Cantor's first proof).
  - Given any list x₁, x₂, …, choose nested closed intervals Iₙ with xₙ ∉ Iₙ. A point in every Iₙ is not on the list.
  - Say in prose that F2.3 gave the diagonal proof via decimal expansions, taken there as a fact from school. This proof needs no decimals, only the axiom.
  - Flag the choice of intervals in one clause: it is a definition by recursion, and needs no choice beyond that. Be accurate here.
- **Closing subsection: "What the axiom bought us".**
  - A table of the facts of this chapter against their failure in ℚ or in ℝ(x).
  - A prose forward pointer: several other properties are *equivalent* to the axiom (monotone convergence, Bolzano–Weierstrass, Cauchy completeness together with Archimedes), and the last main-line chapter of Part I proves it.
- **Check.** Why must the intervals be closed? Give a one-line witness.
- **Exercises.**
  - **A:** which hypothesis fails for four nested families.
  - **B:** prove the nested interval property for intervals [aₙ, bₙ] with bₙ − aₙ = 2⁻ⁿ, and identify the point for aₙ = the n-digit decimal truncation of √2.
  - **C:**
    - **exit-check review:** re-prove the nested interval property, then derive the LUB property from "nested intervals + Archimedes" in an ordered field. This is one arrow of the later equivalence theorem, previewed; phrase it so it is complete in itself.
    - show that the set of reals not in a given countable set is dense.
