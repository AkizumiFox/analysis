### 4.0 `index.md`

- **Title** `# Sequences, Subsequences, and Cauchy Sequences`.
- **Story** (two paragraphs, ~250 words). Chapter 1 said "from some point on" (`@cor-archimedean-epsilon`, "Moreover") and approximated a supremum by a sequence of elements (`@cor-sup-approximation`); Chapters 2 and 3 measured closeness with balls. This chapter makes "the terms settle down" precise and asks what completeness buys for sequences. In an ordered field, *Number Systems* already proved the limit laws; what it could not prove is that a bounded monotone sequence converges, that a bounded sequence has a convergent subsequence, or that a Cauchy sequence converges: each fails in ℚ. In ℝ each holds, and each is a consequence of the least upper bound axiom. Second paragraph: the zigzag sequence 1, 2, 3/2, 5/3, 8/5, …, which is not monotone and whose limit cannot be read off, and the question it raises: how to prove that a sequence converges without knowing its limit. ### 4.1 Limits of Real Sequences (`01-limits-of-real-sequences.md`)

**Budget:** main line ≤ 5,000 (expected ~4,500). Quick checks 4, warnings 2. Subsections in this order.

**Opening (~120).** Chapter 1's "from some point on" and Chapter 3's balls; *Number Systems* defined the limit of a sequence in any ordered field and proved the limit laws there; in ℝ the same definition reads through intervals, and what is new is that completeness now guarantees limits. This section sets up the definition in ℝ, practises it, and lists what carries over.

**`## A sequence that will not sit still` (hook, ~350).** x₁ ≔ 1, xₙ₊₁ ≔ 1 + 1/xₙ. The terms 1, 2, 3/2, 5/3, 8/5, 13/8, 21/13, 34/21 (the drafter shows the decimals 1, 2, 1.5, 1.667, 1.6, 1.625, 1.615, 1.619 to three places, verified in `verify/ch04/exm-zigzag-subsequences.py`). One sentence: numerators and denominators are consecutive Fibonacci numbers (stated, not used). They jump up and down, by less each time. Questions (Q1)–(Q3) of §1, displayed. "The obvious tool, guessing L and checking |xₙ − L| < ε, needs L. This chapter answers all three; Section 4.3 settles the first two and Section 4.5 the third." No answer is given here.

**`## Sequences and their limits` (~1,000).**
1. **`def-sequence`** `[Sequence]` (minor; steps 4, 7, 8): a **sequence** in a set X is a function a: ℤ_{>0} → X; aₙ is its n-th **term**; written (aₙ)_{n≥1} or (aₙ); {aₙ : n ≥ 1} is its set of values. Sequences indexed from some n₀ ∈ ℤ are allowed. A property holds **eventually** if there is N with the property for every n ≥ N. One sentence: *Number Systems* indexed from 0 (`@fd3:def-sequence-ordered-field`); shifting the index changes no limit (`@fd3:prp-tail-change-ordered-field`), so its results apply here.
2. **Failure first** (~120): "the terms get closer and closer to L". The sequence (1/n) gets closer and closer to −1: |1/(n+1) − (−1)| < |1/n − (−1)|. The sequence 1, 0, 1/2, 0, 1/3, 0, … should have limit 0, but it does not get closer at every step. So the definition must not compare consecutive terms with L: it must say that **every** tolerance is **eventually** met **for good**.
3. **`def-seq-limit`** `[Limit of a Sequence]` (major notion; spiral form of the explain template: situate (F3.9 recalled with `@fd3:def-sequence-limit-ordered-field`), slogan, definition, symbols, paraphrase, examples, non-example, warning, payoff). Let (aₙ) be a real sequence and L ∈ ℝ. (aₙ) **converges to** L, written aₙ → L, if **for every** ε > 0 **there exists** N ∈ ℤ_{>0} such that |aₙ − L| < ε **for every** n ≥ N. Symbols: (∀ε > 0)(∃N ∈ ℤ_{>0})(∀n ≥ N) |aₙ − L| < ε. A sequence that converges to some L is **convergent**; otherwise **divergent**. Slogan: *every tolerance is eventually met, and met for good.* Paraphrase clause by clause, then the interval reading: by `@eq-abs-interval`, |aₙ − L| < ε says aₙ ∈ (L − ε, L + ε), so aₙ → L says every open interval centred at L contains all terms from some index on. (This pays Chapter 1's pointers at `01-ordered-fields.md:233` and `05-archimedean-property.md:111`; seam item, §7.) It is *Number Systems'* definition with F = ℝ, word for word. lim notation waits for uniqueness (`thm-real-limit-laws` (a)).
4. Examples (each checked clause by clause): the constant sequence (degenerate case: N = 1 for every ε); 1/n → 0 by `@cor-archimedean-epsilon` (the "Moreover" clause is exactly "for every n ≥ N"); 1, 0, 1/2, 0, 1/3, 0, … → 0 (the terms are a_{2k−1} = 1/k and a_{2k} = 0; given ε, choose M with 1/M < ε and N ≔ 2M − 1: an odd n = 2k − 1 ≥ N has k ≥ M, so 1/k ≤ 1/M < ε). Non-example by minimal change: (−1)ⁿ/n → 0 but (−1)ⁿ diverges: for L, ε = 1 fails, since consecutive terms are 2 apart and cannot both lie within 1 of L (strict).
5. **Quick check** (weird examples): "(a) Does changing the first million terms of a convergent sequence change whether it converges, or its limit? (b) Is 'aₙ → L' the same as '|aₙ − L| ≤ ε eventually, for every ε > 0'? (c) Does the sequence 3, 3, 3, … converge to 3.0001?" *Solution:* (a) no to both: take N beyond 10⁶ (`@fd3:prp-tail-change-ordered-field`); (b) yes: given ε, apply the weak form to ε/2 (strict < follows); (c) no: ε = 0.0001 fails for every n.
6. **Warning** `**N may depend on ε, and on nothing else.**` "'Take N = 1/ε' is not yet a choice: 1/ε need not be an integer, and N must not depend on n. Choose N by the Archimedean property, as an integer larger than the bound found in scratch work."

**`## Proving a limit from the definition` (~800).**
1. **`exm-epsilon-n-rational`** `[A Limit from the Definition]`: "Show that (4n − 1)/(2n + 3) → 2."
   - **`[Scratch work]`** (first in the book): |aₙ − 2| = |4n − 1 − 4n − 6|/(2n + 3) = 7/(2n + 3). We want this < ε. Solving exactly is possible but untidy; bound by something a little bigger: 7/(2n + 3) < 7/(2n), and 7/(2n) < ε exactly when n > 7/(2ε). So any integer N > 7/(2ε) works. Givens/goal in prose: the goal is "find N"; the gap is closed by the bound.
   - *Solution* (forward): "Let ε > 0. By `@thm-naturals-unbounded` choose N ∈ ℤ_{>0} with N > 7/(2ε). For n ≥ N, |aₙ − 2| = 7/(2n + 3) < 7/(2n) ≤ 7/(2N) < ε." Aftermath: N depends on ε only; the proof need not find the least N.
2. **Quick check:** "For ε = 1/10, which N does the solution produce? What is the least N that works?" *Solution:* any integer N > 35, e.g. 36; the least is 34, since 7/(2n + 3) < 1/10 ⇔ 2n + 3 > 70 ⇔ n ≥ 34 (n = 33 gives 7/69 > 1/10). Sidecar `verify/ch04/exm-epsilon-n-rational.py`.
3. **`exm-epsilon-n-root`** `[Bounding by Something Smaller]`: "Show that √(n + 1) − √n → 0." Idea (two lines, fading): multiply by the conjugate, √(n+1) − √n = 1/(√(n+1) + √n) < 1/(2√n), and 1/(2√n) < ε ⇔ n > 1/(4ε²) (square roots of `@thm-nth-root`; x ↦ √x strictly increasing on [0, ∞), ledger: from uniqueness of roots and `@thm-ordered-field-rules`). *Solution* forward with N > 1/(4ε²). Aftermath, planting S5: the steps √(n+1) − √n shrink to 0 while √n itself exceeds every bound; Section 4.5 returns to this.

**`## What carries over from an ordered field` (~700).**
1. Lead: ℝ is an ordered field (`@def-ordered-field`), so every theorem of *Number Systems*, Chapter 4, holds with F = ℝ.
2. **`thm-real-limit-laws`** `[Limit Laws for Real Sequences]`: Let (aₙ), (bₙ), (cₙ) be real sequences, aₙ → a and bₙ → b, and c ∈ ℝ. (a) If also aₙ → a′, then a = a′. (b) (aₙ) is bounded. (c) aₙ + bₙ → a + b, caₙ → ca, aₙbₙ → ab, and, if b ≠ 0 and bₙ ≠ 0 for every n, aₙ/bₙ → a/b. (d) If aₙ ≤ bₙ eventually, then a ≤ b. (e) (Squeeze) If a = b and aₙ ≤ cₙ ≤ bₙ eventually, then cₙ → a. (f) |aₙ| → |a|.
   - *Proof.* (a)–(e) are, with F = ℝ: `@fd3:thm-limit-unique-ordered-field`, `@fd3:prp-convergent-bounded-ordered-field`, `@fd3:thm-limit-laws-ordered-field`, `@fd3:prp-limit-preserves-order-ordered-field` (a), (c); the definitions agree with `@def-seq-limit` after re-indexing (`@fd3:prp-tail-change-ordered-field`). (f): ||aₙ| − |a|| ≤ |aₙ − a| by `@thm-triangle-inequality` (b); the same N works.
   - Then the notation lim aₙ = a, justified by (a).
   - **Remark** (converse failures, STYLE §10): (f)'s converse fails, (−1)ⁿ with |aₙ| → 1; strict inequalities do not pass to the limit, 1/n > 0 with limit 0; in (e), the convergence of (cₙ) is a conclusion, not a hypothesis.
3. **`exm-limit-laws-in-use`** `[The Laws at Work]`: "Find lim (3n² + n)/(n² − 5)." *Solution:* for n ≥ 3, n² − 5 ≠ 0 and the quotient equals (3 + 1/n)/(1 − 5/n²); 1/n → 0 and 1/n² = (1/n)(1/n) → 0, so by (c) the limit is 3/1 = 3. The first two terms are irrelevant (re-indexing). 
4. **`exm-sup-approximation-limit`** `[A Supremum Is a Limit]` (pays `04-epsilon-characterization.md:123`): "Let A ⊆ ℝ be non-empty and bounded above, and let aₙ be as in `@cor-sup-approximation`. Show that aₙ → sup A." *Solution:* sup A − 1/n < aₙ ≤ sup A, both outer sequences converge to sup A, squeeze (e). One sentence: the choice of one aₙ for every n was flagged in Chapter 1.
5. **Quick check:** "Why can the quotient law not be applied to (n² + 1)/(n + 1) as it stands?" *Solution:* neither n² + 1 nor n + 1 converges; the law needs convergent numerator and denominator. (The sequence tends to ∞; next subsection.)

**`## Divergence to infinity` (~650).**
1. **`def-diverge-infinity`** `[Divergence to Infinity]` (minor; steps 4, 7, 8, 10): aₙ → ∞ if for every M ∈ ℝ there is N with aₙ > M for every n ≥ N; aₙ → −∞ if −aₙ → ∞. Such a sequence **diverges to** ±∞; it is divergent, since ∞ is not a real number (Chapter 1's convention, `03-the-axiom.md`, "Conventions"). Examples: n; n² − 10n (for n ≥ 20, n² − 10n = n(n − 10) ≥ 10n ≥ n, so any N > max(20, M) works); −√n (given M, any N > M²).
2. Non-example by minimal change, planting **S1**: aₙ = n^{(−1)ⁿ}, i.e. 1, 2, 1/3, 4, 1/5, …: unbounded above, yet not → ∞ (every odd term is at most 1).
3. **`prp-infinite-limit-rules`** `[Rules for Infinite Limits]`: (a) if aₙ → ∞ and (bₙ) is bounded below, then aₙ + bₙ → ∞; (b) if aₙ → ∞ and bₙ ≥ c eventually for some c > 0, then aₙbₙ → ∞; (c) if aₙ > 0 eventually, then aₙ → ∞ ⇔ 1/aₙ → 0; (d) if aₙ ≤ bₙ eventually and aₙ → ∞, then bₙ → ∞. Proof: (a) and (c) written; (b), (d) one line each ("given M, use M/c" and "the same N").
4. **Warning** `**∞ − ∞ is not a number.**` n − n → 0, (n + 1) − n → 1, n² − n → ∞: three sequences of the form "∞ − ∞" with three behaviours, so no rule assigns a value.
5. **Quick check:** "True or false: if aₙ → ∞ then (aₙ) has a least term." *Solution:* true: take M = a₁; beyond some N every term exceeds a₁, so the least of a₁, …, a_N (a finite set, `@fd2:prp-finite-max` for the minimum, or Chapter 1's finite-max fact; ledger) is the least term.

**`## Five standard limits` (~850).**
1. **`thm-standard-limits`** `[Standard Limits]`:
   (a) n^{−1/k} → 0 for each integer k ≥ 1;
   (b) aⁿ → 0 if |a| < 1, and aⁿ → ∞ if a > 1;
   (c) a^{1/n} → 1 for each a > 0;
   (d) n^{1/n} → 1;
   (e) n^k aⁿ → 0 for each k ∈ ℕ and |a| < 1.
2. **Two inequalities from *Analytic Preliminaries*** (F4.6), recalled with by-hand checks (rule 3): Bernoulli, (1 + h)ⁿ ≥ 1 + nh for h ≥ −1 and n ≥ 1 (induction, three lines); the binomial lower bound, (1 + h)ⁿ ≥ C(n, j) hʲ for h ≥ 0 and 0 ≤ j ≤ n (every term of the binomial expansion is ≥ 0). Ledger lines cite F4.6.
3. **`[Scratch work]` for (d)** (the root-expansion technique): write n^{1/n} = 1 + hₙ with hₙ ≥ 0 (n^{1/n} ≥ 1 since a root of a number ≥ 1 is ≥ 1). Then n = (1 + hₙ)ⁿ ≥ C(n, 2) hₙ² = n(n − 1)hₙ²/2 for n ≥ 2, so hₙ² ≤ 2/(n − 1), hₙ ≤ √(2/(n − 1)). The right side → 0 by (a) with k = 2 and a shift; squeeze.
4. **Proof** (forward, one paragraph per part): (a) |n^{−1/k}| < ε ⇔ n > ε^{−k} (roots strictly increasing; ledger). (b) |a| = 1/(1 + h) with h > 0 (a ≠ 0; a = 0 trivial); Bernoulli gives |a|ⁿ ≤ 1/(1 + nh) < 1/(nh); for a > 1, aⁿ = (1 + h)ⁿ ≥ 1 + nh → ∞ by `prp-infinite-limit-rules` (d). (c) for a ≥ 1, a^{1/n} = 1 + tₙ, a = (1 + tₙ)ⁿ ≥ 1 + ntₙ, so 0 ≤ tₙ ≤ (a − 1)/n; for 0 < a < 1, a^{1/n} = 1/(1/a)^{1/n}, quotient law. (d) as in scratch work. (e) |a| = 1/(1 + h); for n ≥ 2(k + 1), (1 + h)ⁿ ≥ C(n, k + 1)h^{k+1} ≥ (n/2)^{k+1} h^{k+1}/(k + 1)!, since each factor n − j ≥ n/2 for j ≤ k; so n^k|a|ⁿ ≤ 2^{k+1}(k + 1)!/(h^{k+1} n) → 0. Sidecar checks the inequality for small n, k.
5. Aftermath: (e) says powers beat polynomials; *Integration, Series, and Function Spaces* uses (b)–(e) in the root and ratio tests (prose, no number; AN1.3).
6. **Quick check:** "Find lim (1/2)ⁿ · n^{1/n} and lim n^{1/n}·(n + 1)/n." *Solution:* 0·1 = 0 and 1·1 = 1, by the product law and (b), (d).

### 4.2 Monotone Sequences (`02-monotone-sequences.md`)

**Budget:** ≤ 5,000 (expected ~4,300). Quick checks 3, warnings 2, Try it first 1.

**Opening (~150).** *Number Systems* ended with a sequence of rationals that decreases, is bounded below, and has no rational limit (`@fd3:thm-sqrt2-cauchy-no-rational-limit`); Chapter 1's story had the increasing 1, 1.4, 1.41, …. In ℚ such sequences may fail to converge. In ℝ they cannot: this is the first theorem about sequences that needs the least upper bound axiom.

**`## Monotone sequences and the monotone convergence theorem` (~1,300).**
1. **`def-monotone-sequence`** `[Monotone Sequence]` (minor): **non-decreasing** if aₙ ≤ aₙ₊₁ for every n; **strictly increasing** if <; **non-increasing**, **strictly decreasing** likewise; **monotone** if non-decreasing or non-increasing. Examples: 1 − 1/n; constant (both); non-example (−1)ⁿ/n.
2. ***Try it first*** (STYLE §11.8): "A non-decreasing sequence bounded above: what should its limit be? Try to prove it converges before reading on."
3. **`thm-monotone-convergence`** `[Monotone Convergence Theorem]`: (a) A non-decreasing real sequence that is bounded above converges, and lim aₙ = sup{aₙ : n ≥ 1}. (b) A non-increasing real sequence that is bounded below converges to inf{aₙ : n ≥ 1}. (c) A non-decreasing sequence that is not bounded above diverges to ∞ (non-increasing, not bounded below: −∞).
   - **`[Scratch work]`** (starts from what the try-it-first runs into: "which number is L?"): The candidate is s = sup of the values, which exists by `@ax-least-upper-bound` (non-empty, bounded above). Goal: for ε > 0, an N with s − ε < aₙ ≤ s for n ≥ N. Right half free: s is an upper bound. Left half: s − ε is not an upper bound (`@thm-sup-epsilon`), so some a_N > s − ε: **sup approximation hands you N**. Then non-decreasing pushes every later term above a_N. Table in prose: Givens (non-decreasing; bounded above; s = sup) / Goal (|aₙ − s| < ε for n ≥ N) / gap closed by a_N and monotonicity.
   - **Proof** (a) forward; (b) apply (a) to (−aₙ) and `@thm-inf-neg-sup`; (c) given M, M is not an upper bound, so a_N > M, and non-decreasing.
   - Aftermath (meta-claim, checkable): the proof of (a) uses the axiom once, in the existence of s, and does not use the Archimedean property; Chapter 10 needs that observation (prose pointer).
4. **`cor-monotone-bounded-iff`** `[Monotone Sequences: Convergent Iff Bounded]`: a monotone real sequence converges if and only if it is bounded. Proof: `thm-real-limit-laws` (b) and the theorem.
5. Counterexamples per hypothesis (STYLE §10): drop "bounded": n; drop "monotone": (−1)ⁿ; drop completeness (in ℚ): **S2**, the decimal truncations tₙ of √2: rational, non-decreasing, bounded by 2, and their limit in ℝ is √2 (`@thm-sqrt2-exists`; tₙ ≤ √2 < tₙ + 10^{−n}, squeeze), so by uniqueness no rational number is their limit.
6. **Warning** `**Eventually monotone is enough; bounded is not.**` "The theorem applies to a sequence that is monotone from some index on (only the tail matters). It does not apply to a bounded sequence that is not monotone: (−1)ⁿ."
7. **Quick check:** "(a) Does a non-decreasing sequence of negative numbers converge? To a negative number? (b) Does a strictly decreasing sequence of positive numbers converge to 0?" *Solution:* (a) yes, bounded above by 0; its limit is ≤ 0 and may be 0 (−1/n). (b) it converges (bounded below by 0) but not necessarily to 0: 1 + 1/n.

**`## Recursive sequences` (~1,000).**
1. Lead: a sequence defined by xₙ₊₁ = f(xₙ) is monotone or not according to where it starts. The pattern: show bounds by induction, show monotone, apply the theorem, then **locate the missing limit** (named in *Number Systems*, Chapter 4; recalled, not re-proved).
2. **`exm-recursion-three-fates`** `[One Recursion, Three Fates]`: xₙ₊₁ = (xₙ² + 6)/5. Determine the behaviour for (i) x₁ = 1, (ii) x₁ = 5/2, (iii) x₁ = 4.
   - **`[Scratch work]`**: fixed points: x = (x² + 6)/5 ⇔ x² − 5x + 6 = 0 ⇔ x ∈ {2, 3}. The step: xₙ₊₁ − xₙ = (xₙ − 2)(xₙ − 3)/5, positive outside [2, 3], negative inside (2, 3). And x ↦ (x² + 6)/5 is increasing on [0, ∞), so it maps (0, 2) into (6/5, 2), (2, 3) into (2, 3), (3, ∞) into (3, ∞).
   - *Solution:* (i) by induction 0 < xₙ < 2; so xₙ₊₁ > xₙ; non-decreasing and bounded: converges to L with 0 ≤ L ≤ 2; passing to the limit in xₙ₊₁ = (xₙ² + 6)/5 (laws (c), and xₙ₊₁ → L by re-indexing) gives L ∈ {2, 3}; so L = 2. Terms 1, 7/5, 199/125, … (sidecar). (ii) 2 < xₙ < 3 and decreasing: L ∈ [2, 5/2], so L = 2. (iii) xₙ > 3 and increasing; if bounded, L ≥ x₁ = 4 would be a fixed point, impossible; so not bounded, and xₙ → ∞ by (c).
   - Aftermath: the order matters: "pass to the limit" only after the theorem has given a limit (forward reference in prose to `exm-fixed-point-trap`, Section 4.5).
3. **Quick check:** "What happens for x₁ = 3? For x₁ = −1?" *Solution:* constant 3; x₂ = 7/5, after which the sequence behaves as in (i), limit 2 (re-indexing).

**`## The number e` (~1,000).**
1. **`exm-euler-number`** `[The Sequence (1 + 1/n)ⁿ]`: "Show that eₙ ≔ (1 + 1/n)ⁿ is strictly increasing and bounded above by 3."
   - Idea (no full scratch: the techniques are F4.6's): increasing by AM–GM; bounded by the binomial theorem.
   - *Solution:* (Increasing) AM–GM (F4.6, stated with its by-hand reference; ledger) for the n + 1 positive numbers 1 + 1/n (n times) and 1: their arithmetic mean is (n + 2)/(n + 1) = 1 + 1/(n + 1), so (1 + 1/n)ⁿ · 1 ≤ (1 + 1/(n + 1))^{n+1}, with strict inequality since the numbers are not all equal. (Bounded) the binomial theorem (F4.6) gives eₙ = Σ_{k=0}^{n} C(n, k)/nᵏ, and C(n, k)/nᵏ = (1/k!)·∏_{j<k}(1 − j/n) ≤ 1/k! ≤ 1/2^{k−1} for k ≥ 1 (k! ≥ 2^{k−1}, induction); so eₙ ≤ 1 + Σ_{k=1}^{n} 2^{1−k} = 3 − 2^{1−n} < 3 (finite geometric sum, F4.6).
   - Values e₁ = 2, e₂ = 9/4, e₃ = 64/27 (sidecar).
2. **`def-euler-number`** `[The Number e]`: e ≔ lim (1 + 1/n)ⁿ, which exists by `thm-monotone-convergence`; 9/4 ≤ e ≤ 3 by `thm-real-limit-laws` (d) (and e > 9/4 since the sequence is strictly increasing). Prose pointer: *Integration, Series, and Function Spaces* meets e again as a sum and as exp(1) (AN1.3, AN1.10; §7 coordination). 4.2 C2 sharpens the bound to e ≤ 11/4.
3. **`exm-limit-without-formula`** `[A Limit with No Formula]`: sₙ ≔ Σ_{k=1}^{n} 1/k². Show (sₙ) converges. *Solution:* non-decreasing; for k ≥ 2, 1/k² < 1/(k(k − 1)) = 1/(k − 1) − 1/k, so sₙ < 1 + 1 − 1/n < 2 (telescoping). The theorem gives a limit in [5/4, 2]. Aftermath: the theorem says that a limit exists and says nothing about its value; no value is claimed (no promise opened).
4. **Quick check:** "Is e₁₀ < e? Is e₁₀ < 3?" *Solution:* yes (strictly increasing, so e₁₀ < e₁₁ ≤ e); yes.

Prove that (yₙ) converges and find its limit. *Solution:* induction: 1 ≤ yₙ < 3 (2y + 3 < 9); yₙ₊₁² − yₙ² = (3 − yₙ)(1 + yₙ) > 0, so non-decreasing (both positive); limit L ∈ [1, 3]; from yₙ₊₁² = 2yₙ + 3, L² = 2L + 3, so L = 3. ### 4.3 Subsequences and the Bolzano–Weierstrass Theorem (`03-subsequences.md`)

**Budget:** ≤ 5,000 (expected ~4,700). Quick checks 4, warnings 2, self-explain 1 (`lem-monotone-subsequence`).

**Opening (~120).** The zigzag is not monotone, but its terms of odd index rise and its terms of even index fall. Picking out terms is a tool; this section makes it precise and proves that every bounded sequence of reals has a convergent subsequence.

**`## Subsequences` (~1,000).**
1. **Failure first** (~100): "a subsequence is what remains when some terms are deleted": if we may also repeat or reorder, then from (−1)ⁿ we could "select" the constant sequence a₂, a₂, a₂, …, or 1, −1, 1, … in any order, and nothing could be inferred. The indices must strictly increase.
2. **`def-subsequence`** `[Subsequence]`: given (aₙ) and a strictly increasing sequence of positive integers n₁ < n₂ < ⋯, the sequence (a_{n_k})_{k≥1} is a **subsequence** of (aₙ). Examples: (a_{2k}), (a_{k²}), the tail (a_{k+5}); (aₙ) itself. Non-examples: (a₁, a₁, a₂, a₂, …) (indices not strictly increasing); (a₂, a₁, a₄, a₃, …).
3. **`lem-subsequence-index`** `[Indices of a Subsequence]`: n_k ≥ k for every k. Proof: induction.
4. **`lem-subsequence-of-subsequence`** `[A Subsequence of a Subsequence]`: a subsequence of a subsequence of (aₙ) is a subsequence of (aₙ). Proof: a composition of strictly increasing maps ℤ_{>0} → ℤ_{>0} is strictly increasing. (Used in 4.7.)
5. **`thm-subsequence-limit`** `[Subsequences Inherit Limits]`: if aₙ → L (L ∈ ℝ, or L = ±∞), then a_{n_k} → L for every subsequence. Proof (3 lines): same N, since k ≥ N ⇒ n_k ≥ k ≥ N.
6. **`cor-divergence-by-subsequences`** `[Two Subsequences, Two Limits]`: if two subsequences have different limits (in ℝ or ±∞), the sequence diverges; so does a sequence with a divergent subsequence. Examples: (−1)ⁿ (even → 1, odd → −1); (−1)ⁿ n/(n + 1).
7. **`prp-even-odd-subsequences`** `[Even and Odd Terms]`: aₙ → L if and only if a_{2k} → L and a_{2k−1} → L. Proof: (⇒) the theorem; (⇐) N ≔ max(2K₁, 2K₂ − 1); finiteness of the max is what makes it legitimate (STYLE §4, H13).
8. **Quick check:** "Is (a_{⌊k/2⌋+1})_{k≥1} a subsequence of (aₙ)? Is (a_{2k+1})_{k≥1}?" *Solution:* no: indices 1, 2, 2, 3, 3, … repeat; yes.

**`## The zigzag converges` (~800).**
1. **`exm-zigzag-subsequences`** `[Back to the Zigzag]` (pays (Q1), (Q2)): "Show that the sequence of Section 4.1 converges, and find its limit." *Solution*, in steps (an ordinary Idea first: two steps of the recursion form one increasing map):
   - (i) 1 ≤ xₙ ≤ 2 for all n (induction: x ≥ 1 ⇒ 1 < 1 + 1/x ≤ 2).
   - (ii) xₙ₊₂ = g(xₙ) with g(x) ≔ 1 + 1/(1 + 1/x) = (2x + 1)/(x + 1) = 2 − 1/(x + 1), which is strictly increasing on [1, 2].
   - (iii) x₁ = 1 < 3/2 = x₃, so by induction (apply g) x_{2k−1} < x_{2k+1}: the odd terms increase; x₂ = 2 > 5/3 = x₄, so the even terms decrease.
   - (iv) Both are bounded (i), so both converge (`thm-monotone-convergence`), to L₁, L₂ ∈ [1, 2].
   - (v) Passing to the limit in x_{2k+1} = g(x_{2k−1}) (laws (c)): L₁ = (2L₁ + 1)/(L₁ + 1), so L₁² − L₁ − 1 = 0, L₁ = φ ≔ (1 + √5)/2 (the other root is negative). Same for L₂.
   - (vi) `prp-even-odd-subsequences`: xₙ → φ.
   - Aftermath: (Q1), (Q2) answered; (Q3) is not: the proof used a special structure (g increasing, so each half is monotone), which a general sequence lacks. Section 4.5.
2. **Quick check:** "Why does x₁ < x₃ imply x₃ < x₅?" *Solution:* g is strictly increasing, so g(x₁) < g(x₃), i.e. x₃ < x₅.

**`## Every sequence has a monotone subsequence` (~900).**
1. **`lem-monotone-subsequence`** `[Monotone Subsequence Lemma]`: every real sequence has a monotone subsequence.
   - **`[Scratch work]`** (peaks): call m a **peak** if a_m ≥ aₙ for every n > m (the term is at least everything after it; picture: a mountain range seen from the left, peaks visible from infinitely far to the right). Two cases, and they are exhaustive: infinitely many peaks or finitely many. Infinitely many peaks m₁ < m₂ < ⋯: a_{m₁} ≥ a_{m₂} ≥ ⋯, non-increasing. Finitely many: beyond the last one, no index is a peak, so every index has a later, strictly larger term: climb. Run on (−1)ⁿ (peaks: the even m), on 1/n (every m), on 1 − 1/n (none).
   - **Proof.** Case 1 by listing the peaks (the set of peaks is an infinite subset of ℤ_{>0}, enumerated in increasing order: well-ordering, ledger F2.2). Case 2: let N exceed every peak; n₁ ≔ N; given n_k ≥ N, n_k is not a peak, so the set {n > n_k : aₙ > a_{n_k}} is non-empty; let n_{k+1} be its least element (well-ordering; the recursion is a definition by recursion, no choice needed: one clause says so, STYLE §10). Then (a_{n_k}) is strictly increasing.
   - *Self-explain prompt:* "*Before reading on: why does Case 2 take the least such index rather than any?*" (Answer in the next sentence: it makes the construction a recursion with no choices.)
2. **`thm-bolzano-weierstrass-sequences`** `[Bolzano–Weierstrass Theorem for Sequences]`: every bounded real sequence has a convergent subsequence. Proof: the lemma gives a monotone subsequence; it is bounded; `thm-monotone-convergence`.
   - Counterexample per hypothesis: unbounded, n; over ℚ, the truncations of √2 (S2: every subsequence converges in ℝ to √2, so none has a rational limit).
   - "Alternatively," paragraph (Apostol's route, ≤ 90 words, prose pointer to Chapter 2's Bolzano–Weierstrass theorem for sets): if the set of values is finite, some value is taken infinitely often (constant subsequence); if infinite, it is a bounded infinite set, so it has an accumulation point p, and choosing n_k > n_{k−1} with |a_{n_k} − p| < 1/k gives a_{n_k} → p. Section 4.6 makes the link exact (`prp-accumulation-sequence`).
3. **Warning** `**A convergent subsequence says little about the sequence.**` "(−1)ⁿ has convergent subsequences and diverges. The theorem gives existence, not uniqueness of the limit, and not which subsequence."

**`## Subsequential limits` (~700).**
1. **`def-subsequential-limit`** `[Subsequential Limit]`: s ∈ ℝ ∪ {−∞, ∞} is a **subsequential limit** of (aₙ) if some subsequence tends to s. Examples: (−1)ⁿ: {−1, 1}; n^{(−1)ⁿ} (S1): 0 and ∞; a convergent sequence: only its limit (`thm-subsequence-limit`).
2. **`exm-every-point-a-limit`** `[A Sequence That Comes Back Everywhere]` (S3): "Let (qₙ) list the rationals in [0, 1] (they form a countably infinite set, F2.3). Show that every x ∈ [0, 1] is a subsequential limit." *Solution:* recursively, n_k > n_{k−1} with |q_{n_k} − x| < 1/k: possible since (x − 1/k, x + 1/k) ∩ [0, 1] contains infinitely many rationals (`@thm-rationals-dense`, applied repeatedly to shrinking intervals; it is an interval of positive length inside [0, 1]), and only finitely many have index ≤ n_{k−1}. Least such index, no choice. Row S3.
3. **Quick check:** "Can a sequence have exactly the subsequential limits 0 and 1? Exactly the subsequential limits 1/k, k ≥ 1, and no others?" *Solution:* yes (0, 1, 0, 1, …); no: Section 4.4 C3 shows that 0 would also be one (the drafter phrases the answer as "no; see `exr-upper-and-lower-limits-c3`", which proves the set of subsequential limits is closed).

### 4.4 Upper and Lower Limits (`04-upper-and-lower-limits.md`)

**Budget:** ≤ 5,000 (expected ~4,700). Quick checks 4, warnings 2, self-explain 1 (`thm-limsup-subsequential`).

**Opening (~120).** A bounded sequence need not converge, but it has a largest and a smallest place where its terms accumulate. Apostol's §8.3 and Rudin's 3.16–3.17 give two descriptions; this section defines one, proves the other, and adds a third in the exercises.

**`## The extended real line` (~400).** **`def-extended-reals`** `[Extended Real Line]` (minor): [−∞, ∞] ≔ ℝ ∪ {−∞, ∞} with −∞ < x < ∞ for every real x. Every subset has a supremum and an infimum in [−∞, ∞]: sup S = ∞ if S ⊆ ℝ is not bounded above, sup S = −∞ if S = ∅ or S = {−∞} (Chapter 1's conventions, made official here). No arithmetic is defined except x + ∞ = ∞ for x > −∞ (and its mirror), used in `prp-limsup-rules` (c). A monotone sequence in [−∞, ∞] converges in the extended sense to its sup or inf (extend `def-diverge-infinity`; one sentence and `thm-monotone-convergence`). NOTATION row (§5).

**`## Tail suprema` (~1,100).**
1. **Failure first** (~120): the sup of the terms is spoiled by early terms: aₙ ≔ (−1)ⁿ + 5/n has terms 4, 7/2, 2/3, 9/4, 0, 11/6, …, sup 4, yet from some index on every term is within 1/10 of 1 or of −1. Forget the first n terms.
2. **`def-limsup`** `[Upper and Lower Limits]` (major notion, full template): for a real sequence (aₙ), let uₙ ≔ sup{a_k : k ≥ n} and ℓₙ ≔ inf{a_k : k ≥ n} in [−∞, ∞]. (uₙ) is non-increasing and (ℓₙ) non-decreasing, so both have limits in [−∞, ∞]; lim sup aₙ ≔ lim uₙ = inf_n uₙ and lim inf aₙ ≔ lim ℓₙ = sup_n ℓₙ. Slogan: *the upper limit is the ceiling the sequence approaches once its early terms are forgotten.* Paraphrase; well-definedness (monotone, so the limit exists in [−∞, ∞]; ℓₙ ≤ uₙ, so lim inf ≤ lim sup).
3. **`exm-limsup-first`** `[First Upper and Lower Limits]`: (i) (−1)ⁿ(1 + 1/n): uₙ = 1 + 1/m with m the least even index ≥ n, so lim sup = 1, lim inf = −1; (ii) S1, n^{(−1)ⁿ}: uₙ = ∞ for all n, lim sup = ∞; ℓₙ = 0 for all n (the odd terms 1/k → 0 are positive), lim inf = 0; (iii) 1/n: both 0; (iv) n: both ∞ (degenerate: uₙ = ∞ and ℓₙ = n). Non-example by minimal change: replacing lim uₙ by sup uₙ gives u₁ = sup aₙ, back to the failure.
4. **Quick check** (quantifier swap, STYLE §10): "Compare (A) 'for every ε > 0, aₙ < U + ε for all n from some index on' with (B) 'there is an index from which aₙ < U + ε for every ε > 0'." *Solution:* (B) says aₙ ≤ U from some index on; (A) allows aₙ = U + 1/n.
5. **Warning** `**The upper limit is not the supremum.**` lim sup aₙ ≤ sup aₙ, often strictly ((−1)ⁿ + 5/n: 1 < 4); and some terms may exceed the upper limit infinitely often (1 + 1/n, upper limit 1, every term > 1).

**`## Two descriptions of the upper limit` (~1,400).**
1. **`thm-limsup-epsilon`** `[ε-Description of the Upper Limit]`: Let (aₙ) be a real sequence and U ∈ ℝ. Then U = lim sup aₙ if and only if for every ε > 0: (i) aₙ < U + ε for every n from some index on, and (ii) aₙ > U − ε for infinitely many n. Moreover lim sup aₙ = ∞ if and only if (aₙ) is not bounded above, and lim sup aₙ = −∞ if and only if aₙ → −∞.
   - **`[Scratch work]`** (tail suprema, first appearance): (i) is about uₙ < U + ε for one n; (ii) is about every uₙ > U − ε, i.e. inside every tail some term exceeds U − ε, which is `@thm-sup-epsilon` applied to the tail set. Givens/goal both ways.
   - **Proof** (⇒) and (⇐), each ≤ 10 lines; the "moreover" clauses in 4 lines.
2. **`thm-limsup-subsequential`** `[Extreme Subsequential Limits]`: lim sup aₙ is a subsequential limit of (aₙ) (in [−∞, ∞]), and every subsequential limit s satisfies lim inf aₙ ≤ s ≤ lim sup aₙ. So lim sup aₙ is the largest and lim inf aₙ the smallest subsequential limit.
   - Idea (two lines; the construction is the 4.3 C1 / `exm-every-point-a-limit` pattern): use (ii) with ε = 1/k and a fresh index each time; (i) traps the subsequence from above.
   - Proof: case U ∈ ℝ (build n_k > n_{k−1} with a_{n_k} > U − 1/k and n_k beyond the index of (i) for ε = 1/k; squeeze); cases ±∞ (two lines each, from the "moreover"); the inequality: a_{n_k} ≤ u_{n_k}, and u_{n_k} → lim sup by `thm-subsequence-limit`; laws (d) in the extended sense.
   - *Self-explain prompt:* "*Self-explain the line choosing n_k: why must it exceed both n_{k−1} and the index from (i)?*"
3. **`thm-convergence-iff-limsup-liminf`** `[Convergence by Upper and Lower Limits]`: for L ∈ [−∞, ∞], aₙ → L if and only if lim inf aₙ = lim sup aₙ = L. Proof: (⇒) every subsequence tends to L (`thm-subsequence-limit`) and both extremes are subsequential limits; (⇐) for L real, ℓₙ ≤ aₙ ≤ uₙ and squeeze; L = ±∞: from the "moreover" clauses.
4. Rudin's addition, one remark: the set of subsequential limits is closed (prose; proved in C3).
5. **Quick check:** "A sequence has lim sup = 3 and lim inf = 3. Must it converge? Must it be eventually constant?" *Solution:* yes (to 3); no (3 + 1/n).

**`## Rules` (~600).**
1. **`prp-limsup-rules`** `[Rules for Upper and Lower Limits]`: for real sequences: (a) if aₙ ≤ bₙ eventually, then lim sup aₙ ≤ lim sup bₙ and lim inf aₙ ≤ lim inf bₙ; (b) lim inf aₙ = −lim sup(−aₙ); (c) lim sup(aₙ + bₙ) ≤ lim sup aₙ + lim sup bₙ whenever the right side is not ∞ + (−∞) (nor −∞ + ∞); (d) if bₙ → b ∈ ℝ, then lim sup(aₙ + bₙ) = lim sup aₙ + b.
   - Proof: (a) uₙ(a) ≤ uₙ(b) for large n; (b) sup(−S) = −inf S (`@thm-inf-neg-sup`); (c) tail sup of a sum ≤ sum of tail sups (`@thm-sup-sum`'s ≤ half, or directly), laws (d); (d) apply (c) twice, once to aₙ = (aₙ + bₙ) + (−bₙ).
   - Strictness in (c): aₙ = (−1)ⁿ, bₙ = −aₙ: 0 < 2.
2. **Quick check:** "Find lim sup of aₙ + bₙ with aₙ = (−1)ⁿ and bₙ = 1/n." *Solution:* 1, by (d).

### 4.5 Cauchy Sequences (`05-cauchy-sequences.md`)

**Budget:** ≤ 5,000 (expected ~4,600). Quick checks 4, warnings 2, Try it first 1, self-explain 1 (`thm-cauchy-criterion`), faded items: worked (`exm-zigzag-cauchy`), B2, C2.

**Opening (~120).** Question (Q3): prove convergence without knowing the limit. *Number Systems* introduced Cauchy sequences and showed that in ℚ they can fail to converge; in ℝ they cannot, and this section proves it and turns it into a working tool.

**`## Why the limit should not be needed` (~500).**
1. Every proof of convergence so far either named L (Section 4.1) or got L from a monotone structure (Sections 4.2–4.3).
2. **`exm-fixed-point-trap`** `[Solving for the Limit Too Early]`: x₁ = 1, xₙ₊₁ = 2/xₙ. "If xₙ → L then L = 2/L, so L = √2." But the sequence is 1, 2, 1, 2, …, which diverges (`cor-divergence-by-subsequences`). The fixed-point equation gives a candidate only once convergence is known.
3. Naive internal test: "consecutive terms get close". It fails: √(n + 1) − √n → 0 (`exm-epsilon-n-root`) while √n → ∞ (row **S5**). We need all pairs of late terms close, not neighbours.

**`## Cauchy sequences` (~900).**
1. **`def-cauchy`** `[Cauchy Sequence]` (major notion; spiral form, recalling `@fd3:def-cauchy-sequence-ordered-field`): a real sequence (aₙ) is **Cauchy** if **for every** ε > 0 **there exists** N ∈ ℤ_{>0} such that |a_m − aₙ| < ε **for all** m, n ≥ N. Symbols. Slogan: *late terms are close to each other, all of them, pairwise.* Paraphrase; the definition mentions no limit.
2. Examples: 1/n (for m, n ≥ N, |1/m − 1/n| ≤ max(1/m, 1/n) ≤ 1/N, so any N > 1/ε works); a convergent sequence. Non-examples: √n (|√(4n) − √n| = √n ≥ 1); (−1)ⁿ (consecutive terms 2 apart).
3. **`prp-cauchy-basics`** `[Cauchy Sequences: First Facts]`: (a) every convergent real sequence is Cauchy; (b) every Cauchy real sequence is bounded. *Proof:* `@fd3:prp-convergent-cauchy-ordered-field`, `@fd3:prp-cauchy-bounded-ordered-field`, F = ℝ. One-sentence Idea for (a): third point L, ε/2 each.
4. **Quick check** (quantifier swap): "Compare (A) (∀ε > 0)(∃N)(∀n ≥ N) |aₙ₊₁ − aₙ| < ε with `def-cauchy`." *Solution:* (A) compares neighbours only; √n satisfies (A) and is not Cauchy.
5. **Warning** `**All pairs, not neighbours.**` One sentence and the √n witness.

**`## The Cauchy criterion` (~1,300).**
1. **`lem-cauchy-subsequence`** `[A Cauchy Sequence with a Convergent Subsequence Converges]`: if (aₙ) is Cauchy and some subsequence converges to L, then aₙ → L.
   - **`[Scratch work]`** (a third point): |aₙ − L| ≤ |aₙ − a_{n_k}| + |a_{n_k} − L|. The first is small when n and n_k are both late (Cauchy, ε/2); the second when k is late (subsequence, ε/2). One k suffices, chosen after N; n_k ≥ k (`lem-subsequence-index`) makes it late.
   - Proof forward.
2. ***Try it first:*** "Prove that every Cauchy sequence of reals converges. Which theorem of Section 4.3 supplies a candidate limit?"
3. **`thm-cauchy-criterion`** `[Cauchy Criterion]`: a real sequence converges if and only if it is Cauchy. Proof: (⇒) `prp-cauchy-basics` (a); (⇐) bounded (`prp-cauchy-basics` (b)), so a convergent subsequence (`thm-bolzano-weierstrass-sequences`), so convergent (`lem-cauchy-subsequence`).
   - *Self-explain prompt:* "*Before reading on: trace where the least upper bound axiom enters this proof.*" Answer in the aftermath: through Bolzano–Weierstrass, through the monotone convergence theorem, at the existence of a supremum.
   - Aftermath (pays `03-the-axiom.md:28`, seam item): this is the second meaning of "complete": every Cauchy sequence in ℝ converges; Chapter 5 calls a metric space with this property complete. Counterexample to the hypothesis "in ℝ": ℚ (**S6**, below). Chapter 10 shows that in an ordered field "every Cauchy sequence converges" is equivalent to the axiom only together with the Archimedean property (prose pointer).
4. **Quick check:** "Prove that a Cauchy sequence of integers is eventually constant." *Solution:* ε = 1/2: for m, n ≥ N, |a_m − aₙ| < 1/2 forces a_m = aₙ.

**`## Steps that shrink geometrically` (~1,400).**
1. **`prp-contractive-sequence`** `[Contractive Sequences Converge]`: let 0 ≤ c < 1 and let (aₙ) satisfy |aₙ₊₂ − aₙ₊₁| ≤ c|aₙ₊₁ − aₙ| for every n ≥ 1. Then (aₙ) is Cauchy, hence converges to some L, and for m > n ≥ 1,
   |a_m − aₙ| ≤ c^{n−1}|a₂ − a₁|/(1 − c), and |L − aₙ| ≤ c^{n−1}|a₂ − a₁|/(1 − c)   (`eq-contractive-bound`).
   - **`[Scratch work]`** (telescope and sum geometrically): induction gives |a_{k+1} − a_k| ≤ c^{k−1}d with d ≔ |a₂ − a₁|. Telescope: a_m − aₙ = Σ_{k=n}^{m−1}(a_{k+1} − a_k), triangle inequality, finite geometric sum (F4.6, with its one-line check): ≤ d c^{n−1}(1 − c^{m−n})/(1 − c) ≤ d c^{n−1}/(1 − c). The right side → 0 (`thm-standard-limits` (b); c = 0 trivial).
   - Proof forward; then the criterion; the bound on |L − aₙ| by letting m → ∞ (laws (d), (f)).
   - Counterexample for c < 1: aₙ = √n has |aₙ₊₂ − aₙ₊₁| ≤ |aₙ₊₁ − aₙ| (c = 1) and diverges.
2. **`exm-zigzag-cauchy`** `[The Zigzag, Without Guessing]` (pays (Q3); first of the faded triple, worked in full): xₙ₊₂ − xₙ₊₁ = 1/xₙ₊₁ − 1/xₙ = (xₙ − xₙ₊₁)/(xₙxₙ₊₁), and xₙxₙ₊₁ = xₙ + 1 ≥ 2 since xₙ ≥ 1; so c = 1/2, d = |x₂ − x₁| = 1, and |x_m − xₙ| ≤ 2^{2−n}. Then (row **S6**): every xₙ is rational and (xₙ) is Cauchy, but its limit φ is irrational (√5 ∉ ℚ; ledger: proved like √2, F3 divisibility; one sentence in the text), so in ℚ it is a Cauchy sequence with no limit, a companion to *Number Systems*' √2 example.
   - **Looking ahead** (`::: {.remark}`, the hook's last payment, prose pointer): on [3/2, 2] the map g(x) = 1 + 1/x sends the interval into itself and shrinks distances by at least the factor 4/9 (|g(x) − g(y)| = |x − y|/(xy), xy ≥ 9/4); the zigzag is its orbit from x₂ = 2. ### 4.6 Sequences in a Metric Space (`06-sequences-in-metric-spaces.md`)

**Budget:** ≤ 5,000 (expected ~4,800). Quick checks 4, warnings 2.

**Opening (~180, the spiral written out).** Sections 4.1–4.5 worked in ℝ. Chapter 3 measured distance in any metric space. Monotone sequences and upper limits use the order of ℝ and do not survive; every argument that used only |x − y| and the triangle inequality does, with d(x, y) in place of |x − y|. Apostol states the definitions in a metric space from the start; we arrive there second.

**`## Convergence in a metric space` (~1,300).**
1. **`def-metric-limit`** `[Convergence in a Metric Space]` (major, spiral form: steps 1, 3, 4, 5, 7, 8, 10): (xₙ) in (X, d) **converges to** x ∈ X if for every ε > 0 there is N with d(xₙ, x) < ε for every n ≥ N; equivalently d(xₙ, x) → 0 in ℝ; equivalently every open ball B(x, ε) (Chapter 3) contains xₙ eventually. Slogan: *every ball around the limit eventually swallows the sequence.* For X = ℝ with d(x, y) = |x − y| this is `def-seq-limit`.
2. **`exm-metric-sequences`** `[Sequences in Three Metric Spaces]`:
   - (i) the discrete metric (F4.11): xₙ → x if and only if xₙ = x eventually (ε = 1/2);
   - (ii) a subspace: (1/n) converges in ℝ but not in the subspace (0, 1] (Chapter 3's subspace metric): its only candidate is 0 ∉ (0, 1] (by uniqueness in ℝ); convergence depends on the space;
   - (iii) the sup metric on B(S) (F4.11): fₙ(t) ≔ tⁿ. On S = [0, 1/2], d_∞(fₙ, 0) = 2^{−n} → 0. On S = [0, 1), fₙ(t) → 0 for each t (`thm-standard-limits` (b)), but d_∞(fₙ, 0) = 1 for every n: for 0 < δ < 1 the point t ≔ (1 − δ)^{1/n} lies in [0, 1) and has tⁿ = 1 − δ, so the supremum of tⁿ over [0, 1) is 1. So (fₙ) does not converge to 0 in B([0, 1)), and it has no other limit, since a limit in the sup metric is also a pointwise limit (4.6 C3 proves this; here the text checks it in one line: |fₙ(t) − f(t)| ≤ d_∞(fₙ, f)). Row **S8**. Prose pointer: *Integration, Series, and Function Spaces*, Chapter 6 calls convergence in the sup metric uniform convergence (AN1.9).
3. **Quick check:** "In ℝ with the discrete metric, does (1/n) converge?" *Solution:* no: it is never eventually constant.
4. **`prp-metric-limit-basics`** `[Limits in a Metric Space]`: let (xₙ) be a sequence in (X, d). (a) It has at most one limit. (b) If it converges, the set {xₙ : n ≥ 1} is bounded (Chapter 3's definition: inside some ball). (c) If xₙ → x, every subsequence (`def-subsequence`, read in X) converges to x. (d) Changing finitely many terms changes neither convergence nor the limit. Proof: (a) d(x, y) ≤ d(x, xₙ) + d(xₙ, y) < 2ε for every ε > 0, and a number t ≥ 0 below every positive number is 0 (if t > 0, take ε = t; proved inline, since Chapter 1 has it only as an exercise); (b) the ball around x of radius 1 + max{d(x_k, x) : k < N} with N from ε = 1; (c) the same N, by `lem-subsequence-index`; (d) the max of the finitely many changed indices.
5. **Warning** `**Convergence depends on the space and on the metric.**` (ii) and (i) above, one sentence each.

**`## Closure and closed sets by sequences` (~1,300).**
1. Lead: Chapter 3 defined adherent points, closure, closed sets and accumulation points with balls; sequences give a second description, often easier to use (STYLE §4, H12).
2. **`thm-sequential-closure`** `[Closure by Sequences]`: let A ⊆ X and x ∈ X. Then x is an adherent point of A (x lies in the closure of A) if and only if some sequence of points of A converges to x.
   - **`[Scratch work]`** (one ball per n): (⇒) every ball B(x, 1/n) meets A; pick aₙ there; d(aₙ, x) < 1/n → 0. (⇐) every ball B(x, ε) contains some aₙ (indeed all late ones). Flag: picking one aₙ for each n is countable choice, one clause (STYLE §10).
   - Proof forward.
3. **`cor-closed-sequential`** `[Closed Sets Contain Their Limits]`: A is closed if and only if, whenever (aₙ) is a sequence in A converging to some x ∈ X, x ∈ A. Proof: Chapter 3's "closed ⇔ equal to its closure" and the theorem.
4. **`prp-accumulation-sequence`** `[Accumulation Points by Sequences]`: x is an accumulation point of A if and only if some sequence of points of A ∖ {x} converges to x, if and only if some sequence of **distinct** points of A converges to x. Proof: first ⇔ from the theorem applied to A ∖ {x}; for distinctness, choose radii rₖ ≔ min(1/k, d(a_{k−1}, x)) recursively (positive since a_{k−1} ≠ x); the converse is immediate. Aftermath: this is the bridge between Chapter 2's Bolzano–Weierstrass theorem for sets and `thm-bolzano-weierstrass-sequences`.

2. **`prp-metric-cauchy-basics`** `[Cauchy Sequences in a Metric Space]`: (a) convergent ⇒ Cauchy; (b) Cauchy ⇒ bounded; (c) Cauchy with a convergent subsequence ⇒ convergent, to the same limit. Proofs: (a) third point x, ε/2; (b) as `prp-metric-limit-basics` (b) with x_N in place of the limit; (c) "the proof of `lem-cauchy-subsequence`, with d(·, ·) in place of |· − ·|" (fading: no scratch).

- **`exr-sequences-in-metric-spaces-c1`** `[C1: Distances pass to the limit]`. (a) Prove that if xₙ → x and yₙ → y then d(xₙ, yₙ) → d(x, y). (b) Deduce that every closed ball B̄(x, r) = {y : d(x, y) ≤ r} is closed. *Solution:* (a) |d(xₙ, yₙ) − d(x, y)| ≤ d(xₙ, x) + d(yₙ, y) (two triangle inequalities); (b) `cor-closed-sequential` and laws (d).
- **`exr-sequences-in-metric-spaces-c2`** `[C2: Find the error]` (false conclusion). "Claim: in every metric space, every Cauchy sequence converges. 'Proof': (d(xₙ, x₁)) is a Cauchy sequence of reals (by C1's inequality), so it converges to some r (`thm-cauchy-criterion`). Let x be a point with d(x, x₁) = r. Then xₙ → x." *Solution:* conclusion false (S7). Two illegal steps: such an x need not exist, and even if it does, d(xₙ, x₁) → d(x, x₁) does not give xₙ → x. Counterexample to the first step: X = (0, 1], x₁ = 1, xₙ = 1/n, r = 1: no x ∈ (0, 1] has |x − 1| = 1. To the second: X = ℝ, x₁ = 0, xₙ = (−1)ⁿ for n ≥ 2: d(xₙ, x₁) = 1, and x = 1 has d(x, 0) = 1, yet xₙ does not converge to 1 (this sequence is not Cauchy, but the step itself made no use of Cauchy).
- **`exr-sequences-in-metric-spaces-c3`** `[C3: Sup metric versus pointwise]`. In B(S) with the sup metric, prove that fₙ → f implies fₙ(t) → f(t) for every t ∈ S, and show by `exm-metric-sequences` (iii) that the converse fails. *Solution:* |fₙ(t) − f(t)| ≤ d_∞(fₙ, f); the converse fails for tⁿ on [0, 1) with f = 0, and no other limit exists since it would have to equal the pointwise limit 0.

### 4.7 Sequences in Euclidean Space and in the Complex Plane (`07-sequences-in-euclidean-space.md`)

**Budget:** ≤ 5,000 (expected ~4,700). Quick checks 3, warnings 1, self-explain 1 (`thm-bolzano-weierstrass-rn`). R group here (STYLE §6, §11.5).

**Opening (~150).** In ℝⁿ with the Euclidean distance (F4.8, F4.11) the failures of Section 4.6 disappear: every Cauchy sequence converges and every bounded sequence has a convergent subsequence. The reason is that a point of ℝⁿ is n real numbers, and the order of ℝ comes back through the coordinates (STYLE §4, H15).

Notation: a sequence in ℝⁿ is (x_k)_{k≥1}, with coordinates x_k = (x_{k,1}, …, x_{k,n}); ‖·‖ the Euclidean norm, d(x, y) = ‖x − y‖ (NOTATION row, §5).

**`## Coordinates` (~1,200).**
1. **`lem-coordinate-bounds`** `[Coordinates and the Euclidean Norm]`: for x ∈ ℝⁿ and each i, |xᵢ| ≤ ‖x‖ ≤ Σ_j |x_j| ≤ n · max_j |x_j|. Proof: two lines, by squaring (‖x‖² = Σ x_j² ≤ (Σ |x_j|)²); F4.8/F4.11 compare d₁, d₂, d_∞ (pointer and ledger).
2. **`thm-coordinatewise-convergence`** `[Convergence in ℝⁿ Is Coordinatewise]`: x_k → x in ℝⁿ if and only if x_{k,i} → xᵢ for each i = 1, …, n; and (x_k) is Cauchy if and only if each coordinate sequence is Cauchy. The same holds for d₁ and d_∞. Proof: the lemma, and N ≔ the max of n thresholds (finitely many; H13).
3. **`cor-rn-cauchy-criterion`** `[Cauchy Criterion in ℝⁿ]`: every Cauchy sequence in ℝⁿ converges. Proof: coordinates and `thm-cauchy-criterion`. Aftermath: Chapter 5 will say "ℝⁿ is complete".
4. **`prp-rn-limit-laws`** `[Limit Laws in ℝⁿ]`: if x_k → x, y_k → y in ℝⁿ and t_k → t in ℝ, then x_k + y_k → x + y, t_k x_k → t x, ⟨x_k, y_k⟩ → ⟨x, y⟩ and ‖x_k‖ → ‖x‖. Proof: coordinates and `thm-real-limit-laws`; the norm by the reverse triangle inequality for ‖·‖ (F4.8; ledger).
5. **Quick check:** "Does x_k ≔ (k/(k + 1), 2^{−k}, (−1)^k/k) converge in ℝ³? To what?" *Solution:* (1, 0, 0), coordinatewise.

**`## Bolzano–Weierstrass in ℝⁿ` (~1,300).**
1. **`thm-bolzano-weierstrass-rn`** `[Bolzano–Weierstrass Theorem in ℝⁿ]`: every bounded sequence in ℝⁿ has a convergent subsequence.
   - **`[Scratch work]`** (extract, then extract again): bounded in ℝⁿ ⇒ each coordinate sequence bounded (lemma). By `thm-bolzano-weierstrass-sequences`, the first coordinates converge along some subsequence. Along it, the second coordinates are still bounded; extract again; the first coordinates still converge (`thm-subsequence-limit`). After n extractions, a subsequence of (x_k) (`lem-subsequence-of-subsequence`) along which every coordinate converges. Why not extract each coordinate separately? Because the n index sets need not share any index.
   - Proof: induction on the number of coordinates made to converge.
   - *Self-explain prompt:* "*Before reading on: where does the proof use that a subsequence of a convergent sequence converges to the same limit?*"
2. **`thm-closed-bounded-sequential`** `[Closed Bounded Sets in ℝⁿ]`: for K ⊆ ℝⁿ the following are equivalent: (a) K is closed and bounded; (b) every sequence in K has a subsequence converging to a point of K. Proof: (a ⇒ b) `thm-bolzano-weierstrass-rn` and `cor-closed-sequential`; (b ⇒ a) not bounded: ‖x_k‖ > k, and no subsequence is bounded, so none converges (`prp-metric-limit-basics` (b)); not closed: some sequence in K converges to x ∉ K (`cor-closed-sequential`), and all its subsequences converge to x (`prp-metric-limit-basics` (a), (c)).
   - Remark (prose pointers): Chapter 2 proved (a) ⇔ "every open cover has a finite subcover" (Heine–Borel); Chapter 8 shows that in every metric space "compact" ⇔ (b), and that (a) is not enough there: the closed unit ball of ℓ^∞ is closed and bounded and contains (eₖ) (S9; 4.7 C3).
3. **Quick check:** "Which of these sets K ⊆ ℝ² have property (b): the closed unit disc; the punctured disc 0 < x² + y² ≤ 1; the hyperbola xy = 1?" *Solution:* yes; no ((1/k, 0) → (0, 0) ∉ K); no (unbounded: (k, 1/k)).

**`## Sequences in the complex plane` (~900).**
1. ℂ is ℝ² with |z − w| as distance (F4.1: |z|² = (Re z)² + (Im z)²; prose pointer *Analytic Preliminaries*, Chapter 5). So z_k → z if and only if Re z_k → Re z and Im z_k → Im z, and every Cauchy sequence in ℂ converges (`thm-coordinatewise-convergence`, `cor-rn-cauchy-criterion`). Apostol 8.2's complex sequences, for CA.
2. **`prp-complex-limit-laws`** `[Limit Laws in ℂ]`: if z_k → z and w_k → w in ℂ, then z_k + w_k → z + w, z_k w_k → zw, and, if w ≠ 0 and w_k ≠ 0 for every k, z_k/w_k → z/w; also |z_k| → |z| and z̄_k → z̄. Proof: sums and conjugates coordinatewise; product by z_k w_k − zw = (z_k − z)w_k + z(w_k − w), |w_k| bounded, |uv| = |u||v| (F4.1; ledger); quotient via 1/w_k → 1/w with |w_k| ≥ |w|/2 eventually. "The proofs are F3.9's with |·| the complex modulus" is said in one sentence, but written out, since F3.9 is about ordered fields and ℂ is not one.
3. **`exm-complex-powers`** `[Powers of a Complex Number]`: (a) if |z| < 1 then z^k → 0 (|z^k| = |z|^k, `thm-standard-limits` (b)); (b) if |z| ≥ 1 and z ≠ 1 then (z^k) diverges. *Solution* (b), locate the missing limit: if z^k → L then z^{k+1} → L (re-indexing) and z^{k+1} = z·z^k → zL, so L = zL and L = 0 (z ≠ 1); but |z^k| = |z|^k ≥ 1, so |L| ≥ 1 (laws (d) on |z^k| → |L|), a contradiction. Row **S10**: for |z| = 1, z ≠ 1, the sequence is bounded and never settles. (No trigonometry is used.)
4. **Quick check:** "Does (i^k/k) converge? Does (i^k)?" *Solution:* yes, to 0 (|i^k/k| = 1/k); no, by (b).

'Proof': the first coordinates have a convergent subsequence (x_{n_k,1}) and the second coordinates have a convergent subsequence (x_{m_k,2}).
