The least upper bound axiom enters through Heine–Borel and Bolzano–Weierstrass (Chapters 2 and 4) and directly in the IVT. Chapter 10 shows that each of these theorems is equivalent to the axiom.

- **Named moves.**

  - **Compactness by contradiction.** Negate the uniform statement, choose a sequence of bad points with 1/k, extract a convergent subsequence, and contradict continuity at its limit.
  - **Extend by limits.** Define F(x) as lim f(dₖ) along dₖ → x, show the limit exists (Cauchy plus completeness) and does not depend on the sequence (interleave two sequences).
  - **Construct a point as a supremum** (from Chapter 1), now proving the IVT.
  - **A telescoping sum forces a sign change.** If g(x₀) + ⋯ + g(xₙ₋₁) = 0, the values cannot all be positive or all negative.

### 4.1 Section 7.1: Continuous Images of Compact Sets (`01-compact-images.md`)

**Budget:** ≤ 5,000 (expected ~4,500). Four Quick checks, two warnings, one Looking-ahead remark.

**Opening frame (~150, spiral rule STYLE §10).** Recall compactness from Chapter 2 (every open cover has a finite subcover; in ℝⁿ, compact ⇔ closed and bounded, by Heine–Borel). One sentence on what changes: compactness was a property of sets; now it is carried forward by continuous maps. Throughout, K ⊆ ℝⁿ carries the metric of ℝⁿ, and continuity on K is Chapter 6's continuity relative to the subspace K.

**`## Bounds that fail` (motivation, ~450).** Three functions, each failing to attain a supremum for a different reason, set out as a table to be completed by the section:
- 1/x on (0, 1]: continuous, unbounded; the domain is not closed.
- x/(1 + x) on [0, ∞): continuous, bounded, sup 1 not attained; the domain is not bounded.
- f(x) = x on [0, 1), f(1) = 0: bounded on a compact set, sup 1 not attained; f is not continuous at 1.

Then **`exm-unbounded-on-rationals`** `[Continuous and unbounded on a closed bounded subset of the rationals]`: on the metric space ℚ, the set A = ℚ ∩ [1, 2] is closed and bounded, and f(q) = 1/(q² − 2) is continuous on A and unbounded. *Solution:* q² ≠ 2 for q ∈ ℚ (`@fd1:thm-sqrt2-irrational`), so f is defined and continuous (Chapter 6: quotient of continuous functions with nonzero denominator). Unbounded: by `thm-rationals-dense` choose qₖ ∈ ℚ with √2 < qₖ < √2 + 1/k (and qₖ < 2). Then 0 < qₖ² − 2 = (qₖ − √2)(qₖ + √2) < 4/k, so f(qₖ) > k/4. Aftermath: A is closed and bounded in ℚ but not compact. The cover proof below breaks exactly where Heine–Borel would be used.

**Quick check:** "In which row of the table is the domain compact? What fails there?" *Solution:* the third: [0, 1] is compact, and continuity fails at 1.

**`## The image of a compact set` (~900).**
1. **`thm-continuous-image-compact`** `[Continuous Image of a Compact Set]`: "Let K ⊆ ℝⁿ be compact and f: K → ℝᵐ continuous. Then f(K) is compact."
2. **`[Scratch work]` (pull a cover back, ≤ 20 lines).** Goal: an arbitrary open cover {V_α} of f(K) has a finite subcover. The only thing known about K is covers, so make a cover of K out of the V_α. Preimages f⁻¹(V_α) are open *in K* (Chapter 6, preimage characterization relative to K): f⁻¹(V_α) = U_α ∩ K with U_α open in ℝⁿ (Chapter 3, relative openness). The U_α cover K, so finitely many U_{α₁}, …, U_{α_N} do. Push forward: every y ∈ f(K) is f(x) for some x in some U_{αᵢ} ∩ K, hence y ∈ V_{αᵢ}. "The proof writes this forwards."
3. **Proof** (8–10 lines) as in the Scratch Work. The first sentence: "Let {V_α : α ∈ A} be a family of open subsets of ℝᵐ whose union contains f(K)."
4. **Alternatively** (one paragraph, STYLE §4): by sequences. Given yₖ = f(xₖ), Bolzano–Weierstrass in ℝⁿ (Chapter 4) gives xₖⱼ → x ∈ K (K closed), and f(xₖⱼ) → f(x) ∈ f(K). This shows that f(K) is sequentially compact. Chapter 8 shows that for subsets of ℝᵐ (indeed of any metric space) this is the same as compact. The paragraph says only that much and does not use it.
5. **`cor-continuous-bounded-on-compact`**: f(K) is bounded (Heine–Borel). One line.
6. **Warning** `**Images, not preimages.**` "The preimage of a compact set need not be compact: the constant function 0 on ℝ has f⁻¹({0}) = ℝ. The image of a closed set need not be closed: 1/(1 + x²) maps the closed set ℝ onto (0, 1]."

**`## The extreme value theorem` (~700).**
1. **`thm-extreme-value`** `[Extreme Value Theorem]`: "Let K ⊆ ℝⁿ be non-empty and compact, and f: K → ℝ continuous. Then there are p, q ∈ K with f(p) ≤ f(x) ≤ f(q) for every x ∈ K."
2. Idea (3 lines): f(K) is compact, so closed and bounded. A non-empty closed bounded subset of ℝ contains its supremum, because sup approximation produces points of the set converging to the sup.
3. Proof: f(K) is non-empty and bounded above, so M = sup f(K) exists (`ax-least-upper-bound`). By `cor-sup-approximation` there are yₖ ∈ f(K) with M − 1/k < yₖ ≤ M, so yₖ → M. f(K) is closed (Heine–Borel), so M ∈ f(K) (Chapter 3, sequential description of closed sets), M = f(q). The minimum comes from −f.
4. Aftermath and the witness table completed: compactness dropped (rows 1–2), continuity dropped (row 3), ℚ in place of ℝ (`exm-unbounded-on-rationals`).
5. **Quick check** (weird example): "Does f(x) = x/(1 + x²) attain a maximum on ℝ? Does this contradict anything?" *Solution:* yes, ½ at x = 1, since 1 + x² − 2x = (x − 1)² ≥ 0. No contradiction: compactness is sufficient, not necessary.

**`## Compactness is exactly what is needed` (~550).**
1. **`thm-noncompact-witnesses`** `[Non-compact Sets Carry Bad Functions]`: "Let K ⊆ ℝⁿ be non-empty and not compact. Then (a) there is a continuous f: K → ℝ that is unbounded, and (b) there is a continuous g: K → ℝ that is bounded and attains no maximum."
2. **`[Scratch work]` (short, ≤ 10 lines; build a bad function from a missing point).** By Heine–Borel, K is not closed or not bounded. If it is not closed, some p ∉ K is a limit of points of K, and 1/‖x − p‖ blows up near p. If it is unbounded, ‖x‖ does. For (b), squash: t ↦ t/(1 + t) maps [0, ∞) into [0, 1) and keeps "gets arbitrarily close to the top".
3. Proof: (a) Case not closed: p ∈ closure of K, p ∉ K; f(x) = 1/‖x − p‖ is continuous on K and unbounded because points of K approach p. Case unbounded: f(x) = ‖x‖. (b) g = f/(1 + f) with f ≥ 0 from (a): 0 ≤ g < 1, and sup g = 1 since f takes arbitrarily large values; 1 is not attained.
4. **Quick check:** "For K = (0, 1] ∪ {2}, write down the functions the proof produces." *Solution:* p = 0: f(x) = 1/x, g(x) = 1/(1 + x).
5. Aftermath: together with `thm-extreme-value`, a subset of ℝⁿ is compact if and only if every continuous real function on it attains a maximum.

**`## Reducing to a compact set` (~700).**
1. **`exm-coercive-minimum`** `[A minimum on the whole line]`: "Show that p(x) = x⁴ − 3x + 1 attains a minimum on ℝ." *Solution:* for |x| ≥ 2, x⁴ = |x|³·|x| ≥ 8|x|, so p(x) ≥ 8|x| − 3|x| + 1 = 5|x| + 1 ≥ 11 > 1 = p(0). By `thm-extreme-value` p has a minimum point c on [−2, 2], and p(c) ≤ p(0) = 1 < p(x) for |x| ≥ 2. So p(c) is the minimum on ℝ. Aftermath names the move *Reduce to a compact set*.
2. **`exm-closest-point`** `[A closest point]`: "Let F ⊆ ℝⁿ be non-empty and closed, and p ∈ ℝⁿ. Show that some point of F is closest to p." *Solution:* pick a ∈ F, R = ‖p − a‖; F′ = F ∩ B̄(p, R) is closed and bounded, non-empty (a ∈ F′), so compact. x ↦ ‖x − p‖ is continuous (|‖x − p‖ − ‖y − p‖| ≤ ‖x − y‖, F4.8). Its minimum on F′ is at most R, and points of F ∖ F′ are at distance > R. Non-uniqueness: F = {−1, 1} ⊆ ℝ, p = 0. Necessity of closedness: F = (0, 1), p = 2.
3. **Quick check:** "Why can't the solution simply take the minimum of ‖x − p‖ over F?" *Solution:* F need not be bounded, hence not compact, so `thm-extreme-value` does not apply to F itself.

**`## Inverses of continuous bijections` (~650).**
1. Lead: a continuous bijection need not have a continuous inverse. **`exm-inverse-not-continuous`** `[A continuous bijection with a discontinuous inverse]`: A = [0, 1) ∪ [2, 3], f(x) = x on [0, 1), x − 1 on [2, 3]; f: A → [0, 2] is a continuous bijection, f⁻¹(1) = 2, but f⁻¹(1 − 1/k) = 1 − 1/k → 1 ≠ 2.
2. **`thm-compact-inverse-continuous`** `[Inverse on a Compact Set]`: "Let K ⊆ ℝⁿ be compact and f: K → ℝᵐ continuous and injective. Then the inverse f⁻¹: f(K) → K is continuous."
3. Idea (2 lines): continuity of f⁻¹ means that f maps sets closed in K to sets closed in f(K). A closed subset of a compact set is compact, and its image is compact, hence closed.
4. Proof (6 lines): C ⊆ K relatively closed ⇒ C closed in ℝⁿ (K closed) and bounded ⇒ compact ⇒ f(C) compact (`thm-continuous-image-compact`) ⇒ closed. (f⁻¹)⁻¹(C) = f(C). Preimage characterization with closed sets (Chapter 6).
5. **Looking ahead** remark: Chapter 8 proves these theorems with K any compact metric space. The proofs are the ones above, and the new work is to decide which metric spaces are compact.

### 4.2 Section 7.2: Uniform Continuity (`02-uniform-continuity.md`)

**Budget:** ≤ 5,000 (expected ~4,300). Five Quick checks, two warnings.

**Opening frame (~150).** Recall continuity on a set (Chapter 6), and the formula work of *Logic and Proof*, Chapter 6: there the order of ∃δ and ∀x was the whole difference (`@fd1:exm-square-not-uniform`). Now the difference gets a use.

**`## The tabulation problem` (failure first, ~600).**
1. A table of values of f at grid points x₀ < x₁ < ⋯ with spacing h gives f(x) to within ε for every x if |x − y| < h implies |f(x) − f(y)| < ε. For continuity, the δ may depend on x. A table needs one h for all x.
2. **`exm-reciprocal-not-uniform`** `[One spacing cannot serve 1/x]`: for f(x) = 1/x on (0, 1] and ε > 0, find the largest δ that works at x. *Solution:* for 0 < y < x, 1/y − 1/x < ε ⇔ y > x/(1 + εx). For y > x, 1/x − 1/y < 1/x − 1/(x + δ) is smaller, so the binding side is y < x, and δ(x) = x − x/(1 + εx) = εx²/(1 + εx). A three-row table for ε = 1: x = 1 gives ½; x = 0.1 gives 0.01/1.1 ≈ 0.0091; x = 0.01 gives 0.0001/1.01 ≈ 0.000099. δ(x) → 0 as x → 0, so no single spacing serves (0, 1]. Explicitly: xₖ = 1/k and yₖ = 1/(k + 1) satisfy |xₖ − yₖ| = 1/(k(k + 1)) → 0 and |f(xₖ) − f(yₖ)| = 1.
3. Lead to the definition: "We need a word for the functions that some table serves."

**`## The definition` (~900; major notion, all eleven steps of STYLE §3).**
1. **Slogan** (italics): *one δ serves every point.*
2. **`def-uniformly-continuous`** `[Uniformly Continuous]`: "Let (X, d) and (Y, ρ) be metric spaces. A map f: X → Y is **uniformly continuous** (on X) if **for every** ε > 0 **there exists** δ > 0 such that **for all** x, y ∈ X with d(x, y) < δ we have ρ(f(x), f(y)) < ε." In symbols: ∀ε > 0 ∃δ > 0 ∀x ∈ X ∀y ∈ X (d(x, y) < δ ⇒ ρ(f(x), f(y)) < ε). Then continuity on X in the same symbols, with ∀x moved in front of ∃δ. For a subset A ⊆ X, "uniformly continuous on A" means the restriction f|_A is uniformly continuous on the metric space A.
3. **Paraphrase** clause by clause. δ is chosen after ε and before x and y, so it may depend on ε and on f and A, never on the points.
4. **Examples:** (i) a constant map (any δ); (ii) f(x) = 3x + 1 on ℝ (δ = ε/3); (iii) the inclusion of a subspace, or any isometry (δ = ε); (iv) the degenerate case: on a set X with the discrete metric, every map is uniformly continuous with δ = 1 (pairs at distance < 1 coincide). Each is checked against the definition.
5. **Non-example by minimal change:** 1/x on (0, 1] (`exm-reciprocal-not-uniform`) against 1/x on [1/10, 1]: the same function with the domain moved away from 0, uniformly continuous with δ = ε/100 (|1/x − 1/y| = |x − y|/(xy) ≤ 100|x − y|). The clause that fails on (0, 1] is "there exists δ": every candidate δ is beaten by a pair near 0.
6. **`prp-uniform-implies-continuous`**: one line, citing `@fd1:exm-uniform-implies-continuous` for the formula version.
7. **Quick check (quantifier swap, STYLE §10):** "Move ∃δ in front of ∀ε in the definition. What does the new statement say about f: ℝ → ℝ?" *Solution:* there is one δ with ρ(f(x), f(y)) < ε for every ε whenever |x − y| < δ, i.e. f(x) = f(y) whenever |x − y| < δ. Then f is constant on ℝ, because any two points are joined by finitely many steps shorter than δ.
8. **Warning** `**The domain is part of the statement.**` "'x² is uniformly continuous' is neither true nor false until the domain is named: it is true on [0, 5] (|x² − y²| ≤ 10|x − y|) and false on ℝ (`@fd1:exm-square-not-uniform`)."
9. **Why this definition:** the tabulation problem, and the Looking-ahead that compact domains always allow a table (§7.3).

**`## Lipschitz functions` (~700).**
1. Failure motivation: proofs of uniform continuity need an explicit δ. If one constant bounds every difference quotient, δ = ε/L.
2. **`def-lipschitz`** `[Lipschitz]`: f: X → Y is **Lipschitz with constant L** (L ≥ 0) if ρ(f(x), f(y)) ≤ L·d(x, y) for all x, y ∈ X. (Minor auxiliary definition: steps 4, 7 and 8 only.)
3. **`prp-lipschitz-uniformly-continuous`**: Lipschitz ⇒ uniformly continuous (δ = ε/(L + 1), which covers L = 0).
4. **`exm-distance-to-set-lipschitz`** `[Distances are Lipschitz]`: in a metric space X, for a ∈ X and non-empty A ⊆ X, x ↦ d(x, a) and x ↦ dist(x, A) are Lipschitz with constant 1. *Solution:* triangle inequality, then inf over A. (If AN2.1 or F4.11 already defines dist(x, A), cite it; §8 item 4.)
5. **`exm-sqrt-uniform-not-lipschitz`** `[Uniformly continuous but not Lipschitz]`: √x on [0, ∞). *Solution:* for 0 ≤ y ≤ x, √x ≤ √y + √(x − y), since squaring gives x ≤ y + 2√(y(x − y)) + (x − y). So |√x − √y| ≤ √|x − y|, and δ = ε² works. It is not Lipschitz on [0, 1]: (√x − √0)/(x − 0) = 1/√x is unbounded as x → 0.
6. **Quick check:** "Find a Lipschitz constant for x³ on [−2, 2]." *Solution:* |x³ − y³| = |x − y|·|x² + xy + y²| ≤ 12|x − y|.

**`## Two sequences drifting together` (~800).**
1. **`thm-uniform-continuity-sequences`** `[Sequential Criterion for Uniform Continuity]`: "f: X → Y is **not** uniformly continuous if and only if there are ε > 0 and sequences (xₖ), (yₖ) in X with d(xₖ, yₖ) → 0 and ρ(f(xₖ), f(yₖ)) ≥ ε for every k."
2. **`[Scratch work]`** (≤ 20 lines). Negate the definition (*Logic and Proof*, Chapter 6; `@fd1:exm-not-uniform-derived`): ∃ε > 0 ∀δ > 0 ∃x, y (d(x, y) < δ ∧ ρ(f(x), f(y)) ≥ ε). Feed in δ = 1/k, one k at a time. Givens/Goal table in prose form:

   | Givens | Goal |
   |---|---|
   | f not uniformly continuous | ε > 0 and sequences with d(xₖ, yₖ) → 0, ρ(f(xₖ), f(yₖ)) ≥ ε |
   | some ε > 0 beats every δ | for each k, a pair at distance < 1/k with images ≥ ε apart |
   | δ = 1/k beaten by (xₖ, yₖ) | d(xₖ, yₖ) < 1/k → 0: the gap closes |

   The converse: given such sequences and any δ, some k has d(xₖ, yₖ) < δ, so δ fails for ε. "The proof writes this forwards."
3. **Proof** (8 lines). The choice of one pair for each k is a countable sequence of choices; one clause flags it (STYLE §10).
4. **`exm-zigzag-function`** `[The zigzag]`: define z on (0, 1] by z(1/k) = 1 for k ≥ 1, z(mₖ) = 0 at mₖ = ½(1/k + 1/(k + 1)), linear between consecutive points of 1 > m₁ > ½ > m₂ > ⅓ > ⋯. Show that z is continuous and bounded, and not uniformly continuous. *Solution:* continuous: near any x > 0, z is given by at most two linear pieces (x lies in some [1/(k + 1), 1/k]) that agree at their common point. Bounded: 0 ≤ z ≤ 1. Not uniformly continuous: xₖ = 1/k, yₖ = mₖ, d = 1/(2k(k + 1)) → 0, |z(xₖ) − z(yₖ)| = 1. A TikZ picture of the first five teeth (one idea per figure).
5. **Quick check:** "Is z uniformly continuous on [1/10, 1]?" *Solution:* yes: there it is made of finitely many linear pieces. Each piece has slope at most 2·10·11 = 220 in absolute value (rise 1 over run 1/(2k(k + 1)), k ≤ 10), so z is Lipschitz with constant 220 there. (Alternatively: §7.3.)

**`## Algebra of uniformly continuous maps` (~450).**
1. **`prp-uniform-continuity-algebra`**: (a) the composition of uniformly continuous maps is uniformly continuous; (b) for f, g: X → ℝᵐ uniformly continuous and c ∈ ℝ, f + g and cf are uniformly continuous. Proofs: (a) δ for ε/… chained; (b) ε/2 + ε/2.
2. **Warning** `**Products can fail.**` "f(x) = x is uniformly continuous on ℝ, but f·f = x² is not (`@fd1:exm-square-not-uniform`). The proof for sums has no analogue: |xy − x′y′| ≤ |x||y − y′| + |y′||x − x′| needs bounds on |x| and |y′|." (C2 of §7.4 proves the bounded case is fine.)
3. **Quick check:** "Every function f: ℕ → ℝ is uniformly continuous. Why?" *Solution:* take δ = ½: distinct natural numbers are at distance ≥ 1, so d(x, y) < ½ forces x = y.

**Exercises (7.2).**

(c) True or false, with a reason: every Lipschitz function is uniformly continuous; every uniformly continuous function on ℝ is bounded; the sum of two uniformly continuous functions on ℝ is uniformly continuous; their product is.   *Solution:* (a) ∃ε > 0 ∀δ > 0 ∃x, y ∈ A (|x − y| < δ ∧ |f(x) − f(y)| ≥ ε). (b) continuity at every point of A. (c) true (`prp-lipschitz-uniformly-continuous`); false (x); true (`prp-uniform-continuity-algebra`); false (x·x). (d) 10. (e) Two sequences drifting together.

If |x − y| < δ, then |√x − √y| = |x − y|/(√x + √y) ≤ |x − y|/√x < ε. Hence √x is uniformly continuous." Is the conclusion true? Does the argument prove it?

### 4.3 Section 7.3: Continuity on a Compact Set Is Uniform (`03-heine-cantor.md`)

**Budget:** ≤ 5,000 (expected ~4,200). Four Quick checks, one warning. **Key proof** (`thm-heine-cantor`), with a Try-it-first prompt and a self-explanation prompt.

**Opening frame (~200).** The tabulation problem again: on [1/10, 1] a table for 1/x exists, on (0, 1] none does. What did [1/10, 1] have? Compactness. The section's theorem: on a compact set, continuity is automatically uniform.

**`## The theorem` (~1,300).**
1. **`thm-heine-cantor`** `[Heine–Cantor Theorem]`: "Let K ⊆ ℝⁿ be compact, (Y, ρ) a metric space, and f: K → Y continuous. Then f is uniformly continuous on K."
2. *Try it first (ten minutes): suppose f is not uniformly continuous. What does the sequential criterion give you, and what does compactness let you do with it?*
3. **`[Scratch work]`** (compactness by contradiction, ≤ 20 lines). It starts from the obstacle the attempt meets: a direct proof must produce δ from the continuity δ(x) at each x, and the infimum of the δ(x) may be 0, as for 1/x. So argue by contradiction. Givens/Goal table:

   | Givens | Goal |
   |---|---|
   | f continuous on K, K compact, f not uniformly continuous | a contradiction |
   | ε > 0, xₖ, yₖ ∈ K, ‖xₖ − yₖ‖ → 0, ρ(f(xₖ), f(yₖ)) ≥ ε | a point where continuity fails |
   | xₖⱼ → x ∈ K (Bolzano–Weierstrass, K closed), yₖⱼ → x | f(xₖⱼ), f(yₖⱼ) → f(x): then ρ(f(xₖⱼ), f(yₖⱼ)) → 0, against ≥ ε |

   *Before reading on: where will closedness of K be used, and where boundedness?* (self-explanation prompt, STYLE §10).
4. **Proof** (10–12 lines). Bolzano–Weierstrass in ℝⁿ (Chapter 4) for boundedness; closedness for x ∈ K; continuity at x (sequential form, Chapter 6); the triangle inequality ρ(f(xₖⱼ), f(yₖⱼ)) ≤ ρ(f(xₖⱼ), f(x)) + ρ(f(x), f(yₖⱼ)).
5. **Alternatively** (one paragraph, the cover proof, Apostol's route): for each x ∈ K choose δₓ with ρ(f(x′), f(x)) < ε/2 when ‖x′ − x‖ < δₓ. The balls B(x, δₓ/2) cover K, and finitely many with centres x₁, …, x_N do. Then δ = min δₓᵢ/2 works: if ‖x − y‖ < δ and x ∈ B(xᵢ, δₓᵢ/2), then both x and y lie within δₓᵢ of xᵢ. The halving is the point of the argument. §7.3 C1 (b) asks for a third route, by the Lebesgue number.
6. Aftermath (2 sentences): neither proof computes δ. Compactness says one exists. When a δ is wanted, a Lipschitz bound gives it.

**`## Without compactness` (~600).**
1. **`prp-noncompact-not-uniform`** `[Bounded Non-compact Sets]`: "Let K ⊆ ℝⁿ be bounded and not compact. Then some continuous f: K → ℝ is not uniformly continuous."
2. Idea (2 lines, fading): K is not closed; take p in its closure, not in K, and f(x) = 1/‖x − p‖ (from `thm-noncompact-witnesses`); two sequences drifting together towards p.
3. Proof: choose xₖ ∈ K with xₖ → p, and for each k an index m(k) > k with ‖x_{m(k)} − p‖ ≤ ½‖xₖ − p‖. Then f(x_{m(k)}) ≥ 2f(xₖ), so f(x_{m(k)}) − f(xₖ) ≥ f(xₖ) ≥ 1 for k large (f(xₖ) → ∞), while ‖xₖ − x_{m(k)}‖ ≤ ‖xₖ − p‖ + ‖x_{m(k)} − p‖ → 0. Apply `thm-uniform-continuity-sequences`.
4. Aftermath: for bounded K ⊆ ℝⁿ, K is compact ⇔ every continuous real function on K is uniformly continuous.
5. **Quick check:** "Why does the proposition assume K bounded? Think of ℕ." *Solution:* ℕ is closed and unbounded, so not compact, yet every function on ℕ is uniformly continuous (δ = ½). Unbounded sets may or may not carry a bad function: on ℝ, x² is one.

**`## Tables and partitions` (~1,200).**
1. **`cor-small-oscillation-partition`** `[Small Oscillation on Small Pieces]`: "Let f: [a, b] → ℝ be continuous and ε > 0. There is N ≥ 1 such that, for the points xᵢ = a + i(b − a)/N, sup f − inf f < ε on each [xᵢ₋₁, xᵢ]." Proof: δ from `thm-heine-cantor`, N > (b − a)/δ. On each piece any two points are less than δ apart. By `thm-extreme-value` the sup and inf on the piece are values f(u), f(v), so sup − inf = |f(u) − f(v)| < ε. Aftermath: the strict inequality is where the EVT is used. Looking ahead (prose): *Integration, Series, and Function Spaces*, Chapter 2 turns this into "every continuous function on [a, b] is integrable".
2. **`thm-piecewise-linear-approximation`** `[Polygonal Approximation]`: "Let f: [a, b] → ℝ be continuous and ε > 0. There is a continuous g: [a, b] → ℝ, linear on each piece of some partition of [a, b] into equal pieces, with |f(x) − g(x)| < ε for all x ∈ [a, b]." Proof: take the partition of the corollary and g the interpolant of f at the xᵢ. On [xᵢ₋₁, xᵢ], g(x) = (1 − t)f(xᵢ₋₁) + t f(xᵢ) with t ∈ [0, 1], so |f(x) − g(x)| ≤ (1 − t)|f(x) − f(xᵢ₋₁)| + t|f(x) − f(xᵢ)| < ε. Looking ahead (prose): AN2.6 replaces g by a polynomial (Weierstrass).
3. **`exm-tabulating-a-root`** `[How many entries?]`: "How many equally spaced points of [0, 4] are needed so that every value √x, 0 ≤ x ≤ 4, is within 0.01 of the value at the nearest grid point to its left?" *Solution:* δ = ε² = 10⁻⁴ (`exm-sqrt-uniform-not-lipschitz`). Spacing 4/N < 10⁻⁴ needs N > 40,000. So N = 40,001 intervals, i.e. 40,002 points, will do. Aftermath: the tabulation problem of §7.2 is solved for every continuous function on a compact interval, though Heine–Cantor alone does not say how fine.
4. **Quick check:** "Does `cor-small-oscillation-partition` hold for the zigzag z on (0, 1], with (0, 1] cut into N equal pieces?" *Solution:* no: the first piece (0, 1/N] contains a full tooth, so sup − inf = 1 for every N.
5. **Warning** `**Heine–Cantor needs the whole set compact.**` "Continuity on each compact piece [1/k, 1] of (0, 1] gives a δₖ for each piece, but the δₖ may shrink to 0: for 1/x they must."

### 4.4 Section 7.4: Cauchy Sequences and Continuous Extension (`04-continuous-extension.md`)

**Budget:** ≤ 5,000 (expected ~3,900). Four Quick checks, one warning, one proof-ordering item (B1). **Key proof** (`thm-extension-uniformly-continuous`).

**Opening frame (~200).** Recall Cauchy sequences and completeness (Chapters 4–5), and density (Chapter 3). The question: a function known only on ℚ, or only on (0, 1), when does it have a continuous extension to ℝ, or to [0, 1]?

**`## A function on the rationals` (motivation, ~500).** **`exm-step-at-sqrt2`** `[Continuous on ℚ, with no continuous extension]`: s(q) = 0 for q ∈ ℚ with q < √2, s(q) = 1 for q > √2. *Solution:* s is continuous on ℚ: at q, δ = |q − √2| gives a neighbourhood in ℚ on which s is constant. It is not uniformly continuous on ℚ ∩ [1, 2]: by `thm-rationals-dense` there are rₖ < √2 < sₖ rational with sₖ − rₖ < 1/k. No continuous S: ℝ → ℝ extends it: S(√2) would be the limit of S(rₖ) = 0 and of S(sₖ) = 1. Aftermath: the obstruction is exactly a pair of sequences drifting together with images apart.

**`## Uniformly continuous maps preserve Cauchy sequences` (~600).**
1. **`thm-uniformly-continuous-cauchy`**: "If f: X → Y is uniformly continuous and (xₖ) is Cauchy in X, then (f(xₖ)) is Cauchy in Y." Proof (5 lines; δ before N).
2. **Warning** `**Continuity is not enough.**` "1/x on (0, 1] is continuous and maps the Cauchy sequence 1/k to k, which is not Cauchy."
3. **Quick check:** "x² on ℝ is not uniformly continuous. Does it map Cauchy sequences to Cauchy sequences?" *Solution:* yes: in ℝ a Cauchy sequence converges (Chapter 5), xₖ → x gives xₖ² → x², and convergent sequences are Cauchy. So the converse of the theorem fails.

**`## The extension theorem` (~1,500).**
1. **`prp-continuous-agree-on-dense`** `[Agreement on a Dense Set]`: "If F, G: X → Y are continuous and agree on a dense subset D of X, then F = G." Proof: x = lim dₖ, F(x) = lim F(dₖ) = lim G(dₖ) = G(x), by uniqueness of limits. (If AN2.1 or AN1.5 already proves it, cite it and drop the label; §8 item 5.)
2. **`thm-extension-uniformly-continuous`** `[Extension from a Dense Set]`: "Let D be dense in the metric space X, let Y be complete, and let f: D → Y be uniformly continuous. Then there is exactly one continuous F: X → Y with F = f on D, and F is uniformly continuous."
3. **`[Scratch work]`** (define by limits, then check, ≤ 20 lines). What must F(x) be? If F is continuous and dₖ → x with dₖ ∈ D, then F(x) = lim f(dₖ). So that is the definition, and three things need checking: (i) the limit exists (f(dₖ) is Cauchy by `thm-uniformly-continuous-cauchy`, Y complete); (ii) it does not depend on the sequence (interleave d₁, d₁′, d₂, d₂′, …: still → x, so its images converge, and two subsequences have the same limit); (iii) F = f on D (constant sequence) and F is uniformly continuous (pass to the limit in ρ(f(dₖ), f(dₖ′)) < ε/2, which gives ≤ ε/2 < ε). *Before reading on: which of (i)–(iii) uses completeness, and which uses uniform rather than plain continuity?*
4. **Proof** (Step 1–3 with Claims, 15–20 lines). Uniqueness by `prp-continuous-agree-on-dense`.
5. Aftermath: `exm-step-at-sqrt2` shows that uniform continuity cannot be weakened to continuity, and Y = ℚ shows completeness cannot be dropped (f = id on ℚ ⊆ ℝ into ℚ has no extension ℝ → ℚ). Looking ahead (prose): the same theorem extends integrals from step functions (MT) and bounded operators from dense subspaces (FA).
6. **Quick check:** "Where in the proof is it used that D is dense?" *Solution:* in choosing, for every x ∈ X, a sequence in D converging to x.

**`## Extension to the closure` (~900).**
1. **`cor-uniform-iff-extends-to-closure`** `[Uniform Continuity on Bounded Sets]`: "Let A ⊆ ℝⁿ be bounded and f: A → ℝᵐ continuous. Then f is uniformly continuous if and only if f extends to a continuous function on the closure of A." In particular, for A = (a, b) ⊆ ℝ: f is uniformly continuous ⇔ the one-sided limits of f at a and at b exist (Chapter 6). Proof: (⇒) the theorem, with X = closure of A and Y = ℝᵐ complete (Chapter 5). (⇐) the closure is closed and bounded, so compact, and Heine–Cantor applies to the extension. Restriction keeps uniform continuity.
2. **`cor-uniformly-continuous-bounded`**: a uniformly continuous function on a bounded A ⊆ ℝⁿ is bounded (its extension is bounded on a compact set).
3. **`exm-extension-tests`** `[Four functions on an interval]`: decide uniform continuity on (0, 1]: (a) x·z(x); (b) z(x); (c) (1 − √x)/(1 − x) on (0, 1); (d) 1/√x. *Solution:* (a) yes: |x z(x)| ≤ x → 0, so it extends by 0 to [0, 1]. (b) no: z(1/k) = 1 and z(mₖ) = 0, so z has no limit at 0. (c) yes: it equals 1/(1 + √x), which extends continuously to [0, 1] with values 1 and ½ at the ends. (d) no: unbounded (`cor-uniformly-continuous-bounded`).
4. **Quick check:** "Does the corollary apply to x² on ℝ?" *Solution:* no: ℝ is not bounded, and indeed x² is continuous on the closure ℝ without being uniformly continuous.
5. **Remark** (one sentence, the AN1.1 promise for aˣ): one could define 2ˣ for irrational x by extending r ↦ 2ʳ from the rationals in this way (C1). *Integration, Series, and Function Spaces*, Chapter 7 defines the exponential by a power series instead, and nothing in this book depends on C1.

### 4.5 Section 7.5: The Intermediate Value Theorem (`05-intermediate-values.md`)

**Budget:** ≤ 5,000 (expected ~4,600). Five Quick checks, two warnings, one Looking-ahead remark. **Key proof** (`lem-bolzano`).

**Opening frame (~200).** Recall the opening of Chapter 1: x² − 2 changes sign on [1, 2] and has no rational zero. Chapter 1 proved √2 exists, and the same supremum move proves the general theorem here.

**`## Gaps in the domain` (failure motivation, ~450).**
1. **`exm-gap-no-intermediate-value`** `[A domain with a gap]`: f = 0 on [0, 1], f = 1 on [2, 3]. f is continuous on [0, 1] ∪ [2, 3] and takes no value ½. Then f(x) = x² − 2 on ℚ ∩ [0, 2] recalled (gap in the number line).
2. **`def-interval`** `[Interval]`: "I ⊆ ℝ is an **interval** if for all x, y ∈ I and every t with x < t < y, t ∈ I." Slogan: *no gaps.* Minor-plus definition: steps 4, 7, 8, 10. Examples: [0, 1), ℝ, a singleton, ∅ (vacuous). Non-example by minimal change: [0, 1] ∪ [2, 3] (t = 1.5 fails).
3. **`prp-interval-classification`**: every interval is ∅, a singleton, or one of (a, b), [a, b), (a, b], [a, b], (a, ∞), [a, ∞), (−∞, b), (−∞, b], ℝ with a < b. Proof (8 lines): with a = inf I and b = sup I (where they exist), every t strictly between a and b lies in I by sup and inf approximation and betweenness. Which endpoints belong is the only choice. (If AN1.4 states this, cite it; §8 item 6.)
4. **Warning** `**Betweenness is all.**` "An interval need not be open, closed, bounded, or non-empty; ℚ ∩ [0, 1] is not one (t = √2/2)."

**`## Bolzano's theorem` (~1,200).**
1. **`lem-bolzano`** `[Bolzano's Theorem]`: "Let f: [a, b] → ℝ be continuous with f(a) < 0 < f(b). Then f(c) = 0 for some c ∈ (a, b)."
2. Idea (4 lines, faded; no Scratch Work): *construct a point as a supremum* (Chapter 1, `thm-sqrt2-exists`; Chapter 2's Heine–Borel). "Before reading on: which set S would you take?" Then S = {x ∈ [a, b] : f(x) < 0} and c = sup S. Rule out f(c) > 0 and f(c) < 0, each by the persistence of sign near c.
3. **Proof** (14–16 lines). *Sign persistence* as a Claim with its own proof: if f(c) ≠ 0, then with ε = |f(c)| continuity gives δ > 0 such that f has the sign of f(c) on (c − δ, c + δ) ∩ [a, b]. S is non-empty (a ∈ S) and bounded above by b, so **c = sup S exists by `ax-least-upper-bound`**. This is the only line that uses the axiom, and the proof says so in one clause. c ∈ [a, b]. *Case f(c) > 0:* c ≠ a; points of (c − δ, c] are not in S, and no point beyond c is, so max(a, c − δ/2) is an upper bound of S smaller than c, a contradiction. *Case f(c) < 0:* c ≠ b; c + δ/2 or b, whichever is smaller, lies in S and exceeds c, a contradiction. So f(c) = 0, and c ≠ a, b.
4. **Alternatively** (one paragraph): bisection with `thm-nested-intervals`, halving [aₖ, bₖ] while keeping f(aₖ) < 0 ≤ f(bₖ) (in the closed-up form). The common point c has f(c) ≤ 0 and f(c) ≥ 0 by continuity along aₖ → c and bₖ → c.
5. **`thm-intermediate-value`** `[Intermediate Value Theorem]`: "Let f: [a, b] → ℝ be continuous and y a number between f(a) and f(b). Then f(c) = y for some c ∈ [a, b]." Proof: the cases y = f(a), y = f(b) are trivial; otherwise apply `lem-bolzano` to f − y or y − f.
6. **Quick check (the trail, first payment):** "A continuous f on [0, 1] has f(0) = f(1). Show that f(x + ½) = f(x) for some x ∈ [0, ½]." *Solution:* g(x) = f(x + ½) − f(x) on [0, ½] has g(½) = f(1) − f(½) = −g(0). If g(0) = 0, take x = 0. Otherwise g changes sign, and `thm-intermediate-value` applies.
7. **`exm-bisection`** `[Locating a root]`: f(x) = x⁵ + x − 1 on [0, 1]. Five bisection steps, with exact values recorded in a sidecar: f(0) = −1, f(1) = 1, f(0.5) = −0.46875, f(0.75) ≈ −0.012695, f(0.875) ≈ 0.387909, f(0.8125) ≈ 0.166593, f(0.78125) ≈ 0.072288. The root lies in (0.75, 0.78125), an interval of length 1/32. After n steps the length is 2⁻ⁿ, so 20 steps give 10⁻⁶ (2²⁰ > 10⁶). The root is unique because f is strictly increasing.

**`## Images of intervals` (~900).**
1. **`cor-image-of-interval`** `[Continuous Image of an Interval]`: "If I is an interval and f: I → ℝ is continuous, then f(I) is an interval." Proof: y between f(u) and f(v) lies in f([u, v]) (or [v, u]) by `thm-intermediate-value`.
2. **`cor-image-closed-bounded-interval`**: f([a, b]) = [m, M], where m and M are the minimum and maximum (`thm-extreme-value` together with `cor-image-of-interval`).
3. **Quick check:** "Can a continuous function map [0, 1] onto (0, 1)? Onto ℝ? Can one map (0, 1) onto [0, 1]?" *Solution:* no, since the image is a closed bounded interval (`cor-image-closed-bounded-interval`); no, for the same reason; yes: f(x) = min(1, max(0, 3x − 1)) is continuous on (0, 1) (a composition of continuous functions), equals 0 on (0, ⅓], equals 1 on [⅔, 1), and takes every value in between, so f((0, 1)) = [0, 1].

**`## Three applications` (~900).**

### 4.6 Section 7.6: Inverse Functions and Horizontal Chords (`06-inverses-and-chords.md`)

**Budget:** ≤ 5,000 (expected ~4,400). Four Quick checks, one warning. Try-it-first on `thm-horizontal-chord`. The R group is here.

**Opening frame (~150).** Chapter 1 proved that n-th roots exist. Are they continuous functions of the number? More generally: when is the inverse of a continuous function continuous? On a compact set, §7.1 answered. On an interval, monotonicity answers.

**`## Continuous injections are monotone` (~900).**
1. **`thm-injective-continuous-monotone`** `[Continuous Injections on Intervals]`: "Let I be an interval and f: I → ℝ continuous and injective. Then f is strictly monotone."
2. **`[Scratch work]`** (move two points at once, ≤ 20 lines). If f is not strictly monotone, some pair x₁ < x₂ goes up (f(x₁) < f(x₂)) and some pair x₃ < x₄ goes down. Slide one pair into the other: for t ∈ [0, 1], u(t) = (1 − t)x₁ + t x₃ and v(t) = (1 − t)x₂ + t x₄. These stay in I (interval), and u(t) < v(t) for all t (a convex combination of two strict inequalities). h(t) = f(v(t)) − f(u(t)) is continuous, h(0) > 0 > h(1), so h(t₀) = 0 for some t₀ by the IVT. Then f(u(t₀)) = f(v(t₀)) with u(t₀) ≠ v(t₀), against injectivity. "The proof writes this forwards."
3. **Proof** (8 lines). The continuity of h comes from the composition of continuous maps (Chapter 6) and t ↦ (1 − t)x₁ + t x₃ being Lipschitz.
4. **Quick check:** "Find a continuous injective function on (0, 1) ∪ (1, 2) that is not monotone." *Solution:* f(x) = x on (0, 1), f(x) = 3 − x on (1, 2): images (0, 1) and (1, 2) are disjoint, so f is injective, while f increases on the first piece and decreases on the second.

**`## Monotone functions onto intervals` (~800).**
1. **`thm-monotone-interval-image-continuous`** `[Monotone with an Interval Image]`: "Let A ⊆ ℝ and f: A → ℝ be monotone with f(A) an interval. Then f is continuous." (The domain need not be an interval. This generality is what makes the inverse theorem work.)
2. Idea (3 lines): a monotone function can fail to be continuous only by a jump (Chapter 6). A jump leaves a gap in the image, and an interval has no gaps.
3. Proof (12 lines, f increasing). Suppose f is discontinuous at c ∈ A. Then for some ε > 0 there are points of A arbitrarily close to c on one side, say xₖ ↑ c, with f(xₖ) ≤ f(c) − ε. Monotonicity gives f(x) ≤ f(c) − ε for all x ∈ A with x < c, and f(x) ≥ f(c) for x ≥ c. So f(A) contains f(x₁) < f(c) − ε and f(c), and misses (f(c) − ε, f(c)), against betweenness. The other side is symmetric. (Written directly with ε, so it needs only monotonicity and not Chapter 6's one-sided-limit theorem. S3 may instead cite Chapter 6's jump classification when the domain is an interval.)
4. **Warning** `**The image, not the domain.**` "f(x) = x for x < 0 and f(x) = x + 1 for x ≥ 0 is strictly increasing on the interval ℝ and discontinuous at 0; its image (−∞, 0) ∪ [1, ∞) has a gap."

**`## The inverse function theorem for continuous functions` (~800).**
1. **`thm-continuous-inverse`** `[Continuous Inverse]`: "Let I be an interval and f: I → ℝ continuous and strictly monotone. Then J = f(I) is an interval, f: I → J is a bijection, and f⁻¹: J → I is continuous and strictly monotone in the same sense."
2. Proof (5 lines): J is an interval by `cor-image-of-interval`. f⁻¹ is strictly monotone (F4.7), and its image is I, an interval. Apply `thm-monotone-interval-image-continuous` to f⁻¹.
3. **`exm-root-functions-continuous`** `[Roots are continuous]`: x ↦ xⁿ is continuous and strictly increasing on [0, ∞) and unbounded, so its image is the interval [0, ∞) (`cor-image-of-interval`: it contains 0 and arbitrarily large values). This gives `thm-nth-root` a second proof, and x ↦ x^{1/n} is continuous on [0, ∞). For n odd, the same holds on ℝ.
4. **`exm-inverse-of-cubic`** `[The inverse of x³ + x]`: g(x) = x³ + x is continuous, strictly increasing (sum of strictly increasing functions), and unbounded in both directions, so g: ℝ → ℝ is a bijection with continuous inverse. g⁻¹(1) is the number Chapter 1's C4 of its last section located between 0.68 and 0.69 (prose mention only; text never cites an exercise in a proof).

- **R1.** "Let f(x) = x + ⌊x⌋ on [0, 3]. Find the one-sided limits of f at 1, 2 and 3, and classify each discontinuity." *Solution:* (Chapter 6's classification.) At 1: left limit 1, right limit and value 2, a jump. At 2: left 3, right and value 4, a jump. At 3: left limit 5, value 6, a jump from the left. f is increasing, so only jumps occur.

Not compact: 1/x is continuous and unbounded on it (`thm-noncompact-witnesses` in ℝ, or directly: the cover by the sets (1/k, 1] ∩ (0, ½], k ≥ 3, has no finite subcover).
