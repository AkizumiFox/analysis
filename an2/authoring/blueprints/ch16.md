## Chapter hook and where it is paid

**Hook (index.md, "Six sentences").** The index prints six sentences in a box. Each sounds true after a first calculus course:
1. A function that is continuous on a dense set, and integrable, behaves like a continuous function.
2. If f′ = 0 except on a set of measure zero, f is constant.
3. A bounded derivative can be integrated, so ∫ₐᵇ F′ = F(b) − F(a).
4. A continuous function is differentiable at some point.
5. A smooth function is determined, near a point, by its derivatives there.
6. A curve is one-dimensional: it cannot fill a square.

The reader marks each true or false before starting. Each is paid in one section (§01–§06, in that order). The **closing table** in §06 records the verdicts with their witnesses. Sentence 2 has a true repaired form, "countable" in place of "measure zero" (§02 C-exercise), and the table says so.

**Hooks this chapter opens** (prose pointers only, since nothing may depend on an optional chapter; the coordinator may add soft `see AN2.15` edges):
- Cantor function → MT.10 (absolute continuity; the Lebesgue FTC).
- Volterra → MT: the Lebesgue integral of V′ exists and equals V(1) − V(0). Also AN2.14, optional, in prose only.
- Space-filling curve → AM / MT: a C¹ curve has image of measure zero.

## 01-thomae-and-continuity-sets.md — Continuity on a dense set

**Budget:** ≤ 3,500 main-line words. **Breaks sentence 1.**

- **Hook (recall box).** AN1.5 proved that t (t(p/q) = 1/q in lowest terms with q ≥ 1, t(x) = 0 at irrationals, on [0, 1]) is continuous exactly at the irrationals. Two questions are new here: can it be integrated, and could the roles be swapped, with continuity exactly on ℚ?
- **`thm-thomae-integrable`.** t ∈ 𝓡[0, 1] and ∫₀¹ t = 0.
  - *Route 1:* the discontinuity set is ℚ ∩ [0, 1], which is countable, hence of measure zero. Apply the Lebesgue criterion (AN2.10).
  - *Route 2, direct (Darboux, AN1.8):* fix ε. Only finitely many x have t(x) ≥ ε/2, namely those with q ≤ 2/ε, say N of them. Choose a partition whose subintervals containing these points have total length ≤ ε/2. Then U(t, P) ≤ ε/2 · 1 + 1 · ε/2 = ε, and L(t, P) = 0 because irrationals are dense.
  - Give both routes. Route 2 is the worked proof, since it shows *why* the measure-zero bound works.
- **The FTC at a discontinuity.** F(x) = ∫₀ˣ t = 0 for all x, so F′ = 0 ≠ t at every rational. FTC part 1 gives F′(x) = f(x) only at continuity points (AN1.8), and here it fails exactly at the others.
- **`thm-composition-not-integrable`, with `exm-thomae-composition`.** Let g = 1_{(0,1]} on [0, 1], which is integrable with one discontinuity. Then g ∘ t = 1_ℚ on [0, 1], which is not integrable (AN1.8, Dirichlet). So **integrable ∘ integrable need not be integrable**. Remark: continuous ∘ integrable is integrable (cite AN2.10 if it proves this; otherwise state it with a pointer to the Lebesgue criterion and make it B3 below).
- **Failure-motivated definition: `def-g-delta-set`.**
  - The failure: "the continuity set of a function can be any set we like" sounds plausible, and t realizes the irrationals. To say which sets can occur, we need a name for their shape.
  - A G_δ set is a countable intersection of open sets. Give it in symbols. Examples: every open set, every closed subset of ℝ (∩ₙ {x : d(x, F) < 1/n}), and the irrationals (∩_q (ℝ ∖ {q})).
- **`thm-continuity-set-gdelta`.** For every f : ℝ → ℝ, C_f = ⋂ₙ {x : ω_f(x) < 1/n}, and each set in the intersection is open.
  - *Proof sketch:* if ω_f(x) < 1/n, some interval (x − δ, x + δ) has f-diameter < 1/n. Each point of that interval has a smaller interval inside it, so its oscillation is also < 1/n.
- **`thm-no-function-continuous-on-rationals`.** No f : ℝ → ℝ is continuous at exactly the rationals.
  - *Route:* suppose ℚ = ⋂ Uₙ with Uₙ open. Each Uₙ ⊇ ℚ is dense. The sets ℝ ∖ {q_k} are dense and open. All of them together form a countable family of dense open sets with empty intersection, which contradicts Baire (AN2.6, for the complete metric space ℝ).
  - This pays a promise AN1.5's old blueprint carried ("optional, via Baire"); see coordinator-notes.
- **Warning.** "Continuous on a dense set" says nothing about continuity elsewhere. 1_ℚ is continuous nowhere, and t is continuous on a dense set; the dense set alone does not decide.
- **Quick checks.**
  - (i) Is t continuous at 1/2? *No: t(1/2) = 1/2, and irrationals arbitrarily close give 0.*
  - (ii) Is [0, 1] a G_δ subset of ℝ? *Yes: it is closed, or directly ⋂ₙ (−1/n, 1 + 1/n).*
- **Exercises.**
  - **A1.** Compute U(t, P) for the uniform partition of [0, 1] into 4 pieces. *Answer: the subinterval sups are 1, 1/2, 1/2, 1 (the endpoints 0, 1/2 and 1 lie in them), so U = (1 + 1/2 + 1/2 + 1)/4 = 3/4.*
  - **A2.** List the x ∈ [0, 1] with t(x) ≥ 1/4. *Answer: 0, 1, 1/2, 1/3, 2/3, 1/4, 3/4; that is 7 points.*
  - **A3.** Write the irrationals in [0, 1] as an explicit countable intersection of relatively open sets. *Answer: ⋂_k ([0, 1] ∖ {q_k}) for an enumeration (q_k) of ℚ ∩ [0, 1].*
  - **B1.** Show that the modified function t₂(p/q) = 1/q², t₂ = 0 at irrationals, is also integrable with integral 0, by Route 2. *Answer: the points with t₂ ≥ ε/2 are those with q ≤ (2/ε)^{1/2}; the same partition argument applies.*
  - **B2.** Let f = 1_{[0,1/2]} on [0, 1]. Find C_f and write it as a G_δ in the form of `thm-continuity-set-gdelta`. *Answer: C_f = [0, 1] ∖ {1/2}; ω_f = 1 at 1/2 and 0 elsewhere, so every set {ω_f < 1/n} equals C_f, which is open in [0, 1].*
  - **B3.** Prove: if f ∈ 𝓡[a, b] and g is continuous on an interval containing f([a, b]), then g ∘ f ∈ 𝓡[a, b]. Use the Lebesgue criterion. *Answer: g ∘ f is bounded, and it is continuous wherever f is, so its discontinuity set lies inside that of f and has measure zero.*
  - **C1. Thomae is differentiable nowhere.**
    - (a) Show t is not differentiable at any rational.
    - (b) Dirichlet's approximation (prove it by pigeonhole on the fractional parts of 0, x, 2x, …, Qx): for irrational x there are infinitely many p/q with |x − p/q| < 1/q².
    - (c) Deduce that t is not differentiable at any irrational.
    - *Answer:* (a) t is discontinuous there. (c) Along irrationals the difference quotient is 0, so t′(x) would be 0. Along the approximants it is ≥ (1/q)/(1/q²) = q, and q is unbounded because the approximants are infinitely many distinct rationals.
  - **C2.** Let f equal t on (0, 1] and set f(0) = 0. Find C_f, and check directly that it is a G_δ subset of [0, 1]. *Answer: C_f = ([0, 1] ∖ ℚ) ∪ {0}. f is continuous at 0 because t(x) → 0 as x → 0 (only finitely many x have t(x) ≥ ε); nothing changes at the other points. C_f = ⋂_k ([0, 1] ∖ {q_k}) over an enumeration (q_k) of ℚ ∩ (0, 1].*

## 02-the-cantor-function.md — The Cantor function

**Budget:** ≤ 4,500 main-line words. **Breaks sentence 2.** Pays AN1.4 (first half).

- **Hook.** The Cantor set C has measure zero (AN1.4, AN2.10). Can a continuous function climb from 0 to 1 while increasing only on C?
- **Construction, `thm-cantor-function`.** Let X = {f ∈ C[0, 1] : f(0) = 0, f(1) = 1}, a closed subset of the complete space C[0, 1] (AN1.9). Define
  - (Kf)(x) = f(3x)/2 on [0, 1/3],
  - (Kf)(x) = 1/2 on [1/3, 2/3],
  - (Kf)(x) = 1/2 + f(3x − 2)/2 on [2/3, 1].
  - K maps X to X (check the joins at 1/3 and 2/3) and ‖Kf − Kg‖_∞ = ½‖f − g‖_∞. By Banach (AN2.2) there is a unique fixed point φ, the **Cantor function**. This reprises AN2.2's fixed point in a function space.
  - The nondecreasing members of X form a closed K-invariant subset, so φ is nondecreasing (start the iteration at f₀(x) = x).
  - **Proof Idea only** (Scratch Work halved): "the picture says what φ must do on each third; write that down as an equation φ = Kφ."
  - **Digit formula:** for x = Σ d_k 3^{−k} ∈ C with d_k ∈ {0, 2} (unique on C), φ(x) = Σ (d_k/2) 2^{−k}. Prove it from φ = Kφ by induction on the number of digits plus continuity.
- **Worked example `exm-cantor-values`:** φ(1/4) = 1/3, since 1/4 = 0.0202…₃ and so φ(1/4) = 0.0101…₂. Then φ(3/4) = 2/3 by the symmetry φ(1 − x) = 1 − φ(x), which comes from the uniqueness of the fixed point.
- **Properties:**
  - continuous, nondecreasing, φ([0, 1]) = [0, 1] (IVT);
  - constant on each removed interval, so φ′ = 0 on [0, 1] ∖ C;
  - φ(C) = [0, 1]: φ maps the complement onto a countable set of dyadic rationals, and those values are also taken at endpoints in C.
  - **AN1.4 hook paid:** a set of measure zero maps continuously onto an interval. "Small" in length is not "small" in size.
- **Failure-motivated definition: `def-singular-function`.**
  - The failure: sentence 2. The MVT needs a derivative at **every** point, and φ lacks one only on a null set, yet φ(1) − φ(0) = 1.
  - Definition: f : [a, b] → ℝ is **singular** if it is continuous, nondecreasing and nonconstant, and f′(x) = 0 for every x outside some set of measure zero.
  - `thm-cantor-function-singular`: φ is singular.
- **BV and length (AN2.9):**
  - V₀¹(φ) = 1, since φ is monotone.
  - **`thm-cantor-graph-length`.** The graph x ↦ (x, φ(x)) has length exactly 2.
  - *Upper bound:* length ≤ V(x) + V(φ) = 1 + 1 (AN2.9).
  - *Lower bound:* take the partition by the endpoints of the stage-n removed intervals. The horizontal pieces have total length 1 − (2/3)ⁿ. The 2ⁿ remaining pieces each rise 2^{−n}, so each has length ≥ 2^{−n}, contributing ≥ 1. Let n → ∞.
  - Remark: a graph that is flat "almost everywhere" is as long as the L-shaped path.
- **Stieltjes integrals (AN2.10), `thm-cantor-moments`:** ∫₀¹ x dφ = 1/2 and ∫₀¹ x² dφ = 3/8.
  - *Route:* split at 1/3 and 2/3; on [1/3, 2/3] the integrator is constant. The self-similarity identities are ∫₀^{1/3} f(x) dφ(x) = ½∫₀¹ f(u/3) dφ(u) and the analogue on [2/3, 1]. Prove them by matching Riemann–Stieltjes sums for corresponding partitions, or by AN2.10's change of variable.
  - With m_k = ∫ x^k dφ: m₁ = ½(m₁/3) + ½(2/3 + m₁/3) gives m₁ = 1/2. Likewise m₂ = m₂/9 + 2/9 + 1/9 gives m₂ = 3/8.
  - Cross-check m₁ by integration by parts: ∫ x dφ = 1 − ∫₀¹ φ dx = 1 − 1/2.
  - **Scratch Work** (first appearance of the self-similarity equation): write the unknown on both sides, then solve. Keep it apart from the proof.
- **Weird example `exm-cantor-plus-identity`.** ψ(x) = x + φ(x) is a strictly increasing homeomorphism [0, 1] → [0, 2]. It maps each removed interval onto an interval of the same length, so ψ([0, 1] ∖ C) has total length 1 and ψ(C) is a set of positive length. **Homeomorphisms need not preserve measure zero.** (C-exercise C2 below fills in the details.)
- **Warning.** φ is continuous and BV, but ∫₀¹ φ′ (over [0, 1] ∖ C, where φ′ = 0) ≠ φ(1) − φ(0). FTC part 2 needs F′ at every point and integrable (AN1.8). Pointer: MT.10 names the missing property (absolute continuity).
- **Quick checks.**
  - (i) φ(7/9)? *3/4: φ(7/9) = 1/2 + φ(1/3)/2 = 1/2 + 1/4.*
  - (ii) Is φ Lipschitz? *No: φ(3^{−n}) = 2^{−n}, and the ratio (3/2)ⁿ is unbounded.*
- **Exercises.**
  - **A1.** Compute φ(1/9), φ(2/9) and φ(1/10). *Answer: 1/4, 1/4, and 1/10 = 0.00220022…₃, so φ = 0.00110011…₂ = 3/15 = 1/5.*
  - **A2.** On which removed interval is φ = 5/8? *Answer: 5/8 = 0.101₂, so the ternary digits are 2, 0 and then the middle digit 1: the stage-3 interval (0.201₃, 0.202₃) = (19/27, 20/27).*
  - **A3.** Compute ∫₀¹ φ(x) dx. *Answer: 1/2, by φ(1 − x) = 1 − φ(x).*
  - **B1.** Prove the symmetry φ(1 − x) = 1 − φ(x) from the uniqueness of the fixed point. *Answer: f(x) = 1 − φ(1 − x) lies in X and Kf = f; check each third.*
  - **B2.** Show that φ is Hölder: |φ(x) − φ(y)| ≤ 2|x − y|^{α} with α = log 2/log 3. *Answer: let x < y and choose n ≥ 0 with 3^{−n−1} ≤ y − x < 3^{−n}. The gaps between stage-n intervals have length ≥ 3^{−n}, so [x, y] contains no whole gap and meets at most one stage-n interval in more than a point. φ rises by 2^{−n} across a stage-n interval and is constant on gaps, so φ(y) − φ(x) ≤ 2^{−n} = 2(3^{−n−1})^{α} ≤ 2(y − x)^{α}, using 3^{α} = 2.*
  - **B3.** Compute ∫₀¹ x³ dφ. *Answer: by self-similarity, m₃ = m₃/27 + ½ Σ_{j=0}^{3} C(3, j)(2/3)^{3−j}(1/3)^{j} m_j with m₀ = 1. This gives m₃ = 5/16.* S2a verifies the value numerically.
  - **C1. The repaired sentence 2** (construct a point as a sup, faded: the last step is left blank). Let f be continuous on [a, b], and let f′(x) = 0 for every x outside a countable set E = {e₁, e₂, …}. Show f is constant.
    - Hint: fix ε. Let S be the set of x such that f(y) − f(a) ≤ ε(y − a) + ε Σ_{e_k<y} 2^{−k} for all y ∈ [a, x]. Show sup S = b.
    - *Answer:* the right side is nondecreasing and left-continuous, so s = sup S belongs to S. If s < b and s ∉ E, use f′(s) = 0. If s = e_k, use continuity and the jump ε2^{−k} that e_k adds once y > s. Either way the inequality extends beyond s, a contradiction. So f(b) − f(a) ≤ ε(b − a + 1); apply the same to −f and to subintervals.
    - Then state: φ shows "countable" cannot be weakened to "measure zero".
  - **C2.** Prove the claims of `exm-cantor-plus-identity`. Then deduce that ψ(C) does not have measure zero. *Answer: ψ is continuous and strictly increasing, and on a removed interval (a, b) it is x + const, so lengths are preserved. ## 03-volterra.md — A bounded derivative that cannot be integrated

**Budget:** ≤ 4,500 main-line words. **Breaks sentence 3.** Pays AN1.8's statement-only Volterra example.

- **Hook.** AN1.8 stated that FTC part 2 needs F′ integrable, and named Volterra's function as the witness without proof. Here is the proof.
- **Fat Cantor set K.**
  - At stage n ≥ 1, remove the open middle interval of length 4^{−n} from each of the 2^{n−1} remaining closed intervals. (Each remaining interval has length > 2^{−n−1} ≥ 4^{−n}, so this fits.)
  - The removed length is Σ 2^{n−1}4^{−n} = 1/2. K is compact and nowhere dense, and contains no interval.
  - If AN1.4 already built K, cite it and keep only the lemma.
  - **`lem-fat-cantor-not-null`.** K does not have measure zero. *Route:* suppose open intervals of total length < 1/2 cover K. Take a finite subcover. Add the removed intervals and extract a finite subcover of [0, 1]; its total length is < 1. This contradicts the covering lemma (finitely many open intervals covering [a, b] have total length > b − a), which AN2.10 has; if it does not, prove it here by induction on the number of intervals.
- **The local pathology.** g(u) = u² sin(1/u), g(0) = 0, has g′(u) = 2u sin(1/u) − cos(1/u) for u ≠ 0 and g′(0) = 0 (AN1.7). g′ is bounded near 0 but takes the values ±1 at u = 1/(kπ), arbitrarily close to 0.
- **Scratch Work** (first appearance of *transplanting*). We want the bad point 0 copied to every point of K. K has no interior, so put copies at the endpoints of each gap, joined smoothly in the middle. The join must have zero slope; pick it at a zero of g′.
- **`exm-volterra-transplant`, the construction.**
  - For a gap (a, b) of length ℓ, let c = c(ℓ) be the largest zero of g′ in (0, ℓ/2]. It exists: zeros of g′ accumulate at 0 by the IVT between consecutive 1/(kπ), and the supremum of the zero set is a zero by continuity.
  - Define h on (a, b): g(y − a) on (a, a + c]; g(c) on [a + c, b − c]; g(b − y) on [b − c, b).
  - Set V = h on each gap and V = 0 on K.
- **`thm-volterra`.** V is differentiable at every point of [0, 1], |V′| ≤ 2, V′ is discontinuous at every point of K, and V′ ∉ 𝓡[0, 1].
  - *Route:*
    - (i) On gaps, h is differentiable, and the joins match because g′(c) = 0.
    - (ii) |V(y)| ≤ dist(y, K)² everywhere: |g(u)| ≤ u², and the middle constant satisfies |g(c)| ≤ c². Gap endpoints lie in K. So for x ∈ K, |V(y) − V(x)| ≤ |y − x|², which gives V′(x) = 0.
    - (iii) |g′(u)| ≤ 2|u| + 1 ≤ 2 for |u| ≤ 1/8; gaps have length ≤ 1/4.
    - (iv) At a gap endpoint a, V′(a) = 0, but V′ takes the values ±1 on points y ↓ a. Every x ∈ K is a limit of gap endpoints, since K is nowhere dense. So ω_{V′}(x) ≥ 2 on K.
    - (v) K is not measure zero, so the Lebesgue criterion (AN2.10) gives V′ ∉ 𝓡.
- **Consequences, prose:**
  - FTC part 2's hypothesis "F′ ∈ 𝓡" cannot be dropped, even for bounded F′.
  - V′ still has the intermediate value property (Darboux, AN1.7): a derivative can be very discontinuous and still have no jumps.
  - Pointers: the Lebesgue integral of V′ exists and equals V(1) − V(0) (MT). The gauge integral handles it too (AN2.14, optional; prose only).
- **Warning.** Building V on the ordinary Cantor set gives a function whose derivative **is** integrable, since its discontinuity set has measure zero. The fat set is essential.
- **Quick checks.**
  - (i) Why do we need g′(c) = 0 at the join? *Otherwise h′ jumps from g′(c) to 0 at a + c, and h is not differentiable there. (It is still continuous.)*
  - (ii) Is V′ continuous at points of the gaps? *Yes: on each gap, V′ is continuous (h is C¹ off the joins and the joins match).*
- **Exercises.**
  - **A1.** Compute the lengths of the stage-1 and stage-2 intervals that remain. *Answer: stage 1 leaves [0, 3/8] and [5/8, 1], each of length 3/8. Stage 2 removes 1/16 from each, leaving four intervals of length (3/8 − 1/16)/2 = 5/32.*
  - **A2.** Evaluate g′(1/(kπ)). *Answer: −cos(kπ) = (−1)^{k+1}.*
  - **B1.** Show that the derivative of G(x) = x² sin(1/x²), G(0) = 0, exists everywhere and is unbounded on [−1, 1]. Hence G′ ∉ 𝓡[−1, 1], yet G′ has only one discontinuity. *Answer: G′(x) = 2x sin(1/x²) − (2/x)cos(1/x²) for x ≠ 0 and G′(0) = 0; at x = 1/√(2kπ), |G′| = 2√(2kπ).* Contrast this with V: here non-integrability comes from unboundedness, there from a large discontinuity set.
  - **B2.** Show directly that any x ∈ K is a limit of gap endpoints. *Answer: every interval around x contains a point not in K (K has no interior), hence meets a gap (a, b); since x ∉ (a, b), the endpoint between x and that point lies in the interval.*
  - **C1.** Modify the construction to produce F differentiable on [0, 1] with F′ bounded and discontinuous exactly on K. *Answer: V itself does this. V′ is continuous on gaps, so the discontinuity set is exactly K.* Then prove that a derivative's discontinuity set can never be all of [0, 1]. (Hint: derivatives are pointwise limits of continuous difference quotients. Cite AN2.6's Baire-class remark if present; otherwise this part is starred and statement-only.)
  - **C2.** Prove the covering lemma used in `lem-fat-cantor-not-null` by induction on the number of intervals. *Answer: an interval containing a has the form (c, d) with c < a. Remove it and apply induction to [d, b], or stop if d > b.*

## 04-nowhere-differentiable.md — Continuous everywhere, differentiable nowhere

**Budget:** ≤ 4,500 main-line words. **Breaks sentence 4.** Pays AN1.7's hook.

- **Hook (recall).** AN1.7 asked whether a continuous function must be differentiable somewhere, and every example so far failed at isolated points (|x|, x sin(1/x)). AN1.9 built T with the M-test and proved it continuous. Here is the proof that T has no derivative anywhere.
- **The function.** s(x) = dist(x, ℤ). T(x) = Σ_{n≥0} 2^{−n} s(2ⁿx). It is continuous by the M-test (AN1.9).
- **`exm-takagi-values`.** T(1/2) = 1/2, T(1/4) = 1/2, T(1/3) = 2/3 (every term equals 1/3 · 2^{−n}).
- **`lem-straddling-chords`.** Suppose f′(x) exists and uₘ ≤ x ≤ vₘ, uₘ < vₘ, vₘ − uₘ → 0. Then (f(vₘ) − f(uₘ))/(vₘ − uₘ) → f′(x). Endpoints equal to x are allowed.
  - *Route:* the chord slope is a convex combination λQ(vₘ) + (1 − λ)Q(uₘ) of difference quotients at x, with λ = (vₘ − x)/(vₘ − uₘ). Treat a degenerate side separately.
  - Warning: the lemma fails for chords that do not straddle x (f(x) = x² sin(1/x) at 0, with chords [1/((2k+1)π), 1/(2kπ)]). Its converse is false too.
- **Scratch Work** (first appearance of straddling chords; one of AN2's halved set). Chord slopes over dyadic intervals are easy to compute, because the high-frequency terms vanish at dyadic endpoints. So straddle x with dyadic intervals.
- **`lem-takagi-dyadic-slopes`.** On J = [k2^{−m}, (k+1)2^{−m}]:
  - terms with n ≥ m vanish at both endpoints;
  - each term with n < m is linear on J with slope ±1;
  - so the chord slope of T over J is an integer σ(J) ≡ m (mod 2).
  - Moreover, the left half of J has slope σ(J) + 1 and the right half σ(J) − 1.
- **`thm-takagi-nowhere-differentiable`.** *Route:* for each x choose the level-m dyadic interval Jₘ ∋ x. The slopes σ(Jₘ) are integers whose parity alternates with m, so they do not converge. By `lem-straddling-chords`, T′(x) does not exist. This is the worked, full version of the move.
- **`thm-takagi-nowhere-monotone`.** T is monotone on no interval. *Route:* any interval contains some J. Going down the left-most branch d levels gives slope σ(J) + d, and the right-most gives σ(J) − d. For d > |σ(J)| these have opposite signs.
- **Typical, not rare.** AN2.6 shows the nowhere-differentiable functions form a comeager subset of C[0, 1]. State the result and point to it; do not re-prove it.
- **Remark.** Weierstrass's original cosine series Σ aⁿ cos(bⁿπx) also works under conditions on a and b; statement only, no proof claimed.
- **Remark (AN2.9).** T is not BV on any interval (C1 below), so its graph over any interval is not rectifiable.
- **Quick checks.**
  - (i) What is σ([0, 1/2])? *+1: only the n = 0 term counts, with slope +1 on [0, 1/2]. Check with T(0) = 0 and T(1/2) = 1/2.*
  - (ii) Swap the quantifiers: "for every x there is a sequence of straddling chords whose slopes diverge" versus "there is a sequence of chords such that for every x…". *Only the first is proved and only the first is needed.*
- **Exercises** (fading, halved: full in the text, last step blank in B2, last half blank in C2).
  - **A1.** Compute T(1/8) and T(3/8). *Answer: T(1/8) = 1/8 + 1/8 + 1/8 = 3/8. T(3/8) = 3/8 + (1/2)(1/4) + (1/4)(1/2) = 5/8.*
  - **A2.** Compute σ([1/4, 1/2]). *Answer: (T(1/2) − T(1/4))/(1/4) = 0, which has the parity of m = 2.*
  - **B1.** Show that T(x) ≤ 2/3 for all x, with equality at x = 1/3. *Answer: the value at 1/3 is from `exm-takagi-values`. For the bound, group the terms in pairs: T(x) = Σ_{j≥0} 4^{−j}[s(y_j) + s(2y_j)/2] with y_j = 4^{j}x. By periodicity and the symmetry s(−y) = s(y), take y ∈ [0, 1/2]. On [0, 1/4] the bracket is 2y ≤ 1/2; on [1/4, 1/2] it is y + (1 − 2y)/2 = 1/2. So T ≤ Σ_j 4^{−j}/2 = 2/3.* (A first attempt via T(x) = s(x) + T(2x)/2 gives only M ≤ 1/2 + M/2, i.e. M ≤ 1; the text may show that attempt as the reason for pairing.)
  - **B2. Faded.** For F(x) = Σ_{n≥0} 4^{−n} s(4ⁿx): (a) show that chord slopes over 4-adic intervals of level m are sums of m terms ±1; (b) *Name the move, then complete it.* *Answer: (b) straddling chords plus parity; F is nowhere differentiable.*
  - **C1. Infinite variation.** Show V(T; J) = ∞ for every dyadic J.
    - Hint: at depth d, the 2^d sub-intervals carry slopes σ(J) + W over all ±1 sequences of length d. So Σ|ΔT| = 2^{−m} E|σ + W_d|, where W_d is the simple random walk sum.
    - Use E|σ + W| ≥ E|W| (symmetry and |w + σ| + |w − σ| ≥ 2|w|) and the Hölder bound E|W| ≥ (EW²)^{3/2}/(EW⁴)^{1/2} with EW² = d and EW⁴ = 3d² − 2d.
    - *Answer:* Σ ≥ 2^{−m}√(d/3) → ∞.
  - **C2. Faded (last half blank).** Prove that Σ_{n≥0} 2^{−n} s(4ⁿx) is continuous; then *name the move, then complete it* to show it is nowhere differentiable, by computing chord slopes over 4-adic intervals of level m. *Answer: on a level-m 4-adic interval J ∋ x (length 4^{−m}), each term with n < m is linear on J with slope ±2^{−n}4ⁿ = ±2ⁿ, and each term with n ≥ m vanishes at both endpoints. So the chord slope over level m is σₘ = Σ_{n<m} ±2ⁿ, and |σ_{m+1} − σₘ| = 2^{m}. The slopes are not Cauchy, so by straddling chords there is no derivative at x.*

## 05-flat-functions.md — Smooth but invisible to Taylor

**Budget:** ≤ 3,500 main-line words. **Breaks sentence 5.**

- **Hook (recall).** AN1.10 proved that E(x) = e^{−1/x} (x > 0), E = 0 (x ≤ 0), is C^∞ with every derivative 0 at 0. Its Taylor series at 0 converges, to the wrong function. How much freedom does this give?
- **Failure-motivated definition: `def-flat-function`.** The failure: the Taylor series of E at 0 is 0, yet E ≠ 0 near 0. A C^∞ function is **flat at a** if f^{(k)}(a) = 0 for all k.
- **`lem-smooth-step`, with `exm-plateau-bump`.**
  - S(x) = E(x)/(E(x) + E(1 − x)) is C^∞, equals 0 for x ≤ 0 and 1 for x ≥ 1. The denominator is never 0.
  - β(x) = S(2 + x)S(2 − x) is C^∞, equals 1 on [−1, 1] and 0 outside (−2, 2).
  - Worked check: for |x| ≤ 1 both arguments are ≥ 1; for x ≥ 2 the second argument is ≤ 0.
- **Smooth gluing (statement + B1).** Given smooth f, g on ℝ, there is a smooth function equal to f on (−∞, 0] and to g on [1, ∞): (1 − S)f + Sg.
- **Proof Idea, then proof, `thm-borel-sequence`.** For every real sequence (aₙ) there is f ∈ C^∞(ℝ) with f^{(n)}(0) = aₙ for all n.
  - *Route:* gₙ(x) = (aₙ/n!) xⁿ β(x/εₙ). For k < n, the product rule gives ‖gₙ^{(k)}‖_∞ ≤ |aₙ| M_{n,k} εₙ^{n−k}, where M_{n,k} depends only on n, k and β (support |x| ≤ 2εₙ).
  - Choose εₙ ∈ (0, 1] with |aₙ| M_{n,k} εₙ ≤ 2^{−n} for all k < n.
  - For each k, Σ_{n>k} gₙ^{(k)} converges uniformly by the M-test. Term-by-term differentiation (AN1.9), applied k times, makes f = Σ gₙ C^∞, with f^{(k)}(0) = Σₙ gₙ^{(k)}(0) = a_k, since gₙ = (aₙ/n!)xⁿ near 0.
  - **Scratch Work** (first appearance of *shrinking supports*, counted in the halved set): first see why the naive Σ aₙxⁿ/n! fails (radius of convergence 0), then cure each term by cutting it off.
- **`cor-taylor-radius-zero`.** There is a C^∞ function whose Taylor series at 0 has radius of convergence 0. *Route:* take aₙ = (n!)², so the coefficients are n!; ratio test (AN1.3).
- **Weird examples for the table:** a nonzero flat function (E); a smooth function with divergent Taylor series (the corollary). Remark, statement only: there are C^∞ functions analytic at no point (no proof is claimed).
- **Pointer (prose).** For functions of a complex variable, one derivative already forces analyticity (CA.1). E(1/z²)-type examples blow up along the imaginary axis.
- **Warning.** "All derivatives vanish at a" does not give "f = 0 near a", even with all derivatives continuous.
- **Quick checks.**
  - (i) Is β analytic at x = 1? *No. β = 1 on [−1, 1], so its derivatives at 1, computed from the left, are β(1) = 1 and 0 for every order ≥ 1. Its Taylor series at 1 is the constant 1. But β(x) = S(2 + x)S(2 − x) < 1 for 1 < x < 2, so the series does not equal β on any neighbourhood of 1.*
  - (ii) Why is εₙ ≤ 1 needed? *So that εₙ^{n−k} ≤ εₙ for all k < n, and one condition per n controls every k.*
- **Exercises.**
  - **A1.** Compute S(1/2). *Answer: E(1/2)/(2E(1/2)) = 1/2.*
  - **A2.** Give a C^∞ function that is 0 on (−∞, 0], positive on (0, 1) and 0 on [1, ∞). *Answer: E(x)E(1 − x).*
  - **B1.** Prove the gluing statement, including smoothness at 0 and 1. *Answer: (1 − S)f + Sg is a combination of smooth functions; on x ≤ 0 it equals f and on x ≥ 1 it equals g.*
  - **B2.** Show there is a C^∞ f with f^{(n)}(0) = n! for all n whose Taylor series nevertheless converges only on (−1, 1). Is f(x) = 1/(1 − x) near 0 an example? *Answer: yes, near 0; adjusting it with β gives one defined on all of ℝ: β(2x)/(1 − x) is C^∞ on ℝ (it vanishes for |x| ≥ 1) and agrees with 1/(1 − x) on [−1/2, 1/2].*
  - **C1.** For a < b < c < d, construct a C^∞ function with values in [0, 1], equal to 1 on [b, c] and 0 outside (a, d). Then show that every continuous function on [0, 1] is a uniform limit of C^∞ functions without using Weierstrass's theorem (hint: smooth the piecewise-linear interpolants with such plateaus, or glue local constants). *Answer: S((x − a)/(b − a)) · S((d − x)/(d − c)). For the second part, a partition of unity Σ_i χ_i = 1 on [0, 1] built from these plateaus, with supports of length < δ, gives Σ_i f(x_i)χ_i(x) within the uniform-continuity ε of f.* S2a keeps the second part only if the partition-of-unity sketch is made complete; otherwise the exercise ends after the first part.
  - **C2.** Show that the f from `thm-borel-sequence` can be chosen with support in (−1, 1). *Answer: multiply by β(2x), which is 1 near 0, so the derivatives at 0 are unchanged.*

## 06-space-filling-curve.md — A curve that fills a square, and the table closed

**Budget:** ≤ 5,000 main-line words (it carries the closing table and the R group). **Breaks sentence 6.** Pays AN1.4 (second half). This is the backbone item, Apostol §9.7.

- **Hook.** A continuous image of [0, 1] in ℝ² "should" be thin. Here a continuous γ : [0, 1] → [0, 1]² hits every point, and its parameters can all be taken in the Cantor set.
- **Failure-motivated definition: `def-space-filling-curve`.** The failure: sentence 6. A continuous γ : [0, 1] → ℝ² is **space-filling** if its image has non-empty interior. Ours has image exactly [0, 1]².
- **Construction, `thm-schoenberg-curve`.**
  - Let ψ on [0, 1] be 0 on [0, 1/3], 3t − 1 on [1/3, 2/3] and 1 on [2/3, 1]. Extend it to be even on [−1, 1] and 2-periodic on ℝ. It is continuous with values in [0, 1].
  - Define x(t) = Σ_{n≥1} 2^{−n} ψ(3^{2n−2}t) and y(t) = Σ_{n≥1} 2^{−n} ψ(3^{2n−1}t). Both are continuous by the M-test (AN1.9).
  - The notation ψ avoids a clash with the Cantor function φ; Apostol's letter is not reused.
- **Scratch Work** (first appearance of *digit interleaving*). Given (a, b), we need t whose "odd digits" read a and "even digits" read b. ψ reads one ternary digit, but only if the digit is 0 or 2. So t must lie in C.
- **Surjectivity.**
  - Let a = Σ aₙ2^{−n} and b = Σ bₙ2^{−n} be binary expansions. Set c_{2n−1} = aₙ, c_{2n} = bₙ and t = Σ_{k≥1} 2c_k 3^{−k} ∈ C.
  - Then 3^{j}t = (an even integer) + 2c_{j+1}/3 + r with r ∈ [0, 1/3]. So ψ(3^{j}t) = c_{j+1}, which gives x(t) = a and y(t) = b.
  - **AN1.4 hook paid:** the Cantor set alone already maps onto the square.
- **`exm-schoenberg-point`.** Find t with γ(t) = (1/2, 1/2): a = 0.1000…₂ and b = 0.1000…₂, so c = 1, 1, 0, 0, … and t = 2/3 + 2/9 = 8/9. Check: x(8/9) = ½ψ(8/9) + Σ_{n≥2}2^{−n}ψ(3^{2n−2} · 8/9). Since 3^{2n−2} · 8/9 = 8 · 3^{2n−4} is an even integer for n ≥ 2, those terms are 0, and ψ(8/9) = 1. So x = 1/2. Do y the same way: 3 · 8/9 = 8/3, an even integer + 2/3, so ψ = 1; the later terms are 0.
- **`thm-no-injective-space-filling`.** No continuous γ : [0, 1] → [0, 1]² is a bijection.
  - *Route (AN2.3):* a continuous bijection from a compact space to a metric space is a homeomorphism. Removing an interior point disconnects [0, 1], but removing any point leaves [0, 1]² connected.
- **`thm-rectifiable-not-space-filling`.** No rectifiable curve (AN2.9) has image containing [0, 1]².
  - *Route:* cut [0, 1] into N pieces of length L/N each (by arc length, or by a partition with each piece's length ≤ L/N). Each image piece lies in a closed square of side 2L/N.
  - **Grid lemma:** N closed squares of side r contain at most N(rM + 1)² of the (M + 1)² grid points of spacing 1/M in [0, 1]². With r = 2L/N and M = N, the count N(2L + 1)² is < (N + 1)² for large N.
- **Remark (C2 below).** The same grid argument shows that no space-filling curve is Hölder with exponent > 1/2. Schoenberg's curve is Hölder with exponent log 2/log 9.
- **Warning.** "Continuous and onto" is not "homeomorphism"; dimension is not preserved by continuous maps. The positive result for C¹ curves (image of measure zero) is a pointer to AM / MT.
- **The table, closed: `tbl-weird-examples-closed`.**
