## 01-weierstrass-bernstein.md — Polynomials are dense: Bernstein's proof

Budget ≤ 3,500 main-line words.
- **Hook.** Interpolation is the obvious way to build a polynomial close to f, and it fails. `exm-runge`: equally spaced interpolation of 1/(1 + 25x²) on [−1, 1] gets worse as the degree grows. State it as a fact, with a sidecar plot or table, and no proof. Matching values at points is not the same as being close everywhere, so a different recipe is needed.
- **`def-bernstein-polynomial`.** For f : [0,1] → ℝ and n ≥ 1, set
  Bₙf(x) = Σ_{k=0}^{n} f(k/n) p_{n,k}(x), where p_{n,k}(x) = C(n,k) x^k (1 − x)^{n−k}.
  - Picture: a weighted average of the samples f(k/n). The weights are non-negative on [0,1], sum to 1, and pile up near k ≈ nx.
  - One sentence of probabilistic reading (k successes in n trials of probability x), as motivation only, with no probability used in proofs.
- **Try it first:** compute B₁ and B₂ of f(x) = x², and guess Bₙ(x²).
- **`lem-bernstein-moments`.** For n ≥ 1 and every real x:
  - Σ_k p_{n,k}(x) = 1;
  - Σ_k k p_{n,k}(x) = nx;
  - Σ_k (k − nx)² p_{n,k}(x) = nx(1 − x).
  - Proof: binomial theorem (F2.2). Differentiate (x + y)ⁿ = Σ C(n,k) x^k y^{n−k} once and twice in x, multiply by x and x², then set y = 1 − x. Polynomial identities only.
- **`prp-bernstein-positive`.** Bₙ is linear; f ≤ g on [0,1] ⇒ Bₙf ≤ Bₙg on [0,1]; Bₙ1 = 1, Bₙx = x, and Bₙ(x²) = x² + x(1 − x)/n (`exm-bernstein-square`). Bₙf(0) = f(0) and Bₙf(1) = f(1).
- **`def-modulus-of-continuity`** ω_f(δ). f is uniformly continuous iff ω_f(δ) → 0 as δ → 0⁺ (quick verification).
- **Scratch Work (near/far split).** Write |Bₙf(x) − f(x)| ≤ Σ |f(k/n) − f(x)| p_{n,k}(x).
  - Near terms (|k/n − x| ≤ δ) cost ω_f(δ).
  - Far terms cost 2‖f‖ times their total weight. On them, 1 ≤ (k − nx)²/(n²δ²), so the weight is ≤ x(1 − x)/(nδ²) ≤ 1/(4nδ²).
  - Choose δ first from ε, then n. Kept apart from the proof.
- **`thm-weierstrass-bernstein`** (key proof 1). If f ∈ C[0,1], then for every δ > 0 and n ≥ 1,
  ‖Bₙf − f‖ ≤ ω_f(δ) + ‖f‖/(2nδ²),
  and hence Bₙf → f uniformly on [0,1].
  - Proof: as in the Scratch Work. It cites `lem-bernstein-moments`, uniform continuity from `thm-compact-uniformly-continuous`, and p_{n,k}(x) ≥ 0 **for x ∈ [0,1]**.
  - Self-explain prompt: "*Where is uniform continuity used, and why would continuity at each point not be enough?*"
  - Aftermath: the approximants are explicit, and Bₙ needs only the values f(k/n).
- **`thm-weierstrass-approx`.** For f ∈ C[a,b] (a < b) and ε > 0, there is a polynomial p with ‖f − p‖ < ε, and p may be taken with rational coefficients.
  - Proof: the affine map t = a + (b − a)x reduces to [0,1].
  - Rational coefficients: perturb the coefficients of p. The error is ≤ Σ |cᵢ − rᵢ| M^i with M = max(|a|, |b|, 1).
- **`cor-abs-value-approx`.** For M > 0 there are polynomials pₙ with pₙ(0) = 0 and pₙ → |t| uniformly on [−M, M].
  - Subtract qₙ(0). The error at most doubles because |qₙ(0)| = |qₙ(0) − |0|| ≤ ‖qₙ − |t|‖.
  - Flag it as the tool for §3.
- **`cor-polys-completion`.** C[a,b] with the sup metric is the completion of the polynomials with the sup metric. This pays AN1.9's `exm-polynomials-not-closed` pointer.
  - Proof: polynomials are dense (`thm-weierstrass-approx`), C[a,b] is complete (`cor-ck-complete`), and completions are unique (`thm-completion`).
- **Warning.** Bₙf converges slowly. `exm-bernstein-square` shows the error for x² is exactly x(1 − x)/n, even for a polynomial. Bernstein buys existence and explicitness, not speed.
- **Weird example:** Runge, again. Interpolation diverges while Bernstein converges, for the same function.
- **Quick checks.**
  - Bₙ of a constant? Of 3x − 1? Answer: themselves, by linearity and Bₙ1 = 1, Bₙx = x.
  - Is ‖Bₙf‖ ≤ ‖f‖? Answer: yes, since |Bₙf| ≤ Bₙ|f| ≤ ‖f‖ Bₙ1.
- **Exercises.**
  - **A1 (key proof comprehension).**
    - (a) Which step of the proof of `thm-weierstrass-bernstein` needs x ∈ [0,1]? Answer: the weights p_{n,k}(x) are non-negative, so the triangle inequality and the far-weight bound apply.
    - (b) Where is uniform continuity used? Answer: one δ serves every x, so the near-term bound ω_f(δ) is uniform in x.
    - (c) Run the bound on f(x) = x² with δ = n^{−1/3}, and compare with the exact error 1/(4n) at x = 1/2. Answer: ω_f(δ) ≤ 2δ gives 2n^{−1/3} + n^{−1/3}/2 = (5/2) n^{−1/3}, far worse than 1/(4n). The bound is crude but uniform.
  - **A2.** Show Bₙf(0) = f(0) and Bₙf(1) = f(1). Show that Bₙ maps linear functions to themselves.
  - **B1.** Show Bₙ(x³) = ((n − 1)(n − 2)x³ + 3(n − 1)x² + x)/n², and check n = 1. Answer: the third factorial moment Σ k(k − 1)(k − 2) p_{n,k} = n(n − 1)(n − 2)x³ (sidecar `verify/ch12/bernstein_cubic.py`).
  - **B2.** Let f ∈ C[0,1] with ∫₀¹ f(x) xⁿ dx = 0 for every n ≥ 3. Show f = 0.
    - Answer: g = x³f has ∫ g q = 0 for every polynomial q. Choose qₖ → g uniformly (`thm-weierstrass-approx`).
    - Then ∫ g² = lim ∫ g qₖ = 0 (`thm-uniform-limit-integral`), so g ≡ 0 by continuity.
    - Hence f = 0 on (0, 1], and f(0) = 0 by continuity.
  - **B3.** If f is L-Lipschitz on [0,1], show ‖Bₙf − f‖ ≤ L/(2√n).
    - Hint: Cauchy–Schwarz for sums with weights p_{n,k}(x).
    - Answer: |Bₙf(x) − f(x)| ≤ L Σ |k/n − x| p_{n,k} ≤ L (Σ (k/n − x)² p_{n,k})^{1/2} = L √(x(1 − x)/n) ≤ L/(2√n).
  - **C1 (Korovkin).** Let Tₙ : C[0,1] → C[0,1] be linear and positive (f ≥ 0 ⇒ Tₙf ≥ 0), with Tₙg → g uniformly for g = 1, x, x². Show Tₙf → f uniformly for every f.
    - Answer: fix ε and take δ from uniform continuity. Then for all s, x: |f(s) − f(x)| ≤ ε + 2‖f‖(s − x)²/δ².
    - Apply Tₙ in the variable s at fixed x. Positivity gives |Tₙf(x) − f(x)Tₙ1(x)| ≤ ε Tₙ1(x) + (2‖f‖/δ²) Tₙ[(s − x)²](x).
    - Expand (s − x)² = s² − 2xs + x². Then Tₙ[(s − x)²](x) → 0 uniformly in x, by the three hypotheses.
    - **Marking scheme** (10): 2 for the global inequality with both pieces; 3 for applying Tₙ with positivity, stated; 3 for expanding (s − x)² and invoking the three hypotheses uniformly in x; 2 for collecting terms with Tₙ1 → 1. Fatal error: δ depending on x.
  - **C2.** Show that a uniform limit on all of ℝ of polynomials is a polynomial, so `thm-weierstrass-approx` fails without compactness.
    - Answer: pₙ − pₘ is bounded on ℝ for n, m ≥ N, hence constant. So pₙ = p_N + cₙ, the cₙ are Cauchy and converge to some c, and the limit is p_N + c.

## 02-lattice-stone-weierstrass.md — What made it work: the lattice form

Budget ≤ 2,500 main-line words.
- **Hook.** Bernstein's proof uses the grid k/n and the arithmetic of [0,1]. On the square [0,1]², on the Cantor set, or on an arbitrary compact metric space there is no grid. So ask instead what *property* of a family of functions forces density. First attempt: closure under ∨ and ∧, plus enough functions to match f somewhere.
- **`def-function-lattice`.** L ⊆ C(K) with f ∨ g, f ∧ g ∈ L whenever f, g ∈ L.
- **`def-two-point-interpolation`** (failure-motivated).
  - Constants form a lattice and match any f at any **one** point, yet are not dense in C[0,1]. So ask for **two**: for all x, y ∈ K and a, b ∈ ℝ (with a = b if x = y), some g ∈ L has g(x) = a and g(y) = b.
  - Say why a = b is forced when x = y, and that the x = y clause matters only when K is a single point.
- **Scratch Work (patch by compactness, twice).**
  - Fix f and ε. For each pair (x, y), g_{xy} agrees with f at x and y.
  - Stage 1: fix x. Each g_{xy} is below f + ε near y. Finitely many y suffice, and their min hₓ is below f + ε everywhere, with hₓ(x) = f(x).
  - Stage 2: each hₓ is above f − ε near x. Finitely many x suffice, and their max is within ε of f.
  - Why strict inequalities: they give open sets.
- **`thm-stone-weierstrass-lattice`** (key proof 2). Let (K, d) be a compact metric space and L ⊆ C(K) a lattice with the two-point interpolation property. Then L is dense in C(K).
  - Idea: Step roadmap ① ②.
  - Proof: two Claims. Each covers K by open sets {z : g_{xy}(z) < f(z) + ε}, resp. {z : hₓ(z) > f(z) − ε}, and takes a finite subcover by `def-compact`. Then min/max of finitely many members stays in L by induction. K = ∅ is trivial; say so in one clause.
  - Self-explain prompt: "*Where is compactness used, and why exactly twice?*"
  - Aftermath: the proof never used that K is metric beyond continuity and compactness. AN2.8 runs it on compact Hausdorff spaces (prose pointer).
- **`exm-pl-lattice`.** Continuous piecewise-linear functions on [a,b] form a lattice: the max of two has finitely many breakpoints. It interpolates at two points with a line. So it is dense. It is **not** an algebra: x · x is not piecewise linear.
- **`exm-lipschitz-dense`.** On any compact metric K, Lipschitz functions form a lattice. They interpolate via g(z) = a + (b − a) d(z, x)/d(x, y) for x ≠ y. So they are dense in C(K).
- **Non-examples (witnesses for each hypothesis).**
  - {f ∈ C[0,1] : f(0) = f(1)}: a closed lattice, with interpolation failing at (0, 1). Not dense.
  - Increasing continuous functions: a lattice, no interpolation with a > b at x < y. Not dense.
  - Compactness: see C2.
- **Warning.** The interpolating functions g_{xy} depend on f, x and y. Nothing is uniform until compactness makes the families finite.
- **Quick check.** Do the finite maxima of affine functions on [0,1] form a lattice? Answer: no. Every such function is convex, but min(x, 1 − x) is not.
- **Exercises.**
  - **A1 (key proof comprehension).**
    - (a) Why are the sets {z : g_{xy}(z) < f(z) + ε} open? Answer: g_{xy} − f is continuous, and the preimage of (−∞, ε) is open.
    - (b) What fails if the min in Stage 1 is over infinitely many y? Answer: the infimum of infinitely many continuous functions need not be continuous, and need not lie in L.

## 03-algebra-stone-weierstrass.md — The algebra form, and the failure of each hypothesis

Budget ≤ 3,500 main-line words.
- **Hook.** The polynomials are not a lattice: |x| is not a polynomial on [−1, 1]. Yet `cor-abs-value-approx` puts |x| in their *closure*. So an algebra becomes a lattice once it is closed, and §2 applies.
- **`def-function-algebra`.** A subalgebra of C(K) is a linear subspace closed under pointwise products. Constants are **not** required.
- **Failure-motivated definitions.**
  - `exm-even-polys`: even polynomials on [−1, 1] form an algebra, but every member has g(−x) = g(x), so the closure contains only even functions. This motivates `def-separates-points`: for x ≠ y some g ∈ A has g(x) ≠ g(y).
  - `exm-no-constant-term`: polynomials with p(0) = 0 on [0, 1] form an algebra that separates points, but every uniform limit vanishes at 0. This motivates `def-vanishes-nowhere`: for each x some g ∈ A has g(x) ≠ 0.
- **`lem-closure-subalgebra`.** The closure of a subalgebra is a subalgebra. Use ‖fg − f′g′‖ ≤ ‖f‖‖g − g′‖ + ‖g′‖‖f − f′‖.
- **`lem-closed-algebra-lattice`.** If K is compact and A ⊆ C(K) is a closed subalgebra, then f ∈ A ⇒ |f| ∈ A, and hence A is a lattice (f ∨ g = (f + g + |f − g|)/2).
  - Proof: M = ‖f‖ (finite by compactness). Take pₙ from `cor-abs-value-approx`. Then pₙ ∘ f ∈ A because pₙ has no constant term, and pₙ ∘ f → |f| uniformly.
  - Say in one sentence why p(0) = 0 is needed: A need not contain constants.
- **`lem-algebra-interpolation`.** If A separates points and vanishes nowhere, A has the two-point interpolation property.
  - Proof: for x ≠ y take g with g(x) ≠ g(y), and h, k ∈ A with h(x) ≠ 0, k(y) ≠ 0.
  - Set u = gk − g(x)k and v = gh − g(y)h. Then u(x) = 0, u(y) = k(y)(g(y) − g(x)) ≠ 0, v(y) = 0, v(x) = h(x)(g(x) − g(y)) ≠ 0.
  - So (a/v(x))v + (b/u(y))u interpolates. For x = y use (a/h(x))h.
- **`thm-stone-weierstrass-real`.** K compact metric, A ⊆ C(K) a subalgebra that separates points and vanishes nowhere. Then A is dense in C(K).
  - Proof: Ā is a closed subalgebra (`lem-closure-subalgebra`), hence a lattice (`lem-closed-algebra-lattice`). It interpolates because A ⊆ Ā does (`lem-algebra-interpolation`). By `thm-stone-weierstrass-lattice`, Ā is dense, and it is closed, so Ā = C(K).
- **`cor-sw-characterization`.** For a subalgebra A ⊆ C(K): A is dense ⇔ A separates points and vanishes nowhere.
  - (⇒) Point evaluations are continuous. The functions d(·, x) and 1 lie in C(K), so a dense A cannot fail either property.
  - This is the "counterexample for every hypothesis" remark in its strongest form (STYLE §10).
- **`cor-multivariable-weierstrass`.** For compact K ⊆ ℝⁿ, polynomials in x₁, …, xₙ are dense in C(K). Also with rational coefficients.
- **Worked examples.**
  - span{e^{kx} : k ≥ 1} is dense in C[a,b] with **no** constants. It is closed under products since e^{jx}e^{kx} = e^{(j+k)x}, separates via e^x, and vanishes nowhere since e^x > 0.
  - Finite sums Σ gᵢ(x)hᵢ(y) are dense in C([0,1]²).
  - The algebra generated by x(1 − x) on [0,1] is not dense: it vanishes at 0 and 1, and it does not separate x from 1 − x.
- **Weird example.** A uniform limit of polynomials can be nowhere differentiable (the Takagi function, §6). Density controls values, not derivatives.
- **Quick check.** Do polynomials in x² separate points of [0, 1]? Of [−1, 1]? Answer: yes; no.

## 04-complex-and-trigonometric.md — Complex scalars, trigonometric polynomials, separability

Budget ≤ 3,500 main-line words.
- **Hook.** Fourier's question from AN1.9's opening crisis: is every continuous 2π-periodic function a uniform limit of trigonometric polynomials? The natural tool is e^{inθ}, which is complex-valued. So: does Stone–Weierstrass hold over ℂ?
- **Failure-motivated definition.** `exm-z-bar`: on 𝕋, the polynomials in z form a complex algebra that separates points (z itself) and vanishes nowhere (1). Yet z̄ is not a uniform limit of them.
  - Proof: ∫₀^{2π} p(e^{iθ}) e^{iθ} dθ = 0 for every polynomial p, since each term integrates e^{i(k+1)θ} with k + 1 ≥ 1. But for z̄ the integral is 2π.
  - Uniform limits preserve the integral (`thm-uniform-limit-integral`, applied to real and imaginary parts).
  - This motivates `def-self-adjoint-algebra`: f ∈ A ⇒ f̄ ∈ A.
  - Prose hook to CA: on the closed disc, uniform limits of polynomials are holomorphic inside.
- **`thm-stone-weierstrass-complex`.** K compact metric, A ⊆ C(K, ℂ) a complex subalgebra that separates points, vanishes nowhere and is self-adjoint. Then A is dense.
  - Proof: Re f = (f + f̄)/2 and Im f = (f − f̄)/(2i) lie in A. So A_ℝ = A ∩ C(K, ℝ) separates points (if f(x) ≠ f(y), then Re f or Im f differs) and vanishes nowhere (|f|² = f f̄ ∈ A_ℝ).
  - Apply `thm-stone-weierstrass-real` to A_ℝ and approximate u and v separately.
- **`def-trig-polynomial`.** Σ_{|n|≤N} cₙ e^{inθ}, and the real form a₀ + Σ (aₙ cos nθ + bₙ sin nθ). Real trigonometric polynomials are exactly the real parts.
- **`lem-periodic-circle`.** F ↦ F(e^{iθ}) is a bijection from C(𝕋, ℂ) onto the continuous 2π-periodic functions ℝ → ℂ, preserving sup norms.
  - Surjectivity: for f periodic, define F(e^{iθ}) = f(θ). This is well defined by periodicity and `thm-exp-periodic`.
  - F is continuous because e : [0, 2π] → 𝕋 is a continuous surjection from a compact space, so it maps closed sets to closed sets (`thm-closed-subset-compact`, `thm-continuous-image-compact`). Hence F^{−1}(C) = e(f^{−1}(C) ∩ [0, 2π]) is closed.
- **`thm-trig-dense`.** Every continuous 2π-periodic f : ℝ → ℂ is a uniform limit of trigonometric polynomials. If f is real, real trigonometric polynomials suffice (take real parts).
  - Proof: Laurent polynomials Σ cₙ zⁿ on 𝕋 form a self-adjoint algebra (z̄ = z^{−1} on 𝕋) that separates points and vanishes nowhere. Then use `lem-periodic-circle`.
  - Alternatively (one paragraph): real polynomials in x, y restricted to 𝕋 ⊆ ℝ² are the real trigonometric polynomials, so `cor-multivariable-weierstrass` already gives the real case.
  - Aftermath: this says nothing about Fourier partial sums. They can diverge (FA.4), while Cesàro means converge (HA.2, branch; AN2.13's summability).
- **`cor-ck-separable`.** For compact K ⊆ ℝⁿ, C(K) is separable (rational polynomials, `thm-countable-union` for countability). The general compact metric case is C1.
- **Quick checks.**
  - Is the conjugate of a trigonometric polynomial a trigonometric polynomial? Answer: yes.
  - On the interval [0, 1] ⊆ ℂ, are polynomials in z self-adjoint? Answer: yes, since z̄ = z there, so they are dense in C([0,1], ℂ).

## 05-baire.md — Small sets in a complete space: the Baire category theorem

Budget ≤ 4,000 main-line words.
- **Hook (Q2 returns).** "A typical continuous function is nowhere differentiable" needs a meaning for "most" in C[0,1].
  - First candidate: countable sets are small. It fails, because every ball of C[0,1] is uncountable, and so is the set of functions differentiable somewhere.
  - Second candidate: measure zero (AN2.10). It has no meaning in C[0,1].
  - What survives is a notion that uses only the metric. A set is small if near every point there is a ball avoiding it.
  - Recall AN1.4's preview on ℝ in one sentence: what changes is the space, and what survives is completeness as the only hypothesis.
- **`def-nowhere-dense`.** The closure has empty interior. **`lem-nowhere-dense-ball`:** E is nowhere dense ⇔ every non-empty open U contains a non-empty open V with V ∩ E = ∅.
- **Examples.**
  - ℤ ⊆ ℝ; the Cantor set (AN1.4).
  - The fat Cantor set (`exm-fat-cantor-set`, AN1.4): nowhere dense, of positive length.
  - ℚ: dense, so not nowhere dense.
  - A closed proper linear subspace of a normed space: nowhere dense. If it contained a ball it would contain every vector by scaling.
- **`def-meager`** (a countable union of nowhere dense sets) and **`def-comeager`** (the complement is meager). **`def-g-delta`** (G_δ, F_σ). ℚ is meager in ℝ (`thm-rationals-countable`).
- **Quick check** (before the theorem): can [0,1] be a countable union of closed sets with empty interior? Answer: no. This is what the theorem proves, and AN1.4's preview gave the case of ℝ.
- **Scratch Work (nested closed balls).**
  - Given dense open G₁, G₂, … and a ball U, pick a closed ball inside U ∩ G₁, then one inside its interior ∩ G₂, and so on, with radii < 1/n.
  - Centers are Cauchy, so completeness gives a limit, which lies in every ball.
  - Why closed balls: the limit must stay inside. Why radii → 0: Cauchy.
- **`thm-baire`.** Let (X, d) be a non-empty complete metric space.
  - (a) If G₁, G₂, … are open and dense in X, then ⋂ Gₙ is dense in X.
  - (b) Equivalently, no non-empty open subset of X is meager. In particular X is not meager in itself, and comeager sets are dense.
  - Proof of (a): the nested construction. It cites `thm-cantor-intersection` (or does the Cauchy argument directly) and flags the sequence of choices (dependent choice) in one clause, per STYLE §10.
  - (a) ⇔ (b): complements of closed nowhere-dense sets are dense open sets.
  - Self-explain prompt: "*Why must the radius of the n-th ball go to 0? Which line fails in ℚ?*"
- **Necessity of completeness.** In X = ℚ every singleton is nowhere dense (no isolated points), so ℚ is meager in itself.
  - Remark: the conclusion holds for open subsets of complete spaces such as (0, 1) (C2). So it is a topological property, though completeness is not (AN2.2).
- **`cor-perfect-complete-uncountable`.** A non-empty complete metric space without isolated points is uncountable.
  - This is the third proof that ℝ is uncountable, after `thm-cantor` (F2.3) and AN1.4's perfect sets. Recall both in one line.
- **`cor-q-not-g-delta`** (category bookkeeping, worked in full; faded triple 1).
  - Suppose ℚ = ⋂ Gₙ with Gₙ open. Each Gₙ ⊇ ℚ is dense. The sets ℝ ∖ {q}, q ∈ ℚ, are dense and open.
  - The countable family of all of these has empty intersection, contradicting `thm-baire`.
  - Name the move on the page.
- **`def-oscillation`** (or cite AN2.10) and **`lem-continuity-points-g-delta`**. For any f : X → ℝ, the set of continuity points is ⋂ₙ {x : osc_f(x) < 1/n}, and each of these sets is open.
- **`thm-no-continuity-exactly-q`.** No f : ℝ → ℝ is continuous exactly at the rationals. This pays AN1.5, and Thomae's function (`exm-thomae`) shows the irrationals are possible. The proof is the two lemmas plus `cor-q-not-g-delta`.
- **`thm-baire-one-continuity`.** Let gₙ : X → ℝ be continuous on a complete metric space X with gₙ → g pointwise. Then the set of continuity points of g is comeager, hence dense.
  - Proof (**Baire pigeonhole**, local form): fix ε > 0 and a non-empty open U. The sets F_N = {x ∈ X : |gₙ(x) − gₘ(x)| ≤ ε for all m, n ≥ N} are closed and cover X.
  - Apply `thm-baire` (b) to the open set U: some F_N ∩ U has non-empty interior V. On V, |g − g_N| ≤ ε, and g_N is continuous, so osc_g < 3ε on a smaller open set inside V.
  - So {osc_g < 3ε} contains a dense open set. Intersect over ε = 1/k and use `lem-continuity-points-g-delta`.
- **`cor-dirichlet-not-baire-one`.** The Dirichlet function 1_ℚ is not a pointwise limit of continuous functions, since it is continuous nowhere. This pays AN1.9's `rem-dirichlet-double-limit`. The derivative of a differentiable f : ℝ → ℝ is continuous on a dense G_δ (gₙ(x) = n(f(x + 1/n) − f(x))).
- **`exm-null-comeager`.** Enumerate ℚ = {q₁, q₂, …} and let G = ⋂ₘ ⋃ₖ (qₖ − 2^{−k−m}, qₖ + 2^{−k−m}).
  - G is a dense G_δ, hence comeager.
  - It has measure zero: the m-th union has total length ≤ 2^{1−m}.
  - So ℝ is the union of a meager set and a null set: the two notions of small disagree completely (prose hook to MT and HA.9; AN2.10 as **see** for measure zero).
- **Exercises.**
  - **A1 (Baire proof comprehension).**
    - (a) Where is completeness used? Answer: the centers form a Cauchy sequence, and its limit exists.
    - (b) Why must the closed balls sit inside the previous open ball? Answer: so that all later centers, and hence the limit, lie in each closed ball.
    - (c) Run the construction in X = ℚ with Gₙ = ℚ ∖ {qₙ} and say which line fails. Answer: the Cauchy centers converge in ℝ, possibly to an irrational, and there is no limit in X.
  - **A2.** Classify as nowhere dense, meager but not nowhere dense, or neither, in ℝ:
    - ℤ (nowhere dense);
    - ℚ (meager, not nowhere dense);
    - the Cantor set (nowhere dense);
    - [0, 1] (neither);
    - the irrationals (neither: comeager);
    - {1/n : n ≥ 1} (nowhere dense).
  - **B1 (proof ordering).** Seven shuffled lines of the proof of `thm-baire` (a), plus two distractors:
    - "choose rₙ = 1 for all n" (radii not shrinking);
    - "choose an open ball B(xₙ, rₙ) ⊆ Gₙ ∩ B(xₙ₋₁, rₙ₋₁)" (open, so the limit may escape).
    - The solution gives an admissible order, the other admissible orders, and why each distractor fails.
  - **B2 (faded triple 2: last step blank).** Liouville numbers: L = {x ∉ ℚ : for every n there are p, q with q ≥ 2 and 0 < |x − p/q| < q^{−n}}.
    - Given: L = (⋂ₙ Uₙ) ∖ ℚ with Uₙ = ⋃_{q≥2} ⋃_p (p/q − q^{−n}, p/q + q^{−n}), each Uₙ open and dense.
    - *Name the move, then complete it:* conclude that L is comeager.
    - Answer: ⋂ Uₙ is a dense G_δ, hence comeager (`thm-baire`). ℚ is meager. A comeager set minus a meager set is comeager.
  - **B3.** Let X be complete with no isolated points. Show every dense G_δ in X is uncountable.
    - Answer: if a dense G_δ G were countable, X = G ∪ (X ∖ G) would be meager, since singletons are nowhere dense and X ∖ G is meager.
  - **C1.** Let f : [1, ∞) → ℝ be continuous with f(nx) → 0 as n → ∞ for each x ≥ 1. Show f(x) → 0 as x → ∞.
    - Answer: fix ε. The sets F_N = {x ≥ 1 : |f(nx)| ≤ ε for all n ≥ N} are closed and cover the complete space [1, ∞).
    - Baire pigeonhole gives (a, b) ⊆ F_N. So |f| ≤ ε on ⋃_{n≥N} (na, nb). These intervals overlap once n > a/(b − a), so the union contains (n₀a, ∞).

  - **C2.** Show the conclusion of `thm-baire` (a) holds in every open subset U of a complete metric space. Answer: choose the closed balls inside U; the limit lies in the closed ball, which lies in U.
  - **C3.** Let f : ℝ → ℝ be differentiable. Show f′ cannot be discontinuous at every point of an interval (a, b).
    - Answer: on a closed [c, d] ⊆ (a, b), a complete space, f′ = lim gₙ with gₙ(x) = n(f(x + 1/n) − f(x)) continuous. By `thm-baire-one-continuity` the continuity points of f′|_{[c,d]} are dense, and interior ones are continuity points of f′.

## 06-typical-functions.md — Nowhere-differentiable functions are typical

Budget ≤ 4,500 main-line words.
- **Hook.** Back to the Takagi function T(x) = Σ_{k≥0} 2^{−k} φ(2^k x), with φ the distance to the nearest integer. AN1.9 proved T continuous (M-test). First finish the proof that T has no derivative anywhere. Then show this is what most continuous functions do.
- **`rem-takagi-recap`** (recall box). AN1.9's `exr-function-series-c2` proved T nowhere differentiable. On a dyadic interval of length 2^{−n} containing x, the chord slope of T is a sum of n terms ±1. So consecutive chord slopes differ by 1, and a derivative at x would force them to converge (the straddle lemma there). Four lines, no new proof.
- **Try it first.** Why not take Eₙ = {f differentiable somewhere with |f′| ≤ n} and show it is closed? Answer to discover: it is not closed. Smooth functions converge uniformly to |x − 1/2|, which has bounded difference quotients but no derivative at 1/2. Use a condition that survives uniform limits: a Lipschitz bound at one point.
- **`thm-nowhere-diff-generic`** (key proof 3). In C[0,1] with the sup metric, the set D of functions differentiable at some point of [0,1] (one-sided at 0 and 1) is meager. Hence the nowhere-differentiable functions form a comeager, in particular dense and non-empty, subset of C[0,1].
  - **Idea: Step roadmap.**
    - ① Let Eₙ = {f : there is x ∈ [0,1] with |f(t) − f(x)| ≤ n|t − x| for all t ∈ [0,1]}. Then D ⊆ ⋃ Eₙ.
    - ② Each Eₙ is closed.
    - ③ Each Eₙ has empty interior.
    - ④ Category bookkeeping and `thm-baire` with `cor-ck-complete`.
  - **Step 1.** Near x, |f(t) − f(x)| ≤ (|f′(x)| + 1)|t − x| for |t − x| < δ. Away from x, |f(t) − f(x)| ≤ 2‖f‖ ≤ (2‖f‖/δ)|t − x|. Take n ≥ both constants.
  - **Step 2.** Let fₖ ∈ Eₙ with witnesses xₖ and fₖ → f. By compactness of [0,1] a subsequence xₖ → x. Then fₖ(xₖ) → f(x) (uniform convergence and continuity of f), and the inequality passes to the limit.
  - **Step 3.** Given f and ε, take a polynomial p with ‖f − p‖ < ε/2 (`thm-weierstrass-approx`). p is L-Lipschitz (`thm-mean-value`). Let s be a sawtooth with ‖s‖ ≤ ε/2 and slopes ±M with M > n + L. On a closed linear piece of s containing x, choose t ≠ x: then |(p + s)(t) − (p + s)(x)| ≥ (M − L)|t − x| > n|t − x|. So p + s ∈ B(f, ε) ∖ Eₙ.
  - Self-explain prompt at Step 3: "*Why must the slope of the sawtooth beat n + L, and not just n?*"
  - **Step 4.** D is contained in a meager set, so it is meager, and its complement is comeager, hence dense, by `thm-baire`.
  - Aftermath:
    - This is an existence proof with no formula. Together with `rem-takagi-recap` it gives two routes to the same object.
    - Category is not probability. Prose only: a probabilistic version, almost every Brownian path, exists.
    - FA.4 runs the same scheme on operators (prose hook).
