## Purpose

- **The failure.** The Riemann integral of AN1.8/AN2.10 leaves two holes that a student meets immediately: (i) a function can be a derivative on all of [a, b] and still not be Riemann integrable, so "∫ₐᵇ F′ = F(b) − F(a)" needs a hypothesis that has nothing to do with F; (ii) a monotone limit of Riemann-integrable functions, all with integral 0, can fail to be integrable.
- **The repair.** Riemann measures fineness by one number δ for the whole interval. Allow δ to depend on the point: a **gauge**. With that single change the integral (Henstock–Kurzweil) integrates every derivative, with FTC holding with no hypothesis at all, integrates every Riemann and every improper Riemann integral with the same value, and obeys a monotone convergence theorem.
- **The price, said honestly.** The integral is not absolute (|f| need not be integrable when f is), and the full convergence theory needs measure-theoretic ideas. The chapter ends by placing the gauge integral between Riemann and Lebesgue, with MT named (in prose) as the place the Lebesgue side is built.

**Chapter hook** (in `index.md` and §01): the function F(x) = x² sin(1/x²), F(0) = 0. It is differentiable at every point of [0, 1] (F′(0) = 0 by the difference quotient), but F′(x) = 2x sin(1/x²) − (2/x) cos(1/x²) for x ≠ 0 is unbounded near 0, so F′ is not Riemann integrable on [0, 1] (AN1.8: Riemann-integrable functions are bounded). Question posed: *is there an integral for which ∫₀¹ F′ = F(1) − F(0) = sin 1, with no further hypothesis?* **Paid in §03** (`thm-gauge-ftc`, worked example `exm-gauge-ftc-hook`). A second hook, the Dirichlet function 1_ℚ and the increasing sequence of indicators of {r₁, …, rₙ}, is **paid in §02** (`exm-dirichlet-gauge`) and **again in §04** (`exm-mct-dirichlet`).

**Hooks this chapter pays from earlier chapters** (prose back-pointers, no edge needed):
- AN1.8's warning that a derivative need not be Riemann integrable (if AN1.8 carries it; otherwise the hook above stands on its own).
- AN2.10's closing remark that Riemann integration is inadequate (C5: "Riemann 的不足 (AN2.10) → MT"). This chapter gives the *non-measure-theoretic* answer; MT gives the measure-theoretic one. Say that both are answers to the same failure.

**Named moves** (in `index.md`, "Named moves"):
- **Tag forcing.** To make every δ-fine partition use c as a tag, require δ(t) ≤ |t − c|/2 for t ≠ c.
- **Budget the bad points.** Enumerate the exceptional points c₁, c₂, … and give the k-th one a gauge so small that its contribution is below ε·2⁻ᵏ; a point tags at most two subintervals.
- **Straddle and telescope.** Write F(b) − F(a) as Σ [F(xᵢ) − F(xᵢ₋₁)] and compare each term with F′(tᵢ)(xᵢ − xᵢ₋₁) using the straddle lemma.
- **Fill the gaps** (Saks–Henstock). A δ-fine *partial* partition can be completed by fine partitions of the gaps whose sums are as close as we like to the gaps' integrals; then let the closeness go to 0.
- **A gauge chosen pointwise from a sequence.** Given gauges δₙ, choose an index n(x) for each point and set δ(x) = δ_{n(x)}(x).
- Reused from AN1.1: **construct a point as a sup** (the proof of Cousin's lemma).

## index.md

- **Story.** Riemann asked that every subinterval be short. Near a point where f misbehaves, "short" should mean *shorter*; near a point where f is tame, a long subinterval does no harm. A gauge says how short, point by point. The chapter shows that this one change repairs FTC completely and fixes the limit failure of 1_ℚ, and then says what it does not fix.

## 01-gauges.md — Gauges and fine partitions

**Budget:** ≤ 3,200 main-line words.

- **Hook (failure-motivated definition).** Show F(x) = x² sin(1/x²) and its derivative on (0, 1]: F′ oscillates between roughly ±2/x. A Riemann sum with mesh < δ has a first subinterval [0, x₁] whose tag t₁ can be chosen where |F′(t₁)| is as large as we like, so the sums are unbounded for every δ. The trouble is *one point*: 0. Any reasonable sum should force small subintervals near 0 and allow coarse ones elsewhere. That is a function δ(x), not a number.
- **`def-interval-gauge`** (a function δ: [a, b] → (0, ∞)) and **`def-delta-fine`** (each [xᵢ₋₁, xᵢ] ⊆ (tᵢ − δ(tᵢ), tᵢ + δ(tᵢ))). Symbols form given. Note that the tag must lie in its subinterval (from AN2.10's definition) and the subinterval must sit inside the δ(tᵢ)-neighbourhood of its own tag.
- **`prp-constant-gauge-mesh`.** For a constant gauge δ: mesh(Ṗ) < δ ⇒ Ṗ is δ-fine ⇒ mesh(Ṗ) < 2δ. Proof: two lines. Aftermath: Riemann's condition is exactly "fine for a constant gauge", up to a factor 2.
- **Quick check.** δ(x) = x/2 on (0, 1], δ(0) = 1/10. Is {(0, [0, 1/20]), (1/2, [1/20, 1])} δ-fine? *Answer:* no; the second subinterval reaches 1/20 < 1/2 − 1/4. (Folded solution: the first piece is fine since 1/20 < 1/10.)
- **`lem-tag-forcing`.** Let c ∈ [a, b] and let δ be a gauge with δ(t) ≤ |t − c|/2 for t ≠ c. Then in every δ-fine tagged partition, c is a tag of every subinterval that contains c. Proof: if c ∈ [xᵢ₋₁, xᵢ] with tag tᵢ ≠ c, then |c − tᵢ| < δ(tᵢ) ≤ |tᵢ − c|/2, impossible. Name the move **tag forcing**.
  - `exm-forced-tag`: with c = 1/3 on [0, 1] and δ(t) = |t − 1/3|/2 (any δ(1/3) > 0), show one δ-fine partition and point to where 1/3 sits. Remark: a point tags at most two subintervals (it can be the right end of one and the left end of the next).
- **`thm-cousin` (Cousin's lemma).** For every gauge δ on [a, b] there is a δ-fine tagged partition of [a, b].
  - **Scratch Work (first appearance: building a fine partition).** Try to partition greedily from a: [a, a + δ(a)/2] tagged a, then from the new endpoint … — the steps may shrink and accumulate before b (δ(x) = (1 − x)/2 near b, say). So greed fails; take a sup instead. Set S = {x ∈ (a, b] : [a, x] has a δ-fine tagged partition}. S ∋ a + min(δ(a), b − a)/2, so it is non-empty; s = sup S exists (`ax-least-upper-bound`). Now play the sup against δ(s).
  - **Proof.** Choose y ∈ S ∪ {a} with s − δ(s) < y ≤ s (`thm-sup-epsilon`; take y = a if s − δ(s) < a). Append [y, s] tagged s (omit if y = s) to a δ-fine partition of [a, y]: so s ∈ S. If s < b, append [s, s′] tagged s with s′ = min(b, s + δ(s)/2): then s′ ∈ S and s′ > s, a contradiction. So s = b ∈ S. Point out where the δ(s)-neighbourhood is used twice.
  - **Alternatively** (one paragraph): bisection. If [a, b] had no δ-fine partition, one half has none; nested intervals (`thm-nested-intervals`) shrink to a point c; once the interval has length < δ(c), it is itself δ-fine with tag c.
- **Warning.** Cousin's lemma is the reason the gauge integral is well defined at all (§02 uniqueness). It is not obvious, and it uses completeness: over ℚ, or for a "gauge" allowed to take the value 0 at a point, it fails. Witness for the second: δ(0) = 0 makes no subinterval containing 0 fine. (C2 shows the ℚ failure is no accident.)
- **Exercises.**
  - **A1.** True or false: every δ-fine partition is also (δ/2)-fine. *Answer:* false; take δ ≡ 1 on [0, 1] and the single subinterval [0, 1] tagged 1/2 — it is 1-fine but not ½-fine.
  - **A2.** If δ₁ ≤ δ₂ pointwise, which implication holds between "δ₁-fine" and "δ₂-fine"? *Answer:* δ₁-fine ⇒ δ₂-fine.
  - **A3.** Show a δ-fine partition of [0, 1] for δ(x) = 1/4 for x ≤ 1/2 and δ(x) = 1 for x > 1/2. *Answer:* e.g. tags 1/8, 3/8 on [0, 1/4], [1/4, 1/2] (each inside the 1/4-ball of its tag) and tag 3/4 on [1/2, 1].
  - **B1.** For the gauge δ(x) = x/2 (x > 0), δ(0) = 1/4 on [0, 1], prove that 0 is the tag of the first subinterval of every δ-fine partition, and that x₁ < 1/4. *Answer:* tag forcing with c = 0 (|t − 0|/2 = δ(t)); fineness at tag 0 gives x₁ < δ(0).
  - **B2.** For the same gauge, prove every δ-fine partition has at least 3 subintervals, and find one with exactly 3. *Answer:* the first piece is [0, x₁] with x₁ < 1/4. A piece [u, v] with tag t > 0 has u > t/2 and v < 3t/2, so v < 3u; hence the second piece ends before 3x₁ < 3/4, and a third is needed. Example with exactly 3: (0, [0, 1/5]), (3/10, [1/5, 2/5]), (7/10, [2/5, 1]); checks: 1/5 < 1/4; 3/20 < 1/5 and 2/5 < 9/20; 7/20 < 2/5 and 1 < 21/20.
  - **B3.** Combine two gauges: given δ₁, δ₂, show there is one partition that is fine for both. *Answer:* Cousin for δ₁ ∧ δ₂.
  - **C1.** Prove Cousin's lemma by bisection in full and say which completeness axiom it uses. *Answer:* nested intervals (AN1.1); the interval [aₙ, bₙ] with bₙ − aₙ < δ(c) is fine with tag c.
  - **C2.** In an ordered field, define gauges and δ-fine partitions in the same way. Show that if Cousin's lemma holds for every interval, the least upper bound property holds. *Answer:* let A be non-empty, bounded above, with no supremum; U = the set of upper bounds; pick a ∈ A, b ∈ U (a ∉ U, else a = max A = sup A). For x ∈ U there is an upper bound x′ < x (x is not least); put δ(x) = x − x′, so (x − δ(x), x + δ(x)) ⊆ U. For x ∉ U there is a′ ∈ A with a′ > x; put δ(x) = a′ − x, so the neighbourhood misses U. Each piece of a δ-fine partition of [a, b] lies in its tag's neighbourhood, hence wholly in U or wholly outside; adjacent pieces share an endpoint, so all pieces are of one kind; b ∈ U forces a ∈ U, a contradiction.

## 02-the-gauge-integral.md — The integral and its first properties

**Budget:** ≤ 4,600 main-line words.

- **`def-gauge-integral`.** f: [a, b] → ℝ is gauge integrable with integral A if ∀ε > 0 ∃ a gauge δ ∀ δ-fine Ṗ: |S(f, Ṗ) − A| < ε. Symbols form. Explain template: the only change from AN2.10's mesh definition is "a number δ" → "a function δ".
- **`thm-gauge-integral-unique`.** Two values A, A′: take δ ∧ δ′, a common fine partition exists by `thm-cousin`, so |A − A′| < 2ε. Aftermath: without Cousin this definition would be vacuous for some gauges; say so.
- **`thm-riemann-implies-gauge`.** If f is Riemann integrable on [a, b] (AN1.8), it is gauge integrable with the same integral. Proof: by `thm-riemann-sum-criterion` (AN2.10, α(x) = x) there is η with |S(f, Ṗ) − (R)∫f| < ε when mesh < η; use the constant gauge η/2 and `prp-constant-gauge-mesh`.
- **`thm-gauge-linear`, `thm-gauge-monotone`.** ∫(αf + βg) = α∫f + β∫g; f ≤ g ⇒ ∫f ≤ ∫g. Proofs: common gauge δ_f ∧ δ_g and one fine partition. Brief.
- **Worked example `exm-dirichlet-gauge` (pays the second hook).** 1_ℚ on [0, 1] has gauge integral 0.
  - **Scratch Work (first appearance: budgeting bad points).** Only rational tags contribute. A rational tag r contributes the length of its subinterval(s). We cannot make the *number* of rational tags small, but we can make each one's subintervals tiny, provided each rational has its own budget. Enumerate ℚ ∩ [0, 1] = {r₁, r₂, …} (F2.3) and aim for ε·2⁻ᵏ at rₖ.
  - **Proof.** δ(rₖ) = ε·2⁻ᵏ⁻², δ(x) = 1 at irrationals. For δ-fine Ṗ, a subinterval tagged rₖ has length < 2δ(rₖ) = ε·2⁻ᵏ⁻¹, and rₖ tags at most two subintervals, so S(1_ℚ, Ṗ) < Σₖ ε·2⁻ᵏ = ε (AN1.3).
  - Aftermath: 1_ℚ is the standard non-Riemann-integrable function (AN2.10: discontinuous everywhere). Name the move **budget the bad points**.
- **`thm-gauge-null-exceptions`.** If f = 0 except on a set N of measure zero (`def-measure-zero`, AN2.10), then f is gauge integrable and ∫f = 0. *No boundedness assumed.*
  - Idea: split N into Nₙ = {x ∈ N : n − 1 < |f(x)| ≤ n}; cover Nₙ by open intervals of total length < ε/(n·2ⁿ); for t ∈ Nₙ take δ(t) so that (t − δ(t), t + δ(t)) lies in one of those intervals; δ = 1 off N. The subintervals with tags in Nₙ do not overlap and lie in the union of the cover, so their total length is < ε/(n·2ⁿ), and their contribution is < ε/2ⁿ.
  - Proof written out; the point "non-overlapping intervals inside a union of intervals have total length at most the cover's total length" is proved in one paragraph (sort the finitely many subintervals; each lies in one cover interval; a finite sub-collection of the cover suffices; sum of lengths of non-overlapping intervals inside a finite union of intervals ≤ sum of their lengths, by induction on the number of cover intervals). *S2a item: this paragraph must be airtight; it is the only measure-flavoured step in the chapter.*
  - `cor-gauge-countable-exceptions`: changing f on a countable set changes neither integrability nor the integral (countable sets have measure zero, AN2.10).
- **Quick check.** Is the function equal to 1/q at p/q (lowest terms) and 0 at irrationals (Thomae's function) gauge integrable on [0, 1], and what is its integral? *Answer:* yes, 0 — it is Riemann integrable with integral 0 (AN2.10), or use `cor-gauge-countable-exceptions`.
- **`thm-gauge-cauchy`.** f is gauge integrable iff ∀ε ∃δ with |S(f, Ṗ) − S(f, Q̇)| < ε for all δ-fine Ṗ, Q̇. Proof: gauges δₙ for ε = 1/n, replaced by δ₁ ∧ ⋯ ∧ δₙ so they decrease; Cousin gives δₙ-fine Ṗₙ; (S(f, Ṗₙ)) is Cauchy (AN1.2), its limit is the integral.
- **`thm-gauge-subinterval`.** Gauge integrable on [a, b] ⇒ gauge integrable on every [c, d] ⊆ [a, b]. Proof via the Cauchy criterion: fix δ-fine partitions of [a, c] and [d, b] (Cousin) and attach them to any two δ-fine partitions of [c, d]; the sums differ by exactly the difference on [c, d].
- **`thm-gauge-additive`.** For a < c < b: f integrable on [a, c] and on [c, b] ⇒ integrable on [a, b] with ∫ₐᵇ = ∫ₐᶜ + ∫ᶜᵇ. Proof: **tag forcing** at c with δ = δ₁ on [a, c), δ₂ on (c, b], δ(c) = δ₁(c) ∧ δ₂(c), and δ(t) ≤ |t − c|/2; split the subinterval tagged c at c (same Riemann sum); each half is fine for its own gauge.
- **Warning.** "Gauge integrable ⇒ bounded" is false (`thm-gauge-null-exceptions` with f(1/n) = n, or §03's hook). Every AN1.8 argument that starts "let M bound |f|" is unavailable here.
- **Warning 2.** The gauge for 1_ℚ depends on the *enumeration*, not just on ε; this is normal, and a reader should not look for a formula.
- **Exercises.**
  - **A1.** Why can the integral of 1_ℚ not be computed by a constant gauge? *Answer:* a constant gauge allows every tag rational, giving sum 1.
  - **A2.** f(x) = 1/x for x = 1/n (n ≥ 1) and 0 otherwise on [0, 1]. Integrable? Value? *Answer:* yes, 0 (countable exceptions).
  - **A3.** If f is gauge integrable and g = f except at 5 points, what is ∫g? *Answer:* ∫f.
  - **B1.** Prove `thm-gauge-monotone` in full. *Answer:* common gauge; S(f, Ṗ) ≤ S(g, Ṗ); let ε → 0.
  - **B2.** Using only the definition, show 1_{ℚ} − 1_{[0,1/2]} is gauge integrable on [0, 1] with integral −1/2. *Answer:* linearity + `thm-riemann-implies-gauge` + `exm-dirichlet-gauge`.
  - **B3.** Let f = 1_C, C the Cantor set (AN1.4). Show ∫₀¹ f = 0. *Answer:* C has measure zero (AN1.4/AN2.10); `thm-gauge-null-exceptions`. (Also Riemann integrable — say so.)
  - **C1.** Prove: if f ≥ 0 is gauge integrable and ∫ₐᵇ f = 0, then {x : f(x) > 0} need not be empty but every subinterval contains points where f < any given η > 0. *Answer:* if f ≥ η on [c, d], then ∫ ≥ η(d − c) > 0 by monotonicity and additivity. *(Statement kept to what is provable here; the "f = 0 a.e." version is MT.)*
  - **C2.** Show that the set of gauge-integrable functions on [a, b] is a vector space containing every function that is 0 off a measure-zero set, and that it is not closed under taking |·| — postpone the last claim with a pointer to §05. *Answer:* linearity; `thm-gauge-null-exceptions`; `thm-gauge-not-absolute`.

## 03-fundamental-theorem.md — Every derivative is integrable

**Budget:** ≤ 4,000 main-line words.

- **Lead-in.** AN1.8's FTC needed F′ Riemann integrable. The gauge integral removes that hypothesis.
- **`lem-straddle`.** Let F be differentiable at t ∈ [a, b] (one-sided at an endpoint). For every ε > 0 there is δ > 0 such that for all u ≤ t ≤ v in [a, b] with [u, v] ⊆ (t − δ, t + δ) (the neighbourhood form, to match `def-delta-fine`): |F(v) − F(u) − F′(t)(v − u)| ≤ ε(v − u).
  - Proof: insert F(t). From the derivative, |F(v) − F(t) − F′(t)(v − t)| ≤ ε(v − t) and the same for u; add (the triangle inequality, with (v − t) + (t − u) = v − u). Cases u = t or v = t included.
  - Warning embedded: the point t must lie *between* u and v. For u < v both on the same side of t the estimate is false for F(x) = x² sin(1/x) near 0 (B3 below).
- **`thm-gauge-ftc`.** If F: [a, b] → ℝ is differentiable at every point (one-sided at a, b), then F′ is gauge integrable and ∫ₐᵇ F′ = F(b) − F(a).
  - **Scratch Work (first appearance: straddle and telescope).** F(b) − F(a) is a telescoping sum over any partition. Each term F(xᵢ) − F(xᵢ₋₁) is close to F′(tᵢ)(xᵢ − xᵢ₋₁) when the subinterval is short *relative to tᵢ* — exactly what fineness at tᵢ says. So let `lem-straddle` choose δ(t) point by point. The total error is ≤ Σ ε(xᵢ − xᵢ₋₁) = ε(b − a).
  - **Proof.** δ(t) from `lem-straddle` with tolerance ε; for δ-fine Ṗ, |S(F′, Ṗ) − (F(b) − F(a))| ≤ ε(b − a).
  - Aftermath: the gauge is not chosen to make sums small; it is *read off the derivative*. No continuity of F′, no boundedness.
- **Worked example `exm-gauge-ftc-hook` (pays the chapter hook).** F(x) = x² sin(1/x²), F(0) = 0: F is differentiable on [0, 1], so ∫₀¹ F′ = sin 1. Note that F′ is not Riemann integrable (unbounded), and that the improper Riemann integral also exists here and agrees (§05 Hake).
- **Prose pointer.** AN2.15 builds Volterra's function: a derivative that is *bounded* and still not Riemann integrable. `thm-gauge-ftc` integrates it too. (Prose only: AN2.15 is later and optional.)
- **`thm-gauge-ftc-countable`.** Let F be continuous on [a, b] and differentiable at every point except those of a countable set E. Let f = F′ off E, and f arbitrary on E. Then f is gauge integrable and ∫ₐᵇ f = F(b) − F(a).
  - Idea: **budget the bad points** again. Enumerate E = {c₁, c₂, …}. At cₖ, continuity of F gives δ(cₖ) with |F(v) − F(u)| < ε·2⁻ᵏ for u, v ∈ (cₖ − δ(cₖ), cₖ + δ(cₖ)), and also |f(cₖ)|·2δ(cₖ) < ε·2⁻ᵏ. Each cₖ tags at most two subintervals. Total error ≤ ε(b − a) + 4ε.
  - Proof written in full; this is the second use of the budget move, so no Scratch Work (fading).
- **Worked example `exm-inverse-sqrt`.** f(x) = 1/√x on (0, 1], f(0) = 0. F(x) = 2√x is continuous on [0, 1] and differentiable on (0, 1]; E = {0}. So ∫₀¹ f = 2. No improper limit is taken.
- **`exm-cantor-ftc-fails` (failure: "countable" cannot become "measure zero").** The Cantor function φ (AN2.9, or the two properties stated: φ is continuous and increasing on [0, 1], φ(0) = 0, φ(1) = 1, and φ′ = 0 at every point off the Cantor set C). Take f = 0. Then f = φ′ off C, C has measure zero, ∫₀¹ f = 0 ≠ φ(1) − φ(0). So `thm-gauge-ftc-countable` fails with "countable" replaced by "measure zero", even for continuous increasing F. Point to MT (prose) for the repair (absolute continuity).
- **`cor-gauge-parts` (integration by parts).** If F, G are differentiable on [a, b], then F′G is gauge integrable iff FG′ is, and then ∫F′G = F(b)G(b) − F(a)G(a) − ∫FG′. Proof: (FG)′ = F′G + FG′ is integrable by `thm-gauge-ftc`; linearity.
- **Quick check.** Is F′ integrable for F(x) = |x| on [−1, 1]? *Answer:* F is not differentiable at 0, but continuous; `thm-gauge-ftc-countable` with E = {0} gives ∫ f = 0 for any value f(0).
- **Warning.** `thm-gauge-ftc` says nothing about ∫ₐˣ f being differentiable with derivative f for an arbitrary integrable f; that holds only almost everywhere and is MT territory. Here we have the direction "differentiate, then integrate".
- **Exercises.**
  - **A1.** Compute ∫₀¹ F′ for F(x) = x³/² sin(1/x), F(0) = 0. *Answer:* F is differentiable on [0, 1] (F′(0) = lim h^{1/2} sin(1/h) = 0), so ∫ = sin 1.
  - **A2.** Which hypothesis of `thm-gauge-ftc-countable` fails for F = 1_{[1/2, 1]} on [0, 1]? *Answer:* continuity at 1/2; indeed f = 0 off {1/2} has integral 0 ≠ 1.
  - **B1.** Prove ∫₀¹ x^{−1/3} dx = 3/2 with f(0) = 0, citing exactly one theorem. *Answer:* `thm-gauge-ftc-countable`, F(x) = (3/2)x^{2/3}.
  - **B2.** Use `cor-gauge-parts` to show ∫₀¹ x·F′(x) dx = sin 1 − ∫₀¹ F(x) dx for the hook's F, and say why each integral exists. *Answer:* G(x) = x; FG′ = F is continuous, hence Riemann and gauge integrable; so F′G is integrable.
  - **B3.** For F(x) = x² sin(1/x), F(0) = 0 (so F′(0) = 0), find 0 < u < v inside any (−η, η) with |F(v) − F(u) − F′(0)(v − u)| ≥ (1/2)(v − u). Conclude that the straddle hypothesis u ≤ t ≤ v cannot be dropped. *Answer:* p = 2nπ + π/2, q = 2nπ + 3π/2, v = 1/p, u = 1/q. Then F(v) = 1/p², F(u) = −1/q², v − u = π/(pq), and (F(v) − F(u))/(v − u) = (1/p² + 1/q²)·pq/π ≥ (2/(pq))·pq/π = 2/π > 1/2 (AM–GM).
  - **C1.** Let F be continuous on [a, b] and differentiable off a countable set with F′ ≥ 0 there. Prove F is increasing. *Answer:* apply `thm-gauge-ftc-countable` on [x, y] and `thm-gauge-monotone` (with f = 0 on E).
  - **C2.** Show that the gauge in `thm-gauge-ftc` cannot in general be taken constant, using the hook's F: for every η > 0 and every M exhibit a tagged partition of mesh < η whose Riemann sum for F′ exceeds M. *Answer:* tag the first subinterval [0, x₁] at a point t where F′(t) > M/x₁ (possible since F′ is unbounded above on (0, x₁)); the remaining sum is bounded (F′ bounded on [x₁, 1], continuous there).

## 04-limits.md — Saks–Henstock and the convergence theorems

**Budget:** ≤ 4,600 main-line words.

- **Lead-in (failure revisited).** fₙ = 1_{{r₁, …, rₙ}} increases to 1_ℚ, each (R)∫fₙ = 0, and the limit is not Riemann integrable (AN2.10). For the gauge integral, §02 already shows ∫1_ℚ = 0; this section proves that this is no accident.
- **`def-partial-tagged-partition`**: finitely many non-overlapping closed subintervals of [a, b] with tags, not necessarily covering; δ-fine as before.
- **`lem-saks-henstock`.** Let f be gauge integrable on [a, b], and let δ be a gauge with |S(f, Ṗ) − ∫ₐᵇ f| ≤ ε for every δ-fine Ṗ. Then for every δ-fine partial tagged partition {(tⱼ, Iⱼ)}: |Σⱼ (f(tⱼ)|Iⱼ| − ∫_{Iⱼ} f)| ≤ ε.
  - **Scratch Work (first appearance: fill the gaps).** The partial sum is not a Riemann sum of anything. Complete it: the gaps K₁, …, K_p are closed intervals on which f is integrable (`thm-gauge-subinterval`), so each has fine partitions whose sums are within η/p of ∫_{K_l} f. Gluing gives a δ-fine partition of [a, b]; its error is ≤ ε, and the gap part of the error is < η. Let η → 0.
  - Proof written in full, with the gap gauges chosen ≤ δ on Kₗ, `thm-cousin` on each Kₗ, and `thm-gauge-additive` to write ∫ₐᵇ f = Σⱼ ∫_{Iⱼ} f + Σₗ ∫_{Kₗ} f.
- **`thm-indefinite-gauge-continuous`.** If f is gauge integrable on [a, b], then Φ(x) = ∫ₐˣ f is continuous. Proof: Saks–Henstock with the single pair (x, [x, x + h]) gives |Φ(x + h) − Φ(x)| ≤ ε + |f(x)|·h for 0 ≤ h < δ(x); same on the left.
- **`thm-gauge-uniform-limit`.** fₙ gauge integrable, fₙ → f uniformly on [a, b] (definition restated from AN1.9) ⇒ f gauge integrable and ∫fₙ → ∫f. Idea only (the ε/3 argument of AN1.9, with `thm-gauge-monotone` for |∫fₙ − ∫fₘ| ≤ (b − a) sup|fₙ − fₘ|). Remark: this theorem is not the interesting one — uniform convergence was already enough for Riemann.
- **`thm-gauge-mct` (monotone convergence).** Let fₙ be gauge integrable on [a, b] with fₙ(x) ≤ fₙ₊₁(x) and fₙ(x) → f(x) for every x. If sup ∫fₙ < ∞, then f is gauge integrable and ∫f = lim ∫fₙ. (If sup ∫fₙ = ∞, f is not integrable, by monotonicity.)
  - Idea only (fading): let A = lim ∫fₙ; fix r with A − ∫f_r < ε. For each n take a Saks–Henstock gauge δₙ for fₙ with tolerance ε·2⁻ⁿ. For each x choose n(x) ≥ r with f(x) − f_{n(x)}(x) < ε, and set δ(x) = δ_{n(x)}(x) — **a gauge chosen pointwise from a sequence**.
  - Proof: for δ-fine Ṗ split S(f, Ṗ) − A into three sums: (i) Σ [f(tᵢ) − f_{n(tᵢ)}(tᵢ)]|Iᵢ| ≤ ε(b − a); (ii) Σ [f_{n(tᵢ)}(tᵢ)|Iᵢ| − ∫_{Iᵢ} f_{n(tᵢ)}], grouped by the value of n(tᵢ), each group a δₙ-fine partial partition, total ≤ Σ ε·2⁻ⁿ ≤ ε; (iii) Σ ∫_{Iᵢ} f_{n(tᵢ)} − A, squeezed between ∫f_r − A > −ε and ∫f_p − A ≤ 0 with p = max n(tᵢ), using monotonicity on each Iᵢ and additivity. Total < ε(b − a + 2).
- **`exm-mct-dirichlet`** (pays the limit hook a second time): fₙ ↑ 1_ℚ, ∫fₙ = 0 ⇒ ∫1_ℚ = 0.
- **`exm-mct-inverse-sqrt`.** fₙ = min(1/√x, n) on (0, 1], fₙ(0) = 0: each is Riemann integrable with ∫fₙ = 2 − 1/n; MCT gives ∫₀¹ 1/√x = 2, matching `exm-inverse-sqrt`. Show the computation ∫₀^{1/n²} n + ∫_{1/n²}^1 x^{−1/2} = 1/n + 2 − 2/n.
- **`thm-gauge-dct` — stated, not proved.** If fₙ → f pointwise and g ≤ fₙ ≤ h with g, h gauge integrable, then f is gauge integrable and ∫fₙ → ∫f. Say plainly that the proof needs a lattice property (max and min of integrable functions with an integrable bound are integrable) whose proof uses measure-theoretic ideas; MT proves the Lebesgue version. **No exercise or proof in this chapter uses it.**
- **Quick check.** Can MCT be applied to fₙ = n·1_{(0,1/n)} on [0, 1]? *Answer:* no — the sequence is not increasing (and fₙ → 0 while ∫fₙ = 1).
- **Warning.** MCT needs monotonicity *at every point* (here; MT relaxes to almost every point). The example in the Quick check shows what fails without it.
- **Exercises.**
  - **A1.** In `lem-saks-henstock`, why must the partial partition be δ-fine for the *same* δ? *Answer:* the completed partition must be δ-fine to use the hypothesis.
  - **A2.** State MCT for decreasing sequences. *Answer:* apply MCT to −fₙ; requires inf ∫fₙ > −∞.
  - **B1.** Prove `thm-indefinite-gauge-continuous` in full. *Answer:* as sketched, both sides.
  - **B2.** Use MCT to show ∫₀¹ Σₖ 1_{[0, 2⁻ᵏ]} = 1, the sum taken pointwise (with value +∞ excluded: what happens at 0?). *Answer:* the series diverges at 0 only; redefine f(0) = 0 (countable exceptions); partial sums have integrals Σ_{k≤n} 2⁻ᵏ → 1.
  - **B3.** Prove `thm-gauge-uniform-limit` in full. *Answer:* ∫fₙ is Cauchy; choose N, then a gauge for f_N; ε/3.
  - **C1.** Show that the condition sup ∫fₙ < ∞ in MCT cannot be dropped: give increasing fₙ, each gauge integrable, with pointwise limit f finite everywhere and not gauge integrable. *Answer:* fₙ = min(1/x, n) on (0, 1], fₙ(0) = 0; ∫fₙ ≥ the lower bounds of `exm-reciprocal-not-integrable`, unbounded.
  - **C2.** (Term-by-term integration.) Let gₖ ≥ 0 be gauge integrable on [a, b], Σₖ gₖ(x) = g(x) for every x, and Σₖ ∫gₖ < ∞. Prove g is integrable with ∫g = Σ∫gₖ. Apply it to g(x) = Σ_{k≥1} xᵏ/k on [0, 1), g(1) = 0. *Answer:* MCT on partial sums. For the application set gₖ(x) = xᵏ/k on [0, 1), gₖ(1) = 0 (countable exceptions, so ∫gₖ = 1/(k(k + 1))); Σ 1/(k(k + 1)) = 1 by telescoping, so ∫₀¹ g = 1.

## 05-comparison.md — Riemann, improper Riemann, gauge

**Budget:** ≤ 3,800 main-line words (including the two tables and the List of Results).

- **`thm-hake` (improper integrals are gauge integrals).** Let f be gauge integrable on [c, b] for every c ∈ (a, b], and let L = lim_{c→a⁺} ∫ᶜᵇ f exist. Then f is gauge integrable on [a, b] (with any value at a) and ∫ₐᵇ f = L. Conversely, if f is gauge integrable on [a, b], then ∫ᶜᵇ f → ∫ₐᵇ f (from `thm-indefinite-gauge-continuous`).
  - Idea (proof sketch written in full in the draft): take b = c₀ > c₁ > c₂ > ⋯ → a. On [cₖ, cₖ₋₁] take a Saks–Henstock gauge with tolerance ε·2⁻ᵏ; for x ∈ (cₖ, cₖ₋₁) also require δ(x) ≤ dist(x, {cₖ, cₖ₋₁}) and δ(x) ≤ (x − a)/2; at cₖ take the minimum of the two neighbouring gauges; at a choose δ(a) with |∫ᶜᵇ f − L| < ε for a < c < a + δ(a) and |f(a)|·δ(a) < ε. In a δ-fine partition, a is the tag of the first piece [a, x₁] (**tag forcing**); every later piece lies in one [cₖ, cₖ₋₁] after splitting pieces tagged at some cₖ; Saks–Henstock on each block, summed, gives |S(f, Ṗ) − f(a)(x₁ − a) − ∫_{x₁}^b f| ≤ ε; with |f(a)|(x₁ − a) < ε and |∫_{x₁}^b f − L| < ε, |S(f, Ṗ) − L| < 3ε.
  - *S2a item: the piece containing x₁ lies in a block only partly covered; check that Saks–Henstock (partial partitions) handles it, and that the splitting at cₖ keeps fineness.*
  - Consequence: every absolutely or conditionally convergent improper Riemann integral on a bounded interval is a gauge integral with the same value. `exm-gauge-ftc-hook` and `exm-inverse-sqrt` are instances.
- **`exm-reciprocal-not-integrable`.** f(x) = 1/x on (0, 1], f(0) = 0, is not gauge integrable. Proof without logarithms: on [2⁻ᵏ, 2⁻ᵏ⁺¹], f ≥ 2ᵏ⁻¹, so ∫ ≥ 1/2 there (Riemann, monotone); if f were integrable on [0, 1], then for every m, ∫₀¹ f ≥ ∫_{2⁻ᵐ}^1 f ≥ m/2 (`thm-gauge-subinterval`, `thm-gauge-additive`, f ≥ 0). Aftermath: Hake's theorem needs the limit to *exist*.
- **`thm-gauge-not-absolute` and `exm-not-absolute`.** There is a gauge-integrable f with |f| not gauge integrable: f = F′ for F(x) = x² cos(π/x²), F(0) = 0.
  - F is differentiable on [0, 1] (F′(0) = 0), so f is integrable (`thm-gauge-ftc`).
  - With aₖ = (2/(4k + 1))^{1/2} and bₖ = (2k)^{−1/2}: F(aₖ) = 0, F(bₖ) = 1/(2k), and the intervals [aₖ, bₖ] ⊆ (0, 1] are pairwise disjoint (bₖ₊₁ < aₖ < bₖ). If |f| were integrable, then ∫₀¹ |f| ≥ Σ_{k≤m} ∫_{aₖ}^{bₖ} |f| ≥ Σ_{k≤m} |F(bₖ) − F(aₖ)| = Σ_{k≤m} 1/(2k), unbounded (AN1.3). Uses `thm-gauge-subinterval`, `thm-gauge-additive`, `thm-gauge-monotone`, and `thm-gauge-ftc` on each [aₖ, bₖ].
  - *S2a: verify cos(π(4k + 1)/2) = 0 and cos(2πk) = 1, and the interlacing bₖ₊₁ < aₖ.*
