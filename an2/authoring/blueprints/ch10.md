**Purpose.**
- AN2.2 proved Banach's fixed-point theorem (Apostol 4.48) and promised a payoff. This chapter pays it. It solves initial value problems y′ = f(t, y), y(t₀) = y₀ in ℝⁿ by turning them into fixed-point problems for the **Picard operator** on a closed ball of C(I, ℝⁿ), which is complete by AN1.9.
- It removes Apostol's restriction h < 1/L: the iterates Tᵐ contract even when T does not (factorial beats geometric).
- It proves Gronwall's inequality. From it come global uniqueness, Lipschitz dependence on the initial value, and continuous dependence on the right-hand side and on parameters.
- It ends with the global picture: maximal solutions, the blow-up alternative, and global existence for systems that are Lipschitz on strips, linear systems in particular.
- The reader leaves able to:
  - (i) rewrite an IVP or an integral equation as x = Tx on a complete space, choosing the space so that T maps it into itself;
  - (ii) decide whether T, or some Tᵐ, contracts, and bound the error of the k-th iterate;
  - (iii) name the hypothesis that fails in each of the chapter's weird examples;
  - (iv) apply Gronwall to compare two solutions;
  - (v) decide whether a solution exists for all time.

## 01-ivp-fixed-point.md — The Initial Value Problem as a Fixed-Point Problem

**Budget:** ≤ 3,800 main-line words. **Fading level:** full (first section).

- **Hook** (the chapter's two IVPs, stated as examples).
  - `exm-cube-root-nonunique` [Infinitely many solutions]: y′ = y^{1/3}, y(0) = 0 (real cube root, defined on all of ℝ).
    - For each c ≥ 0, y_c(t) = 0 for t ≤ c and y_c(t) = (2(t − c)/3)^{3/2} for t ≥ c; −y_c is a solution too.
    - Check: for t > c, y_c′(t) = (2(t − c)/3)^{1/2} = y_c(t)^{1/3}; at t = c both one-sided derivatives are 0.
    - Also y ≡ 0. Backward from 0 nothing branches: y^{1/3} has the sign of y, so |y| can only grow forward (§04 B2 uses this). One sentence: the right-hand side is continuous, so continuity alone cannot be what forces uniqueness.
  - `exm-ivp-blowup` [A polynomial right-hand side that blows up]: y′ = y², y(0) = 1.
    - y(t) = 1/(1 − t) solves it on (−∞, 1), and |y(t)| → ∞ as t → 1⁻.
    - Whether some other solution continues past 1 is left open here and settled in §05.
- **Definition, failure-motivated** (why say "on an interval": y = 1/(1 − t) also "solves" the equation on (1, ∞), on the wrong side of the singularity, and that piece has nothing to do with the initial value).
  - `def-ivp` [Initial value problem; solution on an interval]. D ⊆ ℝ × ℝⁿ, f: D → ℝⁿ continuous, (t₀, y₀) ∈ D.
  - A solution on an interval J ∋ t₀ (J not a single point) is a differentiable y: J → ℝⁿ with (t, y(t)) ∈ D for all t ∈ J, y′(t) = f(t, y(t)) for t ∈ J (one-sided at endpoints of J in J), and y(t₀) = y₀.
  - Systems: n components. Quantifiers are shown in symbols after the prose (STYLE §10).
- **Vector-valued integrals.**
  - `lem-vector-integral` [Integrals of ℝⁿ-valued functions]. For g: [a, b] → ℝⁿ continuous, ∫ₐᵇ g is taken componentwise. Then:
    - (a) the integral is linear and additive over intervals;
    - (b) if g is continuous on an interval J and t₀ ∈ J, then G(t) = ∫_{t₀}^t g is C¹ on J with G′ = g; if y is C¹ on J, then y(t) − y(t₀) = ∫_{t₀}^t y′;
    - (c) |∫ₐᵇ g| ≤ ∫ₐᵇ |g|.
  - Proof of (a) and (b): componentwise, from AN1.8's FTC.
  - Proof of (c): v ≔ ∫g; if v = 0 there is nothing to prove; otherwise |v|² = Σ vᵢ∫gᵢ = ∫⟨v, g⟩ ≤ ∫|v||g| (Cauchy–Schwarz, F4.8, and monotonicity, AN1.8); divide by |v| > 0.
  - Warning: (c) is not "componentwise (c)". The Euclidean norm needs the Cauchy–Schwarz step.
- **The equivalence.**
  - `thm-ivp-integral-equation` [IVP ⟺ integral equation]. f continuous on D; y: J → ℝⁿ continuous with graph in D. Then y solves the IVP on J if and only if y(t) = y₀ + ∫_{t₀}^t f(s, y(s)) ds for all t ∈ J. In that case y is C¹.
  - Proof: (⇒) y′ = f(·, y(·)) is continuous (composition, AN1.5), so y is C¹ and the FTC (`lem-vector-integral` (b)) applies. (⇐) The integrand is continuous, so the right-hand side is C¹ with derivative f(t, y(t)) by (b); evaluate at t₀.
  - Aftermath: the integral equation asks only for **continuity**, which is what a complete space of continuous functions can deliver.
  - Quick check (why continuity of f matters): f(t, y) = 0 for t < 0 and f(t, y) = 1 for t ≥ 0. Is y(t) = t₊ a solution of the integral equation with y(0) = 0? Is it a solution of the IVP on (−1, 1)? *Answer:* yes; no, since y is not differentiable at 0. The equivalence needs f continuous.
- **The Picard operator.**
  - `def-picard-operator` [Picard operator; Picard iterates]. (Tu)(t) ≔ y₀ + ∫_{t₀}^t f(s, u(s)) ds, defined for continuous u on J with graph in D. The iterates are u₀ ≡ y₀ and u_{k+1} ≔ Tu_k (whenever defined).
  - Remark: solutions on J are exactly the fixed points of T among continuous maps J → ℝⁿ with graph in D (`thm-ivp-integral-equation`). Whether T is even defined on a whole space (the graph must stay in D) is the first thing §03 arranges.
  - `exm-picard-exponential` [Picard rebuilds the exponential] (worked).
    - y′ = y, y(0) = 1: u_k(t) = Σ_{j=0}^k t^j/j! by induction.
    - On every [−r, r] the iterates converge uniformly to exp (AN1.10's series, M-test with r^j/j!), and the limit is a fixed point: pass to the limit under ∫ by AN1.9's uniform-limit theorem.
    - Sentence: the fixed-point view rediscovers AN1.10's series, and §03's uniqueness will show that exp is the only solution.
  - `exm-picard-gaussian` [A second exponential] (worked): y′ = 2ty, y(0) = 1. u_k(t) = Σ_{j≤k} t^{2j}/j!, which tends to e^{t²}.
  - Quick check: write the IVP y″ = −y, y(0) = 0, y′(0) = 1 as an integral equation for Y = (y, y′). *Answer:* Y(t) = (0, 1) + ∫₀ᵗ (Y₂(s), −Y₁(s)) ds.
- **Exercises.**
  - **A1** (parts):
    - (a) Write y′ = t + y, y(0) = 0 as an integral equation, and compute u₁ and u₂. *Answer:* u₁ = t²/2, u₂ = t²/2 + t³/6.
    - (b) True or false: a continuous solution of the integral equation, with f continuous, is differentiable. *Answer:* true, by `thm-ivp-integral-equation`.
    - (c) Why is y_c with c < 0 not a solution in `exm-cube-root-nonunique`? *Answer:* y_c(0) = −c³ ≠ 0.
    - (d) In `def-ivp`, why must the graph lie in D? *Answer:* otherwise f(t, y(t)) is undefined.
  - **B1** [Iterates and Taylor coefficients]. Compute the Picard iterates u₁, u₂, u₃ for y′ = 1 + y², y(0) = 0. Compare them with tan t = t + t³/3 + 2t⁵/15 + 17t⁷/315 + ⋯ (series quoted from AN1.10's exercises or computed). Hence state up to which power u₃ agrees with tan.
    - *Answer:* u₁ = t, u₂ = t + t³/3, u₃ = t + t³/3 + 2t⁵/15 + t⁷/63. Agreement through t⁵, since 1/63 = 5/315 ≠ 17/315.
  - **B2** [Checking a family]. Verify that −y_c solves y′ = y^{1/3}, y(0) = 0 on ℝ for every c ≥ 0, and that the function equal to y_c for t ≥ 0 and to 0 for t < 0 is differentiable at 0. Hence list four different solutions on (−1, 1).
    - *Answer:* (−y)^{1/3} = −y^{1/3} (odd root). Examples: y ≡ 0, y₀, −y₀, y_{1/2}.
  - **C1** [Local, not global]. (a) Show that y₀/(1 − y₀t) solves y′ = y², y(0) = y₀ > 0 on (−∞, 1/y₀). (b) Deduce that no single h > 0 can serve as an existence time for all y₀ > 0 with this formula's solution. (c) Explain in one sentence why this forces any existence theorem for y′ = y² to be **local**.
    - *Answer:* (a) differentiate. (b) 1/y₀ → 0 as y₀ → ∞. (c) The formula's solution dies at 1/y₀, and §05 shows nothing else continues it.

## 02-contraction-revisited.md — The Contraction Principle, Revisited

**Budget:** ≤ 4,500 words. **Fading:** Idea + back-reference to AN2.2 (the theorem itself is not re-proved).

- **Spiral opening** (STYLE §10): recall AN2.2's `def-contraction` and `thm-banach-fixed-point` with `@ref`, in one statement block marked "Recall" (no proof). One sentence: AN2.2 had only a few examples; here the spaces are function spaces, and the questions are how fast and with which power of T.
- **Error bounds.**
  - `cor-contraction-error-bounds` [A-priori and a-posteriori bounds]. X complete, T a contraction with constant q ∈ [0, 1), x₀ ∈ X, xₙ ≔ Tⁿx₀, x* the fixed point. Then:
    - (a) d(xₙ, x*) ≤ qⁿ/(1 − q) · d(x₁, x₀);
    - (b) d(xₙ, x*) ≤ q/(1 − q) · d(xₙ, x_{n−1}) for n ≥ 1.
  - Proof:
    - (a) Telescoping gives d(x_{n+k}, xₙ) ≤ Σ_{j<k} q^{n+j} d(x₁, x₀) ≤ qⁿ/(1 − q) · d(x₁, x₀); let k → ∞, using continuity of d.
    - (b) d(xₙ, x*) ≤ d(xₙ, x_{n+1}) + d(x_{n+1}, x*) ≤ q d(x_{n−1}, xₙ) + q d(xₙ, x*); rearrange (1 − q > 0).
  - If AN2.2 already has (a), this becomes a recall plus (b).
  - `exm-cosine-fixed-point` [Solving cos x = x with a guarantee] (worked; sidecar `verify/ch10/cosine.py`).
    - X = [0, 1] is closed in ℝ, so complete; cos maps [0, 1] into [cos 1, 1] ⊆ [0, 1].
    - By the MVT, |cos x − cos y| ≤ (sin 1)|x − y| (|sin ξ| ≤ sin 1 for ξ ∈ [0, 1]), so q = sin 1 ≈ 0.84147.
    - x₀ = 1 gives d(x₁, x₀) = 1 − cos 1 ≈ 0.45970.
    - A-priori: qⁿ/(1 − q) · 0.45970 ≤ 10⁻⁶ holds for n ≥ 87.
    - In fact 32 iterations already reach accuracy 10⁻⁶ (x* ≈ 0.7390851).
    - After 20 iterations the a-posteriori bound is ≈ 1.3 × 10⁻³, against a true error ≈ 9.9 × 10⁻⁵.
    - Lesson in one sentence: the a-priori bound is a guarantee, not an estimate.
  - Quick check: on which interval [0, r] is x ↦ x² a contraction mapping [0, r] into itself? *Answer:* any r < 1/2: |x² − y²| ≤ 2r|x − y| and r² ≤ r.
- **Each hypothesis is needed** (the weird examples; STYLE §10 "a counterexample for every hypothesis").
  - `exm-shrinking-no-fixed-point` [Shrinking every distance is not enough]. T(x) = √(1 + x²) on [0, ∞), which is complete.
    - |Tx − Ty| = |x − y|(x + y)/(√(1 + x²) + √(1 + y²)) < |x − y| for x ≠ y.
    - T(x) > x for all x, so there is no fixed point.
    - The ratio |Tx − Ty|/|x − y| → 1 as x, y → ∞, so no uniform q exists.
  - `exm-contraction-incomplete` [A contraction on an incomplete space]: T(x) = x/2 on (0, 1]. The constant is q = 1/2, and the only candidate, 0, lies outside the space.
  - Warning: "d(Tx, Ty) < d(x, y) for x ≠ y" is called a weak contraction in some books; Banach's theorem does not apply to it. (Exception, compact X: §05 R3.)
- **When T does not contract but a power does.**
  - Motivation: the Volterra equation u(x) = 1 + λ∫₀ˣ u on [0, 1]. ‖Tu − Tv‖_∞ ≤ |λ|‖u − v‖_∞ is sharp (take u − v ≡ 1), so for |λ| ≥ 1 the theorem says nothing. Yet the solution e^{λx} exists for every λ.
  - `thm-iterate-contraction` [A contracting iterate suffices]. X complete, T: X → X (no continuity assumed), Tᵐ a contraction for some m ≥ 1. Then T has exactly one fixed point x*, and Tᵏx → x* for every x ∈ X.
    - *Try it first:* show that T x* is a fixed point of Tᵐ.
    - Proof:
      - Tᵐ(Tx*) = T(Tᵐx*) = Tx*, so Tx* = x* by uniqueness for Tᵐ.
      - Any fixed point of T is fixed by Tᵐ, which gives uniqueness.
      - For r = 0, …, m − 1, T^{km+r}x = (Tᵐ)ᵏ(Tʳx) → x* as k → ∞, and m subsequences that cover ℕ all converge to x*.

## 04-gronwall-dependence.md — Gronwall's Inequality and Dependence on the Data

**Budget:** ≤ 4,000 words. **Fading:** Scratch Work 2 (first appearance of the Gronwall move); fixed-point set-up now at "last step blank" (B1).

- **Hook.** `thm-picard-lindelof` gives uniqueness only on the small interval I_h and only among solutions in the ball. Two questions: do two solutions on a long common interval agree? If the initial values differ by δ, how far apart are the solutions at time t?
- **Scratch work 2** [an integral inequality, treated like a linear ODE].
  - From φ(t) ≤ A + L∫_{t₀}^t φ, put Ψ ≔ ∫_{t₀}^t φ, so Ψ′ ≤ A + LΨ.
  - If it were an equality, the solution would be (A/L)(e^{L(t−t₀)} − 1). So multiply by e^{−L(t−t₀)}: (e^{−L(t−t₀)}Ψ)′ ≤ Ae^{−L(t−t₀)}.
  - Integrate, then substitute back into φ ≤ A + LΨ.
  - Show the dead end first: iterating the inequality gives the exponential series term by term (as in Step 3 of §03). That route works too, but it is longer.
- `lem-gronwall` [Gronwall's inequality]. **Key proof 2.**
  - Hypotheses: φ continuous on [t₀, t₁]; A, B ≥ 0, L > 0; φ(t) ≤ A + B(t − t₀) + L∫_{t₀}^t φ for t ∈ [t₀, t₁].

- `thm-uniqueness-lipschitz` [Uniqueness on any common interval]. D open, f continuous and locally Lipschitz in y on D. If y, z solve the IVP on an interval J ∋ t₀, then y = z on J.
  - *Try it first:* show they agree near t₀.
  - Proof:
    - s* ≔ sup{s ∈ J, s ≥ t₀ : y = z on [t₀, s]}.
    - If s* is an interior point of J, then y(s*) = z(s*) by continuity. Take a neighbourhood U of (s*, y(s*)) with Lipschitz constant L; both graphs stay in U on [s*, s* + η].
    - φ ≔ |y − z| satisfies φ ≤ L∫_{s*}^t φ, so φ ≡ 0 there by `lem-gronwall` with A = B = 0. This contradicts the choice of s*.
    - The backward half is symmetric.
  - Aftermath: the "silent" iterates of `exm-picard-silent` now make sense: wherever f is locally Lipschitz, nothing else can be heard.
- `thm-dependence-initial-data` [Lipschitz dependence on the initial value]. f continuous on D and Lipschitz in y on D with constant L; y, z solutions of y′ = f(t, y) on J ∋ t₀ (with any initial values). Then |y(t) − z(t)| ≤ |y(t₀) − z(t₀)|e^{L|t−t₀|} for t ∈ J.

  - Proof (both theorems): φ = |y − z| ≤ |y(t₀) − z(t₀)| + ε|t − t₀| + L∫φ by `lem-vector-integral` (c); apply `lem-gronwall` with B = ε (forward and backward).

Λ a metric space; f(t, y, λ) on D × Λ, continuous in (t, y) and Lipschitz in y with one L for all λ, and sup_D |f(·, ·, λ) − f(·, ·, μ)| → 0 as μ → λ. Then solutions with the same initial point, on a common bounded J, satisfy ‖y_λ − y_μ‖_∞ → 0 as μ → λ.

## 05-maximal-solutions.md — Maximal Solutions, Blow-up, and Global Existence

**Budget:** ≤ 4,800 words. **Fading:** Idea + back-reference for set-ups; main move at "last half blank" (C1). Last section: the R group and the List of Results.

- **Hook paid, second half** (the chapter's y′ = y²): solutions of y′ = y², y(0) = 1 exist on (−1, 1/2) and on (−5, 0.9), and all are pieces of 1/(1 − t). "The" solution needs a largest interval.
- **Failure-motivated definition.**
  - `def-extension-maximal` [Extension; maximal solution]. A solution (J̃, ỹ) extends (J, y) if J ⊆ J̃ and ỹ|_J = y. A solution is maximal if it has no extension to a strictly larger interval.
- **Compactness supplies uniform constants (AN2.3).**
  - `lem-locally-lipschitz-compact` [Lipschitz on compact sets]. f continuous and locally Lipschitz in y on open D; K ⊆ D compact. Then f is Lipschitz in y on K.
  - Proof by contradiction: take pairs with |f(t, yₖ) − f(t, zₖ)| > k|yₖ − zₖ|. Then |yₖ − zₖ| ≤ 2M/k, where M = max_K |f|. A common subsequence converges to a single point (t, y) ∈ K, and that contradicts the local constant at (t, y).
  - `cor-picard-uniform-time` [A uniform existence time on compact sets]. D open, f continuous and locally Lipschitz in y, K ⊆ D compact. There is h > 0 such that for every (s, z) ∈ K the IVP with initial point (s, z) has a solution on [s − h, s + h].
  - Proof:
    - δ ≔ ½ dist(K, ℝ^{n+1} ∖ D) > 0 (or δ = 1 if D is the whole space).
    - K_δ ≔ {p : dist(p, K) ≤ δ} is compact (Heine–Borel) and contained in D.
    - M ≔ 1 + max_{K_δ}|f|, and L from the lemma on K_δ.
    - For (s, z) ∈ K the box with a = b = δ/√2 lies in K_δ. Apply `thm-picard-lindelof` with h = min{δ/√2, δ/(√2M)}.
- `thm-maximal-solution` [Existence and uniqueness of the maximal solution]. D open, f continuous and locally Lipschitz in y. For each (t₀, y₀) ∈ D there is exactly one maximal solution. Its interval (α, β) is open (−∞ ≤ α < t₀ < β ≤ ∞), and every solution of the IVP is a restriction of it.
  - Proof:
    - Take the union of the intervals of all solutions. Glue the solutions; this is well defined by `thm-uniqueness-lipschitz` (overlaps are intervals containing t₀).
    - The glued function is a solution (differentiability is local).
    - Openness: if β belonged to the interval, apply `cor-picard-lindelof-open` at (β, y(β)) and glue through the integral equation. That gives a strict extension, a contradiction.
- `thm-blowup-alternative` [The blow-up alternative]. **Key proof 3.**
  - Hypotheses as above; y the maximal solution on (α, β).
  - If β < ∞, then for every compact K ⊆ D there is t_K < β with (t, y(t)) ∉ K for all t ∈ (t_K, β). The same holds at α.
  - Idea: if the graph returned to K at times tₖ → β, start a solution at (tₖ, y(tₖ)) that lives for a **uniform** time h. Once tₖ > β − h, it reaches past β. *Before reading on: why must h not depend on k?*
  - Proof:
    - Suppose not: there are tₖ ↑ β with (tₖ, y(tₖ)) ∈ K.
    - h from `cor-picard-uniform-time`. Pick k with tₖ > β − h.
    - The solution z through (tₖ, y(tₖ)) lives on [tₖ − h, tₖ + h] and agrees with y on the overlap (`thm-uniqueness-lipschitz`).
    - Gluing gives a solution on (α, tₖ + h) ⊋ (α, β), contradicting maximality.
- `cor-blowup-rn` [Blow-up in ℝⁿ]. If D = (α₀, β₀) × ℝⁿ and β < β₀, then |y(t)| → ∞ as t → β⁻.
  - Proof: K = [t₀, β] × \bar B(0, r) is compact in D for each r.
- `exm-blowup-revisited` [y′ = y² again]. The maximal interval is (−∞, 1) and |y| → ∞, as the corollary demands. The hook is paid: "smooth on ℝ²" does not prevent blow-up, because blow-up is about growth, not smoothness.
- `exm-backward-blowup` [Global one way only]. y′ = −y³, y(0) = 1: y = (1 + 2t)^{−1/2} on (−1/2, ∞). It is global forward and blows up backward.
- **Global existence.**
  - `thm-global-existence-lipschitz` [Global existence for strip-Lipschitz systems]. J = (α₀, β₀) open (possibly infinite), f continuous on J × ℝⁿ, and for each compact [c, d] ⊆ J f is Lipschitz in y on [c, d] × ℝⁿ. Then every maximal solution is defined on all of J.
  - Proof (**a priori bound plus continuation**):
    - Suppose β < β₀ and pick d ∈ (β, β₀).
    - On [t₀, d] × ℝⁿ: |f(t, y)| ≤ C + L|y| with C = max_{[t₀, d]} |f(t, 0)| (EVT, AN1.6).
    - So |y(t)| ≤ |y₀| + C(t − t₀) + L∫|y| on [t₀, β). By `lem-gronwall`, y is bounded there.
    - That contradicts `cor-blowup-rn`. Backward is symmetric.
  - `cor-linear-global` [Linear systems are global]. A: J → ℝ^{n×n} and g: J → ℝⁿ continuous. Then y′ = A(t)y + g(t), y(t₀) = y₀ has a unique solution on all of J.
    - Proof: the Lipschitz constant on [c, d] is max ‖A(t)‖, where ‖A‖ is the Frobenius norm (Cauchy–Schwarz row by row; no operator-norm theory, which is AN3.1).
    - Forward pointer: the solution formula (matrix exponential, variation of constants) is AN3.3.
  - `exm-pendulum-global` [The pendulum swings forever]. y″ = −sin y as a system is globally Lipschitz (constant 1, since |sin a − sin b| ≤ |a − b|), so every solution exists on ℝ.
- **Exercises.**
  - **A1:**
    - (a) Define a maximal solution.
    - (b) True or false: if f is C¹ on ℝ², every maximal solution of y′ = f(t, y) is defined on ℝ. *Answer:* F, `exm-blowup-revisited`.
    - (c) Proof comprehension (key proof 3): why must h be uniform? *Answer:* times h(tₖ) → 0 might never reach past β.
    - (d) The maximal interval of y′ = 1 + y², y(0) = 0. *Answer:* (−π/2, π/2), with y = tan.
    - (e) Which hypothesis of `thm-maximal-solution` fails for y′ = y^{1/3}, and what goes wrong? *Answer:* local Lipschitz at y = 0; maximal solutions exist but are not unique.
  - **B1** [A maximal solution]. Find the maximal solution of y′ = 2ty², y(0) = 1. *Answer:* 1/(1 − t²) on (−1, 1).
  - **B2** [Global by the theorem]. Show that every solution of y′ = t sin y + cos t exists on ℝ. *Answer:* the Lipschitz constant on [c, d] × ℝ is max(|c|, |d|).
  - **B3** [Sign of the initial value]. Find the maximal solution of y′ = y², y(0) = −1, and say where |y| → ∞. *Answer:* −1/(1 + t) on (−1, ∞); at −1.
  - **C1** [Faded triple, third instance: last half blank. Global existence by a weighted norm].
    - On C([c, d], ℝⁿ) let ‖u‖_L ≔ sup e^{−2L|t−t₀|}|u(t)|, with t₀ ∈ [c, d] and f continuous and Lipschitz with L on [c, d] × ℝⁿ.
    - (a) ‖·‖_L is equivalent to ‖·‖_∞ (constants 1 and e^{2L(d−c)}), so the space is complete.
    - (b) The Picard operator satisfies ‖Tu − Tv‖_L ≤ ½‖u − v‖_L. Only the first line is given: |Tu(t) − Tv(t)| ≤ L|∫_{t₀}^t e^{2L|s−t₀|} ds| · ‖u − v‖_L. The prompt: "*Name the move, then complete it.*"
    - (c) Deduce existence on [c, d] **without** the blow-up alternative.
    - Marking scheme.
  - **C2** [An a priori bound]. For y′ = −y³ with any y(0):
    - (a) (y²)′ ≤ 0, so every solution is bounded forward and global forward;
    - (b) for y(0) ≠ 0 the backward maximal time is finite. Compute it: α = −1/(2y(0)²).
  - **C3** [Exit check: blow-up]. Prove `cor-blowup-rn` from `thm-blowup-alternative`. Then show that the maximal solution of y′ = y² + t², y(0) = 0 has β < ∞.
    - *Hint ladder:* rung 1: compare with y′ = y² + 1 on t ≥ 1; rung 2: for t ≥ 1, y′ ≥ 1 + y², so arctan y(t) ≥ t − 1 + arctan y(1).
    - *Answer:* β ≤ 1 + π/2.
    - Marking scheme.
  - **C4** [Linear systems in practice]. For y′ = (sin t)y + 1, y(0) = 0, show the solution is global and write it by the integrating factor. *Answer:* y = e^{−cos t}∫₀ᵗ e^{cos s} ds.
- **R. Review** (STYLE §11.5; the problems never name their source, the solutions do):
  - **R1** (previous chapter, AN2.13). Find lim_{x→1⁻} Σ_{n≥0} (−1)ⁿ(n + 1)xⁿ. *Answer:* 1/4, since the sum is 1/(1 + x)². The solution notes the series is Abel summable but not convergent.
  - **R2** (3–4 back, AN1.9). Show fₙ(x) = xⁿ(1 − x) → 0 uniformly on [0, 1]. *Answer:* the maximum is at x = n/(n + 1) and equals (n/(n + 1))ⁿ/(n + 1) ≤ 1/(n + 1).
  - **R3** (spiral from AN1, AN2.3: compactness). X compact metric and d(Tx, Ty) < d(x, y) for x ≠ y. Show that T has a unique fixed point. *Answer:* x ↦ d(x, Tx) is continuous, so it attains a minimum at p; if Tp ≠ p then d(Tp, T²p) < d(p, Tp), a contradiction. The solution contrasts this with `exm-shrinking-no-fixed-point`: compactness replaces the uniform q.
  - **R4** (no hint of method). Find all continuous u on [0, 1] with u(x) = ∫₀ˣ s u(s) ds. *Answer:* u ≡ 0. Tools: Gronwall with A = 0, or `thm-iterate-contraction`. Differentiating gives u′ = xu, u(0) = 0, and uniqueness. The look-alike "Banach on C[0, 1] with constant 1/2" also works here, and the solution says so and why: sup x = 1, the bound is 1/2 by integrating s.
