# Blueprint: AN2.11 — Integrals with a Parameter, Euler Summation, and the Gamma Function

**Directory:** `an2/src/ch08-parameter-integrals-and-gamma/`. **AN2 chapter 8** in the Apostol layout (`an2/authoring/design/layout-apostol.md`), main line. State: blueprint (S1 done), awaiting S2a. Binding plan: math-atlas `spec/08-map-v2.md` §C3 (row 8), §C5 (AN2 column), §C6 (CL.3 → AN2.11), §E1.

**Purpose.**
- Calculus students differentiate under the integral sign, swap the order of integration and interpolate n! without asking when this is allowed. This chapter says when, proves it, and shows each move failing when a hypothesis is dropped.
- Three payoffs carry the chapter: the Gaussian integral and the Dirichlet integral (∫₀^∞ sin x / x dx = π/2) as showcases of the parameter method; the Euler summation formula, which turns the integral test from a bound into an asymptotic expansion with an error term; and the Gamma function, characterised by Bohr–Mollerup, with Stirling's formula as the closing theorem.
- Everything is Riemann. The domination hypotheses here are uniform-convergence hypotheses; the dominated convergence theorem that removes most of them is MT's (prose pointer only, part of the "what Riemann still lacks" thread opened in AN2.10).

**Placement.** After AN1.10, because Γ needs exp, log and real powers t^{x−1} = e^{(x−1) log t}, and the Gaussian computation needs arctan 1 = π/4 (π as defined in AN1.10). This is one of the two allowed deviations from Apostol's section order (`apostol-ma` `deviations`, spec/08 E2 item 4).

## Named moves (index.md, "Named moves")

- **Differentiate a family, then integrate the answer** (the parameter trick): embed a hard number I as F(t₀) of a family whose derivative is easy, compute F′, integrate, fix the constant at a convenient t.
- **Uniform tail control:** to pass a limit, derivative or integral through ∫_a^∞, make sup_t |∫_R^∞ f(x,t) dx| small, then treat F_R(t) = ∫_a^R f(x,t) dx as a uniformly convergent sequence (R = R_k) and quote AN1.9.
- **Sum = integral + sawtooth correction:** write Σ f(n) = ∫ f d⌊x⌋, replace ⌊x⌋ by x − ½ − P₁(x), integrate by parts; repeat with P₂, P₃ to push the error down.
- **Log-convexity by Cauchy–Schwarz:** for F(x) = ∫ w(t) e^{x φ(t)} dt with w ≥ 0, F F″ ≥ (F′)².
- **Squeeze by slopes:** a convex function's difference quotients increase; trap the unknown value between two known slopes (Bohr–Mollerup, and Stirling for real arguments).

## 01-parameter-integrals.md — Integrals that depend on a parameter (budget ≤ 4,200 main-line words)

- **Hook.** F(t) = ∫₀^1 x/(1 + t x²) dx can be computed in closed form, log(1 + t)/(2t). Differentiating under the sign and then setting t = 1 gives ∫₀^1 x³/(1 + x²)² dx with no new antiderivative work. Is that legal? Show next to it the weird example where the same move gives a wrong answer.
- **`exm-diff-under-integral-fails`** (weird example, shown before the theorem). f(x,t) = x t³/(x² + t²)² for (x,t) ≠ (0,0), f(0,0) = 0. Then F(t) = ∫₀^1 f(x,t) dx = t / (2(1 + t²)), so F′(0) = 1/2; but ∂f/∂t(x,0) = 0 for every x ∈ [0,1], so ∫₀^1 ∂f/∂t(x,0) dx = 0. The culprit: f(t,t) = 1/4 for t ≠ 0, so f is not even continuous at the origin, and f_t is not continuous on the rectangle. (Verified with sympy.)
- **`def-parameter-integral`**: for f : [a,b] × T → ℝ with each f(·,t) integrable, F(t) = ∫_a^b f(x,t) dx. Short; the definition is notation.
- **`thm-parameter-continuity`**: f continuous on [a,b] × [c,d] ⇒ F continuous on [c,d].
  - *Proof sketch:* the rectangle is compact (AN1.4), so f is uniformly continuous (AN2.3); |F(t) − F(s)| ≤ (b − a) sup_x |f(x,t) − f(x,s)| < (b − a)ε once |t − s| < δ.
- **`thm-diff-under-integral`**: f and ∂f/∂t continuous on [a,b] × [c,d] ⇒ F is differentiable on [c,d] (one-sided at endpoints) and F′(t) = ∫_a^b ∂f/∂t(x,t) dx; F′ is continuous.
  - **Scratch Work** (first appearance; kept apart from the proof): write the difference quotient as ∫ (f(x,t+h) − f(x,t))/h dx; MVT in t gives ∂f/∂t(x, t + θh) with θ = θ(x,h) depending on x; the trouble is that θ depends on x, so uniform continuity of f_t on the rectangle is exactly what removes the dependence. Work out which δ is needed from the ε wanted at the end, then write the proof forwards.
  - *Proof:* given ε, uniform continuity of f_t gives δ; for 0 < |h| < δ, MVT pointwise in x gives |(f(x,t+h) − f(x,t))/h − f_t(x,t)| < ε for every x; integrate. Continuity of F′ is `thm-parameter-continuity` applied to f_t.
  - Say in one sentence where the weird example fails: f_t is not continuous at (0,0).
  - The R–S version (Apostol 7.24, integrator α of bounded variation on [a,b] in place of dx) is stated in a remark with "the same proof, with |∫ g dα| ≤ sup|g| · V(α)" (AN2.10). Not used later in this chapter.
- **`thm-leibniz-rule`**: f, f_t continuous on [a,b] × [c,d], u, v : [c,d] → [a,b] differentiable ⇒ d/dt ∫_{u(t)}^{v(t)} f(x,t) dx = f(v(t),t) v′(t) − f(u(t),t) u′(t) + ∫_{u(t)}^{v(t)} f_t(x,t) dx.
  - *Proof sketch:* H(p,q,t) = ∫_p^q f(x,t) dx has continuous partials H_q = f(q,t) (FTC), H_p = −f(p,t), H_t = ∫_p^q f_t (`thm-diff-under-integral`); the chain rule for H(u(t), v(t), t) needs H differentiable, which follows from continuity of its partials. **Prerequisite issue:** "continuous partials ⇒ differentiable" is AN3.1 (later). Route around it: prove the one-variable claim directly by splitting the difference quotient into three pieces (∫_{v(t)}^{v(t+h)} f(x,t+h) dx/h → f(v(t),t) v′(t) by uniform continuity and the integral MVT; same at u; the middle piece by `thm-diff-under-integral`). The blueprint fixes this three-piece route. S2a: check no step uses the multivariable chain rule.
- **`thm-interchange-order`** (Apostol 7.25, continuous case): f continuous on [a,b] × [c,d] ⇒ ∫_a^b (∫_c^d f(x,y) dy) dx = ∫_c^d (∫_a^b f(x,y) dx) dy.
  - *Proof sketch (by the parameter trick):* for u ∈ [a,b] put φ(u) = ∫_a^u ∫_c^d f(x,y) dy dx and ψ(u) = ∫_c^d ∫_a^u f(x,y) dx dy. Both vanish at a. φ′(u) = ∫_c^d f(u,y) dy by FTC and `thm-parameter-continuity`. For ψ, g(u,y) = ∫_a^u f(x,y) dx has ∂g/∂u = f(u,y), continuous on the rectangle, so `thm-diff-under-integral` gives ψ′(u) = ∫_c^d f(u,y) dy. Equal derivatives, equal at a.
  - Remark (prose only): AN3.4 generalises this to integrable f on rectangles (Fubini for Riemann integrals); MT removes the boundedness.
- **`exm-iterated-integrals-differ`** (weird example). g(x,y) = (x − y)/(x + y)³ on (0,1] × (0,2]. Integrating in y first: ∫₀^2 g dy = 2/(x + 2)², then ∫₀^1 2/(x + 2)² dx = **1/3**. Integrating in x first gives **−2/3**. (Inner antiderivative: (x − y)/(x + y)³ = 2x/(x + y)³ − 1/(x + y)², so ∂/∂y of y/(x + y)² is g. Values verified with sympy.) g is continuous on the half-open rectangle but unbounded near (0,0), so `thm-interchange-order` does not apply; the integrals are improper. Both iterated values exist and differ by 1.
- **`exm-gaussian-by-parameter`** (worked example; proves `thm-gaussian-integral`: ∫₀^∞ e^{−x²} dx = √π / 2).
  - F(t) = (∫₀^t e^{−x²} dx)², G(t) = ∫₀^1 e^{−t²(1 + x²)}/(1 + x²) dx. F′(t) = 2e^{−t²} ∫₀^t e^{−x²} dx (FTC); G′(t) = −2t e^{−t²} ∫₀^1 e^{−t²x²} dx = −2e^{−t²} ∫₀^t e^{−u²} du (`thm-diff-under-integral`, then u = tx). So F + G is constant, equal to G(0) = arctan 1 = π/4 (AN1.10). 0 ≤ G(t) ≤ e^{−t²} π/4 → 0. Hence (∫₀^∞ e^{−x²})² = π/4; the improper integral converges by comparison with e^{−x} on [1,∞) (AN1.8).
  - Only proper integrals are differentiated: the limit t → ∞ is taken after the identity is proved. Point this out; §02 is for when that is not possible.
- **Quick checks.**
  - (a) Can `thm-diff-under-integral` be applied to ∫₀^1 |x − t| dx on [0,1]? *Answer:* no, f_t does not exist on the diagonal; yet F(t) = t² − t + 1/2 is differentiable. The theorem's hypotheses are sufficient, not necessary.
  - (b) In `exm-iterated-integrals-differ`, which hypothesis of `thm-interchange-order` fails? *Answer:* g is not continuous (not even bounded) on the closed rectangle.
- **Exercises.**
  - **A1.** Compute d/dt ∫₀^1 sin(tx)/x dx (integrand extended by t at x = 0). *Answer:* ∫₀^1 cos(tx) dx = sin t / t for t ≠ 0, and 1 at t = 0.
  - **A2.** Use `thm-leibniz-rule` to differentiate G(t) = ∫₀^t sin(tx) dx; confirm with G(t) = (1 − cos t²)/t. *Answer:* G′(t) = sin t² + ∫₀^t x cos(tx) dx; the two agree (sympy-checked).
  - **B1.** Finish the hook: from F(t) = ∫₀^1 x/(1 + t x²) dx = log(1 + t)/(2t), find ∫₀^1 x³/(1 + x²)² dx. *Answer:* −F′(1) = (log 2)/2 − 1/4.
  - **B2.** In `exm-iterated-integrals-differ` replace (0,2] by (0,a], a > 0. Find both iterated integrals as functions of a. *Answer:* 1/(1 + a) (y first) and −a/(1 + a) (x first, sympy-checked); they differ by 1 for every a.
  - **C1.** Prove `thm-leibniz-rule` by the three-piece route without the multivariable chain rule.
  - **C2 (exit check).** Prove `thm-diff-under-integral` in full, and locate the exact step that fails for `exm-diff-under-integral-fails`. *Marking:* uniform continuity of f_t on a compact set (2), MVT pointwise with θ depending on x (2), estimate independent of x (2), failure located at continuity of f_t at (0,0) with f(t,t) = 1/4 (2).

## 02-improper-parameter-integrals.md — Improper integrals with a parameter (budget ≤ 4,800)

- **Failure first: `exm-nonuniform-improper`** (weird example). F(t) = ∫₀^∞ t e^{−tx} dx equals 1 for every t > 0 and 0 at t = 0. The integrand is continuous on [0,∞) × [0,∞); F is not continuous at 0. The tail ∫_R^∞ t e^{−tx} dx = e^{−tR} is small for each t but not small for all t at once: for every R, t = 1/R gives e^{−1}. Exactly as pointwise limits lose continuity (AN1.9), pointwise convergence of an improper integral is too weak.
- **`def-uniform-convergence-improper`**: f : [a,∞) × T → ℝ with each f(·,t) integrable on every [a,R]. ∫_a^∞ f(x,t) dx **converges uniformly on T** if it converges for each t and sup_{t∈T} |∫_R^∞ f(x,t) dx| → 0 as R → ∞. The same for (a,b] with a singular endpoint (tails ∫_a^{a+η}), and for (a,∞) by splitting at an interior point. Say: this is uniform convergence of F_R(t) = ∫_a^R f(x,t) dx to F as R → ∞.
  - **Scratch Work** (first appearance of uniform tail control): in `exm-nonuniform-improper`, compute the worst t for a given R, and see that restricting to t ≥ t₀ > 0 caps the tail by e^{−t₀R}. That cap, independent of t, is the shape of every uniformity proof below.
- **`thm-uniform-cauchy-improper`**: uniform convergence on T ⇔ for every ε there is R₀ with |∫_R^S f(x,t) dx| < ε for all S > R ≥ R₀ and all t ∈ T. *Sketch:* Cauchy criterion for the uniform limit of F_R (AN1.9 Cauchy criterion, with R → ∞ through reals; say how to reduce to sequences).
- **`thm-m-test-improper`** (Weierstrass test for integrals): |f(x,t)| ≤ M(x) for all t ∈ T, x ≥ a, with ∫_a^∞ M convergent ⇒ uniform (and absolute) convergence on T. One-line proof from the Cauchy criterion.
- **`thm-dirichlet-test-improper`**: suppose (i) |∫_a^R g(x,t) dx| ≤ K for all R ≥ a, t ∈ T; (ii) h(x,t) ≥ 0, h(·,t) is C¹ and non-increasing in x; (iii) sup_t h(x,t) → 0 as x → ∞; g, h continuous. Then ∫_a^∞ g h dx converges uniformly on T.
  - *Proof sketch:* integration by parts on [R,S] with G(x,t) = ∫_a^x g: |∫_R^S g h| ≤ |G h|_R^S + ∫_R^S |G| (−h_x) ≤ 2K h(R,t) + K(h(R,t) − h(S,t)) ≤ 4K sup_t h(R,t). Avoids the second mean-value theorem (Apostol 7.22, not covered in AN2.10).
- **`thm-improper-parameter-continuity`**: f continuous on [a,∞) × [c,d], ∫_a^∞ f converges uniformly on [c,d] ⇒ F continuous on [c,d]. *Sketch:* F_{R_k} continuous (`thm-parameter-continuity`), uniform limit (AN1.9).
- **`thm-improper-diff-under-integral`**: f, f_t continuous on [a,∞) × [c,d]; ∫_a^∞ f(x,t₀) dx converges for one t₀ ∈ [c,d]; ∫_a^∞ f_t(x,t) dx converges uniformly on [c,d]. Then ∫_a^∞ f(x,t) dx converges (uniformly) on [c,d], F is differentiable and F′(t) = ∫_a^∞ f_t(x,t) dx.
  - *Sketch:* F_{R_k}′ = ∫_a^{R_k} f_t (`thm-diff-under-integral`), these converge uniformly; F_{R_k}(t₀) converges; AN1.9's differentiation theorem gives uniform convergence of F_{R_k} and F′ = lim F_{R_k}′. Then pass from R_k to real R (any sequence; limits agree).
  - State the companion for a singular endpoint (needed for Γ at 0).
- **`thm-improper-interchange`**: f continuous on [a,∞) × [c,d], ∫_a^∞ f converges uniformly on [c,d] ⇒ ∫_c^d ∫_a^∞ f dx dt = ∫_a^∞ ∫_c^d f dt dx (the right side converging). *Sketch:* `thm-interchange-order` on [a,R] × [c,d], then R → ∞ using sup_t |∫_R^∞ f| (d − c) → 0.
  - Remark: interchanging two improper integrals needs more (MT; Tonelli). State this without proof as the limit of the chapter's methods.
- **`exm-dirichlet-by-parameter`** (worked example; proves `thm-dirichlet-integral`: ∫₀^∞ sin x / x dx = π/2, the integral converging conditionally, not absolutely).
  - I(t) = ∫₀^∞ e^{−tx} (sin x)/x dx for t ≥ 0 (integrand := 1 at x = 0).

## 03-euler-summation.md — The Euler summation formula (budget ≤ 4,200)

- **Failure first.** The integral test (AN1.8) sandwiches Σ_{n=1}^N 1/n between log(N + 1) and 1 + log N: the error is somewhere in [0, 1], and the test cannot say where. It also cannot say whether H_N − log N converges. Want: an exact identity sum = integral + an explicit, estimable correction.
- **`def-sawtooth`.** P₁(x) = x − ⌊x⌋ − 1/2 ({x} − 1/2), periodic with period 1, mean zero over each period, |P₁| ≤ 1/2; P₂(x) = ({x}² − {x} + 1/6)/2, P₃(x) = ({x}³ − (3/2){x}² + (1/2){x})/6. Facts (each one line): P₂, P₃ continuous and periodic; P₂′ = P₁ and P₃′ = P₂ off the integers; P₂(n) = 1/12, P₃(n) = 0 at integers; −1/24 ≤ P₂ ≤ 1/12; P₂ has mean zero; P₃ > 0 on (0, 1/2), P₃ < 0 on (1/2, 1), P₃(1 − u) = −P₃(u); max |P₃| = √3/216. The motivation sentence: ⌊x⌋ = x − 1/2 − P₁(x) splits the step function into a smooth part, which gives the integral, and a bounded oscillating part, which gives the error. (The name "Bernoulli" is mentioned once; Bernoulli numbers are not developed.)

## 04-gamma-function.md — The Gamma function (budget ≤ 3,400)

- **Hook revisited.** Interpolating n! by "any smooth curve through the points" is easy and useless: infinitely many functions pass through (n, (n−1)!). The integral ∫₀^∞ tⁿ e^{−t} dt = n! (n integrations by parts) suggests a single formula that makes sense for non-integers. Which interpolant is *the* right one is the question §05 answers.
- **`def-gamma-function`**: Γ(x) = ∫₀^∞ t^{x−1} e^{−t} dt for x > 0, where t^{x−1} = e^{(x−1) log t} (AN1.10).
- **`thm-gamma-converges`**: the integral converges (absolutely) iff x > 0; convergence is uniform on every [a,b] ⊂ (0,∞). *Sketch:* split at 1. On (0,1]: t^{x−1} e^{−t} ≤ t^{a−1}, integrable iff a > 0. On [1,∞): t^{x−1} e^{−t} ≤ t^{b−1} e^{−t} ≤ C_b e^{−t/2} (t^{b−1} e^{−t/2} bounded, AN1.10). M-test both ends. Divergence for x ≤ 0 from t^{x−1} e^{−t} ≥ e^{−1} t^{−1} on (0,1].
- **`thm-gamma-functional-equation`**: Γ(x + 1) = x Γ(x) for x > 0; Γ(1) = 1. *Sketch:* integration by parts on [ε, R], boundary terms → 0 by AN1.10 limits.
- **`cor-gamma-factorial`**: Γ(n + 1) = n! for n ∈ ℕ. (Induction; ℕ contains 0, so Γ(1) = 0! = 1.)
- **`thm-gamma-smooth`**: Γ is C^∞ on (0,∞) with Γ^{(k)}(x) = ∫₀^∞ t^{x−1} (log t)^k e^{−t} dt. *Sketch:* the singular-endpoint and infinite-endpoint forms of `thm-improper-diff-under-integral`, with M_k(t) = t^{a−1} |log t|^k on (0,1] and t^{b−1} (log t)^k e^{−t} on [1,∞) for x ∈ [a,b]. Fading support: the reader supplies the integrability of M_k (the "your step" box; answer: t^{a/2} |log t|^k → 0 as t → 0⁺, so M_k ≤ C t^{a/2 − 1}).
- **`thm-gamma-half`**: Γ(1/2) = √π. *Sketch:* substitution t = u² on [ε, R] and `thm-gaussian-integral`.
- **`exm-half-factorial`** (worked example; pays the first hook): (1/2)! := Γ(3/2) = (1/2)Γ(1/2) = √π/2; Γ(7/2) = (15/8)√π; ∫₀^∞ x⁴ e^{−x²} dx = (1/2)Γ(5/2) = 3√π/8 (sympy-checked).
- **Remark (no proof needed beyond the formula).** Γ(x) := Γ(x + n)/(x(x + 1)⋯(x + n − 1)) extends Γ to ℝ ∖ {0, −1, −2, …}; Γ(−1/2) = −2√π. The extension to ℂ and the poles: CA.13 (prose).
- **Quick checks.**
  - (a) Is Γ(x) → ∞ as x → 0⁺? *Answer:* yes, Γ(x) = Γ(x + 1)/x and Γ(x + 1) → Γ(1) = 1 by continuity.

## 05-bohr-mollerup.md — Log-convexity and the characterisation of Γ (budget ≤ 4,400)

- **Failure first: `exm-gamma-impostor`** (weird example). For |c| < 1, c ≠ 0, the function f(x) = Γ(x)(1 + c sin 2πx) is positive, satisfies f(x + 1) = x f(x) and f(1) = 1, and is C^∞. So the functional equation and the initial value do not pin Γ down. What f lacks: log f is not convex. In the text, exhibit one point: for c = 0.1, (log f)″(1.25) ≈ −2.39 < 0 (mpmath-checked; the drafter's sidecar recomputes it). The reason in general: (log f)″ = (log Γ)″ + (log(1 + c sin 2πx))″, the second term reaches −4π²|c|/(1 + |c|) once per period while (log Γ)″(x) → 0; the proof for every c ≠ 0 is §05 C4, which needs C3's series.
- **`def-log-convex`**: f > 0 on an interval with log f convex. One sentence: log-convex ⇒ convex (f = e^{log f}, exp convex and increasing), not conversely: x² on (0,∞) is convex, but log x² = 2 log x is concave.
- **`lem-integral-cauchy-schwarz`**: for w ≥ 0 and u, v with w u², w v² improperly integrable on (α,β) (α, β possibly infinite), w u v is absolutely integrable and (∫ w u v)² ≤ (∫ w u²)(∫ w v²). *Sketch:* 2|uv| ≤ u² + v² for absolute integrability; λ ↦ ∫ w(u + λv)² ≥ 0 is a quadratic with discriminant ≤ 0.
- **`lem-log-convex-integral`**: w ≥ 0 continuous on (α,β), φ continuous; J an open interval; suppose for each compact [p,q] ⊂ J the integrals ∫ w e^{xφ} φ^k dt (k = 0, 1, 2) converge uniformly for x ∈ [p,q], and F(x) = ∫ w e^{xφ} dt > 0. Then F is C² on J and F F″ ≥ (F′)², so log F is convex on J.
  - *Sketch:* `thm-improper-diff-under-integral` twice (both endpoints possibly singular); `lem-integral-cauchy-schwarz` with u = e^{xφ/2}, v = φ e^{xφ/2}; (log F)″ = (F F″ − F′²)/F².
- **`thm-gamma-log-convex`**: Γ is log-convex on (0,∞). *Proof:* `lem-log-convex-integral` with w(t) = e^{−t}/t, φ(t) = log t on (0,∞); the uniformity hypotheses are exactly the dominations of `thm-gamma-smooth`.
- **`thm-bohr-mollerup`**: if f : (0,∞) → (0,∞) satisfies f(x + 1) = x f(x), f(1) = 1, and log f is convex, then f = Γ.
  - **Scratch Work** (first appearance of the slope squeeze): for 0 < x ≤ 1 and n ≥ 1, the slopes of the convex function L = log f over [n, n + 1], [n + 1, n + 1 + x], [n + 1, n + 2] increase; L(n + 1) = log n!, L(n + 2) = log (n + 1)!, and L(n + 1 + x) = L(x) + log(x(x + 1)⋯(x + n)). Write the two inequalities, exponentiate, and see the bounds n! nˣ/(x(x+1)⋯(x+n)) ≤ f(x) ≤ n! (n+1)ˣ/(x(x+1)⋯(x+n)) appear (the right one after cancelling); the ratio of the bounds is ((n + 1)/n)ˣ → 1.
  - *Proof:* as in the Scratch Work, for 0 < x ≤ 1, giving f(x) = lim_n n! nˣ/(x(x + 1)⋯(x + n)), a formula not involving f; extend to all x > 0 by the functional equation. Γ satisfies the hypotheses (`thm-gamma-functional-equation`, `thm-gamma-log-convex`), so f = Γ. *S2a: check the slope inequalities at the endpoint case x = 1 and the exact form of the bounds.*
- **`cor-gauss-product`**: Γ(x) = lim_{n→∞} n! nˣ / (x(x + 1)⋯(x + n)) for every x > 0. (Read off from the proof; the extension from (0,1] to x > 0 is a short computation: the expression for x + 1 equals x times that for x, times n/(x + n + 1) → 1.)

Then f(1) = Γ(1 + y)·(1/y)/Γ(y) = 1; B(x + 1, y) = (x/(x + y)) B(x,y), from two identities: B(x,y) = B(x + 1, y) + B(x, y + 1) (multiply the integrand by t + (1 − t) = 1) and y B(x + 1, y) = x B(x, y + 1) (integration by parts on [ε, 1 − ε], boundary terms → 0); so f(x + 1) = x f(x); log f is convex since log Γ(· + y) is convex and log B(·, y) is convex by `lem-log-convex-integral` (w = (1 − t)^{y−1}/t, φ = log t on (0,1)). ## 06-stirling.md — Stirling's formula (budget ≤ 3,800)

- **Hook paid.** How many digits does 100! have? Answer requires log₁₀ 100! to within its distance from an integer; Stirling with an error bound gives 157.97…, so 158 digits.
- **`thm-log-factorial-expansion`**: there is a constant C such that for every integer n ≥ 1, log n! = (n + 1/2) log n − n + C + r_n with 0 < r_n < 1/(12n).
  - *Sketch:* `cor-euler-summation-integers` with f = log on [1, n]: log n! = n log n − n + 1 + (1/2) log n + ∫₁^n P₁(x)/x dx. The integral converges as n → ∞ (parts with P₂: ∫ P₁/x = [P₂/x] + ∫ P₂/x²). Put C = 1 + ∫₁^∞ P₁/x and r_n = −∫_n^∞ P₁/x. Then r_n = 1/(12n) − ∫_n^∞ P₂/x², and ∫_n^∞ P₂/x² = 2∫_n^∞ P₃/x³ (P₃(n) = 0). Pair u with 1 − u in each period: P₃ is odd about 1/2 and positive on (0,1/2), and 1/x³ is decreasing, so each period contributes > 0; hence r_n < 1/(12n). Also 2∫_n^∞ P₃/x³ ≤ 2(√3/216)/(2n²) < 1/(12n), so r_n > 0.
  - Fading support: the period-pairing step is the reader's ("your step"; answer in solutions).
  - Numerical check in the text: r₁ = 0.0811 < 1/12, r₁₀ = 0.0083306 < 0.0083333 (mpmath).
- **`thm-stirling`**: C = (1/2) log 2π, so n! = √(2πn) (n/e)ⁿ e^{r_n}, 0 < r_n < 1/(12n); in particular n! ~ √(2πn)(n/e)ⁿ.
  - *Sketch:* insert the expansion into the Wallis-type limit of §05 B2 — **B2 is an exercise, so the text proves that limit inline here** (two lines from `cor-gauss-product` and `thm-gamma-half`); the main line must not rest on an exercise. The n log n terms cancel, leaving e^C/√2 = √π.
- **`cor-stirling-gamma`**: Γ(x + 1) ~ √(2πx)(x/e)ˣ as x → ∞ through the reals. *Sketch (slope squeeze again):* for n ≤ x < n + 1, log-convexity of Γ (`thm-gamma-log-convex`) traps log Γ(x + 1) between the chord and tangent-slope bounds built from log n! and log (n + 1)!, and both bounds agree with (x + 1/2) log x − x + (1/2) log 2π up to o(1). Name the move: the same squeeze as `thm-bohr-mollerup`.
- **`exm-digits-100-factorial`** (worked example): log₁₀ 100! = [(100.5) ln 100 − 100 + (1/2) ln 2π + r₁₀₀]/ln 10 with 0 < r₁₀₀ < 1/1200; the value lies in (157.9700, 157.9704), so 100! has 158 digits. Second part: n = 10, Stirling without e^{r_n} gives 3598696 vs 10! = 3628800; with the bound, the interval contains 10!. (Drafter: compute and verify both with a sidecar.)
- **Quick checks.**
  - (a) Does n!/(n/e)ⁿ tend to a limit? *Answer:* no, it grows like √(2πn).
  - (b) Which is larger for large n: n! or (n/2)ⁿ? *Answer:* (n/2)ⁿ, since n!/(n/2)ⁿ ~ √(2πn)(2/e)ⁿ → 0.
- **Exercises.**
  - **A1.** Use Stirling to show (n!)^{1/n}/n → 1/e.
  - **A2.** How many digits has 50!? *Answer:* 65 (log₁₀ 50! = 64.483…, sympy).
  - **B1.** Show C(2n, n) ~ 4ⁿ/√(πn). (Check: ratio 0.99875 at n = 100.)
  - **B2.** Prove `cor-stirling-gamma` in detail.
  - **B3.** Show that the bound r_n < 1/(12n) cannot be improved to r_n < c/n with c < 1/12 for all n. *Answer route:* n r_n → 1/12 (from the P₃ estimate, ∫_n^∞ P₂/x² = O(1/n²)).
  - **C1 (exit check).** Prove `thm-log-factorial-expansion` with the bound 0 < r_n < 1/(12n). *Marking:* Euler summation with correct boundary terms (2), convergence of ∫₁^∞ P₁/x (2), r_n = 1/(12n) − ∫ P₂/x² (2), sign by period pairing (2), positive lower bound (1).
  - **C2.** Prove the weaker bound 0 ≤ r_n ≤ 1/(8n) using only P₂ (−1/24 ≤ P₂ ≤ 1/12), and explain what P₃ adds.
