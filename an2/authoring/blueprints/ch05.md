**Purpose.**
- AN1.3 settled one question: when may the terms of *one* series be reordered? This chapter asks the same question for a grid of numbers, for a product of two series, and for an infinite product, and gets the same answer each time: **absolute convergence makes infinite sums behave like finite ones; without it, the order is part of the data.**
- The tool that carries the whole chapter is the **sum over a countable index set**: for an absolutely summable family, the sum does not depend on the enumeration, and it can be computed **by blocks** (rows, columns, diagonals, hyperbolas mn = k). Tonelli and Fubini for series, the Cauchy product and the Euler product are all instances.
- Infinite products are introduced by the failure of the naive definition; their convergence is reduced to series in three ways (monotone bounds, logarithms, absolute convergence).
- The chapter ends with Euler's product for ζ(s) and the payoff of its hook: **the sum of the reciprocals of the primes diverges**, with an explicit lower bound log log(N+1) − 2.

### 5.1 `01-double-sequences.md` — Double sequences and iterated limits

- **Hook.** Display the grid (§2 of this blueprint) as a 5 × 5 corner with "…". Rows sum to 0; columns sum to 1, 0, 0, …. Two honest ways to add the same numbers give different answers. Before sums, look at limits: a grid of partial sums is a function of two indices, and "let both indices go to infinity" can mean three things.
- **`def-double-sequence`:** a function f : ℕ × ℕ → ℝ, written f(p, q) or f_{p,q}. (Complex values: one-line remark, same definitions with |·|.)
- **Failure first.** Three readings of "lim_{p,q→∞} f(p, q)": (a) first q then p; (b) first p then q; (c) both at once. For **f(p, q) = (p + 1)/(p + q + 2)**: reading (a) gives lim_p 0 = 0; reading (b) gives lim_q 1 = 1; reading (c) cannot give a single value because f(n, n) → 1/2. So we must decide what "the limit" means.
- **`def-double-limit`.** lim_{p,q→∞} f(p, q) = a if for every ε > 0 there is N with |f(p, q) − a| < ε **for all** p ≥ N **and** q ≥ N. Full explain template (STYLE §4): slogan *"every entry far enough out in both directions is close to a"*; symbols; paraphrase; picture: the quarter-plane [N, ∞)² of the grid. Uniqueness of the double limit in one line (as for sequences).
- **`def-iterated-limits`:** lim_p lim_q f(p, q) means: for each p the limit F(p) = lim_q f(p, q) exists, and lim_p F(p) exists. Similarly the other order.
- **`thm-double-to-iterated`** (Apostol 8.39). If lim_{p,q} f(p, q) = a and for each p the row limit F(p) = lim_q f(p, q) exists, then lim_p F(p) = a.
  - **Scratch Work 1 (auxiliary index).** Givens: the double-limit N for ε/2; for each p, an M_p (depending on p) for the row limit with ε/2. Goal: |F(p) − a| < ε for p ≥ N. Gap: F(p) and a are not compared directly; route through one entry f(p, q). Which q? One with q ≥ N (for the first estimate) and q ≥ M_p (for the second). It depends on p — harmless, since q does not appear in the conclusion.
  - **Proof** (typeset, 6–8 lines): as in the scratch work, choosing q = max(N, M_p).
  - Remark: by symmetry, if the column limits exist too, both iterated limits equal a.
- **`exm-double-limits-disagree`** (the section's weird examples, each with a two-line verification):
  - (i) f(p, q) = 1 if p = q, 0 otherwise: both iterated limits are 0; no double limit (f(n, n) = 1 while f(n, n + 1) = 0).
  - (ii) f(p, q) = (−1)^q/(p + 1): double limit 0 (|f| ≤ 1/(p + 1) ≤ 1/(N + 1)); no row has a limit, so lim_p lim_q does not exist; lim_q lim_p f = 0. *The double limit does not give the iterated limits without the row hypothesis.*
  - (iii) the opening f(p, q) = (p + 1)/(p + q + 2): iterated limits 0 and 1.
- **`thm-double-cauchy`** (Cauchy criterion). f has a double limit iff for every ε > 0 there is N with |f(p, q) − f(p′, q′)| < ε whenever p, q, p′, q′ ≥ N. Proof sketch: ⇒ by the triangle inequality; ⇐ the diagonal f(n, n) is Cauchy (AN1.2), so it has a limit a; then |f(p, q) − a| ≤ |f(p, q) − f(n, n)| + |f(n, n) − a| with n ≥ N large.
- **`thm-double-monotone`.** If f is non-decreasing in each variable (p ≤ p′, q ≤ q′ ⇒ f(p, q) ≤ f(p′, q′)) and bounded above, then lim_{p,q} f(p, q) = sup f. Proof sketch: sup approximation gives (p₀, q₀) with f(p₀, q₀) > sup f − ε; every (p, q) with p, q ≥ max(p₀, q₀) has f(p, q) ≥ f(p₀, q₀). (This is what §2 uses for non-negative double series.)
- **Quick checks** (3): QC1 does f(p, q) = 1/(p + 1) + 1/(q + 1) have a double limit? (Yes, 0; N > 2/ε.) QC2 negate `def-double-limit` in symbols. QC3 if f(n, n) → a, must the double limit be a? (No: example (i) has f(n, n) → 1 and no double limit; example (iii) has f(n, n) → 1/2.)
- **Exercises.**
  - **A1.** For f(p, q) = (p − q)/(p + q + 1), find both iterated limits and decide whether the double limit exists. *Answer:* lim_q f = −1 for each p, so lim_p lim_q = −1; lim_p f = 1 for each q, so lim_q lim_p = 1; no double limit (by `thm-double-to-iterated` it would equal both).
  - **A2 (proof comprehension, `thm-double-to-iterated`).** (a) Where is the existence of each row limit used? (b) Why may q depend on p? (c) Run the proof on f(p, q) = 1/(p + 1) + 1/(q + 1) with ε = 1/10: give N, M_p and q. (d) Which step fails for example (ii)? *Answers:* (a) to choose M_p and to have F(p) at all; (b) q is an intermediate object, absent from the conclusion |F(p) − a| < ε; (c) a = 0, F(p) = 1/(p + 1); N = 40 (for p, q ≥ 40, |f| ≤ 2/41 < 1/20 = ε/2), M_p = 20 (|f(p, q) − F(p)| = 1/(q + 1) < 1/20 for q ≥ 20), q = max(N, M_p) = 40; (d) F(p) does not exist, so the second estimate cannot be written.
  - **B1.** Write out the ⇐ half of `thm-double-cauchy` in full.
  - **B2 (prove or disprove).** If both iterated limits exist and are equal, the double limit exists. *Verdict:* false; example (i).
  - **B3.** Prove: if lim_{p,q} f(p, q) = a and lim_{p,q} g(p, q) = b then lim (f + g) = a + b and lim fg = ab. *Answer sketch:* as for sequences; boundedness of f on [N, ∞)² for the product.
  - **C1 (preview of uniform convergence, AN1.9).** Suppose F(p) = lim_q f(p, q) **uniformly in p** (for every ε there is M with |f(p, q) − F(p)| < ε for all p and all q ≥ M) and lim_p F(p) = a. Prove lim_{p,q} f(p, q) = a. *Hint ladder:* (1) compare f(p, q) with F(p); (2) |f(p, q) − a| ≤ |f(p, q) − F(p)| + |F(p) − a|. *Answer:* take N ≥ M and N past the threshold for F(p) → a with ε/2 each. Remark in the solution: this is the converse direction promised for AN1.9.
  - **C2.** Construct f with double limit 0 such that **no** row limit and **no** column limit exists. *Answer:* f(p, q) = (−1)^q/(p + 1) + (−1)^p/(q + 1); |f| ≤ 2/(N + 1) on [N, ∞)²; for fixed p the first term oscillates with amplitude 1/(p + 1) while the second → 0; symmetric for columns.

### 5.2 `02-double-series.md` — Double series and sums over countable sets

- **Opening (failure-motivated).** A double series is a grid of terms a_{m,n}. To add it we must choose an order: by rows, by columns, by squares {0,…,N}², by diagonals m + n = N, or by any enumeration of ℕ × ℕ (F2.3). The hook grid shows rows and columns can disagree. Apostol's choice is rectangles; we take it, and then look for an order-free notion.
- **`def-double-series`.** Given a_{m,n}, the rectangular partial sums s(p, q) = Σ_{m=0}^{p} Σ_{n=0}^{q} a_{m,n}; the double series Σ_{m,n} a_{m,n} converges to S if lim_{p,q} s(p, q) = S (`def-double-limit`). It converges **absolutely** if Σ_{m,n} |a_{m,n}| converges.
- **Non-negative terms.** By `thm-double-monotone`, a non-negative double series converges iff its rectangular sums are bounded, and then its sum is sup_{p,q} s(p, q). Every finite F ⊆ ℕ × ℕ lies in some rectangle, and every rectangle is finite, so **the sum is also the sup of Σ_{(m,n)∈F} a_{m,n} over finite F**. This sup mentions no order at all; it is the definition we want.
- **Recall, AN1.3:** `def-sum-countable` (for a countable S and a : S → ℝ with the finite-set sums of |a| bounded, Σ_{s∈S} a(s) is the sum along any bijection ℕ → S) and `thm-sum-countable-well-defined` (the value does not depend on the bijection). Call such a family **absolutely summable**. AN1.3 met it once; this chapter lives on it.
- **`def-sum-nonnegative`.** For a family (a_i)_{i∈I} over a countable I with every a_i ≥ 0: Σ_{i∈I} a_i := sup{Σ_{i∈F} a_i : F ⊆ I finite} ∈ [0, ∞]. Full explain template: slogan *"a sum over a set, with no order chosen"*; paraphrase; the [0, ∞] convention (∞ is a symbol, not a number; F4.6/AN1.1 conventions). So (a_i) is absolutely summable exactly when Σ_{i∈I} |a_i| < ∞ in this sense.
- **`prp-sum-nonnegative-enumeration`.** If a_i ≥ 0 and φ : ℕ → I is a bijection (I infinite), then Σ_k a_{φ(k)} = Σ_{i∈I} a_i in [0, ∞]; in particular, when the sum is finite it agrees with AN1.3's `def-sum-countable`. Proof sketch: each partial sum is a finite-set sum (≤); every finite F lies in {φ(0), …, φ(n)} for n large (≥).
- **`lem-family-finite-approximation`** (Named move 2). If (a_i) is absolutely summable, then for every ε > 0 there is a finite F₀ ⊆ I such that Σ_{i∈G} |a_i| < ε for every finite G disjoint from F₀, and |Σ_{i∈I} a_i − Σ_{i∈F} a_i| ≤ ε for every finite F ⊇ F₀. Proof sketch: choose F₀ with Σ_{F₀} |a_i| > Σ_I |a_i| − ε (sup approximation); then Σ_G |a_i| ≤ Σ_I |a_i| − Σ_{F₀} |a_i| < ε because G ∪ F₀ is finite; for the second claim, compare with partial sums of an enumeration that eventually contain F.
- **`thm-double-series-absolute`** (Apostol 8.42 (a), (b)). For a double sequence a_{m,n}, the following are equivalent: (i) Σ_{m,n} a_{m,n} converges absolutely; (ii) (a_{m,n}) is absolutely summable over ℕ × ℕ; (iii) for some (equivalently every) bijection g : ℕ → ℕ × ℕ, Σ_k a_{g(k)} converges absolutely. When they hold, the double series converges, and its sum equals Σ_{(m,n)∈ℕ²} a_{m,n} = Σ_k a_{g(k)}; it is also the limit of the square sums s(N, N) and of the diagonal sums Σ_{N′ ≤ N} Σ_{m+n=N′} a_{m,n}. Proof sketch: (i) ⇔ (ii) by the non-negative paragraph; (ii) ⇔ (iii) by `prp-sum-nonnegative-enumeration` and `thm-sum-countable-well-defined`; the sums agree by `lem-family-finite-approximation` applied to rectangles [0, p] × [0, q] ⊇ F₀ (which holds once p, q ≥ N for N past the coordinates of F₀). Squares and diagonal triangles are also eventually ⊇ F₀.
  - **Scratch Work 2 (approximate by a finite set).** Givens: Σ|a| < ∞ over ℕ²; an ε. Goal: |s(p, q) − S| < ε for p, q ≥ N, where S is the family sum. Gap: s(p, q) and S are sums in different senses (a rectangle, an enumeration). Bridge: one finite F₀ carrying all but ε/2 of Σ|a|; any finite set containing F₀ has sum within ε/2 of S (`lem-family-finite-approximation`); a rectangle is a finite set, and it contains F₀ once p, q pass F₀'s largest coordinates. The same paragraph then handles squares, triangles and enumerations, so write it once.
- **`exm-grid-orders`** (worked). a_{m,n} = 2^{−m}3^{−n}: by rows Σ_m 2^{−m}·(3/2) = 3; by diagonals the same; check against s(p, q) = (2 − 2^{−p})(3/2 − (1/2)3^{−q}) → 3.

### 5.3 `03-iterated-series.md` — Iterated series: summing by blocks

- **Lead-in.** In the grid of 2^{−m}3^{−n}, rows, columns and diagonals agreed; in the hook grid, rows and columns did not. The difference is absolute summability. One theorem covers rows, columns, diagonals and every other way of cutting I into pieces.
- **`prp-blocks-nonnegative`.** Let a_i ≥ 0 on I, and I = ⋃_{k∈K} I_k a disjoint union over a countable K. Then Σ_{i∈I} a_i = Σ_{k∈K} (Σ_{i∈I_k} a_i) in [0, ∞] (with the convention that a sum containing ∞ is ∞). Proof sketch: (≤) a finite F ⊆ I meets finitely many blocks, and F ∩ I_k ⊆ I_k is finite; (≥) for finitely many blocks k₁, …, k_r and finite F_j ⊆ I_{k_j}, the union is a finite subset of I; take sups one block at a time (sup of sums = sum of sups for finitely many non-negative sets, AN1.1 `thm-sup-sum`).
- **`thm-summable-blocks` (key proof).** Let (a_i)_{i∈I} be absolutely summable, I = ⋃_{k∈K} I_k disjoint, K countable. Then each (a_i)_{i∈I_k} is absolutely summable, the family (Σ_{i∈I_k} a_i)_{k∈K} is absolutely summable, and Σ_{i∈I} a_i = Σ_{k∈K} Σ_{i∈I_k} a_i.
  - *Try it first (ten minutes): prove it for non-negative terms, where both sides are sups.*

For signed terms, split a_i = a_i⁺ − a_i⁻ with a⁺ = max(a, 0), a⁻ = max(−a, 0); apply `prp-blocks-nonnegative` to each (both totals are ≤ Σ |a_i| < ∞, so no ∞ appears); subtract, using `exr-double-series-b2`.
  - **Proof** (typeset, ~10 lines). The subtraction step is where finiteness is essential: ∞ − ∞ is not defined. Name Named move 3 after the proof.
- **`cor-tonelli-series`.** If a_{m,n} ≥ 0, then Σ_m Σ_n a_{m,n} = Σ_n Σ_m a_{m,n} = Σ_{(m,n)∈ℕ²} a_{m,n} in [0, ∞]. (Blocks = rows, blocks = columns.)
- **`cor-fubini-series`** (Apostol 8.43). If Σ_m (Σ_n |a_{m,n}|) < ∞, then (a_{m,n}) is absolutely summable; every row and every column series converges absolutely; both iterated series converge absolutely; and Σ_m Σ_n a_{m,n} = Σ_n Σ_m a_{m,n} = Σ_{m,n} a_{m,n}. Proof: Tonelli on |a| gives absolute summability; then `thm-summable-blocks` with rows and with columns; the double series by `thm-double-series-absolute`.
- **`cor-diagonal-sums`.** Under absolute summability, Σ_{m,n} a_{m,n} = Σ_{N≥0} Σ_{m+n=N} a_{m,n}. (Blocks = diagonals; used in §4.)
- **`exm-zeta-minus-one`** (worked). Σ_{n≥2} Σ_{m≥2} m^{−n} = 1. Non-negative: swap by Tonelli; Σ_{n≥2} m^{−n} = 1/(m(m − 1)); Σ_{m≥2} 1/(m(m − 1)) = 1 by telescoping. Name the result in words: "the numbers Σ_{m≥2} m^{−n}, n ≥ 2, add up to 1" (ζ is defined only in §6; a one-line forward remark).
- **`exm-swap-for-n-x-to-n`** (worked, Fubini). For |x| < 1, Σ_{n≥1} n xⁿ = x/(1 − x)². Write n xⁿ = Σ_{m=1}^{n} xⁿ, a grid a_{m,n} = xⁿ for 1 ≤ m ≤ n; Σ_m Σ_{n≥m} |x|ⁿ = Σ_m |x|^m/(1 − |x|) < ∞; swap: Σ_m x^m/(1 − x) = x/(1 − x)².

The grid is not a paradox; it is a series that is not absolutely summable, the two-dimensional cousin of the alternating harmonic series rearranged. And Tonelli shows the trouble cannot come from non-negative terms.

### 5.4 `04-multiplying-series.md` — Products of series as sums over grids

Apostol 8.44 and the Dirichlet-product paragraph of 8.24. **Not here:** the Cauchy product, `thm-cauchy-product-absolute`, `thm-mertens`, the divergent Cauchy square and E(x)E(y) = E(x + y) are AN1.3 §06 (`def-cauchy-product`, `thm-cauchy-product-absolute`, `thm-mertens`, `exm-cauchy-geometric`, `thm-exp-series-product`, and its weird-examples row 8). This section cites them and does not re-prove Mertens.

- **Lead-in.** AN1.3 multiplied two series along diagonals, and needed a careful split (its named move "split at N") because one factor could be conditionally convergent. When both factors converge absolutely, §3 makes the product a single sum over the grid ℕ × ℕ, and every way of cutting the grid into blocks gives a product formula: rows (the definition), diagonals (Cauchy), hyperbolas de = n (Dirichlet), and for r factors the grid ℕ^r (needed in §6).
- **`thm-product-of-families`** (Apostol 8.44, family form). If (a_i)_{i∈I}, (b_j)_{j∈J} are absolutely summable with sums A, B, then (a_i b_j)_{(i,j)∈I×J} is absolutely summable with sum AB. Proof sketch: `prp-blocks-nonnegative` on |a_i||b_j| with blocks {i} × J gives Σ_i |a_i|·Σ_j |b_j| < ∞; then `thm-summable-blocks` with the same blocks: Σ_i a_i B = AB.
- **Remark: AN1.3's theorem in two lines.** With I = J = ℕ and diagonal blocks (`cor-diagonal-sums`), `thm-product-of-families` gives `thm-cauchy-product-absolute` again. It does **not** give `thm-mertens`: with one factor conditionally convergent the grid (a_m b_n) is not absolutely summable (`exr-multiplying-series-b2`), and AN1.3's weird-examples row 8 shows that diagonal sums can then diverge. The family method trades generality of the blocks for absolute convergence; Mertens trades the other way.
- **`def-dirichlet-product`.** For sequences (a_n)_{n≥1}, (b_n)_{n≥1}: c_n = Σ_{d|n} a_d b_{n/d} (sum over the positive divisors d of n). Example c_6 written out with our own letters.

### 5.5 `05-infinite-products.md` — Infinite products

- **Opening (failure-motivated definition).** A product u_1 u_2 u_3 ⋯ "should" be the limit of the partial products p_n = u_1 ⋯ u_n. Three failures of that naive definition:
  1. If u_1 = 0, every p_n = 0: the product "converges" whatever the other factors do.
  2. Π_{k≥1}(1 − 1/(k + 1)): p_n = 1/(n + 1) → 0. The factors approach 1, but the product shrinks to nothing; its logarithms Σ log(1 − 1/(k + 1)) = −log(n + 1) diverge. Calling this "convergent with value 0" would break the bridge to series we want.
  3. Removing finitely many factors should not change convergence (as with series); under the naive definition, removing a zero factor can turn a "convergent" product into a divergent one.
  So: zeros are allowed only finitely often, and the limit must be non-zero after them.
- **`def-infinite-product`** (Apostol 8.50, rephrased). Let (u_k)_{k≥1} be real. Π u_k **converges** if only finitely many u_k are 0 and, for some N with u_k ≠ 0 for all k > N, the partial products Π_{k=N+1}^{n} u_k converge to a **non-zero** limit q as n → ∞; its value is u_1 ⋯ u_N · q (independent of N, one line). Otherwise it **diverges**; if the partial products → 0 without it converging, it **diverges to zero**. Full explain template: slogan *"a convergent product has a non-zero tail limit"*; the value is 0 exactly when some factor is 0. Write factors as u_k = 1 + a_k throughout, since the interesting case is a_k → 0.
- **`def-product-converges-absolutely`:** Π(1 + a_k) converges absolutely if Σ |a_k| < ∞ (justified by `thm-product-absolute`).
- **`exm-telescoping-products`** (worked). Π_{k≥2}(1 − 1/k²) = 1/2 (p_n = (n + 1)/(2n)); Π_{k≥1}(1 + 1/k) diverges (p_n = n + 1); Π_{k≥2}(1 − 1/k) diverges to zero (p_n = 1/n).
- **`prp-product-factors-to-one`.** If Π u_k converges, u_k → 1. Proof: in the tail, u_k = p_k/p_{k−1} → q/q. The converse fails (Π(1 + 1/k)).
- **`thm-product-cauchy`** (Apostol 8.51). Π u_k converges iff for every ε > 0 there is N with |u_{m+1} ⋯ u_n − 1| < ε for all n > m ≥ N. Proof sketch: ⇒ with the tail partial products bounded below by some c > 0 (non-zero limit), |p_n/p_m − 1| = |p_n − p_m|/|p_m| ≤ |p_n − p_m|/c; ⇐ with ε = 1/2, the tail products lie in [1/2, 3/2] (so no zero and a bound), then (p_n) is Cauchy, and the limit is ≥ ½|p_N| > 0. Remark: the proof uses only |uv| = |u||v| and the triangle inequality, so it holds for complex u_k (F4.1); CA.7 uses it.
- **Box: what we borrow about exp and log** (from F4.7, cashed in AN1.10): (E-a) exp : ℝ → (0, ∞) is a strictly increasing bijection; (E-b) exp(a + b) = exp a · exp b; (E-c) exp x ≥ 1 + x for every x; log is the inverse of exp. "No other fact about exp or log is used in this chapter; each proof that uses one names it."
- **`lem-exp-log-estimates`.** (a) For |h| < 1, |exp h − 1| ≤ |h|/(1 − |h|). (b) For x > −1, x/(1 + x) ≤ log(1 + x) ≤ x. (c) For |x| ≤ 1/2, |log(1 + x)| ≤ 2|x| and 0 ≤ x − log(1 + x) ≤ 2x². Proof sketch: (a) exp h ≥ 1 + h and exp(−h) ≥ 1 − h give 1 + h ≤ exp h ≤ 1/(1 − h) for h < 1, so exp h − 1 ∈ [h, h/(1 − h)]; (b) the right inequality is (E-c) at log(1 + x); the left is (E-c) at −x/(1 + x): exp(−x/(1 + x)) ≥ 1/(1 + x), so exp(x/(1 + x)) ≤ 1 + x; (c) from (b): |log(1 + x)| ≤ max(|x|, |x|/(1 + x)) ≤ |x|/(1 − |x|) ≤ 2|x|, and x − log(1 + x) ≤ x − x/(1 + x) = x²/(1 + x) ≤ 2x².
- **`cor-exp-log-sequential`.** If x_n → x then exp x_n → exp x; if y_n → y > 0 then log y_n → log y. Proof: exp x_n − exp x = exp x·(exp(x_n − x) − 1) and (a); log y_n − log y = log(1 + (y_n/y − 1)) and (c).
- **`thm-product-nonneg`** (Try it first). Let a_k ≥ 0. Then Π(1 + a_k) converges iff Σ a_k converges.
  - *Try it first (ten minutes): bound Π_{k≤n}(1 + a_k) above and below by expressions in Σ_{k≤n} a_k.*
  - *Idea:* the obstacle a first attempt meets is that logs look necessary; they are not. 1 + Σ_{k≤n} a_k ≤ Π_{k≤n}(1 + a_k) (expand, F4.6; induction) and Π_{k≤n}(1 + a_k) ≤ exp(Σ_{k≤n} a_k) ((E-c), (E-b)). The partial products are non-decreasing and ≥ 1, so they converge (to a limit ≥ 1, non-zero) iff bounded (AN1.2).
- **`thm-product-one-minus`.** Let 0 ≤ a_k < 1. Then Π(1 − a_k) converges iff Σ a_k converges; if Σ a_k = ∞ it diverges to zero. Proof sketch: Π_{k=m+1}^{n}(1 − a_k) ≥ 1 − Σ_{k=m+1}^{n} a_k (induction; `exr-infinite-products-b1`), so choosing m with the tail sum < 1/2 the tail partial products decrease and stay ≥ 1/2: limit ≥ 1/2. Conversely Π(1 − a_k) ≤ exp(−Σ a_k) → 0.
- **`thm-product-log`.** Let a_k > −1 (real). Then Π(1 + a_k) converges iff Σ log(1 + a_k) converges, and then Π(1 + a_k) = exp(Σ log(1 + a_k)).
  - **Scratch Work 3 (take logarithms).** log turns p_n into S_n = Σ_{k≤n} log(1 + a_k) (by (E-b), induction). Goal in each direction: from S_n → L get p_n = exp S_n → exp L ≠ 0; from p_n → p ≠ 0 get S_n = log p_n → log p. Gap: exp and log must respect limits — not in the box. That is exactly `cor-exp-log-sequential`. Also p > 0 is automatic: every p_n > 0, and the limit is non-zero by definition, so ≥ 0 and ≠ 0.
  - **Proof** (typeset, ~8 lines).
- **`thm-product-absolute`.** Let a_k be real with Σ |a_k| < ∞. Then Π(1 + a_k) converges, and every rearrangement of its factors converges to the same value. Proof sketch: a_k → 0, so |a_k| ≤ 1/2 for k > N (no zero factors there); Σ_{k>N} |log(1 + a_k)| ≤ 2 Σ |a_k| (`lem-exp-log-estimates` (c)); `thm-product-log` on the tail; rearrangements: the log series is absolutely convergent, so `thm-rearrangement-absolute` (AN1.3) on it, plus the finitely many head factors. Remark: for complex a_k the same holds, via `thm-product-cauchy` and |Π_{m<k≤n}(1 + a_k) − 1| ≤ Π(1 + |a_k|) − 1 ≤ exp(Σ_{m<k≤n} |a_k|) − 1 (`exr-infinite-products-c2`); CA.7.
- **`exm-products-vs-series`** (weird). Convergence of Σ a_k and of Π(1 + a_k) are independent when the a_k change sign:
  - (i) **Series converges, product diverges.** a_k = (−1)^k/√k, k ≥ 2. Σ a_k converges (alternating). Pair the factors k = 2j, 2j + 1 (j ≥ 1): with x = 1/√(2j), y = 1/√(2j + 1), (1 + x)(1 − y) = 1 − b_j with b_j = xy − (x − y). Here xy ≥ y² = 1/(2j + 1) and x − y = (x² − y²)/(x + y) ≤ 1/(2j(2j + 1)·2y) = 1/(4j√(2j + 1)) ≤ 1/(2(2j + 1)) (since √(2j + 1) ≤ 2j). So 1/(2(2j + 1)) ≤ b_j < 1, Σ b_j = ∞, and the paired product diverges to zero by `thm-product-one-minus`; the unpaired partial products differ by one factor → 1. (Verify the constants in S2a and in a sidecar.)
  - (ii) **Product converges, series diverges.** Factors in pairs (1 + 1/√j)(1 − 1/(√j + 1)) = 1, j ≥ 1 (since 1 − x/(1 + x) = 1/(1 + x) with x = 1/√j). Partial products are 1 or 1 + 1/√j → 1, so the product converges to 1. The series: each pair contributes 1/√j − 1/(√j + 1) = 1/(√j(√j + 1)) ≥ 1/(2j), so it diverges.
  - (iii) factors → 1 is not enough: Π(1 + 1/k), Π(1 − 1/k) (from `exm-telescoping-products`).
- **`## A table of warnings`** (the chapter's weird-examples table, 6 rows; also listed in §6 of this blueprint): example — what it shows — which hypothesis fails.

### 5.6 `06-euler-product.md` — The Euler product and the primes

- **Lead-in.** Back to the index's question. Euler's idea: each prime contributes a geometric series 1 + 1/p + 1/p² + ⋯, and multiplying them should produce every 1/n exactly once, because every n factors into primes in exactly one way. With §4 (finite products of series) and §5 (infinite products) this becomes a proof.
- **`def-zeta`.** For real s > 1, ζ(s) = Σ_{n≥1} n^{−s} (converges, `cor-p-series`; real powers from F4.6). ζ(s) ≥ 1.
- **`def-smooth-numbers`.** For N ≥ 1, S_N = {n ≥ 1 : every prime factor of n is ≤ N} (1 ∈ S_N). {1, …, N} ⊆ S_N (`@fd2:thm-prime-factor` repeatedly: every prime factor of n ≤ N is ≤ N).
- **`thm-euler-product`** (Apostol 8.27; key proof). For s > 1, Π_p (1 − p^{−s})^{−1} converges (p over the primes in increasing order) and equals ζ(s).
  - *Idea* (no Scratch Work; fading of the §4 machinery): for the finitely many primes p_1 < ⋯ < p_r ≤ N, each factor is a geometric series Σ_j p^{−js} (|p^{−s}| < 1); by `prp-finite-product-of-series` their product is the sum of (p_1^{j_1} ⋯ p_r^{j_r})^{−s} over (j_1, …, j_r) ∈ ℕ^r; by unique factorization the map (j_1, …, j_r) ↦ p_1^{j_1} ⋯ p_r^{j_r} is a bijection ℕ^r → S_N, so the product is Σ_{n∈S_N} n^{−s} (a sum over a subset, `exr-double-series-c2`). Then 0 ≤ ζ(s) − Σ_{n∈S_N} n^{−s} = Σ_{n∉S_N} n^{−s} ≤ Σ_{n>N} n^{−s} → 0.
  - **Proof** (typeset, ~14 lines). The limit ζ(s) ≥ 1 is non-zero and no factor is zero, so the product converges in the sense of `def-infinite-product`. Remark: it also converges absolutely, since (1 − p^{−s})^{−1} = 1 + p^{−s}/(1 − p^{−s}) and Σ_p 2p^{−s} < ∞; hence the order of the primes does not matter (`thm-product-absolute`).
  - **Where each hypothesis is used** (one paragraph): s > 0 for each geometric series, s > 1 for ζ(s) and the tail bound; unique factorization for injectivity of the exponent map; existence of factorization for {1, …, N} ⊆ S_N.
- **`lem-harmonic-log`.** H_N = Σ_{n=1}^{N} 1/n ≥ log(N + 1). Proof: log(1 + 1/k) ≤ 1/k (`lem-exp-log-estimates` (b)) and Σ_{k≤N} log((k + 1)/k) = log(N + 1) (telescoping with (E-b)).
- **`prp-smooth-lower-bound`.** For N ≥ 1, Π_{p≤N}(1 − 1/p)^{−1} ≥ H_N. Proof: the same expansion at s = 1 (each geometric series Σ_j p^{−j} converges absolutely); the sum over ℕ^r of 1/(p_1^{j_1} ⋯ p_r^{j_r}) counts every n ∈ S_N **at least once** — existence of factorization suffices — and S_N ⊇ {1, …, N}.
  - Quick check placed here: with unique factorization, what is the left side exactly? (Σ_{n∈S_N} 1/n.)
- **`thm-reciprocal-primes-diverge`** (pays the chapter hook). For N ≥ 2, Σ_{p≤N} 1/p > log log(N + 1) − 2. Hence Σ_p 1/p = ∞.
  - *Idea* (take logs, Idea-level per fading): take log of `prp-smooth-lower-bound`: Σ_{p≤N} −log(1 − 1/p) ≥ log H_N ≥ log log(N + 1) (log increasing, (E-a)). For t = 1/p ≤ 1/2: −log(1 − t) = log(1 + t/(1 − t)) ≤ t/(1 − t) = t + t²/(1 − t) ≤ t + 2t² (`lem-exp-log-estimates` (b)). So Σ_{p≤N} 1/p ≥ log log(N + 1) − 2Σ_{p≤N} 1/p², and Σ_p 1/p² ≤ Σ_{n≥2} 1/n² < Σ_{n≥2} 1/(n(n − 1)) = 1.
  - **Proof** (typeset, ~10 lines).
  - **`## Back to the primes`.** The primes are "more numerous" than the squares in the sense the index asked about: Σ 1/n² < ∞ but Σ 1/p = ∞. Corollary in one line: a new proof that there are infinitely many primes (if finitely many, the left side of `prp-smooth-lower-bound` would be bounded while H_N → ∞). Forward pointers in prose: ζ(s) near s = 1 (AN2.11, Euler summation); ζ(2) = π²/6 (HA, Fourier series); the Euler product for L-functions and primes in progressions (HA.8, side branch); ζ as a complex function (CA).
- **`cor-primes-product-zero`.** Π_p (1 − 1/p) diverges to zero. (`thm-product-one-minus` with a_p = 1/p.)
- **Quick checks** (4): QC1 which n ≤ 12 are not in S_5? (7, 11.) QC2 why is {1, …, N} ⊆ S_N? QC3 in `thm-euler-product`, where is uniqueness of factorization used? QC4 why does the proof of `thm-euler-product` fail at s = 1? (ζ(1) is the harmonic series, which diverges: the partial products → ∞, which is not convergence.)
