## 01-integers-as-classes.md — ℤ as Classes of Pairs

- **Hook (a naive notion that fails).** Try "an integer is a natural number with a sign": then 0 has two names (+0, −0), and addition needs four sign cases with a subtraction in ℕ that only works one way round. Pairs record "a − b" without performing it.
- **`def-integers-as-classes`:** on ℕ × ℕ, (a, b) ~ (c, d) ⟺ a + d = b + c; ℤ ≔ (ℕ × ℕ)/~ (`@def-quotient-set`). Full explain template (major for fd3; slogan: *an integer is a difference you have not computed yet*). Say: an element of ℤ is a **set of pairs**, not a number with a sign (compare fd2's "a pair is not a number", `@def-ordered-pair`).
- **`prp-integer-pairs-equivalence`** (Before reading on): ~ is an equivalence relation (`@def-equivalence-relation`). Reflexive and symmetric by (ℕ1). Transitive: from a + d = b + c and c + f = d + e, add: a + d + c + f = b + c + d + e; cancel c + d (ℕ2) to get a + f = b + e. Warning inside the proof: we may not "subtract d", since ℕ has no subtraction; cancellation is the legal step.
- **`exm-integer-pair-classes`:** list the elements of [(3, 5)], [(0, 0)], [(4, 1)] with first coordinate ≤ 4; draw [(3, 5)] as a diagonal line of lattice points (TikZ: the classes are the diagonals b − a = const of the quarter plane).
- **`prp-integer-normal-form`.** (a) Every class contains exactly one pair of the form (n, 0) or (0, n) with n ∈ ℕ, except that (0, 0) has both forms; precisely, for each (a, b) exactly one of: a = b + k with k ≠ 0, and then [(a, b)] = [(k, 0)]; a = b, and then [(a, b)] = [(0, 0)]; b = a + k with k ≠ 0, and then [(a, b)] = [(0, k)]. (b) [(m, 0)] = [(n, 0)] ⇒ m = n, and [(0, m)] = [(0, n)] ⇒ m = n. (c) (stated after §02, as a remark with its one-line proof) ℤ = ι(ℕ) ∪ {−ι(n) : n ∈ ℕ}, the fd2 definition. Proof of (a): trichotomy and the "m < n iff n = m + k, k ≠ 0" clause of (ℕ3); uniqueness from (b) and (ℕ2).
- **Warning.** "[(a, b)] is positive when a > b" is a statement about **one representative** until it is shown to hold for all of them (it does, by (ℕ4) and (ℕ2); proved in §03). Name the trap now.

## 02-well-defined-operations.md — Well-Definedness, and the Arithmetic of ℤ

- **Hook.** fd2 (`@prp-congruence-arithmetic`, `@exm-ill-defined-class-map`) already met "well defined" for ℤ/n. This section isolates the lemma once, for every quotient in fd3 (ℤ here, ℚ in §04, ℝ in F3.10).
- **`thm-well-defined-on-classes`** (the central lemma). Let ~ be an equivalence relation on X and ≈ one on Y.
  - (a) If f : X → Y satisfies x ~ x′ ⇒ f(x) ≈ f(x′) for all x, x′ ∈ X, then there is **exactly one** function F : X/~ → Y/≈ with F([x]) = [f(x)] for every x ∈ X.
  - (b) If g : X × X → X satisfies, for all x, x′, y, y′ ∈ X, x ~ x′ ⇒ g(x, y) ~ g(x′, y) and y ~ y′ ⇒ g(x, y) ~ g(x, y′), then there is exactly one G : (X/~) × (X/~) → X/~ with G([x], [y]) = [g(x, y)].
  - (c) If S ⊆ X satisfies x ~ x′ and x ∈ S ⇒ x′ ∈ S, then S̄ ≔ {[x] : x ∈ S} satisfies [x] ∈ S̄ ⟺ x ∈ S, for every x ∈ X.
  - Proof of (a): F ≔ {([x], [f(x)]) : x ∈ X} ⊆ (X/~) × (Y/≈); every class is some [x] (`@def-quotient-set`); if ([x], [f(x)]) and ([x′], [f(x′)]) have [x] = [x′], then x ~ x′ (`@thm-classes-partition`), so [f(x)] = [f(x′)]: exactly one output (`@def-function`). Uniqueness: two such functions agree on every [x], hence everywhere (`@prp-function-equality`). (b): x ~ x′ and y ~ y′ give g(x, y) ~ g(x′, y) ~ g(x′, y′), transitivity; then as (a) on X × X. (c): ⇐ is the definition; ⇒: [x] = [x′] with x′ ∈ S gives x ~ x′, and the hypothesis (with symmetry) gives x ∈ S.
  - **Remark (each hypothesis has a job):** without the hypothesis of (c), S = {(a, b) : a > 0} on ℕ × ℕ gives [(0, 0)] = [(1, 1)] ∈ S̄ while (0, 0) ∉ S.
- **`def-integer-operations`:** [(a, b)] + [(c, d)] ≔ [(a + c, b + d)], [(a, b)] · [(c, d)] ≔ [(ac + bd, ad + bc)], −[(a, b)] ≔ [(b, a)]. Motivation line: "(a − b)(c − d) = (ac + bd) − (ad + bc)" as a **heuristic** from school, labelled as such; the definition does not depend on it.
- **`prp-integer-operations-well-defined`** (key proof): the three formulas satisfy the hypotheses of `thm-well-defined-on-classes` (b) (and (a) for −). Addition: one line. **Multiplication in full**, first argument: from a + b′ = a′ + b, multiply by c and by d (ℕ1): ac + b′c = a′c + bc and a′d + bd = ad + b′d; add and rearrange to (ac + bd) + (a′d + b′c) = (ad + bc) + (a′c + b′d), which is (ac + bd, ad + bc) ~ (a′c + b′d, a′d + b′c). Second argument: the formula is symmetric under swapping (a, b) with (c, d) (ℕ1), so the same computation applies. Negation: (b, a) ~ (b′, a′) is the hypothesis read backwards. *Before reading on*: "why may we change one argument at a time?" (answer: lemma (b), transitivity).
- **`exm-ill-defined-first-coordinate`:** "[(a, b)] ↦ a" is not a function ℤ → ℕ: [(0, 2)] = [(1, 3)] has outputs 0 and 1. "[(a, b)] ↦ [(a + 1, b)]" is one (it is x ↦ x + 1). False-conclusion item: a "proof" that [(a, b)] ↦ a is well defined because "each class has a smallest first coordinate" picks a representative but then uses an arbitrary one.
- **`prp-naturals-embed-integers`:** ι : ℕ → ℤ, ι(n) ≔ [(n, 0)], is injective (`prp-integer-normal-form` (b)), ι(m + n) = ι(m) + ι(n), ι(mn) = ι(m)ι(n), ι(0) is the zero of `thm-integers-commutative-ring` and ι(1) its one; and [(a, b)] = ι(a) + (−ι(b)). **Identification remark:** from now on write n for ι(n) and a − b for [(a, b)]; ℕ ⊆ ℤ is a convenient abuse, made honest by ι (one sentence: one could replace ι(ℕ) by ℕ inside ℤ, but nothing needs it). Then `prp-integer-normal-form` (c).
- **Warning.** "[(a, b)] · [(c, d)] ≔ [(ac, bd)], like the sum formula" is **not well defined**: (1, 0) ~ (2, 1), yet with (c, d) = (1, 2) the outputs (1, 0) and (2, 2) are not equivalent. And well defined is necessary, not sufficient: x ∗ y ≔ [(ad + bc, ac + bd)] is well defined (it is −(xy)) but gives (−1) ∗ (−1) = −1.

## 03-ordered-rings.md — ℤ as an Ordered Ring

- **`def-commutative-ring-and-field`:** a **commutative ring** is a set R with + and · satisfying (F1)–(F7) and (F9) of linear algebra's numbering **except** that (F7) here does not require 1 ≠ 0; a **field** is a commutative ring with 1 ≠ 0 satisfying (F8). Write a − b, and a/b ≔ ab⁻¹ in a field. One remark: these are the axioms of linear algebra's field definition (F4.2) and an1's ordered field, in the same numbering (prose pointers; no `@ref` into fd4 or an1).
- **`thm-integers-commutative-ring`:** ℤ with `def-integer-operations` is a commutative ring with 1 ≠ 0. Proof by **a table**: each axiom, the two pairs it compares on representatives, and why they are ~-equal (most are literally equal by (ℕ1)); associativity of · in full in the text (both sides are [(ace + adf + bcf + bde, acf + ade + bce + bdf)]); 1 ≠ 0 by `prp-integer-normal-form` (b). Sidecar checks every row. Name the move **reduce to the level below**.
- **`prp-ring-algebra`:** in a commutative ring R, for a, b ∈ R: (a) 0, 1, −a are unique, −(−a) = a; (b) a · 0 = 0; (c) (−a)b = −(ab), (−a)(−b) = ab; (d) (a + b)² = a² + 2ab + b², with 2 ≔ 1 + 1. Proof by uniqueness ("show it satisfies the defining equation"); (a), (b) in full, (c), (d) briefly.
- **`def-ordered-ring-and-field`:** an **ordered commutative ring** is a commutative ring with a relation < satisfying (O1) trichotomy, (O2) transitivity, (O3) a < b ⇒ a + c < b + c, (O4) 0 < a, 0 < b ⇒ 0 < ab; an **ordered field** is a field that is an ordered commutative ring. Conventions a > b, a ≤ b, positive, negative.
- **`prp-order-from-positives`:** let R be a commutative ring and P ⊆ R with (P1) a, b ∈ P ⇒ a + b ∈ P and ab ∈ P, and (P2) for every a exactly one of a ∈ P, a = 0, −a ∈ P. Define a < b ⟺ b − a ∈ P. Then (R, <) satisfies (O1)–(O4) and P = {a : a > 0}. Conversely, in an ordered commutative ring, P ≔ {a : a > 0} satisfies (P1)–(P2). Proof in full ((O1) from (P2) applied to b − a, with −(b − a) = a − b by `prp-ring-algebra`; (O2) from closure under +; (O3) since (b + c) − (a + c) = b − a; (O4) from closure under ·).
- **`def-integer-order`:** P_ℤ ≔ {[(a, b)] : b < a}, well defined by `thm-well-defined-on-classes` (c): if a + b′ = a′ + b and b < a, then b′ < a′ (write a = b + k, k ≠ 0, cancel b by (ℕ2)). x < y ⟺ y − x ∈ P_ℤ.
- **`thm-integers-ordered-ring`:** ℤ is an ordered commutative ring, and: (a) ι(m) < ι(n) ⟺ m < n; (b) ℕ = {n ∈ ℤ : n ≥ 0} and ℤ_{>0} = {n ∈ ℤ : n > 0} = ℕ ∖ {0}; (c) (**discreteness**) there is no integer k with 0 < k < 1, hence for integers m < n, m + 1 ≤ n. Proof: (P1) for sums: (a + c, b + d) with b + d < a + c by (ℕ4) twice; for products, with a = b + k, c = d + l (k, l ≠ 0): expanding, ac + bd = (ad + bc) + kl, and kl ≠ 0 by (ℕ4), so ad + bc < ac + bd by (ℕ3). (P2) from `prp-integer-normal-form` (a). (a)–(b) from the normal form; (c) a positive integer is ι(k) with k ≠ 0, so k ≥ 1 by (ℕ5).
- **`prp-ordered-ring-rules`:** in an ordered commutative ring R and for a, b, c, d ∈ R: (a) a < b ⟺ b − a > 0 ⟺ −b < −a; (b) a ≤ b and c ≤ d ⇒ a + c ≤ b + d, strict if one hypothesis is; (c) a < b, c > 0 ⇒ ac < bc; (d) a < b, c < 0 ⇒ ac > bc; (e) a ≠ 0 ⇒ a² > 0; if 1 ≠ 0, then 1 > 0; (f) ab = 0 ⇒ a = 0 or b = 0; (g) for a, b ≥ 0: a < b ⟺ a² < b²; (h) if 1 ≠ 0, then n · 1 > 0 for every n ∈ ℕ with n ≥ 1, and m · 1 < n · 1 when m < n. Each by "turn the comparison into one positive element" (`prp-order-from-positives`); (h) by induction on n (F3.1) with n · a defined by (ℕ7). Prove (a), (c), (e), (f), (g) in full; (b), (d), (h) in a few lines each; **none left as an exercise** (F3.9 cites them).
- **`prp-integer-least-element`:** a non-empty S ⊆ ℤ with an integer lower bound b has a least element; with an integer upper bound, a greatest one. Proof: s ↦ s − b maps S into {n ∈ ℤ : n ≥ 0} = ℕ (`thm-integers-ordered-ring` (b)); (ℕ6); shift back. Upper bound: apply to −S.
- **`exm-finite-ring-not-orderable`:** the two-element ring {0, 1} with 1 + 1 = 0 (given by tables, checked against (F1)–(F9)) has no order: (h) would give 2 · 1 > 0 while 2 · 1 = 0. Generally, no commutative ring with 1 ≠ 0 and n · 1 = 0 for some n ≥ 1 is orderable; prose pointer: fd2's ℤ/n (`@prp-congruence-arithmetic`) and F3.5's ℤ/nℤ are such rings. (book.yaml key example.)
- **Warning.** (O4) is about **products of positives**; "a < b and c < d ⇒ ac < bd" is false in ℤ: −3 < −1 and −3 < −1, yet 9 > 1.

## 04-rationals-as-classes.md — ℚ as Classes of Fractions

## 05-ordered-field-of-rationals.md — ℚ as an Ordered Field; the Archimedean Property

- **`def-rational-order`:** P_ℚ ≔ {[(p, q)] : p > 0}; well defined by `thm-well-defined-on-classes` (c) because q > 0.
- **`thm-rationals-ordered-field`** (key proof; Before reading on: "where is q > 0 used?"). ℚ with `def-rational-order` is an ordered field (`def-ordered-ring-and-field`); moreover p/q < r/s ⟺ ps < rq for q, s ∈ ℤ_{>0}, and j(m) < j(n) ⟺ m < n. Proof via `prp-order-from-positives`:
  - P_ℚ well defined: if pq′ = p′q, q, q′ > 0 and p > 0, then p′q = pq′ > 0, so p′ > 0 (p′ ≤ 0 would give p′q ≤ 0 by `prp-ordered-ring-rules` (c)).
  - (P1): [(p, q)] + [(r, s)] = [(ps + rq, qs)] with ps + rq > 0 (products and sums of positives in ℤ); product [(pr, qs)], pr > 0.
  - (P2): p > 0, p = 0 or −p > 0, exactly one (trichotomy in ℤ); and [(p, q)] = 0 ⟺ p = 0.
  - The comparison formula: r/s − p/q = [(rq − ps, qs)], positive iff rq − ps > 0.
- **`prp-reciprocal-order`:** in an ordered field, a > 0 ⇒ a⁻¹ > 0, and 0 < a < b ⇒ 0 < 1/b < 1/a. (Proof from `prp-ordered-ring-rules` (c), (e).)
- **Midpoints, briefly** (no label): for rationals a < b, a < (a + b)/2 < b; so there is no least positive rational (x/2 < x). Warning: density is not "next to".
- **`thm-rationals-archimedean`** (Try it first): for every x ∈ ℚ there is n ∈ ℕ with x < n. Proof: x = p/q, q ∈ ℤ_{>0}. If p ≤ 0, then x ≤ 0 < 1. If p > 0, then p ∈ ℕ, q ≥ 1 (discreteness), so p ≤ pq, i.e. p/q ≤ p (comparison formula), and p < p + 1 ∈ ℕ. **No supremum and no completeness is used**: say so; this is the point of contrast with an1 and with ℝ(x) (prose only).
- **`cor-rationals-archimedean-epsilon`:** for every ε ∈ ℚ_{>0} there is n ∈ ℤ_{>0} with 1/n < ε; every m ≥ n then works too. Proof: n > 1/ε by the theorem, then `prp-reciprocal-order`. Quantifier order shown in symbols: n depends on ε (fd1's `@prp-quantifier-negation` for the swapped version's negation is the A item). This is the form F3.9 uses with **rational ε**.
- **`prp-rational-integer-part`:** for every x ∈ ℚ there is exactly one m ∈ ℤ with m ≤ x < m + 1; write ⌊x⌋. Proof: S ≔ {k ∈ ℤ : x < k} is non-empty (theorem) and has an integer lower bound −n with n > −x (theorem applied to −x; then every k ∈ S has k > x > −n); its least element is m + 1 (`prp-integer-least-element`), and m ∉ S gives m ≤ x. Uniqueness by discreteness. (F3.5 revisits it as division with remainder: ⌊p/q⌋ is the quotient.)

## 06-gaps-in-the-rationals.md — The Gaps in ℚ

- **Hook.** ℚ is an ordered field, Archimedean, and dense in itself. Is anything missing? The diagonal of the unit square.
- **`thm-no-rational-square-two`:** there is no x ∈ ℚ with x² = 2. **Descent proof** (proof ordering item; differs from fd1's parity proof, which used school facts about ℚ). Suppose x² = 2; x ≠ 0, and (−x)² = x², so take x > 0, x = p/q with p, q ∈ ℤ_{>0}; then p² = 2q² in ℤ (`prp-integers-embed-rationals` (b)). Let q be least in D ≔ {q ∈ ℤ_{>0} : p² = 2q² for some p ∈ ℤ_{>0}} (`prp-integer-least-element`). Then q < p (else q² ≥ p² = 2q², so q² ≤ 0) and p < 2q (else p² ≥ 4q² > 2q²), by `prp-ordered-ring-rules` (g). Put p′ ≔ 2q − p and q′ ≔ p − q, both in ℤ_{>0}, q′ < q, and p′² − 2q′² = 2q² − p² = 0 (`prp-ring-algebra` (d)). So q′ ∈ D, contradicting minimality. Remark: this is ¬I on "x² = 2" (`@def-rules-negation`), with no RAA (`@def-rule-raa`). Prose comparison: fd1's `@thm-sqrt2-irrational` proves the same statement about the school ℚ by parity; here we have no parity yet (F3.5).
- **`thm-rationals-gap-sqrt2`** (key proof; Try it first): let A ≔ {x ∈ ℚ : x² < 2}. Then A is non-empty and bounded above in (ℚ, ≤), but has no supremum in ℚ (`@def-order-bounds`, `@def-order-supremum`).
  - Bounded: 2 is an upper bound (x ≥ 2 > 0 gives x² ≥ 4).
  - Two maps, for rational s > 0: t(s) ≔ (s² + 2)/(2s) and u(s) ≔ 4s/(s² + 2) = 2/t(s). Identities (sidecar): t(s)² − 2 = (s² − 2)²/(4s²); s − t(s) = (s² − 2)/(2s); u(s) − s = s(2 − s²)/(s² + 2); 2 − u(s)² = 2(s² − 2)²/(s² + 2)².
  - Suppose s = sup A in ℚ. Then s ≥ 1 > 0 (1 ∈ A), and s² ≠ 2 (`thm-no-rational-square-two`). If s² < 2: u(s) ∈ A and u(s) > s, so s is not an upper bound. If s² > 2: t(s) < s, and t(s) is an upper bound (t(s) > 0 and t(s)² > 2; for x ∈ A, x > t(s) would give x² > t(s)² > 2 by `prp-ordered-ring-rules` (g)), so s is not the least. Contradiction either way (trichotomy).
