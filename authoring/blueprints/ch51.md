## Planned sections

1. Functions of bounded variation: total variation, Jordan decomposition into increasing functions; rectifiable curves
2. Monotone functions are differentiable a.e.: Dini derivatives and the Vitali covering theorem (Riesz's rising-sun lemma as an alternative); ∫ₐᵇ f' ≤ f(b) − f(a)
3. The Cantor–Lebesgue function and strictly increasing singular functions; jump functions are differentiable a.e. with derivative 0
4. Absolutely continuous functions; the fundamental theorem of calculus for the Lebesgue integral, both directions
5. Decomposition of a BV function: absolutely continuous + jump + singular continuous
6. Integration by parts and substitution for AC functions; arc length of a rectifiable curve is ∫|γ'| iff γ is AC
7. (Optional) The isoperimetric inequality for rectifiable curves, returning to Part III's Hurwitz proof

## Must prove

- Jordan decomposition of BV functions
- monotone functions are differentiable a.e. and ∫f' ≤ f(b)−f(a)
- BV ⇒ differentiable a.e.
- F(x) = ∫ₐˣ f is AC and F' = f a.e.
- f AC ⇒ f' ∈ L¹ and f(x) − f(a) = ∫ₐˣ f'
- AC with f' = 0 a.e. ⇒ constant
- decomposition BV = AC + jump + singular
- L(γ) = ∫|γ'| for AC curves

## Key examples and counterexamples

- Cantor–Lebesgue function
- a strictly increasing function with f' = 0 a.e.
- x² sin(1/x²) differentiable but not BV
- √x AC on [0,1] but not Lipschitz
- a jump function with jumps at the rationals
