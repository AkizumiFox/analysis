## Planned sections

3. Why each hypothesis is needed: d(Tx,Ty) < d(x,y) without a uniform constant; incomplete spaces
4. Warm-up applications: equations in ℝⁿ, Fredholm integral equations with small kernel, Volterra equations for every λ (iterates or weighted sup norm)
5. Picard–Lindelöf for systems in ℝⁿ with a locally Lipschitz right side; higher-order equations as systems; Picard iterates of y' = y rebuild the exponential series

## Must prove

- Banach's contraction mapping theorem with error bound d(xₙ,x*) ≤ qⁿ/(1−q)·d(x₁,x₀)
- if some iterate Tᵐ is a contraction, T has a unique fixed point
- equivalence of the IVP and the integral equation for continuous f
- Picard–Lindelöf (local existence and uniqueness, Lipschitz in y)
- Gronwall's inequality
- continuous dependence on initial data
- existence of a maximal solution; if the maximal interval ends at T<∞ the solution leaves every compact set

## Key examples and counterexamples

- y' = y^{1/3}, y(0)=0: infinitely many solutions
- y' = y², y(0)=1: blow-up at t=1
- T(x) = x + 1/x on [1,∞): d(Tx,Ty) < d(x,y) and no fixed point
- Volterra equation solved for all λ via Tᵐ
- cos x = x solved by iteration with an explicit error bound
