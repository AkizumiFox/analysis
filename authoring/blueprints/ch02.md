## Planned sections

1. ∀-introduction and elimination: 'let x be arbitrary' and the eigenvariable condition; ∃-introduction and elimination: 'choose x with …' and the fresh-name condition
2. Nested quantifiers: order matters (∀x∃y vs ∃y∀x), negating by pushing ¬ inward, formalizing statements with three nested quantifiers from analysis; existence and uniqueness
3. Equality: reflexivity and substitution; calculation chains; the complete rule / phrase / Lean table (use, obtain, intro x, specialize, rw, calc)
4. Worked example: 'uniformly continuous ⇒ continuous' annotated rule by rule; the converse fails because the ∃I witness δ would depend on an x introduced later
5. The 'what is not allowed' catalogue: one instance for ∀; δ depending on x; the ∃E name treated as arbitrary; proving the converse; a missing case; circularity; using an assumption after its box closes
6. Reading and writing proofs: annotate informal proofs with rules, turn a rule skeleton into prose, and find the error in student proofs
7. The dispute over excluded middle: LEM ≡ DNE ≡ RAA as one extra rule; ¬¬(P∨¬P) is intuitionistically provable; BHK reading; aᵇ rational with a, b irrational, with and without a witness
8. …continued: Brouwer 1908, Hilbert 1927 and the Grundlagenstreit, Heyting 1930, Gödel–Gentzen translation, Bishop 1967; consequences for analysis (located sup, Specker sequence, approximate IVT, the non-constructive step in Bolzano–Weierstrass); Curry–Howard, Lean's Classical.em via Diaconescu and `noncomputable`; the main line stays classical

## Must prove

- quantifier negation laws ¬∀x P ↔ ∃x ¬P and ¬∃x P ↔ ∀x ¬P, flagging that ¬∀ ⊢ ∃¬ needs RAA
- ∃y∀x R(x,y) ⊢ ∀x∃y R(x,y), and a counterexample to the converse
- √2 is irrational (an instance of ¬I, valid intuitionistically)
- if |a − b| < ε for every ε > 0 then a = b
- uniformly continuous ⇒ continuous, annotated with every rule
- LEM, double-negation elimination and RAA are interderivable over the intuitionistic rules
- ⊢ ¬¬(P ∨ ¬P) without LEM
- there are irrational a, b with aᵇ rational: non-constructively via √2^√2, and with a witness √2^(log₂9) = 3

## Key examples and counterexamples

- ∀x∃y (x + y = 0) true on ℝ, ∃y∀x (x + y = 0) false
- f(x) = x² on ℝ (or 1/x on (0,1)) is continuous but not uniformly continuous: the δ must depend on x
- a 'proof' that checks n = 1, 2, 3 and concludes ∀n
- the ∃E name reused as if arbitrary

## Exit checks (C-exercises)

- Negate 'f is uniformly continuous on A' and 'fₙ → f uniformly on A'
- Judge four student proofs and locate the error in each, naming the rule each one breaks (Selden & Selden style)
- Formalize and negate a three-quantifier statement, then prove or refute it
